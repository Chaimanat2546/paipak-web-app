# UXD-002 — Interaction Specification

วันที่: 2 พฤศจิกายน 2026 · Asia/Bangkok · รุ่น: review-4 · สถานะ: รอภูตรวจรับ

เอกสารนี้ระบุ trigger, เงื่อนไข, การเปลี่ยนสถานะ, navigation และการคืน focus สำหรับ [wireframe](annotations.md) ไม่ใช่ข้อความที่นำไปแสดงบนหน้าเว็บ กฎผลิตภัณฑ์อ้าง [UX Requirements](ux-requirements.md) และ [UXD-001 review-2](../../../tasks/design/UXD-001.md#owner-acceptance) โดยไม่เปลี่ยนข้อสรุปที่อนุมัติแล้ว

## Navigation — เพิ่มตามคำสั่งและคำตอบล่าสุดของภู

| รหัส | Trigger | เงื่อนไข/พฤติกรรม | ปลายทาง/ข้อจำกัด |
|---|---|---|---|
| I-19 | เปิด/ปิดเมนู Mobile | ปุ่มเมนูเปิดแผง WF-01N; ปุ่มปิด/Back/Escape ปิดและคืน focus จุดเปิด แผงยาวเลื่อนได้ ไม่บังรายการท้าย | คงหน้าต้นทาง; เป็น navigation panel ไม่ใช่หน้าธุรกิจเพิ่ม |
| I-20 | ไทย / English | ไทยเป็นค่าที่แสดงในแบบ ตัวเลือก English เป็นทางเลือกภาษา ไม่เปลี่ยนสกุลเงินโดยอัตโนมัติ | วิธีเปลี่ยน locale, URL, คำแปลและ fallback ยังไม่กำหนดในงานนี้; ไม่ใช้การเปลี่ยนภาษากู้ Booking Intent หลัง reload ตาม Q-03 |
| I-21 | LINE OA / โทร | เปิดช่องทางทางการหรือคำสั่งโทรเมื่อได้รับ URL/เบอร์ที่ยืนยันแล้ว ไม่ใช้ข้อมูลเว็บอ้างอิงแทน | ปลายทางจริงยังรอข้อมูล; ข้อความข้างโลโก้เป็นข้อความแสดงผล ไม่มีปุ่มโอนเงินหรือธุรกรรมที่เพิ่มจากการแก้ Header |
| I-22 | Logo / หน้าแรก / ค้นหาที่พัก/จอง / บทความ / เข้าสู่ระบบ | Logo และหน้าแรกไป WF-01; ค้นหาที่พัก/จองไป WF-02 โดยไม่บังคับวันหรือ login; บทความไปหน้ารายการบทความใน supporting inventory; Guest เข้าสู่ระบบเปิด WF-05 Login ก่อน แล้วสลับไป WF-05R ได้ | หน้าบทความและ route จริงยังไม่ออกแบบ/implement; Member คงทางเข้าบัญชี WF-09 และเมนูการจอง/ที่พักโปรดเดิม ไม่เปลี่ยน login-only Favorites หรือ Auth return rules |

ข้อสรุปเริ่ม Login ก่อนมาจากคำตอบล่าสุดของภู ซึ่งแทนข้อความก่อนหน้าที่ระบุให้เปิด Register ก่อน การเพิ่มตัวเลือกภาษาและบทความใน Header เป็นขอบเขต wireframe/navigation ไม่ใช่การอนุมัติโค้ด ระบบแปลภาษา หรือ task หน้าบทความ

## ข้อจำกัดและสถานะการยืนยัน

- Q-01 ถึง Q-05 และกฎใน UXD-001 review-2 ได้รับอนุมัติแล้ว การรวบรวมในตารางนี้ไม่เปลี่ยนความหมาย
- การทิ้ง draft filters เมื่อปิดโดยไม่ Apply และ feedback/undo ของ Favorites เป็นข้อเสนอ UXD-002 ที่ยังรอตรวจรับ ไม่ยกระดับเป็นกฎธุรกิจที่อนุมัติแล้ว
- Carousel ในภาพใช้ข้อมูลตัวอย่าง 5 ภาพ จึงมี 5 จุด จำนวนจุดจริงอิงจำนวนภาพ ไม่กำหนดว่าทุกที่พักต้องมี 5 ภาพ ส่วน loop, autoplay, การแสดง controls เมื่อมีภาพเดียว และ fallback เมื่อภาพโหลดไม่ได้ยังไม่ได้ตัดสินใจ ไม่อนุมานการทำงานจากภาพนิ่ง
- ขนาดพื้นที่กด, focus style, motion, breakpoint และกลไกจริงยังต้องออกแบบ/ทดสอบใน task ที่เกี่ยวข้อง
- Wireframe เป็นภาพนิ่ง ตารางนี้เป็น specification ไม่ใช่ผลทดสอบว่าปุ่ม การคืน focus หรือ navigation ทำงานจริงแล้ว
- ยังไม่กำหนด payment endpoints, hold TTL, inventory locking, catalog authority หรือวิธีเก็บสถานะในงานนี้
