## Mapping to papaipak for the next wireframe revision

### Follow-up: actual Reserve flow inspection

หลังเจ้าของทักว่าได้ดู flow จริงหรือไม่ จึงตรวจขั้นหลัง Reserve เพิ่มใน remote browser ที่ viewport 390×844 โดยไม่ใช้บัญชีสมาชิกหรือกรอกข้อมูลส่วนตัว:

1. ตรวจว่า Reserve เป็น `type=button` และไม่ได้อยู่ใน form จากนั้นเปิดขั้นนำทางของปุ่ม
2. ปุ่มพาไป `/book/stays/…` หัวข้อ **Review and continue — Step 1 of 2** ไม่ใช่ยืนยันการจองสำเร็จทันที
3. หน้านี้แสดงที่พัก วันและปุ่มแก้ จำนวนผู้เข้าพักและปุ่มแก้ ยอดรวม/รายละเอียดราคา นโยบาย และกลุ่มเลือกเวลาชำระเงิน ตามข้อมูลของ listing ณ เวลาตรวจ
4. ปุ่มแก้ผู้เข้าพักเปิด dialog มี Cancel/Save ตรวจเฉพาะการเปิดและยกเลิก ไม่เปลี่ยนจำนวนหรือรับกฎความจุ/ผู้ใหญ่/เด็กของ Airbnb เป็นกฎ papaipak
5. ปุ่ม Next เป็น `type=button` และไม่ได้อยู่ใน form; เมื่อกดในสถานะ Guest พบ dialog **Log in or sign up** บนหน้าตรวจรายการเดิม
6. หยุดที่ dialog Auth ไม่กรอกข้อมูล ไม่กด Continue ที่เป็น submit ไม่เข้าสู่ระบบ ไม่เลือก/ส่งข้อมูลวิธีชำระเงิน และไม่ยืนยัน booking/payment

ดังนั้นลำดับที่ตรวจได้จริงสำหรับ URL ซึ่งมีวันแล้วคือ `Detail → Reserve → Review and continue → Next → Auth` ส่วนหลัง Auth ยังไม่ได้ตรวจ ข้อความ “ไม่กด Reserve/ไม่ตรวจ checkout” ในบันทึกรอบแรกด้านบนเป็นขอบเขตรอบแรกเท่านั้น ไม่ใช่ขอบเขตของ follow-up นี้

ข้อกำหนด papaipak ที่ให้ login ก่อน Checkout และคำตอบ Q-11 เรื่อง dialog สรุปก่อนชำระเงินยังไม่ถูกยกเลิกโดยอัตโนมัติจากการตรวจ reference ต้องแยก observed Airbnb flow ออกจากการเปลี่ยนข้อกำหนด papaipak ที่เจ้าของยืนยันไว้ ไม่คัดลอกตำแหน่ง Auth หรือบริการผ่อนชำระของ Airbnb โดยเงียบ ๆ

- ปุ่มจองหลักแยกจากพื้นที่ดูราคา/แก้วันในแถบ Mobile
- เมื่อมีวันแล้ว การแก้วันใช้ date editor เกือบเต็มจอพร้อมบันทึก ตาม reference ที่ตรวจได้; ไม่ยึดแผงเตี้ยที่รวมวัน/จำนวนทั้งหมดจากตัวอย่างก่อนหน้าเป็นแบบอนุมัติ
- คนรวมหนึ่งค่าและสัตว์เลี้ยงแยกตาม UXD-001 ห้ามนำการแยกผู้ใหญ่/เด็ก/ทารกของ reference มาแทน
- คง login gate, ขอบเขต Booking Intent, การตรวจราคา/วันว่าง และการแยก booking/payment states ตามข้อกำหนดเดิม
- Q-11 เป็นขั้นยืนยันของ papaipak ที่เจ้าของเลือกไว้ ไม่อ้างว่าได้ตรวจพบขั้นนี้จาก checkout ของ Airbnb
