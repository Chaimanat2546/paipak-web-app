# UXD-002 — Interaction Specification

วันที่: 3 พฤศจิกายน 2026 · Asia/Bangkok · รุ่น: review-5 · สถานะ: รอตรวจรับภาพและสเปก

คำตอบเจ้าของ Q-01–Q-12 และ F-01 อ้าง [review-decisions](review-decisions.md) / หน้าจอและ Component IDs อ้าง [review-5 inventory](review-5/component-inventory.md) รุ่นก่อนเก็บใน [review-4 specification](rebuilt-1/interaction-specification-review-4.md)

เอกสารนี้ระบุ trigger, เงื่อนไข, การเปลี่ยนสถานะ, navigation และการคืน focus สำหรับ [wireframe](annotations.md) ไม่ใช่ข้อความที่นำไปแสดงบนหน้าเว็บ กฎผลิตภัณฑ์อ้าง [UX Requirements](ux-requirements.md) และ [UXD-001 review-2](../../../tasks/design/UXD-001.md#owner-acceptance) โดยไม่เปลี่ยนข้อสรุปที่อนุมัติแล้ว

## ข้อจำกัดและสถานะการยืนยัน — review-5

- Q-01 ถึง Q-05 และกฎใน UXD-001 review-2 ได้รับอนุมัติแล้ว การรวบรวมในตารางนี้ไม่เปลี่ยนความหมาย
- Q-01 ถึง Q-12 ของรอบ UXD-002 และ F-01 ยืนยันรายละเอียดแล้วตาม review-decisions โดยไม่แทนการอนุมัติแบบสุดท้าย; Filter close ทิ้ง draft และ Favorites ไม่มี Undo ตามคำตอบล่าสุด
- จำนวนจุดอิงภาพจริง ไม่บังคับทุกที่พัก 5 ภาพ; loop/autoplay/single/error ตัดสินใจตาม I-04/I-26 แล้ว ส่วน first-photo symmetry เป็น D-01 รอตรวจแบบ
- [Component inventory](review-5/component-inventory.md) แยก designer proposals D-01 ถึง D-06 และ domain deferrals ไม่ซ่อนสมมติฐานในภาพ
- ขนาดพื้นที่กด, focus style, motion, breakpoint และกลไกจริงยังต้องออกแบบ/ทดสอบใน task ที่เกี่ยวข้อง
- Wireframe เป็นภาพนิ่ง ตารางนี้เป็น specification ไม่ใช่ผลทดสอบว่าปุ่ม การคืน focus หรือ navigation ทำงานจริงแล้ว
- ยังไม่กำหนด payment endpoints, hold TTL, inventory locking, catalog authority หรือวิธีเก็บสถานะในงานนี้
