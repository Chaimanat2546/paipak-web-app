# UID-006 · สเปกการใช้งานหน้ารายการโปรด G4-r1

สเปกประกอบ [แบบอ้างอิง G4-r1 ที่ภูอนุมัติ](README.md) · เฉพาะหน้ารายการโปรดของลูกค้า

## ทางเข้าและการเข้าสู่ระบบ

| จุดเริ่มต้น | เมื่อยังไม่ได้เข้าสู่ระบบ | เมื่อเข้าสู่ระบบสำเร็จหรือมีบัญชีที่เข้าใช้อยู่ |
| --- | --- | --- |
| แถบนำทางเดสก์ท็อปหรือเมนู ☰ บนมือถือ | เลือก **รายการโปรด** แล้วเปิดแบบเข้าสู่ระบบเดิมทันที ถ้าปิดให้กลับหน้าที่กดมา | เปิดรายการโปรดของบัญชี |
| ลิงก์ตรงมายังหน้ารายการโปรด | แสดง **เข้าสู่ระบบเพื่อดูรายการโปรด** และปุ่ม **เข้าสู่ระบบ** กดแล้วเปิดแบบเข้าสู่ระบบเดิม ถ้าปิดให้กลับมาที่หน้านี้ | เปิดรายการโปรดของบัญชี |

บัญชีสมาชิกเป็นผู้ดูและจัดการรายการตามข้อสรุป Q-01 ลิงก์ **รายการโปรด** อยู่ถัดจาก **บทความ** ในแถบนำทางเดสก์ท็อปและเมนูมือถือ เดสก์ท็อปใช้ตัวหนากับชื่อหน้าปัจจุบัน เมื่ออยู่หน้ารายการโปรด ลิงก์ **ค้นหาที่พัก** และ **บทความ** ใช้น้ำหนักปกติ [ข้อสรุป Q-01](../../approved-ux-ui-scope.md) · [แบบเข้าสู่ระบบเดิม](../../dsd-001/home-auth-g4-r1/README.md)

## รายการและสถานะ

| สถานะ | สิ่งที่แสดงและทำต่อได้ |
| --- | --- |
| รอโหลด | ใช้โครงโหลดการ์ดร่วมและข้อความกำลังโหลด จนทราบผลจริง |
| มีรายการ | แสดงจำนวนที่พักที่บันทึกและการ์ด กดการ์ดเพื่อเปิดรายละเอียด เมื่อย้อนจากรายละเอียดให้กลับรายการโปรด |
| นำที่พักออก | กดหัวใจสีชมพูเพื่อนำที่พักออก เมื่อระบบยืนยันผลสำเร็จให้อัปเดตการ์ดและจำนวนพร้อมกัน เอาหลังสุดท้ายออกแล้วเข้าสถานะรายการว่าง |
| รายการว่าง | แสดง **ยังไม่มีรายการโปรด** และปุ่ม **ค้นหาที่พัก** |
| โหลดรายการไม่สำเร็จ | แสดงข้อผิดพลาดและปุ่ม **ลองอีกครั้ง** ใช้ผลของการโหลดรอบใหม่เลือกสถานะที่จะแสดง |

ปุ่มหัวใจและปุ่มเปลี่ยนภาพแยกจากทางเปิดรายละเอียด ชื่อที่โปรแกรมอ่านหน้าจอใช้กับปุ่มหัวใจระบุชื่อที่พักที่นำออก วงโฟกัสใช้ตัวอย่างที่ตรวจบนภาพ ข้อเสนอการคืนโฟกัสหลังนำออกคือเลือกปุ่มหัวใจของการ์ดถัดไป หรือการ์ดก่อนหน้าหากไม่มีถัดไป เมื่อรายการว่างให้ไปที่ **ค้นหาที่พัก** [ภาพตรวจการ์ด](../g3-r1-review/jDp6v.png)

## ภาพอ้างอิงและส่วนประกอบ

| ส่วน | ค่าและที่มาของแบบ |
| --- | --- |
| กริดเดสก์ท็อป 1440 | ขอบ 60 พิกเซล การ์ดกว้าง 312 พิกเซล 4 ใบต่อแถว ช่องระหว่างการ์ด 24 พิกเซล |
| รายการมือถือ 390 | ขอบ 24 พิกเซล คอลัมน์เดียว การ์ดกว้าง 342 พิกเซล ช่องระหว่างการ์ด 20 พิกเซล |
| การ์ดที่พัก | ใช้ `V0hJN` และโครงโหลด `cDP8I` ชื่อยาวตัดด้วยจุดไข่ปลาตามพื้นที่และใช้ชื่อเต็มในการเข้าถึง ซ่อนชุดห้องน้ำเมื่อข้อมูลขาดหรือเป็นศูนย์ |
| รูปที่พัก | ใช้สัดส่วนประมาณ 3 ต่อ 2 ตามการ์ดร่วม มือถือแสดงปุ่มเปลี่ยนรูป เมื่อมีรูปเดียวให้ซ่อนลูกศรและจุด รูปสุดท้ายไปต่อไม่ได้ |
| ปุ่มหลักและสถานะบันทึก | ใช้ปุ่ม `OYERv` สีพื้น `#C5375B` และตัวอักษรขาว หัวใจบันทึกแล้วใช้ `#FD6E88` ขนาด 22 พิกเซลบนพื้นที่กด 44 × 44 พิกเซล |
| ส่วนหัวและท้ายหน้า | ใช้ Header และ Footer r1 ร่วมกัน ปุ่มบัญชีสมาชิกในภาพระบุตำแหน่งของตัวควบคุมสำหรับสมาชิก |

การใช้ส่วนประกอบเดิมช่วยให้ลูกค้าจำทางเปิดรายละเอียดและปุ่มหัวใจได้ แหล่งข้อมูล ลำดับที่พัก และวิธีแสดงผลระหว่างรอการยืนยันผลนำออกยังต้องกำหนดในงานพัฒนา ภาพที่พัก ราคา และข้อมูลติดต่อที่เป็นตัวอย่างใช้สำหรับตรวจแบบ [แบบการ์ดที่อนุมัติ](../../uid-002/g4-r1-review/implementation-reference.md)

## รายการตรวจบนเว็บจริง

- เปิดจากเมนูและลิงก์ตรงทั้งก่อนและหลังเข้าสู่ระบบ ตรวจว่ากลับถูกหน้าหลังสำเร็จหรือปิด
- เอาที่พักออกทั้งกรณีเหลือรายการและกรณีเอาหลังสุดท้ายออก ตรวจว่าจำนวนและกริดตรงกับผลที่ยืนยันแล้ว
- ทดสอบโหลดครั้งแรก ลองอีกครั้ง การเปลี่ยนรูป และการย้อนจากรายละเอียดบนมือถือและเดสก์ท็อป
- ตรวจขนาดจออื่น การแสดงชื่อยาวจริง ลำดับและตำแหน่งโฟกัส และชื่อไอคอนที่โปรแกรมอ่านหน้าจอใช้

การอนุมัติ G4 รับภาพและสเปกเป็นแหล่งอ้างอิงของงานพัฒนา งานพัฒนาเริ่มตามการเลือกงานและการอนุมัติของโครงการ [เงื่อนไขงานพัฒนา](../../../../tasks/design/implementation-gates.yaml)
