## สิ่งที่ให้ตรวจรับ

- **หน้าหลัก** ใช้ Header และ Footer r1, Mitr และรูปที่พักตัวอย่างที่มีในไฟล์โครงการ การ์ดใช้คอมโพเนนต์เดียวกับหน้าค้นหา เดสก์ท็อปใช้สี่คอลัมน์เพื่อเทียบที่พัก มือถือเรียงทีละการ์ดและแสดงปุ่มเปลี่ยนรูปตามแบบหน้าค้นหา [การ์ดและสถานะที่อนุมัติ](../../uid-002/g4-r1-review/implementation-reference.md)
- **ทางเข้าและการล็อกอิน** เดสก์ท็อปเน้นชื่อหน้าปัจจุบันด้วยตัวหนาตาม G2 มือถือใช้เมนูหลักพร้อมภาษาและช่องทางติดต่อเดิม จากเมนูให้เปิด Auth ทันทีเมื่อยังไม่ล็อกอิน จากลิงก์ตรงให้กดปุ่ม **เข้าสู่ระบบ** บนหน้า หากปิด Auth ให้กลับจุดที่เรียกมา หากสำเร็จให้เปิดรายการของบัญชีทันที [แบบ Auth เดิม](../../dsd-001/home-auth-g4-r1/README.md)
- **การดูและนำที่พักออก** กดการ์ดเพื่อดูรายละเอียด กดหัวใจสีชมพูเพื่อเอาที่พักออก เมื่อผลยืนยันสำเร็จ จำนวนและกริดปรับพร้อมกัน หากเอาหลังสุดท้ายออกให้แสดง **ค้นหาที่พัก** ในหน้ารายการว่าง
- **การโหลดและการกู้คืน** ใช้โครงโหลดจากการ์ดร่วมก่อนรู้จำนวนจริง เมื่อโหลดรายการไม่สำเร็จให้กด **ลองอีกครั้ง** สถานะรายการว่างแสดงเมื่อได้ผลว่าไม่มีรายการแล้ว
- **การ์ดจอแคบและคีย์บอร์ด** มีภาพตรวจการ์ดกว้าง 328 พิกเซลสำหรับจอ 360 ใช้ชื่อหนึ่งบรรทัดพร้อมจุดไข่ปลาและยุบข้อมูลห้องน้ำเมื่อไม่มีค่า ปุ่มหัวใจมีพื้นที่กด 44 × 44 พิกเซลและวงโฟกัสชัดบนภาพ เมื่อเอาการ์ดออก เสนอให้คืนโฟกัสไปที่ปุ่มหัวใจใบถัดไปหรือใบก่อนหน้า หากหมดรายการให้ไปที่ **ค้นหาที่พัก** [ภาพตัวอย่างการ์ด](jDp6v.png) · [กติกาชื่อยาว](../../uid-002/g3-r8-review/README.md) · [กติกาห้องน้ำ](../../uid-002/card-bathroom-visibility-r1/README.md)

ปุ่ม **บัญชีสมาชิก** ใช้ตำแหน่งและน้ำหนักของปุ่มรองในภาพเพื่อแสดงสถานะล็อกอิน รายละเอียดเมนูบัญชีอยู่ในงานบัญชีสมาชิก ข้อมูลที่พักและราคาที่เห็นเป็นตัวอย่างสำหรับตรวจแบบ

ตรวจภาพนิ่งทั้ง 12 เฟรม ขอบเขตใน Pencil และตัวอย่างการ์ดจอแคบแล้ว การเข้าสู่ระบบ การนำออกและลองใหม่ และพฤติกรรมคีย์บอร์ด/โปรแกรมอ่านหน้าจอเป็นรายการตรวจบนเว็บจริง [ทะเบียนเฟรม](review-manifest.json)
