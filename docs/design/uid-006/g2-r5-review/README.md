## พฤติกรรมที่ตรวจรับใน G2

- **ทางเข้า** เดสก์ท็อปใช้แถบนำทาง มือถือใช้เมนู ☰ เมื่ออยู่หน้ารายการโปรด ชื่อ **รายการโปรด** บนเดสก์ท็อปใช้น้ำหนัก Mitr 500 และลิงก์อื่นใช้น้ำหนักปกติ [บันทึกตรวจรับเมนูเดสก์ท็อป](owner-desktop-nav-acceptance.json)
- **เข้าสู่ระบบ** เมื่อเข้าจากเมนูขณะยังไม่ได้ล็อกอิน ให้เปิดแบบเข้าสู่ระบบเดิมและกลับหน้าต้นทางหากปิด เมื่อเปิดลิงก์ตรงให้แสดงปุ่ม **เข้าสู่ระบบ** บนหน้ารายการโปรดและกลับมาที่หน้านี้หากปิด ทั้งสองทางเปิดรายการของบัญชีเมื่อเข้าสู่ระบบสำเร็จ [บันทึกตรวจรับสถานะเปิดลิงก์ตรง](../g2-r4-review/owner-direct-entry-acceptance.json)
- **ดูและนำที่พักออก** กดการ์ดเพื่อดูรายละเอียดและย้อนกลับได้ ปุ่มหัวใจใช้เอาที่พักออกโดยตรง เมื่อสำเร็จให้อัปเดตกริดและจำนวนพร้อมกัน เมื่อเอาหลังสุดท้ายออกให้แสดงสถานะรายการว่างพร้อมปุ่ม **ค้นหาที่พัก**
- **ตอบกลับเมื่อโหลดรายการ** ระหว่างโหลดให้แสดงโครงโหลดการ์ด หากโหลดไม่สำเร็จให้แสดงปุ่ม **ลองอีกครั้ง** แสดงจำนวนรายการหลังโหลดสำเร็จ

เกณฑ์โครงหน้าครอบคลุมการใช้การ์ดเดิม เส้นทางกลับ และสถานะรายการว่างทั้งสองจอ การนำทาง การตอบกลับของระบบ และการเข้าถึงจริงต้องตรวจเมื่อพัฒนา [ทะเบียนเฟรม](review-manifest.json)
