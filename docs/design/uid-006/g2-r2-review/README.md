## ผลเมื่อเลือกรายการโปรด

- ผู้ที่เข้าสู่ระบบแล้วเปิดหน้ารายการโปรดได้ทันที
- ผู้ที่ยังไม่ได้เข้าสู่ระบบใช้แบบ Auth เดิม เมื่อสำเร็จให้เปิดรายการโปรดของบัญชี ถ้ายกเลิกให้กลับหน้าต้นทางที่เปิดลิงก์มา
- ภายในหน้าใช้การ์ดและสถานะตาม [โครง G2-r1](../g2-r1-review/README.md) กดการ์ดเพื่อดูรายละเอียด กดหัวใจเพื่อเอาที่พักออก และไปค้นหาที่พักได้จากสถานะรายการว่าง

ตรวจจากภาพนิ่งและตำแหน่งองค์ประกอบใน Pencil การนำทาง การตรวจบัญชี และการกลับต้นทางจริงเป็นงานพัฒนาภายหลัง [แบบ Auth เดิม](../../dsd-001/home-auth-g4-r1/README.md) · [ทะเบียนเฟรม](review-manifest.json)
