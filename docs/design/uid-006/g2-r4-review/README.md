# UID-006 · รายการโปรด · Wireframe G2-r4

20 พฤศจิกายน 2026 (เวลาไทย) · ภูรับสถานะเปิดลิงก์ตรงก่อนเข้าสู่ระบบทั้งสองจอ [บันทึกตรวจรับ](owner-direct-entry-acceptance.json) · [แบบล่าสุด G2-r5](../g2-r5-review/README.md) ใช้ section `eVI9G` ใน Pencil

ภูยืนยันให้เพิ่มสถานะสำหรับเปิดลิงก์หน้ารายการโปรดโดยตรงก่อนเข้าสู่ระบบ หน้านี้แสดงข้อความ **เข้าสู่ระบบเพื่อดูรายการโปรด** และปุ่ม **เข้าสู่ระบบ** [เดสก์ท็อป 1440](fAe8M.png) · [มือถือ 390](USTzy.png)

| กรณี | พฤติกรรม |
| --- | --- |
| เปิดลิงก์ตรงขณะยังไม่ได้เข้าสู่ระบบ | แสดงข้อความและปุ่มบนหน้ารายการโปรด กดปุ่มเพื่อเปิดแบบเข้าสู่ระบบเดิม |
| เข้าสู่ระบบสำเร็จ | เปิดรายการโปรดของบัญชีทันที และแสดงสถานะตามผลที่โหลดได้ |
| ปิดหรือยกเลิกหลังเปิดจากปุ่มกลางหน้า | กลับมาที่ข้อความและปุ่มเข้าสู่ระบบบนหน้ารายการโปรด |
| เปิดจากเมนูบนหน้าอื่นขณะยังไม่ได้เข้าสู่ระบบ | เปิดแบบเข้าสู่ระบบเดิมทันที หากปิดหรือยกเลิกให้กลับหน้าที่กดมา |

ชุดตรวจรวม 12 เฟรม ภาพ 2 เฟรมด้านบนเพิ่มในรอบนี้ ส่วนทางเข้าจากเมนูและสถานะมีรายการ ว่าง กำลังโหลด และโหลดไม่สำเร็จ ดูได้จาก [ภาพ 10 เฟรมใน G2-r3](../g2-r3-review/README.md) บอร์ดปัจจุบันรวมทั้งหมดใน section เดียว
