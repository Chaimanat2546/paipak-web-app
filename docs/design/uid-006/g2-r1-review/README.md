## พฤติกรรมที่ให้ตรวจรับ

- ทางเข้าที่เสนอคือเมนูบัญชีสมาชิกบนเดสก์ท็อปและเมนูหลักบนมือถือ ผู้ที่ยังไม่เข้าสู่ระบบใช้แบบ Auth เดิม เมื่อสำเร็จจึงเปิดรายการโปรดของบัญชี เมื่อยกเลิกให้กลับหน้าต้นทาง
- กดการ์ดเพื่อเปิดรายละเอียดที่พักและย้อนกลับมาที่รายการโปรด หัวใจบนการ์ดเป็นปุ่มแยก มีพื้นที่กด 44 × 44 พิกเซล การกดหัวใจใช้การนำออกโดยตรงตามร่าง F-06 ไม่มีขั้นยืนยันหรือ Undo เมื่อเอาออกสำเร็จ จำนวนและกริดปรับให้ตรงกัน หากเป็นหลังสุดท้ายให้แสดงสถานะรายการว่าง
- สถานะว่างเสนอทางไปค้นหาที่พัก สถานะกำลังโหลดใช้โครงการ์ดแทนรายการระหว่างรอ ส่วนสถานะโหลดไม่สำเร็จให้ลองโหลดซ้ำ จำนวนรายการจะแสดงเมื่อโหลดสำเร็จ
- ตอนทำแบบละเอียด ให้ตรวจโฟกัสที่ปุ่มหัวใจและหลังเอาการ์ดออก ชื่อปุ่มสำหรับโปรแกรมอ่านหน้าจอควรระบุที่พักที่กำลังจะนำออก

ภาพทั้งแปดเป็นโครงหน้าคงที่ การเข้าสู่ระบบ การอ่านรายการ และการนำออกจริงต้องตรวจเมื่อพัฒนา ระบบจัดเก็บ ลำดับข้อมูล และวิธีจัดการผลนำออกที่ยังไม่ยืนยันยังอยู่ในขอบเขตสัญญาข้อมูลภายหลัง
