# สเปคขั้นตอนใช้งานและสถานะหน้าจอจัดการหมวดหมู่บ้านพัก

**Task ID** UID-010  
**เวอร์ชัน** 1.27 · 11 พฤศจิกายน 2026 (เวลาไทย)  
**สถานะ** สเปคประกอบชุด r2 พร้อมขั้นตอนลบหมวดเพิ่มเติม

เอกสารนี้อธิบายว่าการตั้งค่าของแอดมินมีผลกับหมวด บ้าน และหน้าแรกเมื่อใด ใช้ประกอบ [Task Brief และเกณฑ์ตรวจรับ](admin-category-management-brief.md) · [ไวร์เฟรม r2 และผลตรวจ](admin-category-wireframe-r2/README.md)

## 1. งานหลักของแอดมิน

### สร้างหมวด

1. จากรายการหมวด กด **สร้างหมวดหมู่** เพื่อเปิดฟอร์มใหม่ ชื่อและไอคอนหรือรูปทางลัดเริ่มว่าง รายชื่อบ้านเริ่มว่าง สวิตช์ทางลัดกับแถวบ้านเปิดไว้ทั้งคู่
2. ตั้งชื่อและเลือกสื่อทางลัดหนึ่งอย่าง หมวดใหม่เริ่มด้วยประเภท **ใช้ไอคอน** และปุ่ม **เลือกไอคอน** ให้แอดมินเลือกไอคอนจริงเอง แอดมินสลับไป **ใช้รูปภาพ** เพื่ออัปโหลดรูปได้ ทุกหมวดต้องมีสื่อก่อนบันทึกทั้งตอนเปิดและปิดทางลัด สื่อใช้คู่กับชื่อหมวดเฉพาะทางลัดด้านบน ส่วนแถวบ้านใช้ชื่อหมวดและการ์ดบ้าน
3. เลือกบ้านและเรียงภายในหมวดได้ หรือบันทึกหมวดว่างไว้ก่อนก็ได้ เปลี่ยนสวิตช์แต่ละตำแหน่งได้ในฟอร์ม
4. เมื่อกด **บันทึกหมวด** สำเร็จ ระบบสร้างหมวดต่อท้ายรายการและนำค่าที่บันทึกไปแสดงบนหน้าแรกตามเงื่อนไขในข้อ 4

### แก้หมวดและจัดบ้าน

หมวดเดิมทั้งเจ็ดและหมวดที่สร้างใหม่อยู่ในรายการแอดมินเดียวกัน ใช้ฟอร์มและกติกาการแก้ชื่อ สื่อ สวิตช์ รายชื่อบ้าน และลำดับบ้านชุดเดียวกัน เมื่อเริ่มใช้งาน เจ็ดหมวดเดิมมีรายชื่อบ้านว่างทั้งหมด แอดมินเป็นผู้เลือกบ้านเข้าหมวดและจัดลำดับบ้านเอง

1. เลือกหมวดจากรายการเพื่อเปิดชื่อ สื่อทางลัด สวิตช์ รายชื่อบ้าน และลำดับที่บันทึกไว้ บนเดสก์ท็อป แถวหมวดด้านซ้ายแสดงไอคอนหรือรูปที่บันทึกไว้ตามประเภทของหมวดทั้งเมื่อเปิดและปิดทางลัด ส่วนฟอร์มใช้เลือกประเภทและเปลี่ยนสื่อ
2. กด **เพิ่มบ้านพัก** แล้วค้นหาด้วยชื่อหรือรหัส DV ผลค้นหาแสดงบ้านที่ยังไม่อยู่ในรายการ **บ้านในหมวด** ของหมวดที่กำลังแก้ แต่ละแถวมีปุ่ม **เพิ่ม** กดแล้วบ้านเข้าในฟอร์มและหายจากผลค้นหาทันที คงคำค้นเดิมและเปิดหน้าค้นหาไว้ให้เพิ่มหลังอื่นต่อได้
3. จัดลำดับบ้านในหมวดได้ บ้านหลังเดียวอยู่ได้หลายหมวดและมีอันดับต่างกันได้ เมื่อกดกากบาท ให้ถามยืนยันก่อนเอาบ้านหลังนั้นออกจากรายการในฟอร์ม
4. กด **บันทึกหมวด** เพื่อใช้ชื่อ สื่อ สวิตช์ และรายชื่อบ้านตามลำดับที่แก้ไว้ การเอาบ้านออกมีผลกับหมวดที่กำลังแก้เมื่อบันทึกสำเร็จ หากเอาบ้านหลังสุดท้ายออกให้ใช้กติกาหมวดว่าง
5. หากกดอีกหมวดขณะมีการแก้ไขค้างอยู่ ให้ถามว่าจะบันทึก ทิ้งการแก้ไข หรือแก้ต่อ ผลของแต่ละทางเลือกอยู่ในข้อ 3

### เรียงหมวดจากรายการรวม

1. เปิดโหมดจัดลำดับเพื่อเรียงหมวดจากรายการทั้งหมด ลำดับเดียวใช้กับทั้งทางลัดและแถวบ้าน
2. บนมือถือ หมวดและบ้านแต่ละรายการมีจุดจับหนึ่งจุด แอดมินลากจุดจับเพื่อย้าย หรือแตะจุดเดิมเพื่อเปิดตัวเลือกตำแหน่งปลายทาง ทั้งสองวิธีให้ผลการย้ายเดียวกัน
3. กด **บันทึกลำดับ** เพื่อใช้ลำดับหมวดใหม่บนหน้าแรก ส่วนลำดับบ้านภายในหมวดบันทึกผ่าน **บันทึกหมวด** ในฟอร์มนั้น

เจ้าของเลือกให้แอดมินจัดลำดับตั้งต้นของหมวดเดิมและหมวดใหม่จากรายการรวมเอง

## 2. ปุ่มบันทึกตามงานที่กำลังทำ

| งาน | ปุ่มหลัก | สิ่งที่บันทึก |
| --- | --- | --- |
| สร้างหรือแก้หมวด | **บันทึกหมวด** | ชื่อ ไอคอนหรือรูปทางลัด สวิตช์ทั้งสอง รายชื่อบ้านและลำดับบ้านในหมวด |
| จัดลำดับหมวดจากรายการรวม | **บันทึกลำดับ** | ลำดับหมวดที่ใช้บนหน้าแรกทั้งสองตำแหน่ง |

แสดงปุ่มบันทึกหลักหนึ่งปุ่มตามงานที่กำลังทำ การกด **เพิ่ม** ในแถวผลค้นหาปรับรายการในฟอร์ม ส่วนค่าบนหน้าแรกเปลี่ยนเมื่อ **บันทึกหมวด** สำเร็จ

## 3. สถานะฟอร์มและการเปลี่ยนงาน

| สถานการณ์ | สิ่งที่ต้องเกิด |
| --- | --- |
| เปิดฟอร์มสร้าง | เปิดทั้งสองสวิตช์ เลือกประเภท **ใช้ไอคอน** เป็นค่าเริ่มต้น และแสดงปุ่ม **เลือกไอคอน** สำหรับเลือกไอคอนจริง |
| เปิดฟอร์มแก้ไข | แสดงค่าที่บันทึกไว้ของหมวดที่เลือก |
| เลือกประเภทสื่อบนเดสก์ท็อป | ฝั่งขวาวาง **ใช้ไอคอน** เหนือ **ใช้รูปภาพ** พร้อมคำอธิบายใต้ชื่อแต่ละตัวเลือก ฝั่งซ้ายแสดงปุ่ม **เลือกไอคอน** หรือ **เปลี่ยนไอคอน** เมื่อเลือกประเภทไอคอน เมื่อเลือกรูปภาพ ฝั่งซ้ายแสดงช่องเดียวให้คลิกเลือกไฟล์หรือลากรูปมาวาง ทั้งสองวิธีใช้เลือกหรือเปลี่ยนรูปในหมวด |
| เลือกประเภทสื่อบนมือถือ | ใช้ลำดับตัวเลือกเดียวกับเดสก์ท็อป ฝั่งซ้ายของช่องสื่อใช้แตะเลือกหรือเปลี่ยนไอคอน หรือแตะเพื่ออัปโหลดหรือเปลี่ยนรูปตามประเภทที่เลือก รูปหรือไอคอนที่บันทึกไว้แสดงในหน้ารายการหมวด |
| อัปโหลดรูปทางลัดไม่สำเร็จ | แจ้งข้อผิดพลาดที่ช่องรูปและให้เลือกไฟล์ใหม่จากช่องเดิม เดสก์ท็อปยังลากไฟล์ใหม่มาวางได้ ข้อมูลฟอร์มและรูปที่บันทึกไว้เดิมยังอยู่ |
| เลือกไอคอนใหม่ | หน้าต่างแสดงตารางไอคอนหลายแถว แต่ละช่องแสดงรูปไอคอนอย่างเดียวและมีชื่อสำหรับโปรแกรมอ่านหน้าจอ ไอคอนที่แอดมินเลือกมีกรอบเน้น กด **ใช้ไอคอนนี้** เพื่อนำตัวเลือกกลับเข้าฟอร์ม แล้วกด **บันทึกหมวด** เพื่อบันทึกการเปลี่ยนแปลง [ภาพขณะเลือกบนเดสก์ท็อป](admin-category-wireframe-r2/Q50Oa.png) |
| เปิดแผงเลือกไอคอนบนมือถือ | แผงเปิดจากด้านล่าง ใช้ตารางเดียวกับเดสก์ท็อปในพื้นที่แตะขนาดเหมาะกับมือถือ ภาพกว้าง 390 พิกเซลใช้ 6 คอลัมน์ [ภาพตอนเปิด](admin-category-wireframe-r2/hth50.png) · [ภาพขณะเลือกตัวใหม่](admin-category-wireframe-r2/eXJj5.png) |
| กดบันทึกโดยยังไม่ได้เลือกไอคอนหรือรูป | คงฟอร์มไว้ให้เลือกสื่อก่อนบันทึก เงื่อนไขนี้ใช้ทั้งตอนเปิดและปิดทางลัด |
| กดเอาบ้านออกจากหมวด | ถามยืนยันก่อน หากยืนยันจึงนำบ้านออกจากรายการในฟอร์ม หากยกเลิกให้แสดงรายการเดิมในฟอร์ม |
| กดเพิ่มบ้านจากผลค้นหา | บ้านเข้า **บ้านในหมวด** ทันทีและหายจากผลค้นหาของหมวดนี้ระหว่างแก้ฟอร์ม บ้านที่อยู่ในหมวดนี้อยู่แล้วก็ถูกกรองออก การจัดบ้านเข้าหมวดอื่นใช้รายการของหมวดนั้น |
| เปลี่ยนหมวดขณะมีการแก้ไขค้าง แล้วเลือก **บันทึก** | บันทึกหมวดปัจจุบันก่อน เมื่อสำเร็จจึงเปิดหมวดปลายทาง |
| เปลี่ยนหมวดขณะมีการแก้ไขค้าง แล้วเลือก **ทิ้งการแก้ไข** | ทิ้งเฉพาะการแก้ไขในฟอร์ม แล้วเปิดหมวดปลายทาง |
| เปลี่ยนหมวดขณะมีการแก้ไขค้าง แล้วเลือก **แก้ต่อ** | อยู่ที่ฟอร์มเดิมพร้อมค่าที่กำลังแก้ |
| เปิดโหมดจัดลำดับจากฟอร์มที่มีการแก้ไขค้าง หรือออกจากโหมดจัดลำดับขณะมีลำดับที่ยังไม่บันทึก | แสดงกล่องถามให้เลือก **บันทึก**, **ทิ้งการแก้ไข** หรือ **แก้ต่อ** ทั้งบนเดสก์ท็อปและมือถือ |
| เลือก **บันทึก** ก่อนเปลี่ยนโหมด | บันทึกงานที่กำลังทำตามปุ่มของโหมดนั้น เมื่อสำเร็จจึงเปิดปลายทาง หากบันทึกไม่สำเร็จ ให้อยู่ที่หน้าปัจจุบันพร้อมข้อมูลที่แก้ไว้และแจ้งข้อผิดพลาด |
| เลือก **ทิ้งการแก้ไข** หรือ **แก้ต่อ** ก่อนเปลี่ยนโหมด | **ทิ้งการแก้ไข** ยกเลิกเฉพาะรายการที่ยังไม่บันทึกแล้วเปิดปลายทาง ส่วน **แก้ต่อ** ปิดกล่องถามและอยู่ที่หน้าเดิมพร้อมข้อมูลที่แก้ไว้ |

ระหว่างบันทึกหมวดหรือบันทึกลำดับ ให้แสดง Toast **กำลังบันทึก…** ลอยด้านบนและพักการกดบันทึกซ้ำจนได้ผล แถบสีน้ำเงินแสดงว่าระบบกำลังทำงาน เมื่อสำเร็จให้เปลี่ยนเป็น Toast **บันทึกหมวดหมู่สำเร็จ** หรือ **บันทึกลำดับแล้ว** ในตำแหน่งเดียวกัน สถานะสำเร็จมีแถบเวลาและปุ่มปิด หากการบันทึกพาไปอีกหน้าตามขั้นตอน ให้แสดงข้อความยืนยันด้านบนของหน้าปลายทาง ฟอร์มและโฟกัสอยู่ตำแหน่งเดิมเมื่ออยู่หน้าเดิม เมื่อบันทึกไม่สำเร็จให้ปิด Toast แล้วใช้ข้อความผิดพลาดในฟอร์มตามกติกาด้านล่าง [ม็อกอัป Toast เดสก์ท็อป](admin-category-mockup-r1/README.md)

เมื่อบันทึกไม่สำเร็จ ให้คงฟอร์มเดิมพร้อมข้อมูลที่แอดมินแก้ไว้ หากระบุช่องที่ต้องแก้ได้ ให้บอกสิ่งที่ต้องแก้ใต้ช่องนั้น เช่น **กรอกชื่อหมวดก่อนบันทึก** กรณีทั่วไปให้แสดง **บันทึกหมวดไม่สำเร็จ** ด้านบนของฟอร์ม แอดมินแก้ต่อหรือกดปุ่ม **บันทึกหมวด** ในฟอร์มได้เมื่อพร้อม [ข้อผิดพลาดที่ชื่อหมวด](admin-category-wireframe-r2/awOOQ.png) · [ข้อผิดพลาดทั่วไป](admin-category-wireframe-r2/adVRz.png)

ข้อความเฟดเข้าเมื่อแสดงและเฟดออกเมื่อสถานะข้อผิดพลาดถูกล้าง

## 4. ผลหลังบันทึกบนหน้าแรกและผลค้นหา

- **ทางลัด** ขึ้นเมื่อเปิดสวิตช์ทางลัดและหมวดมีบ้านในรายการ ใช้ชื่อและสื่อที่แอดมินเลือก ไอคอนทางลัดบนหน้าแรกแสดงโดยไม่มีแผ่นพื้นหลัง การปิดทางลัดเก็บสื่อเดิมไว้ใช้เมื่อเปิดกลับมา
- **แถวบ้าน** ขึ้นเมื่อเปิดสวิตช์แถวบ้านและมีบ้านพร้อมแสดง ไล่ตามลำดับที่แอดมินจัด ข้ามบ้านที่ไม่พร้อมแสดง แล้วเลือกบ้านที่พร้อมได้สูงสุด 8 หลัง หากมีไม่ถึง 8 ให้แสดงเท่าที่มี การปิดแถวบ้านเก็บรายชื่อและลำดับไว้ใช้เมื่อเปิดกลับมา
- **หมวดว่าง** เมื่อยังไม่มีบ้านในรายการ ให้เก็บหมวดและค่าสวิตช์ไว้ในหน้าแอดมิน แล้วซ่อนหมวดจากทางลัด แถวบ้าน และรายการ **หมวดอื่น ๆ** เมื่อเปิดลิงก์ตรงของหมวดว่าง ให้พาไปหน้าแรก
- **ปิดทั้งสองสวิตช์** ซ่อนหมวดจากทางลัด แถวบ้าน และรายการ **หมวดอื่น ๆ** แม้หมวดนั้นมีบ้านในรายการ หากลูกค้าเปิดลิงก์ตรง ให้พาไปหน้าแรกเหมือนกรณีหมวดว่าง
- **ลำดับหมวด** ทั้งทางลัดและแถวบ้านอ่านลำดับหมวดชุดเดียวกัน แต่ละตำแหน่งแสดงเฉพาะหมวดที่ผ่านเงื่อนไขของตำแหน่งนั้น
- **ผลค้นหา** ทางลัดและ **ดูทั้งหมด** เปิดหมวดเดียวกัน เริ่มจากรายชื่อบ้านที่แอดมินเลือกไว้ทั้งหมดตามลำดับที่จัด โดยลูกค้ากรองต่อได้ในหน้าผลค้นหา [ข้อสรุปการเปิด Results จาก Home](dsd-001/f01-ui-3/home-guided-review/README.md)

### เมื่อหมวดทางลัดล้นแถว

ใช้ชุดทางลัดเดียวกันทั้งเดสก์ท็อปและมือถือ โดยนับเฉพาะหมวดที่เข้าเงื่อนไขแสดงทางลัด หากมีไม่เกินแปดหมวด ให้แสดงครบ หากเกินแปด ให้แสดงเจ็ดหมวดแรกตามลำดับที่แอดมินจัดและใช้ช่องท้ายเป็น **หมวดอื่น ๆ** พร้อมไอคอนจุดสามจุด เมื่อกดจะเปิดรายการหมวดที่เข้าเงื่อนไขแสดงทางลัดทั้งหมดในลำดับเดียวกัน เลือกหมวดแล้วไปหน้าผลค้นหาของหมวดนั้น แถวบ้านด้านล่างใช้เงื่อนไขของแต่ละหมวด [แบบเดสก์ท็อป](admin-category-wireframe-r2/A5snhm.png) · [ท้ายแถวบนมือถือ](admin-category-wireframe-r2/QDROi.png)

เดสก์ท็อปใช้แถวเดียวแบบคงที่เมื่อพื้นที่พอ ส่วนรูปแบบจอแคบให้ปัดทางลัดชุดเดียวกันได้ ใช้พื้นที่จริงของแถบในการกำหนดจุดเปลี่ยนรูปแบบ และทดสอบกับชื่อหมวดยาวก่อนระบุค่าพิกเซล ภาพเดสก์ท็อปกว้าง 1440 พิกเซลเป็นตัวอย่างเมื่อแสดงครบแปดช่อง [ภาพเมื่อหมวดพอดี](admin-category-wireframe-r2/e7FTp.png)

## 5. ประเด็นที่ยังต้องกำหนด

| เรื่อง | รายละเอียดที่ยังต้องกำหนด |
| --- | --- |
| สื่อทางลัด | ชนิดและขนาดไฟล์ อัตราส่วนและการครอป |

**ข้อสรุปก่อนปิดรอบ** เจ้าของเลือกให้ถามก่อนเข้าและออกจากโหมดจัดลำดับเมื่อมีงานค้าง ตามกติกาในข้อ 3

เมื่อมีหน้าจอที่ใช้งานได้ ให้ทดสอบการบันทึก จุดจับบนมือถือทั้งการลากและการแตะเลือกตำแหน่ง และการใช้แป้นพิมพ์ในรอบตรวจการเข้าถึง ส่วนการเชื่อมข้อมูลบ้านจริงขึ้นอยู่กับข้อสรุปเรื่องแหล่งข้อมูลบ้านพัก [ประเด็นแหล่งข้อมูลบ้านพัก](../decisions/open-decisions.yaml) · [เกณฑ์การลากของ W3C](https://www.w3.org/WAI/WCAG22/Understanding/dragging-movements.html)

## 6. การลบหมวดหมู่

1. ในหน้าแก้หมวด ปุ่ม **ลบหมวดหมู่** อยู่ตำแหน่งเดิมของ **ยกเลิก** ข้าง **บันทึกหมวด** ทั้งบนเดสก์ท็อปและมือถือ ระหว่างบันทึกให้พักการกดลบจนทราบผล
2. เมื่อกด **ลบหมวดหมู่** เดสก์ท็อปเปิดหน้าต่างยืนยัน มือถือเปิดแผงยืนยันจากด้านล่างเหนือฟอร์มเดิม เช่นเดียวกับตอนยืนยันเอาบ้านออก ทั้งสองแสดงชื่อหมวดพร้อมข้อความว่าหมวดจะถูกลบถาวรและบ้านพักยังอยู่ในระบบ **ยกเลิก** จะปิดการยืนยันและกลับฟอร์มเดิมพร้อมข้อมูลที่แก้ค้าง เมื่อยืนยันให้พักการกดซ้ำจนทราบผล
3. เมื่อลบสำเร็จ ให้กลับรายการหมวดและแสดง Toast **ลบหมวดหมู่สำเร็จ** หมวดที่ลบและรายการจัดบ้านของหมวดนั้นออกจากรายการ ส่วนลำดับของหมวดที่เหลือและหมวดอื่นของบ้านแต่ละหลังยังคงเดิม
4. หน้าแรกซ่อนหมวดที่ลบจากทางลัด แถวบ้าน และรายการ **หมวดอื่น ๆ** ลิงก์ตรงเดิมพาไปหน้าแรก
5. ถ้าลบไม่สำเร็จ ให้แสดงข้อความในหน้าต่างหรือแผงยืนยันเดิม พร้อมให้ลองใหม่หรือยกเลิก หมวดและบ้านที่จัดไว้ยังอยู่ตามเดิม
