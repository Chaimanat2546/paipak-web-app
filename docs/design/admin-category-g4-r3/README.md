# UID-010 · จัดลำดับหมวดแบบลากทั้งแถว G4-r3

**อนุมัติ G4-r3 และปิดงานออกแบบ** · 18 พฤศจิกายน 2026 · เดสก์ท็อป 1440 × 900

กด **จัดลำดับ** ที่หัวรายการซ้ายก่อน จากนั้นลากหมวดได้ทั้งแถว จุดหกจุดใช้บอกว่าลากได้ ฟอร์มและรายการบ้านของหมวดที่เปิดแก้ยังอยู่ด้านขวา บันทึกหรือยกเลิกการเปลี่ยนลำดับได้ที่ท้ายรายการซ้าย

เปิด section **UID-010 · จัดการหมวดหมู่บ้านพัก** (`jNYEs`) ใน [ไฟล์ Pencil หลัก](../dsd-001/papaipak-ui.pen) ไวร์เฟรมอยู่ซ้าย แบบเดสก์ท็อป G4-r3 ทั้ง 18 เฟรมอยู่ขวาในกลุ่ม `CSOsO` ส่วน [แบบ G4-r2 ที่อนุมัติ](../admin-category-g4-r2/README.md) และ [แบบอ้างอิงมือถือกับหน้าแรกใน G4-r1](../admin-category-g4-r1/README.md) อยู่ด้านล่าง
