# UID-010 · จัดลำดับหมวดจากรายการซ้ายบนเดสก์ท็อป

ใช้คู่กับ [แบบ G4-r3 ที่อนุมัติ](README.md), [กติกาหมวดและบ้านในหมวด](../admin-category-management-interaction-spec.md) และ [แบบจัดลำดับ TikTok G4-r3](../uid-011/g4-r3-review/interaction-spec.md)

## เข้าโหมดและย้ายหมวด

- เมื่อมีหมวดอย่างน้อยสองรายการ ให้กด **จัดลำดับ** ที่หัวรายการซ้ายเพื่อเข้าโหมดจัดลำดับ การกดแถวในรายการปกติเปิดฟอร์มของหมวดนั้น
- ในโหมดจัดลำดับให้ลากได้จากทั้งแถว จุดหกจุดใช้บอกว่าลากได้และไม่รับโฟกัสแยก แสดงเลขตำแหน่งในแต่ละแถวและเส้นบอกตำแหน่งวาง หากรายการยาวให้เลื่อนภายในแผงซ้ายเมื่อกำลังลากใกล้ขอบ
- ใช้ Tab เพื่อโฟกัสแถว กด Space หรือ Enter เพื่อเริ่มย้าย ใช้ลูกศรขึ้นลงเปลี่ยนตำแหน่ง และกด Space หรือ Enter อีกครั้งเพื่อวาง กด Escape เพื่อยกเลิกการย้ายครั้งนั้น คงโฟกัสกับแถวเดิมและประกาศตำแหน่งใหม่ให้โปรแกรมอ่านหน้าจอ
- ฟอร์มและรายการบ้านด้านขวาอยู่กับหมวดเดิมตามรหัสหมวด เก็บค่าที่กรอกค้างไว้แม้หมวดนั้นเปลี่ยนตำแหน่ง

## บันทึกและยกเลิก

- **ยกเลิก** กลับสู่รายการปกติและคืนลำดับที่บันทึกล่าสุด **บันทึกลำดับ** ใช้ได้หลังลำดับเปลี่ยน และมีผลกับลำดับหมวดในทางลัดและแถวบ้านบนหน้าแรกเมื่อสำเร็จ **บันทึกหมวด** ในฟอร์มขวาใช้กับข้อมูลหมวดและลำดับบ้านในหมวด
- ระหว่างบันทึกลำดับให้พักการลากและการส่งซ้ำ พร้อมแสดง Toast ขวาบน เมื่อสำเร็จให้กลับรายการปกติ แสดง Toast ยืนยันและคงฟอร์มหมวดเดิม เมื่อพลาดให้แจ้งในรายการซ้ายและเก็บลำดับที่แก้ไว้เพื่อลองอีกครั้ง
- แบบมือถือและหน้าแรกอ้างอิง [G4-r1](../admin-category-g4-r1/README.md)

## ตรวจเมื่อพัฒนา

ทดสอบการเข้าโหมดก่อนลาก การลากทั้งแถวและเลื่อนรายการยาว การใช้คีย์บอร์ด การเก็บข้อมูลและโฟกัส การยกเลิกและลองบันทึกใหม่ รวมถึงผลหลังบันทึกบนหน้าแรก
