# UID-013 · แบบสุดท้าย G4-r1 ที่อนุมัติ

**ภูอนุมัติ G4-r1 และปิดงานออกแบบ** · 18 พฤศจิกายน 2026 · 23 คู่ เดสก์ท็อป 1440 × 900 และมือถือ 390 × 844 [บันทึกผลอนุมัติ](owner-G4-r1-acceptance.json)

แบบจัดลำดับที่ใช้ตอนนี้อยู่ใน [G4-r5 สำหรับมือถือ](../g4-r5-mobile-order-review/README.md) และ [G4-r4 สำหรับเดสก์ท็อป](../../admin-g4-r4-review/README.md)

ชุดตรวจใช้ [High-Fi G3-r5 ที่ภูอนุมัติ](../g3-r5-review/owner-G3-r5-acceptance.json) 44 เฟรม และ F-08 ฉบับปรับระยะ 2 เฟรม ดูชุดที่ใช้ตรวจรอบนั้นในกลุ่ม `m9iMHK` และ `kU6mv` ของ [ไฟล์ Pencil ก่อนจัดแบบที่อนุมัติ](https://github.com/Chaimanat2546/paipak-web-app/blob/dc7653526101c2418009e577d1759ba72ed9dde3/docs/design/dsd-001/papaipak-ui.pen) แบบมือถือ 23 เฟรมและแบบ FAQ หน้าแรก F-15 ถึง F-18 อยู่ในกลุ่ม `PnmBI` ของ [ไฟล์ Pencil หลัก](../../dsd-001/papaipak-ui.pen) ส่วน F-14 เดสก์ท็อปอยู่ใน [G4-r4](../../admin-g4-r4-review/README.md)
