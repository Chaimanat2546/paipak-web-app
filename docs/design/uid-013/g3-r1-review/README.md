## จุดที่ตรวจ

- ใช้โครงและบทบาทสีจาก [แบบแอดมิน UID-012](../../uid-012/g4-review/README.md) รวมจุดจับทางซ้ายและแผงเลือกตำแหน่ง รอบนี้ใช้ปุ่มหลักชมพูเข้มและปุ่มยืนยันลบถาวรสีแดง
- ในฟอร์มภาษาเดียว ข้อมูลไม่ครบแสดงที่ช่องที่เกี่ยวข้อง บันทึกไม่สำเร็จแล้วข้อความที่กรอกยังอยู่ เมื่อลบข้อสุดท้ายเห็นรายการว่างในแอดมินและหน้าแรกที่ซ่อนส่วน FAQ [สเปกการใช้งานจาก G2](../g2-r2-review/interaction-spec.md)
- ตัวอย่างฝั่งผู้ชม F-15 ถึง F-18 เป็นภาพตัดช่วง FAQ และบริบทหัวกับท้าย ใช้แผงขาวและขอบสระฟ้าอ่อนจาก [FAQ-r4](../../dsd-001/home-faq-r4/README.md) คำถามที่เลือกแสดงมีต้นฉบับและคำแปลเป็นชุดตัวอย่าง

ตรวจขนาดและขอบเขตเลเยอร์ทั้ง 42 เฟรมใน Pencil และดูภาพเรนเดอร์ของฟอร์ม คำตอบยาว ข้อผิดพลาด แผงเลือกตำแหน่ง และหน้าแรก ข้อความขาวบนปุ่มบันทึกวัดได้ 5.16:1 และบนปุ่มยืนยันลบได้ 6.47:1 การใช้คีย์บอร์ด การบันทึก และการแปลจริงอยู่ในรอบทดสอบระบบ
