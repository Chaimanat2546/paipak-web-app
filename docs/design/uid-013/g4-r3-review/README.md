**อนุมัติ G4-r3 และปิดงานออกแบบ** · 18 พฤศจิกายน 2026 · เดสก์ท็อป 1440 × 900

เปิด section **UID-013 · คำถามที่พบบ่อย** (`nev4k`) ใน [ไฟล์ Pencil หลัก](../../dsd-001/papaipak-ui.pen) ไวร์เฟรม G2-r2 อยู่ซ้าย แบบเดสก์ท็อป G4-r3 ทั้ง 18 เฟรมอยู่ขวาใน `W7mUW` ส่วน [แบบอ้างอิงมือถือและหน้าแรก G4-r1](../g4-r1-review/README.md) กับประวัติ G4-r2 อยู่ด้านล่าง
