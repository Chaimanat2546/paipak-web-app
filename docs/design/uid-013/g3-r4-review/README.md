# UID-013 · High-Fi G3-r4 ระบบจัดการคำถามที่พบบ่อย

**ฉบับก่อนจัดแถบคำสั่งมือถือ** · 18 พฤศจิกายน 2026 · 23 คู่ เดสก์ท็อป 1440 × 900 และมือถือ 390 × 844 · [ฉบับสำหรับตรวจ G3-r5](../g3-r5-review/README.md)

เฟรมฟอร์มมือถือรอบเดิมอยู่ในกลุ่มเก็บประวัติ `gad1T`

แก้หน้าหลังบ้านตามที่ภูทักว่าข้อความอยู่เต็มหน้าและมองหาคำสั่งยาก กลุ่มตรวจอยู่ที่ `m9iMHK` ใน [Pencil](../../dsd-001/papaipak-ui.pen)

- เมนูเดสก์ท็อปใช้ชุดสัญลักษณ์จาก [UID-012](../../uid-012/g4-review/README.md) แถวคำถามใช้ดินสอสื่อการแก้ไข หัวรายการกับหัวฟอร์มมีไอคอนช่วยแยกหน้าที่ของแต่ละส่วน
- ปุ่มเพิ่ม จัดลำดับ บันทึก และลบมีสัญลักษณ์คู่กับชื่อคำสั่ง ใช้สัญลักษณ์เตือนในกล่องลบและข้างข้อความผิดพลาด
- หน้าจัดลำดับยังใช้จุดจับตามแบบ UID-012 ส่วน Toast ใช้ไอคอนสถานะจาก [ชุด Toast G3-r2](../g3-r2-review/README.md)
