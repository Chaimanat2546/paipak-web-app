# UID-013 · จัดลำดับตรงรายการเดสก์ท็อป G4-r2

**รอภูตรวจ G4-r2** · 18 พฤศจิกายน 2026

จัดลำดับคำถามจากจุดจับในรายการด้านซ้ายขณะเปิดฟอร์มแก้ไขด้านขวา กดจุดจับเพื่อเลือกตำแหน่งได้เหมือนเดิม เมื่อขยับคำถาม ช่อง **บันทึกลำดับ** กับ **ยกเลิก** จะขึ้นใต้รายการ หน้าแรกใช้ลำดับใหม่เมื่อบันทึกสำเร็จ ส่วนข้อความที่กำลังแก้เก็บอยู่ในฟอร์มด้านขวา

กลุ่ม `AeueW` ใน [Pencil](../../dsd-001/papaipak-ui.pen) มีเฟรมเดสก์ท็อปฉบับปรับ 18 เฟรม แบบมือถืออ้างอิง [G4-r1 ที่อนุมัติ](../g4-r1-review/README.md)
