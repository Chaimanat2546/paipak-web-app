# UID-013 · จุดจับจัดลำดับ FAQ บนมือถือ G4-r5

**อนุมัติแล้ว** · 18 พฤศจิกายน 2026 · มือถือ 390 × 844 · [บันทึกผลอนุมัติ](owner-G4-r5-acceptance.json)

เปิด [ไฟล์ Pencil หลัก](../../dsd-001/papaipak-ui.pen) ที่ section `nev4k` กลุ่มมือถือ `oTVq8` แบบ G4-r5 แทนที่ 6 สถานะจัดลำดับบนมือถือในกลุ่มเดิม [รายการเฟรม](review-manifest.json)

หลังเปิด **จัดลำดับ** ให้ลากได้จากทั้งแถว จุดหกจุดแสดงว่าลากได้และไม่มีกรอบปุ่ม แตะที่แถวเพื่อเปิดแผงเลือกตำแหน่งเดิม ทั้งสองวิธีย้ายเฉพาะลำดับที่กำลังแก้จนกด **บันทึกลำดับ**

รายการที่โฟกัสได้คือแถว กด Enter หรือ Space เพื่อเปิดแผงเลือกตำแหน่งได้ หลังย้ายให้คืนโฟกัสที่แถวของคำถามเดิมและประกาศลำดับใหม่ ระหว่างบันทึกให้พักการย้ายและการส่งซ้ำ
