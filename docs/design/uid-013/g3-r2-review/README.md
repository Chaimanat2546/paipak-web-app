# UID-013 · High-Fi G3-r2 ระบบจัดการคำถามที่พบบ่อย

**ฉบับก่อนปรับระยะกล่องลบ** · 18 พฤศจิกายน 2026 · 23 คู่ เดสก์ท็อป 1440 × 900 และมือถือ 390 × 844 · [ฉบับสำหรับตรวจ G3-r3](../g3-r3-review/README.md)

เฟรมกล่องลบ F-12, F-13 และ F-23 ของรอบเดิมอยู่ในกลุ่มเก็บประวัติ `ITyTy`

ปรับข้อความแจ้งผลจาก [G3-r1](../g3-r1-review/README.md) ตามคำถามของภูเรื่อง Toast ใช้ Toast จาก [แบบ UID-012](../../uid-012/g4-review/interaction-spec.md#บันทึกร่าง-เผยแพร่-และยกเลิกเผยแพร่) โดยตรง กลุ่มตรวจอยู่ที่ `m9iMHK` ใน [Pencil](../../dsd-001/papaipak-ui.pen)

Toast อยู่มุมขวาบนเดสก์ท็อปและใต้แถบหัวบนมือถือ สถานะกำลังส่งแสดงข้อมูลที่หน้าแรกยังใช้อยู่ สถานะสำเร็จแสดงผลที่หน้าแรกเปลี่ยนแล้วและมีปุ่มปิดตามแบบ UID-012 ระหว่างส่งปุ่มคำสั่งเดิมอยู่ในสถานะกำลังทำงาน

ข้อความกรอกไม่ครบยังอยู่ข้างช่อง ข้อผิดพลาดระหว่างบันทึก จัดลำดับ หรือลบยังอยู่ที่ฟอร์ม แผง หรือหน้าต่างของคำสั่งนั้นเพื่อให้ลองใหม่ได้ [สเปกการใช้งาน](../g2-r2-review/interaction-spec.md)

ตรวจขนาดและขอบเขตเลเยอร์ใน Pencil ครบ 46 เฟรม พร้อมตำแหน่งและข้อความของ Toast ทั้ง 12 เฟรม การประกาศข้อความให้โปรแกรมอ่านหน้าจอและเวลาที่ Toast ปิดอยู่ในรอบทดสอบระบบ
