# UID-013 · การใช้งาน Wireframe G2-r2

แบบรอตรวจตาม [ขอบเขต G0 และทิศทาง B](../../../../tasks/design/UID-013.md) ใช้ข้อมูลตัวอย่างทั้งในหลังบ้านและหน้าแรก

## เปิดและบันทึกฟอร์ม

- เข้าจาก **คอนเทนต์ › คำถามที่พบบ่อย** รายการเรียงตามหน้าแรก เดสก์ท็อปเปิดฟอร์มข้างรายการและเน้นข้อที่เลือก มือถือเปิดฟอร์มเต็มความกว้างโดยมีทางกลับรายการ
- **เพิ่มคำถาม** เปิดช่องว่างสองช่อง ต้องกรอกทั้งคำถามและคำตอบ คำตอบเป็นข้อความล้วนและขึ้นบรรทัดใหม่ได้ เมื่อกดบันทึกโดยกรอกไม่ครบ ให้แจ้งใต้ช่องที่ต้องแก้และย้ายโฟกัสไปยังช่องแรกที่มีปัญหา
- **บันทึก** ส่งต้นฉบับภาษาเดียว ระหว่างส่งให้แสดงสถานะกำลังบันทึกและป้องกันการกดซ้ำ หากบันทึกไม่สำเร็จ ให้เก็บข้อความที่กรอกไว้ในฟอร์มและให้ลองอีกครั้ง หน้าแรกยังใช้ข้อมูลที่บันทึกสำเร็จล่าสุด
- เมื่อบันทึกสำเร็จ ให้แจ้งผล เดสก์ท็อปเก็บข้อที่เลือกไว้ มือถือกลับรายการ ข้อเพิ่มใหม่ต่อท้ายรายการเป็นข้อเสนอของแบบรอบนี้ แก้คำตอบแล้วคงลำดับเดิม
- เมื่อมีการแก้ที่ยังไม่ได้บันทึก การเลือกข้ออื่น เปิดฟอร์มเพิ่ม เข้าจัดลำดับ หรือออกจากฟอร์มให้ถามก่อนทิ้งการแก้ไข **แก้ไขต่อ** กลับฟอร์มเดิมพร้อมข้อความที่กรอก **ทิ้งการแก้ไข** พาไปยังปลายทางที่เลือกไว้

## จัดลำดับและลบถาวร

- **จัดลำดับ** เปิดโหมดเรียงคำถามตาม [แบบจัดลำดับบทความ UID-012](../../uid-012/g4-review/interaction-spec.md#ปักหมุด-จัดลำดับ-และผลบนหน้าแรก) แต่ละแถวมีจุดจับทางซ้ายพร้อมเลขตำแหน่งปัจจุบัน ลากจุดจับเพื่อย้ายแถวหรือกดจุดจับเพื่อเปิดแผง **เลือกตำแหน่งคำถาม** ใช้แป้น Enter หรือ Space เปิดแผงได้ ปุ่มจุดจับระบุชื่อคำถามที่กำลังจัดลำดับ
- ระหว่างลากให้แสดงเส้นบอกตำแหน่งที่จะวาง แผงเลือกตำแหน่งแสดงชื่อคำถาม เลขปัจจุบัน และเลขปลายทาง กด **ย้ายไปตำแหน่ง …** เพื่อยืนยันการย้ายในรายการชั่วคราว การยกเลิกกลับไปที่จุดจับเดิมและคงลำดับก่อนเปิดแผง
- ก่อนย้ายใช้ **กลับ** เพื่อออกจากโหมดจัดลำดับ เมื่อย้ายแล้วให้คงโฟกัสที่จุดจับของคำถามเดิม แจ้งลำดับใหม่ และแสดง **ยกเลิก** กับ **บันทึกลำดับ**
- หน้าแรกใช้ลำดับเดิมจนกด **บันทึกลำดับ** สำเร็จ เมื่อบันทึกไม่สำเร็จให้คงลำดับที่กำลังแก้ไว้ให้ลองใหม่ **ยกเลิก** กลับไปยังลำดับที่บันทึกแล้ว
- **ลบถาวร** อยู่ในฟอร์มแก้ไข หน้าต่างยืนยันระบุชื่อคำถาม ผลต่อหน้าแรก และการกู้คืน ให้เริ่มโฟกัสที่ **ยกเลิก** และกด Escape เพื่อปิดได้ก่อนส่งคำสั่ง ระหว่างลบให้ป้องกันการส่งซ้ำ ถ้าลบไม่สำเร็จให้แจ้งในหน้าต่างเดิมและเก็บรายการไว้
- เมื่อลบสำเร็จ กลับรายการและแจ้งผล ย้ายโฟกัสไปยังคำถามที่อยู่ถัดจากตำแหน่งเดิม หรือคำถามก่อนหน้าหากลบข้อท้าย เมื่อลบข้อสุดท้ายให้แสดงหน้ารายการว่างและให้ **เพิ่มคำถาม** เป็นทางไปต่อ

## ผลบนหน้าแรก

- เพิ่มหรือแก้ไขสำเร็จแล้วให้ใช้ต้นฉบับล่าสุดทันที แสดงคำถามกับคำตอบเป็นคู่จากภาษาเดียวกัน หากคำแปลของต้นฉบับล่าสุดในภาษาที่เลือกยังไม่พร้อม ให้แสดงต้นฉบับทั้งคู่ เมื่อคำแปลพร้อม ให้ใช้คำแปลของต้นฉบับฉบับนั้น
- เปิดหน้าแรกโดยปิดคำตอบทุกข้อ และเปิดได้ทีละข้อ เมื่อไม่มีคำถามให้ซ่อนทั้งส่วน FAQ ส่วนบทความและท้ายหน้ายังต่อกันตามแบบหน้าแรก
- ทำตัวอย่างคำตอบยาวให้เห็นการตัดบรรทัด ทดสอบชื่อปุ่มเปิดและปิดสำหรับโปรแกรมอ่านหน้าจอและภาษาของเนื้อหาที่แสดงเมื่อทำระบบจริง
