## จุดที่ต้องการให้ตรวจ

- **รายการและฟอร์ม** เพิ่มและแก้คำถามผ่านช่องคำถามกับคำตอบภาษาเดียว เมื่อสลับข้อระหว่างแก้ค้าง แบบรอบนี้เสนอให้เลือกแก้ต่อหรือทิ้งการแก้ไข เมื่อเพิ่มสำเร็จให้ต่อท้ายรายการก่อนจัดลำดับใหม่ได้
- **จัดลำดับและลบ** ใช้ปุ่มเลื่อนขึ้นและลง แล้วกดบันทึกลำดับ หน้าแรกยังใช้ลำดับเดิมระหว่างรอ เมื่อลบให้ยืนยันโดยเห็นชื่อคำถามและผลต่อหน้าแรก หลังลบข้อสุดท้ายแบบแสดงทั้งรายการว่างในหลังบ้านและหน้าแรกที่เว้นส่วน FAQ
- **ภาษาและผลหลังบันทึก** หน้าแรกแสดงต้นฉบับล่าสุดเมื่อบันทึกสำเร็จและคำแปลยังไม่พร้อม ใช้คำแปลตามภาษาที่เลือกเมื่อต้นฉบับฉบับล่าสุดแปลเสร็จ เริ่มต้นด้วยคำตอบที่ปิดทั้งหมดและเปิดได้ทีละข้อ

ตรวจขนาดและขอบเขตเลเยอร์ในเฟรมทั้ง 36 รายการและดูภาพเรนเดอร์ตัวอย่างของฟอร์ม การจัดลำดับ หน้าต่างลบ และหน้าแรกที่แสดงต้นฉบับ ผลนี้ใช้ตรวจแบบนิ่ง ส่วนการกดคีย์บอร์ดจริง โปรแกรมอ่านหน้าจอ การบันทึก และการแปลอยู่ในรอบทดสอบระบบ
