# UID-013 · High-Fi G3-r5 ระบบจัดการคำถามที่พบบ่อย

**ภูอนุมัติ G3-r5 ทั้งชุด** · 18 พฤศจิกายน 2026 · 23 คู่ เดสก์ท็อป 1440 × 900 และมือถือ 390 × 844 [บันทึกอนุมัติ](owner-G3-r5-acceptance.json)

จัดฟอร์มมือถือใหม่ตามที่ภูขอให้ใช้พื้นที่จอและจัดตำแหน่งปุ่มให้ชัดเจน กลุ่มตรวจ `m9iMHK` อยู่ใน [Pencil](../../dsd-001/papaipak-ui.pen)

- ฟอร์มใช้ความกว้างของหน้า ช่องคำตอบใช้พื้นที่หลักของหน้าจอและจัดความสูงตามพื้นที่ที่เหลือ เมื่อมี Toast จึงเผื่อพื้นที่ใต้แถบหัวตามแบบ
- **ลบถาวร** อยู่ข้างหัวข้อแก้ไข ส่วน **ยกเลิก** และ **บันทึก** อยู่แถวเดียวในแถบคำสั่งท้ายหน้า อ้างอิงแถบคำสั่งบนมือถือจาก [UID-012 G4-r1](../../uid-012/g4-review/README.md)
- กล่องยืนยันแสดงทับฟอร์มและแถบคำสั่ง เมื่อมีข้อผิดพลาดให้แสดงที่ฟอร์มหรือในกล่องของคำสั่งเดิม
