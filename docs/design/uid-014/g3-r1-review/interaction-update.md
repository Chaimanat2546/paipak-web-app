# UID-014 · บทความแนะนำบนหน้าโหลดไม่สำเร็จ

ภูขอเพิ่มทางอ่านบทความอื่นในสถานะโหลดไม่สำเร็จ พร้อมอนุมัติ [Wireframe G2-r3](../g2-r3-review/owner-G2-r3-acceptance.json) ให้ใช้ [สเปก G2-r3](../g2-r3-review/interaction-spec.md) ร่วมกับรายละเอียดด้านล่าง

| เงื่อนไข | แบบ G3-r1 |
| --- | --- |
| บทความหลักโหลดไม่สำเร็จและรายการแนะนำพร้อม | แสดงสถานะ **โหลดบทความไม่สำเร็จ** ตามด้วยปุ่ม **ลองอีกครั้ง** และ **กลับหน้าแรก** แล้วแสดง **บทความแนะนำ** ใต้ส่วนสถานะตาม F-05 |
| มีบทความแนะนำที่เปิดอ่านได้ | ใช้กติกาเดียวกับหน้าอ่าน เรียงวันที่เผยแพร่ฉบับล่าสุด เลือกเรื่องอื่นสูงสุด 2 เรื่องและข้ามเรื่องที่ผู้ชมพยายามเปิด ถ้าเหลือหนึ่งเรื่องแสดงหนึ่งใบในตำแหน่งแรก |
| รายการแนะนำไม่มีเรื่องที่พร้อมแสดงหรือโหลดไม่ได้ | ยุบส่วนบทความแนะนำ ผู้ชมยังลองโหลดบทความเรื่องเดิมหรือกลับหน้าแรกได้ตาม F-10 |
| กดลองอีกครั้ง | โหลดบทความตามลิงก์เดิมและแสดง F-06 ระหว่างรอ เมื่อได้ผลให้เปลี่ยนเป็นหน้าอ่านหรือสถานะที่ตรงกับผล |
| กดบทความแนะนำ | เปิดหน้าอ่านของเรื่องที่เลือก |

## จุดตรวจเมื่อมีหน้าใช้งาน

- ยืนยันว่าการโหลดรายการแนะนำให้ผลแยกจากการโหลดบทความหลัก เพื่อให้ F-05 แสดงลิงก์อ่านต่อได้ตามข้อมูลที่พร้อม
- ตรวจลำดับอ่านและโฟกัสจากข้อความสถานะ → ลองอีกครั้ง → กลับหน้าแรก → การ์ดบทความแนะนำ รวมถึงการแจ้งผลหลังลองใหม่
- ตรวจว่าบทความที่เปิดอยู่ถูกข้าม แม้คำขอโหลดรายละเอียดเรื่องนั้นไม่สำเร็จ
