## สิ่งที่ตรวจในแบบละเอียด

- **หน้าอ่านแนวนิตยสาร** ใช้ Mitr กับอักษรกรมท่าบนพื้นขาว ยึดส่วนหัวและท้ายหน้า r1 จากแบบที่อนุมัติ เดสก์ท็อปให้รูปปกอยู่ในคอลัมน์อ่านเมื่อมีบ้านพักด้านขวา แล้วใช้ภาพในเนื้อหาช่วยแบ่งจังหวะการอ่าน
- **ความต่อเนื่องบนมือถือ** อ่านหัวเรื่องและปกก่อน สารบัญเริ่มแบบพับ บ้านพักที่แนบและบทความแนะนำเรียงหลังเนื้อหา การ์ดแนะนำใช้ภาพย่อข้างชื่อเรื่อง
- **หน้าโหลดไม่สำเร็จ** วาง **ลองอีกครั้ง** และ **กลับหน้าแรก** ก่อนส่วนบทความแนะนำ ใช้การ์ดแบบเดียวกับหน้าอ่าน เมื่อข้อมูลรายการแนะนำพร้อมให้แสดงบทความล่าสุดเรื่องอื่นสูงสุด 2 เรื่อง แบบ F-10 แสดงกรณีไม่มีบทความแนะนำให้แสดง

ชุดตรวจรวม 20 เฟรม ใช้ชื่อและภาพบ้านพักตัวอย่างจากไฟล์ออกแบบของโครงการ ตรวจภาพที่ส่งออกและขนาดหน้าจออ้างอิงแล้ว การกดลิงก์ ลองใหม่ และการใช้งานผ่านคีย์บอร์ดหรือโปรแกรมอ่านหน้าจอเป็นรายการตรวจเมื่อมีหน้าใช้งานจริง
