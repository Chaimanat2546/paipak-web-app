# UID-014 · ความสูงการ์ดบทความแนะนำ G3-r4

- บนเดสก์ท็อปที่วางการ์ดบทความแนะนำสองใบในแถวเดียวกัน ให้แถวสูงตามการ์ดที่มีชื่อเรื่องยาวที่สุด การ์ดทั้งสองใช้ความสูงของแถวร่วมกันและแสดงชื่อเรื่องเต็ม
- ภาพปกสองใบใช้ความสูงเท่ากัน ชื่อเรื่องและลูกศรจัดแนวด้านบนของพื้นที่ข้อความด้วยระยะขอบเท่ากัน
- ใช้กับแถวบทความแนะนำในหน้าอ่านและหน้าโหลดไม่สำเร็จ
