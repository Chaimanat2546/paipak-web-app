# UID-014 · หน้ารายละเอียดบทความ · ชุดส่งมอบ G4-r1

20 พฤศจิกายน 2026 (เวลาไทย) · **ภูอนุมัติ G4-r1 ทั้งเดสก์ท็อปและมือถือ และให้ปิดงานออกแบบ** [บันทึกอนุมัติ](owner-G4-r1-acceptance.json)

ชุดนี้รวมภาพที่ใช้ส่งมอบครบ 20 เฟรมและ [สเปกการใช้งานฉบับเดียว](interaction-spec.md) เปิด [ไฟล์ Pencil หลัก](../../dsd-001/papaipak-ui.pen) ที่ section **UID-014 · หน้ารายละเอียดบทความ** (`DfjX9`) ด้านซ้ายเป็น Wireframe G2-r3 (`Y720PF`) ด้านขวาเป็น Hi-Fi G4-r1 (`YwLah`) เรียง F-01 ถึง F-11 โดยใช้กรอบมือถือคอลัมน์เดียวกัน
