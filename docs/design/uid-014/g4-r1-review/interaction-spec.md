# UID-014 · สเปกการใช้งานและส่งมอบ G4-r1

อ้างอิง [ชุดภาพ G4-r1](README.md), [Wireframe G2-r3](../g2-r3-review/owner-G2-r3-acceptance.json) และ [คำอนุมัติ High-Fi G3-r9](../g3-r9-review/owner-G3-r9-acceptance.json)

## ทางเข้าและฉบับเผยแพร่

- ผู้ชมอ่านได้จากการ์ดบทความบนหน้าแรกหรือจากลิงก์ตรงโดยไม่ต้องเข้าสู่ระบบ การ์ดหน้าแรกเปิดเรื่องที่เลือกจาก [Home G4-r1](../../dsd-001/home-g4-r1/README.md)
- ชื่อ รูปปก เนื้อหา และรหัสบ้านที่แนบใช้ฉบับเผยแพร่ชุดเดียวกัน ผู้ชมเห็นการแก้ไขเมื่อเผยแพร่ฉบับใหม่สำเร็จ การยกเลิกเผยแพร่เปลี่ยนทางเข้าลิงก์เดิมเป็นสถานะ F-04
- เปิดด้วยชื่อเรื่องแล้วตามด้วยรูปปก ใช้วันที่เผยแพร่ฉบับล่าสุดเพื่อเรียงบทความแนะนำ แสดงย่อหน้า หัวข้อย่อย และภาพในเนื้อหาตามลำดับฉบับเผยแพร่

## โครงหน้าและสารบัญ

| องค์ประกอบ | เดสก์ท็อป 1440 พิกเซล | มือถือ 390 พิกเซล |
| --- | --- | --- |
| ชื่อเรื่องและรูปปก | เมื่อมีบ้านพักทางขวา ชื่อเรื่องใช้ความกว้างรวม 1,032 พิกเซล รูปปก 16:9 อยู่ในคอลัมน์อ่านซ้ายกว้าง 680 พิกเซล | ชื่อเรื่องและปกอยู่ในคอลัมน์เดียว เว้นขอบอ่านด้านละ 20 พิกเซล |
| บ้านพักในบทความ | คอลัมน์ขวากว้าง 312 พิกเซล ห่างจากคอลัมน์อ่าน 40 พิกเซล เริ่มตรงขอบบนปกและเลื่อนไปกับหน้า | อยู่หลังเนื้อหาและก่อนบทความแนะนำ |
| ไม่มีบ้านที่เปิดดูได้ | ยุบคอลัมน์บ้านพัก จัดคอลัมน์อ่านอยู่กลางหน้า และใช้รูปปกกว้างเหนือคอลัมน์อ่านตาม F-02 | จากเนื้อหาต่อไปยังบทความแนะนำถ้ามี แล้วจึงส่วนท้ายหน้า |
| รูปปกโหลดไม่ได้ | ยุบพื้นที่ปกเมื่อข้อมูลบทความพร้อม บทนำต่อจากชื่อเรื่อง และบ้านพักเริ่มข้างบทนำ | ยุบพื้นที่ปกและแสดงบทนำต่อจากชื่อเรื่องทันที |

ชื่อเรื่องแสดงเต็มและขึ้นบรรทัดตามพื้นที่ F-08 เป็นช่วงต้นหน้าที่ 360 พิกเซล หากพื้นที่วางสองคอลัมน์ไม่พอ ให้เรียงเนื้อหา บ้านพัก และบทความแนะนำตามลำดับมือถือ

แสดงสารบัญหลังบทนำเมื่อฉบับเผยแพร่มีหัวข้อหลักตั้งแต่ 3 หัวข้อ ใช้ชื่อและลำดับหัวข้อในบทความ เดสก์ท็อปเปิดรายการทันที มือถือเริ่มพับและกดเปิดหรือพับได้ เมื่อเลือกชื่อหัวข้อให้เลื่อนและย้ายโฟกัสไปยังหัวข้อนั้นโดยเว้นพื้นที่ให้พ้นส่วนหัวหน้า

## บ้านพักในบทความ

- แสดงบ้านพักทุกหลังที่แนบไว้ในฉบับเผยแพร่และเปิดหน้าได้ โดยคงลำดับที่บันทึกไว้ เมื่อไม่มีบ้านที่เปิดดูได้ให้ซ่อนทั้งหัวข้อและรายการ
- ใช้รูปปก ชื่อ ทำเล จำนวนผู้เข้าพักสูงสุด ห้องนอน ห้องน้ำ และราคาเริ่มต้นต่อคืนของรหัสบ้านเดียวกัน ทั้งการ์ดเป็นลิงก์เดียวไปหน้ารายละเอียดบ้าน ใช้แนวนำเสนอการ์ดและข้อมูลที่ขาดตาม [UID-002](../../uid-002/g4-r1-review/implementation-reference.md)
- แสดงไอคอนและจำนวนห้องน้ำเมื่อจำนวนมากกว่า 0 ถ้าจำนวนเป็น 0 หรือข้อมูลขาด ให้ยุบชุดข้อมูลห้องน้ำทั้งหมดตาม [กติกาการ์ดบ้านพัก r1](../../uid-002/card-bathroom-visibility-r1/README.md)
- แบบใช้ข้อมูล **Celuna (DV-9)** และ **RimLay (DV-55)** จาก [ชุดตรวจ Property Detail](../../uid-003/property-detail-r31-checklist/README.md) รูปและตัวเลขอ้างอิง [รายการตัวอย่างที่ตรวจแล้ว](../g3-r5-review/interaction-update.md)

## บทความแนะนำ

- เลือกบทความอื่นที่มีฉบับเผยแพร่และเปิดอ่านได้ ข้ามเรื่องปัจจุบัน ตัดรายการซ้ำ และเรียงวันที่เผยแพร่ฉบับล่าสุดจากใหม่ไปเก่าแบบเดียวกับเกณฑ์วันที่ของ [UID-012](../../uid-012/g4-review/interaction-spec.md)
- เลือกสองเรื่องแรกหลังคัดรายการ ถ้ามีเรื่องเดียวแสดงหนึ่งรายการ ถ้าไม่มีรายการพร้อมแสดงให้ยุบทั้งส่วน
- วางหลังเนื้อหา จอกว้างใช้สองคอลัมน์เท่ากัน ในตัวอย่าง 1440 พิกเซลใช้คอลัมน์ละ 328 พิกเซล ช่องว่าง 24 พิกเซล ถ้ามีเรื่องเดียวเริ่มในคอลัมน์ซ้าย จอแคบเรียงหนึ่งคอลัมน์
- รูปย่ออยู่ซ้าย ชื่ออยู่ขวา แท็กหัวข้อหนึ่งรายการอยู่ใต้ชื่อเมื่อมีข้อมูล ทั้งรายการเป็นลิงก์เดียวไปหน้าอ่านและใช้ชื่อเรื่องเป็นชื่อของลิงก์ รูปแบบใช้ทั้งท้ายหน้าอ่านและหน้าโหลดไม่สำเร็จ

## สถานะและทางไปต่อ

| สถานะ | สิ่งที่ผู้ชมเห็นและทำต่อได้ |
| --- | --- |
| F-06 · เปิดครั้งแรกหรือกำลังลองใหม่ | แสดง Skeleton ของหัวเรื่อง ปก และย่อหน้าในพื้นที่บทความ ใช้ข้อความสถานะที่ซ่อนไว้จากภาพสำหรับโปรแกรมอ่านหน้าจอ |
| F-04 · ไม่พบหรือยกเลิกเผยแพร่ | แสดงไอคอน หัวข้อ **ไม่พบบทความนี้** ข้อความอธิบาย และ **กลับหน้าแรก** กลางพื้นที่สีขาวของหน้า |
| F-05 · โหลดรายละเอียดไม่สำเร็จ และมีเรื่องแนะนำพร้อม | แสดง **โหลดบทความไม่สำเร็จ** กลางพื้นหน้า พร้อม **ลองอีกครั้ง** และ **กลับหน้าแรก** จากนั้นแสดงบทความแนะนำ |
| F-10 · โหลดรายละเอียดไม่สำเร็จ และรายการแนะนำไม่พร้อม | แสดงข้อความสถานะและปุ่มทั้งสองตาม F-10 |

ปุ่ม **ลองอีกครั้ง** โหลดบทความตามลิงก์เดิม ระหว่างรอใช้ F-06 เมื่อได้ผลจึงแสดงหน้าอ่านหรือสถานะที่ตรงกับผล การใช้รายการแนะนำใน F-05 ขึ้นกับผลที่พร้อมของรายการนั้นแยกจากรายละเอียดหลัก

## ประเด็นส่งต่อก่อนเปิดใช้จริง

- ยืนยันสัญญาข้อมูลสำหรับลิงก์ประจำบทความ ฉบับเผยแพร่ รูปในเนื้อหา คำอธิบายภาพ ระดับหัวข้อ และแหล่งข้อมูลแท็ก รวมถึงการเลือกแท็กเมื่อมีหลายค่าและการเรียงกรณีเวลาเผยแพร่เท่ากัน
- ตรวจตั้งแต่ลิงก์หน้าแรกและลิงก์ตรง การยกเลิกเผยแพร่ การโหลดข้อมูลหลักและรายการแนะนำแยกกัน ไปจนถึงการลองใหม่และการเปิดบ้านตามรหัส
- ตรวจลำดับโฟกัสและโฟกัสที่มองเห็นได้ ลิงก์รายการและปุ่มต้องใช้คีย์บอร์ดและสัมผัสได้ ตรวจชื่อที่โปรแกรมอ่านหน้าจออ่าน การแจ้งสถานะ และการขยายตัวอักษรบนจอแคบ
- ใช้เฟรม 1440, 390 และ 360 พิกเซลเป็นหลักฐานแบบ ตรวจการเปลี่ยนคอลัมน์เมื่อพื้นที่เปลี่ยนและการตัดบรรทัดด้วยเนื้อหาจริงในรอบหน้าใช้งาน
