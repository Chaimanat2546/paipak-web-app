# UID-014 · สเปก Wireframe G2-r1

ข้อเสนอสำหรับตรวจรับ ใช้คู่กับ [ชุดภาพเดสก์ท็อปและมือถือ](README.md)

## ทางเข้าหน้าอ่านและทางออก

- คลิกการ์ดบทความบนหน้าแรกหรือเปิดลิงก์ตรง ในทั้งสองกรณีผู้ชมเข้าถึงฉบับที่เผยแพร่อยู่ได้โดยไม่ต้องเข้าสู่ระบบ
- ใช้ชื่อ รูปปก เนื้อหา และรายการบ้านพักที่แนบของฉบับเดียวกัน การบันทึกร่างของเรื่องที่เผยแพร่อยู่จะยังใช้ฉบับเผยแพร่เดิม เมื่อยกเลิกเผยแพร่สำเร็จ การเปิดลิงก์เดิมใช้ F-04
- ผู้ชมกลับหน้าแรกจากส่วนหัวหรือท้ายหน้าได้ การเลือกบ้านพักที่แนบเปิดหน้ารายละเอียดบ้านหลังนั้นตามทางเข้า UID-003

## องค์ประกอบและพฤติกรรม

| องค์ประกอบ | แบบและพฤติกรรม |
| --- | --- |
| ชื่อและรูปปก | ชื่อเรื่องเป็นหัวข้อหลักของหน้า ตัดบรรทัดตามพื้นที่และแสดงชื่อเต็ม ปก 16:9 บนเดสก์ท็อปกว้างกว่าคอลัมน์อ่าน ส่วนมือถือกว้างเท่าพื้นที่เนื้อหา |
| เนื้อหาฉบับเต็ม | แสดงย่อหน้า หัวข้อย่อยและภาพตามลำดับต้นฉบับ เนื้อหาจัดเป็นคอลัมน์เดียวทั้งสองขนาด ข้อความรูปใช้คำอธิบายของภาพเมื่อภาพช่วยสื่อเนื้อหา |
| สารบัญ | เสนอให้ใช้หัวข้อหลักของบทความตามลำดับเดิมเมื่อมีอย่างน้อย 3 หัวข้อ แสดงก่อนหัวข้อแรกหลังบทนำ มือถือเริ่มแบบพับ ปุ่มเดิมใช้เปิดและพับโดยคงโฟกัสไว้ที่ปุ่ม รายการแต่ละข้อเป็นลิงก์ไปหัวข้อนั้น เมื่อเลือกให้เลื่อนและย้ายโฟกัสไปหัวข้อปลายทาง โดยเว้นระยะให้พ้นส่วนหัวเว็บไซต์ |
| บ้านพักที่แนบ | แสดงท้ายเรื่องเมื่อมีบ้านที่เปิดดูได้ แสดงเฉพาะบ้านที่เปิดดูได้ตามลำดับจากฉบับเผยแพร่ แต่ละการ์ดเป็นลิงก์เดียว เดสก์ท็อปวางคู่ มือถือเรียงลงหนึ่งใบต่อแถว เมื่อไม่มีบ้านที่เปิดดูได้ ให้บทความจบแล้วต่อส่วนท้ายเว็บไซต์ |

## สถานะหน้า

| เมื่อเกิดเหตุ | ผลที่ผู้ชมเห็นและทำต่อได้ |
| --- | --- |
| กำลังเปิดบทความ | โครงหัวเรื่อง ปก และเนื้อหาตาม F-06 ระบุสถานะกำลังโหลดผ่านข้อความ |
| รูปปกโหลดไม่สำเร็จ แต่ข้อมูลบทความพร้อม | ใช้ F-03 ยุบพื้นที่ปก เนื้อหาและส่วนเสริมที่เข้าเงื่อนไขยังอ่านต่อได้ |
| ไม่พบเรื่อง หรือเรื่องไม่มีฉบับเผยแพร่ | ใช้ F-04 แสดงข้อความกลางและลิงก์กลับหน้าแรก |
| ข้อมูลบทความโหลดไม่สำเร็จ | ใช้ F-05 แสดงปุ่ม **ลองอีกครั้ง** ซึ่งโหลดเรื่องเดิมและกลับ F-06 ระหว่างรอ เมื่อรู้ผลจึงไปหน้าอ่าน, F-04 หรือ F-05 ตามจริง |

## จุดตรวจรอบถัดไป

- ภูเลือกได้ว่าจะใช้เงื่อนไขสารบัญตั้งแต่ 3 หัวข้อและเริ่มพับบนมือถือหรือปรับเกณฑ์ในการตรวจ G2-r1
- สเปกข้อมูลสำหรับชนิดเนื้อหา รูปในบทความ คำอธิบายภาพ และหัวข้อที่ใช้สร้างสารบัญต้องยืนยันก่อนพัฒนา
- ลำดับ Tab วิ่งตามเนื้อหา การ์ดบ้านแต่ละใบมีชื่อบ้านเป็นชื่อของลิงก์ และแสดงจุดโฟกัสชัดเจน ตรวจการเปลี่ยนสถานะการโหลดกับโปรแกรมอ่านหน้าจอ จังหวะคืนโฟกัสหลังลองใหม่ และการอ่านที่ขนาดตัวอักษรขยายในขั้นหน้าใช้งานจริง
