## จุดตรวจ

- **เริ่มอ่านได้เร็ว** F-01 วางชื่อก่อนปก ต้นคอลัมน์อ่านกว้าง 680 พิกเซลที่เดสก์ท็อป เทียบกับปกกว้าง 960 พิกเซล ที่มือถือขอบอ่าน 20 พิกเซลทั้งสองด้านและเรียงเนื้อหาลงมา บทความใช้ข้อมูลตัวอย่างสำหรับตรวจความยาวและลำดับอ่าน
- **สารบัญตามเนื้อหา** ข้อเสนอ G2 ให้แสดงเมื่อมีหัวข้อหลักอย่างน้อย 3 หัวข้อ เดสก์ท็อปเห็นรายการทันที ส่วนมือถือเริ่มแบบพับแล้วแตะเปิดได้ในหน้า F-01, F-02 และ F-07 แสดงสามกรณีนี้
- **อ่านต่อได้เมื่อรูปมีปัญหา** F-03 ยุบพื้นที่ปกหลังรู้ว่าโหลดไม่ได้ F-02 แสดงการจบเรื่องเมื่อไม่มีบ้านพักที่เปิดดูได้
- **แยกทางออกจากทางลองใหม่** F-04 ให้กลับหน้าแรก F-05 ให้ลองเปิดบทความเดิมอีกครั้ง โดยใช้ F-06 ระหว่างรอผล

ตรวจภาพจาก Pencil และตรวจขอบเขตองค์ประกอบของทั้ง 14 เฟรมโดยไม่พบส่วนที่ล้นกรอบ สารบัญ การนำทาง การลองใหม่ และการใช้งานผ่านคีย์บอร์ดหรือโปรแกรมอ่านหน้าจอระบุไว้ใน [สเปกการใช้งาน](interaction-spec.md) สำหรับตรวจเมื่อมีหน้าใช้งานจริง
