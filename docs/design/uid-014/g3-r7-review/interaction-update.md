# UID-014 · แท็กบทความแนะนำ G3-r7

- แสดงแท็กหัวข้อหนึ่งรายการใต้ชื่อเรื่องเมื่อมีข้อมูล ทั้งในหน้าอ่านและหน้าโหลดไม่สำเร็จ แถวที่มีเฉพาะรูปกับชื่อใช้ [รูปแบบ G3-r6](../g3-r6-review/README.md)
- แท็กเป็นข้อความประกอบในแถวลิงก์เดียวกัน กดตรงรูป ชื่อ หรือแท็กแล้วเปิดบทความเรื่องเดียวกัน
