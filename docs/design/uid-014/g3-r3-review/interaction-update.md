# UID-014 · การจัดวางหัวเรื่องและบ้านพักบนเดสก์ท็อป

- เมื่อหน้าอ่านมีคอลัมน์บ้านพักทางขวา ให้ชื่อเรื่องเริ่มแนวเดียวกับคอลัมน์อ่านและใช้ความกว้างรวมสองคอลัมน์ ชื่อเรื่องที่ยาวขึ้นตัดบรรทัดตามพื้นที่และแสดงครบ
- รูปปกอยู่ภายในคอลัมน์อ่านซ้าย คอลัมน์ขวาเริ่มด้วยหัวข้อ **บ้านพักในบทความ** ตามด้วยรายการบ้าน หากรูปปกโหลดไม่ได้ให้บทนำเริ่มต่อจากชื่อเรื่อง และบ้านพักเริ่มข้างบทนำ
- ใช้ [สเปก G2-r3](../g2-r3-review/interaction-spec.md), [ข้อเพิ่มหน้าโหลดไม่สำเร็จ](../g3-r1-review/interaction-update.md) และ [สถานะ Skeleton](../g3-r2-review/interaction-update.md) ประกอบการตรวจ
