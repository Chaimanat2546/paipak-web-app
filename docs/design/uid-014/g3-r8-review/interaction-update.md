# UID-014 · คอลัมน์บทความแนะนำ G3-r8

- จอกว้างวางรายการบทความแนะนำสองคอลัมน์ที่กว้างเท่ากัน เมื่อมีเรื่องเดียวให้แสดงในคอลัมน์ซ้าย จอแคบเรียงหนึ่งคอลัมน์ตามลำดับจากล่าสุดไปเก่าสุด
- แต่ละรายการใช้รูปย่อด้านซ้ายและข้อความด้านขวา ชื่อเรื่องขึ้นบรรทัดตามพื้นที่และแท็กอยู่ใต้ชื่อ
- ใช้รูปแบบนี้ทั้งหน้าอ่านและหน้าโหลดไม่สำเร็จ แต่ละรายการยังเป็นลิงก์เดียวไปหน้าอ่านตาม [กติกาของรายการ](../g3-r6-review/interaction-update.md) และ [กติกาแท็ก](../g3-r7-review/interaction-update.md)
