# UID-014 · สถานะ Skeleton G3-r2

- ใช้ F-06 ฉบับ G3-r2 ทั้งเดสก์ท็อปและมือถือ ระหว่างเปิดบทความครั้งแรกและระหว่างกดลองโหลดบทความเดิมอีกครั้ง พื้นที่บทความแสดงโครงหัวเรื่อง รูปปก และย่อหน้า
- เมื่อมีหน้าใช้งาน ให้โปรแกรมอ่านหน้าจอรับรู้สถานะกำลังโหลดผ่านข้อความที่ซ่อนไว้จากภาพ และระบุ Skeleton เป็นองค์ประกอบตกแต่ง
- เมื่อได้ผลให้แสดงบทความหรือสถานะที่ตรงกับผลตาม [สเปก G2-r3](../g2-r3-review/interaction-spec.md) และ [สเปกหน้าโหลดไม่สำเร็จ G3-r1](../g3-r1-review/interaction-update.md)
