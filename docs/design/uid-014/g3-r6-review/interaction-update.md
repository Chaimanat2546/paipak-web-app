# UID-014 · รายการบทความแนะนำ G3-r6

- ทั้งเดสก์ท็อปและมือถือแสดงหนึ่งเรื่องต่อแถว รูปย่อยึดขนาดตามจอ ชื่อเรื่องเริ่มที่ขอบบนด้านขวาของรูปและตัดบรรทัดได้ตามพื้นที่
- แต่ละแถวใช้รูปปกและชื่อเรื่องจากบทความฉบับเผยแพร่เดียวกัน ทั้งแถวเป็นลิงก์เดียวไปหน้าอ่าน และใช้ชื่อเรื่องเป็นชื่อของลิงก์
- ใช้รูปแบบนี้ทั้งท้ายบทความและใต้ข้อความสถานะในหน้าโหลดไม่สำเร็จ กติกาเรียงวันที่เผยแพร่ฉบับล่าสุด จำนวนสูงสุดสองเรื่อง และกรณีไม่มีเรื่องที่แสดงได้ ใช้ตาม [สเปก G2-r3](../g2-r3-review/interaction-spec.md) และ [ข้อเพิ่มหน้าโหลดไม่สำเร็จ](../g3-r1-review/interaction-update.md)
