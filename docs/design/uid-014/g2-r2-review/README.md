# UID-014 · หน้ารายละเอียดบทความ · Wireframe G2-r2

20 พฤศจิกายน 2026 (เวลาไทย) · ชุดก่อนแก้ตำแหน่งรูปปก ใช้ [G2-r3](../g2-r3-review/README.md) สำหรับการตรวจรับปัจจุบัน

> ไปจัดหน้าใหม่ด้วยขาดส่วน การแนะนำบทความอื่นๆแล้วก็อยากได้บ้านพักอยู่ขวามือมากกว่า

ภาพด้านล่างเป็นหลักฐานของ G2-r2 บอร์ดร่างถูกนำออกจากไฟล์ Pencil หลักเมื่อรวมชุดใช้งานจริงของ UID-014 ดู [Wireframe G2-r3 ที่อนุมัติ](../g2-r3-review/README.md) สำหรับแบบอ้างอิงปัจจุบัน

## สิ่งที่เห็นในแบบ

- **เดสก์ท็อป** รูปปกอยู่เหนือทั้งสองคอลัมน์ เนื้อหาอยู่ซ้ายกว้าง 680 พิกเซล และ **บ้านพักในบทความ** อยู่ขวากว้าง 312 พิกเซล เริ่มข้างบทนำและเลื่อนไปพร้อมหน้า เมื่อไม่มีบ้านพักที่เปิดดูได้ ให้จัดคอลัมน์อ่านกลางหน้าอย่าง F-02
- **มือถือ** อ่านเนื้อหาจนจบ แล้วเห็น **บ้านพักในบทความ** ตามด้วย **บทความแนะนำ** การ์ดแนะนำเป็นแถวแนวนอนขนาดกะทัดรัด อ่านชื่อได้โดยแตะทั้งการ์ด
- **บทความแนะนำ** อยู่ท้ายคอลัมน์อ่าน แสดงเรื่องอื่นตามวันที่เผยแพร่ฉบับล่าสุดได้สูงสุด 2 เรื่อง หากมีเรื่องเดียวให้แสดงใบเดียว และซ่อนส่วนนี้เมื่อไม่มีเรื่องที่เปิดอ่านได้ตาม F-09
- **สารบัญและสถานะการเปิดบทความ** ภูยืนยันกติกาในสเปกแล้ว สารบัญเริ่มที่ 3 หัวข้อหลัก ส่วนกรณีกำลังโหลด ไม่พบ และโหลดไม่สำเร็จ ใช้ F-04 ถึง F-06

ชุดตรวจมีภาพแก้และภาพเพิ่ม 8 เฟรม รวมกับ [กรณีไม่พบ โหลดไม่ได้ กำลังโหลด สารบัญเปิด และชื่อเรื่องยาว](../g2-r1-review/README.md) จากรอบก่อนเป็น 16 เฟรม ภาพข้อมูลตัวอย่างใช้ตรวจโครงหน้าและลำดับการอ่าน
