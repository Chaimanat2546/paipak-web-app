# แบบ UI หลังบ้าน G4-r4 ที่อนุมัติ

**อนุมัติแล้ว** · 18 พฤศจิกายน 2026 · UID-010, UID-011 และ UID-013 [บันทึกผลอนุมัติ](owner-G4-r4-acceptance.json)

เปิด [ไฟล์ Pencil หลัก](../dsd-001/papaipak-ui.pen) ที่ section หมวดหมู่ `jNYEs` คลิป TikTok `FvFoc` และ FAQ `nev4k` แบบเดสก์ท็อปที่อนุมัติรวม 47 เฟรม อยู่คู่กับแบบมือถือ หน้าแรก และขั้นตอนที่ยังใช้ [รายการเฟรม G4-r4](review-manifest.json)

## จุดที่แก้

- จัดรูปย่อหมวดให้อยู่ในช่องไอคอนด้านซ้าย เว้นระยะจากชื่อและสถานะแสดงผล
- ใช้ปุ่ม **บันทึกลำดับ** สีเทาก่อนย้ายหมวด และแสดงวงหมุนหลังส่งบันทึก
- ใช้ชื่อ ลำดับ และตำแหน่งเมนูหลังบ้านชุดเดียวกัน ปุ่ม **ดูเว็บไซต์** อยู่ด้านบนข้างปุ่มเพิ่มรายการ
- ใช้เส้นขอบสี `#6B7280` ที่ช่องชื่อหมวด ช่องลิงก์ และชื่อคลิป ตามแบบฟอร์ม FAQ
- ย้ายข้อความหลังจัดลำดับคลิปและข้อความเมื่อบันทึกไม่สำเร็จมาอยู่ใกล้ **บันทึกลำดับ**
- ใส่ไอคอนเตือนและลดระยะก่อนแถวปุ่มในกล่องลบหมวดและกล่องเตือนการแสดง 7 คลิป
