## จุดที่ขอให้ภูตรวจ

- ชนิดบัญชีที่เห็นปุ่มจัดการรหัสผ่าน และทางไปกู้รหัสผ่านจากในบัญชี
- การใช้รหัสจากอีเมลบัญชีก่อนขอเปลี่ยนข้อมูลในตัวอย่าง กับการใช้รหัสจากอีเมลใหม่เพื่อยืนยันอีเมลใหม่
- แบบเพิ่มและเปลี่ยนเบอร์เริ่มจากยืนยันตัวตน แล้วจบที่ปุ่มถัดไป วิธีตรวจสอบว่าเบอร์ใหม่เป็นของสมาชิกเป็นจุดรอสรุปตามขอบเขต G0
- ตัวอย่างแสดงสถานะสำเร็จ รหัสไม่ถูกต้อง หมดอายุ และส่งไม่สำเร็จ การยืนยันสิทธิ์และการอัปเดตข้อมูลจริงยังรอทดสอบกับระบบ

ตรวจภาพส่งออกครบ 32 เฟรมจาก 16 กรณีแล้ว รวมการจัดเมนูบัญชีและช่อง OTP บนมือถือ การแสดงข้อความใต้ช่อง และการแสดงอีเมลใหม่หลังเปลี่ยนสำเร็จ
