# UID-005 · Toast ตำแหน่งเดียวกับหลังบ้าน · G2-r11

20 พฤศจิกายน 2026 · ภูตรวจรับตำแหน่งในภาพทั้งสองขนาดแล้ว [บันทึกตรวจรับตำแหน่ง G2-r11](owner-g2-r11-placement-acceptance.json)

หลังระบบยืนยันว่าบันทึกสำเร็จ ให้กลับโหมดดูและขึ้น Toast **บันทึกข้อมูลส่วนตัวแล้ว** วางตำแหน่งตาม [สเปค Toast ระบบหลังบ้าน](../../admin-category-g4-r1/README.md#องค์ประกอบและสเปค)

| ขนาดจอ | ตำแหน่ง | ภาพ |
| --- | --- | --- |
| เดสก์ท็อป 1440 × 900 | มุมขวาบน เว้นขอบบน 10 และขวา 18 พิกเซลตาม [ตัวอย่างหลังบ้าน](../../admin-category-mockup-r1/VDWFK.png) | [ดูภาพ](S7ZS3.png) |
| มือถือ 390 × 844 | ลอยใต้แถบหัวของหน้าโปรไฟล์ เว้นข้าง 16 และห่างจากแถบหัว 10 พิกเซล | [ดูภาพ](DnAR8.png) |

Toast ปิดเองหลังแสดง **5 วินาที** ทั้งสองขนาด ผู้ใช้กด **×** เพื่อปิดก่อนได้ ภาพเดสก์ท็อปมี Toast ซ้อนบางส่วนของเมนูด้านขวา ภาพมือถือมี Toast ซ้อนหัวข้อหน้า ตำแหน่งขณะเลื่อนและการนับเวลาจะตรวจบนหน้าที่ใช้งานได้ [บันทึกรับเวลาปิด G2-r11](owner-g2-r11-dismiss-timing-acceptance.json)
