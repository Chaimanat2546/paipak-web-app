# การบันทึกโปรไฟล์และจัดการเบอร์แยกหน้า · G2-r1

UID-005 · ร่างรอตรวจรับ · [ข้อสรุปของภู](owner-scope-decision.json)

| จุดใช้งาน | พฤติกรรมตามแบบ |
| --- | --- |
| ดูและแก้ไขข้อมูลส่วนตัว | แสดงเบอร์ล่าสุดที่ยืนยันแล้ว หรือข้อความ **ยังไม่ได้เพิ่มเบอร์** ตามบัญชี ปุ่ม **บันทึกข้อมูล** ใช้บันทึกชื่อจริง นามสกุล และชื่อผู้ใช้ |
| ไปหน้าจัดการเบอร์ | เปิดเมนูบัญชี **การเข้าสู่ระบบ** ในหน้าแก้ไขโปรไฟล์เมื่อยังไม่มีเบอร์มีข้อความชี้ทางใต้ข้อมูลเบอร์ เพื่อให้หาเมนูได้ |
| เพิ่มหรือเปลี่ยนเบอร์ | หน้า **การเข้าสู่ระบบและความปลอดภัย** แสดง **เพิ่มเบอร์โทร** เมื่อยังไม่มีเบอร์ หรือ **เปลี่ยนเบอร์โทร** เมื่อมีเบอร์ ผู้ใช้ทำขั้นยืนยันบัญชีตามขอบเขต Account Security แล้วใช้ขั้น SMS ที่อนุมัติ |
| หลังยืนยันเบอร์ | กลับมาแสดงผลและเบอร์ล่าสุดในหน้าความปลอดภัย เมื่อเปิดโปรไฟล์จึงอ่านค่าเบอร์เดียวกันจากบัญชี |
| ย้ายหน้าเมื่อมีค่าที่แก้ค้าง | อ้างอิงกรณีออกไปหน้าอื่นจากฟอร์มโปรไฟล์ในชุดสถานะ G2-r8 ซึ่งยังรอตรวจรับ |

ชุดนี้เป็นข้ออ้างอิงล่าสุดสำหรับตำแหน่งปุ่มเพิ่มหรือเปลี่ยนเบอร์ ขอบเขตปุ่มบันทึกโปรไฟล์ และเมนูบัญชี ภาพกรอกเบอร์และตัวเลือกประเทศในร่างก่อนหน้าใช้อ้างอิงขั้นจัดการเบอร์ในหน้าความปลอดภัย ส่วน G2-r9 ใช้กับผลบันทึกข้อมูลส่วนตัว
