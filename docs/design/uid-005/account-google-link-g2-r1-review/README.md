# UID-005 · เชื่อม Google จากหน้าความปลอดภัย · G2-r1

20 พฤศจิกายน 2026 · Wireframe รอภูตรวจรับ [อนุมัติขอบเขต G0](owner-g0-approval.json) · [ข้อกำหนดการใช้งาน](interaction-spec.md)

ผู้ที่ยังไม่เชื่อมกด **เชื่อม Google** จากหน้า **การเข้าสู่ระบบและความปลอดภัย** จากนั้นยืนยันบัญชี papaipak เลือกบัญชีที่ Google กลับมาตรวจบัญชีและกดยืนยันการเชื่อม เมื่อระบบยืนยันผลจึงแสดง **เชื่อมบัญชีแล้ว**

**การเข้าใช้ด้วย Google ที่เชื่อมแล้ว** เข้าสู่บัญชีหลัง Google ยืนยันตัวตนสำเร็จ โดยไม่ต้องกรอก OTP หรือยืนยันอีเมลเพิ่มใน papaipak [ข้อสรุปเรื่องการเข้าสู่ระบบด้วย Google](../../dsd-001/home-auth-google-no-extra-email-verification.json)
