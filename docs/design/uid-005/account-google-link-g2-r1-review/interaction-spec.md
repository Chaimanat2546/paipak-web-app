# เชื่อม Google จากหน้าความปลอดภัย · การใช้งาน G2-r1

UID-005 · รอภูตรวจรับ · [ขอบเขตที่อนุมัติ](owner-g0-approval.json)

**การเข้าใช้ด้วย Google ที่เชื่อมแล้ว** ใช้ผลยืนยันตัวตนจาก Google เพื่อเข้าสู่บัญชี ผู้ใช้ไม่ต้องกรอก OTP หรือยืนยันอีเมลเพิ่มใน papaipak ตารางนี้อ้างถึงการเชื่อมบัญชีครั้งแรกจากหน้าความปลอดภัย [มติเรื่อง Google Login](../../dsd-001/home-auth-google-no-extra-email-verification.json)

| ขั้น | สิ่งที่แสดงและทางเดิน |
| --- | --- |
| ทางเข้าจากบัญชี | ในแถว Google ของหน้า **การเข้าสู่ระบบและความปลอดภัย** แสดง **เชื่อม Google** สำหรับบัญชีที่ยังไม่ได้เชื่อม บัญชีที่เชื่อมแล้วแสดงสถานะตามที่ตรวจสอบได้ |
| ยืนยันบัญชี papaipak | ยืนยันสิทธิ์ในบัญชีปัจจุบันก่อนเลือกบัญชี Google ตัวอย่างแสดง OTP ทางอีเมลสำหรับบัญชีที่มีสิทธิ์ใช้วิธีนี้ ส่งเมื่อผู้ใช้กดขอรหัส |
| เลือกบัญชีที่ Google | หลังผ่านการยืนยัน ให้ผู้ใช้กดเลือกบัญชีที่ Google เมื่อกลับมาให้แสดงอีเมลบัญชี papaipak และบัญชี Google ที่เลือก เพื่อให้ทราบว่าจะเชื่อมบัญชีใด |
| ยืนยันและดำเนินการ | ผู้ใช้กด **ยืนยันการเชื่อม** จึงเข้าสถานะกำลังเชื่อม พักการกดซ้ำระหว่างรอผล |
| เชื่อมสำเร็จ | เมื่อผลการเชื่อมได้รับการยืนยัน ให้กลับหน้าความปลอดภัย แสดงข้อความสำเร็จและสถานะ **เชื่อมบัญชีแล้ว** |
| บัญชีที่เลือกใช้ไม่ได้ | แสดงข้อความที่จุดเลือกบัญชี ให้กด **เลือกบัญชี Google อื่น** ได้ กรณีบัญชี Google ผูกกับบัญชี papaipak อื่นแล้ว ให้รักษาสถานะเดิมและใช้ทางเลือกนี้ |
| เชื่อมไม่สำเร็จหรือยังตรวจผลไม่ได้ | แสดงข้อผิดพลาดพร้อม **ลองเชื่อมอีกครั้ง** เมื่อยืนยันแล้วว่าคำขอเดิมไม่สำเร็จ หากยังไม่ทราบผลให้ตรวจคำขอเดิมก่อนแสดงผลใหม่หรือเปิดให้ส่งซ้ำ |
| ยกเลิกหรือหมดอายุ | ยกเลิกที่ Google ให้กลับมาอยู่จุดเลือกบัญชี ยกเลิกขั้นยืนยันให้กลับหน้าความปลอดภัย หากสิทธิ์ยืนยันหมดอายุ ให้กลับไปยืนยันบัญชี papaipak ใหม่ |

ภาพใช้อีเมลเดียวกันในสองบัญชีเป็นตัวอย่าง เกณฑ์กรณีอีเมลต่างกัน วิธีและอายุการยืนยันสิทธิ์ และการตรวจผลคำขอกับผู้ให้บริการอยู่ในรายการรอสรุป ผลลัพธ์อาศัยสถานะบัญชีที่ยืนยันแล้วตามหลักเดียวกับเส้นทางเชื่อม Google จาก Login [ข้อกำหนด Auth และ Google Link](../../dsd-001/home-auth-desktop-system-requirements.md)

เมื่อเปลี่ยนขั้นให้ย้ายโฟกัสไปที่หัวข้อหรือช่องรหัส เมื่อกลับจาก Google ให้กลับมาที่ขั้นซึ่งตรงกับผลที่ได้รับ การใช้งานจริงกับผู้ให้บริการ คีย์บอร์ด และโปรแกรมอ่านหน้าจอยังรอทดสอบในระบบ
