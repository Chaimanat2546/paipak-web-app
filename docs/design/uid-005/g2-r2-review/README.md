## ผลตรวจ Wireframe

- ตรวจภาพทั้ง 16 เฟรมที่ความกว้าง 1440 และ 390 px เห็นชื่อจริงและนามสกุลในโหมดดูและแก้ไข รวมถึงค่าที่ขาดในตัวอย่างบัญชี Google
- ตรวจว่าภาพกำลังบันทึก ผิดรูปแบบ และบันทึกไม่สำเร็จยังแสดงชื่อจริงและนามสกุลที่กรอกไว้ ภาพบันทึกสำเร็จแสดงค่าที่บันทึกแล้ว
- กติกาการกรอกข้อมูลล่วงหน้าใน Checkout ลำดับโฟกัส และการบันทึกจริงระบุในข้อกำหนดและยังรอทดสอบกับระบบ
