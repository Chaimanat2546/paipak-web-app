# โปรไฟล์ลูกค้า · ข้อมูลสำหรับจอง G2-r2

สถานะรอภูตรวจรับ · ข้อกำหนดการจัดกลุ่มข้อมูลและลำดับโฟกัสใช้ฉบับนี้ พฤติกรรมการเข้าหน้า ยกเลิก และรับผลการบันทึกอ้างอิง [ข้อกำหนด G2-r1](../g2-r1-review/interaction-spec.md) และ [มติปรับขอบเขต](owner-booking-profile-amendment.json)

## ข้อมูลบนหน้าโปรไฟล์

| ส่วน | ข้อมูล | สิ่งที่สมาชิกทำได้ |
| --- | --- | --- |
| ข้อมูลสำหรับจอง | ชื่อจริงและนามสกุล | ดู เพิ่ม และแก้ไขได้แยกช่อง เมื่อขาดค่าใดให้แสดง “ยังไม่ได้ระบุ” ที่ค่านั้น |
| ข้อมูลสำหรับจอง | เบอร์โทร | ดูเบอร์ที่มีอยู่ หรือเพิ่มเมื่อบัญชียังไม่มีเบอร์ |
| ข้อมูลสำหรับจอง | อีเมลบัญชี | ดูอีเมลที่บันทึกไว้ |
| ข้อมูลที่แสดงในบัญชี | ชื่อผู้ใช้ | ดู เพิ่ม และแก้ไขตามกติกาตัวอักษรอังกฤษและตัวเลข 3–20 ตัว |

เดสก์ท็อปวางชื่อจริงกับนามสกุลข้างกัน มือถือเรียงลงมาเพื่อให้แต่ละช่องกว้างพอสำหรับอ่านและกรอก ตัวอย่างชื่อ เบอร์ และอีเมลในภาพใช้เพื่อทบทวน Wireframe

## จากโปรไฟล์ไป Checkout

- ให้สมาชิกเติมข้อมูลสำหรับจองภายหลังได้ เมื่อจะจองให้ Checkout ใช้ข้อมูลที่มีจากบัญชีและขอเพิ่มเฉพาะข้อมูลการจองที่ยังขาด
- สมาชิกที่สมัครผ่าน Google และยังไม่มีชื่อผู้ใช้สามารถบันทึกข้อมูลสำหรับจองที่ต้องการเติมได้ การเติมชื่อผู้ใช้ยังทำได้ภายหลัง
- เกณฑ์ว่าข้อมูลใดจำเป็นในแต่ละกรณีจอง รูปแบบชื่อที่ระบบรองรับ และเงื่อนไขยืนยันข้อมูลติดต่อเป็นประเด็นของข้อกำหนดการจองและบัญชีที่ต้องสรุปก่อนนำไปใช้จริง

## การแก้ไขและโฟกัส

- **แก้ไขข้อมูล** เปิดฟอร์มในหน้าเดิมและเริ่มโฟกัสที่ชื่อจริง จากนั้นเรียงไปนามสกุล ตัวเลือกประเทศและช่องเบอร์เมื่อมี ชื่อผู้ใช้ บันทึก และยกเลิก
- เมื่อกดบันทึกแล้วพบข้อผิดพลาด ให้แจ้งใต้ช่องนั้นและย้ายโฟกัสไปที่ช่องแรกที่ต้องแก้ เมื่อยืนยันว่าบันทึกไม่สำเร็จ ให้คงชื่อจริง นามสกุล เบอร์ที่กรอกได้ และชื่อผู้ใช้ไว้สำหรับลองใหม่
- สถานะกำลังบันทึกคงค่าที่กรอกไว้ เมื่อระบบยืนยันว่าบันทึกสำเร็จจึงแสดงค่าที่บันทึกแล้วในโหมดดูและย้ายโฟกัสกลับไปหัวข้อ **ข้อมูลส่วนตัว**

## จุดตรวจรับ

- ชื่อจริงและนามสกุลแก้ได้ทั้งสองขนาดจอ และอยู่ในส่วนเดียวกับเบอร์โทรและอีเมลที่ใช้จอง
- แสดงค่าที่ขาดตามช่องจริง ชื่อผู้ใช้อยู่คนละส่วนกับข้อมูลสำหรับจอง
- สถานะข้อผิดพลาดและบันทึกไม่สำเร็จมีตัวอย่างชื่อจริงและนามสกุลที่กรอกไว้ ส่วนภาพบันทึกสำเร็จแสดงค่าที่บันทึกแล้ว
- การนำข้อมูลไปใช้ใน Checkout ลำดับโฟกัส และการบันทึกจริงเป็นข้อกำหนดสำหรับการพัฒนาและทดสอบในระบบ
