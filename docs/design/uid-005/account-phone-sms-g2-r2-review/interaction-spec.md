# SMS OTP · เวลาส่งซ้ำและขีดจำกัด G2-r2

UID-005 · ร่างสถานะรอภูตรวจรับ · [มติอนุมัติค่ากติกา](owner-otp-policy-decision.json)

ใช้ค่าที่อนุมัติในเอกสารนี้สำหรับ SMS OTP ในขั้นเพิ่มหรือเปลี่ยนเบอร์ของหน้า Account Security เส้นทางหลักอ้างอิง [Phone SMS G2-r1](../account-phone-sms-g2-r1-review/interaction-spec.md)

| สถานะ | พฤติกรรมที่แสดงในแบบ |
| --- | --- |
| รอส่งใหม่ | ช่องกรอกรหัส 6 หลักพร้อมใช้ถ้ารหัสยังไม่หมดอายุ ตรวจอัตโนมัติเมื่อกรอกครบ รหัสมีอายุ 5 นาที ปุ่มส่งใหม่พักไว้ในช่วงรอ 60 วินาทีและแสดงเวลาที่เหลือในปุ่ม |
| ครบเวลารอ | ปุ่ม **ส่งรหัสใหม่** ใช้ได้เมื่อครบเวลารอและยังมีโควตา |
| ออกรหัสใหม่สำเร็จ | แสดงข้อความให้ใช้รหัสล่าสุด ล้างช่องและคืนโฟกัสไปหลักแรก เริ่มนับเวลารอของรหัสใหม่ รหัสก่อนหน้าสิ้นผลเมื่อระบบยืนยันการออกรหัสใหม่สำเร็จ |
| ส่งใหม่ล้มเหลวหรือยังไม่ทราบผล | ใช้สถานะของรหัสเดิมที่ตรวจสอบได้และให้ตรวจผลคำขอก่อนส่งซ้ำ ถ้ายังไม่มีผลยืนยันการออกรหัสใหม่ให้ยึดสถานะจริงของรหัสเดิม |
| ขอรหัสครบ 10 ครั้งต่อชั่วโมง | พักการขอรหัสเพิ่ม รหัสล่าสุดยังกรอกได้เมื่อยังใช้ได้และยังมีสิทธิ์ตรวจรหัส กรณีรหัสหมดอายุให้ปิดช่องกรอกและแจ้งให้ลองขอใหม่เมื่อพ้นขีดจำกัด |
| กรอกผิดครบ 20 ครั้งต่อชั่วโมง | พักการตรวจรหัส แสดงข้อความและทางยกเลิก จึงกลับมายืนยันได้เมื่อพ้นขีดจำกัดและรหัสยังใช้ได้ |

แสดงเวลารอและผลขีดจำกัดตามสถานะที่ระบบยืนยันได้ นับโควตาของ SMS แยกจาก OTP ทางอีเมล ค่าที่เห็นบนปุ่มในภาพเป็นตัวอย่าง หน่วยที่ใช้ผูกโควตา วิธีนับช่วงหนึ่งชั่วโมง และเวลาที่แต่ละบัญชีลองได้อีกครั้งยังต้องสรุปในสัญญาระบบ การส่งและตรวจรหัสจริงยังรอทดสอบในระบบ
