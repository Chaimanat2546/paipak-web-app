## จุดตรวจรับ

- โหมดดูแสดงข้อมูลที่บันทึกไว้ และบอกเมื่อบัญชี Google ยังไม่มีชื่อผู้ใช้หรือเบอร์โทร
- โหมดแก้ไขให้แก้หรือเพิ่มชื่อผู้ใช้ และมีช่องเบอร์เฉพาะบัญชีที่ยังไม่มีเบอร์ ส่วนอีเมลกับเบอร์เดิมเป็นข้อความ
- ผลการบันทึกอยู่ในหน้าเดิม ข้อผิดพลาดที่ระบุช่องได้อยู่ใต้ช่องนั้น เมื่อบันทึกล้มเหลว ค่าที่กรอกไว้ยังอยู่
- เดสก์ท็อปจัดเมนูและข้อมูลเป็นสองส่วน มือถือเรียงลงมา ทางกลับหลัง Auth และลำดับโฟกัสอยู่ในข้อกำหนดการใช้งาน
