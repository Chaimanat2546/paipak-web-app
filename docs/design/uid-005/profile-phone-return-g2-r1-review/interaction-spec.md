# เพิ่มเบอร์จากโปรไฟล์และกลับมาที่ฟอร์ม · การใช้งาน G2-r1

UID-005 · ร่างรอตรวจรับ · [มติของภู](owner-flow-decision.json)

| กรณี | พฤติกรรมในแบบ |
| --- | --- |
| ยังไม่มีเบอร์ | ในฟอร์มแก้ไขโปรไฟล์ แถวเบอร์แสดง **ยังไม่ได้เพิ่มเบอร์** และปุ่ม **เพิ่มเบอร์โทร** |
| กดเพิ่มเบอร์ | เก็บชื่อจริง นามสกุล และชื่อผู้ใช้ของรอบแก้ไขไว้ เปิดทางเพิ่มเบอร์เดียวกับหน้าความปลอดภัย ใช้ขั้นยืนยันบัญชีตามวิธีที่บัญชีมีสิทธิ์ใช้ ภาพกรอกเบอร์เริ่มหลังผ่านขั้นนี้ |
| กรอกเบอร์และยืนยัน SMS | ส่ง SMS ไปยังเบอร์ใหม่ตามขอบเขตที่อนุมัติ ใช้สถานะผิด หมดอายุ ส่งซ้ำ และตรวจผลจากชุด SMS เดิม พร้อมลิงก์ **กลับไปฟอร์มโปรไฟล์** |
| ยืนยันและอัปเดตสำเร็จ | กลับฟอร์มแก้ไขเดิม แสดงเบอร์ที่เพิ่งยืนยันพร้อมค่าชื่อจริง นามสกุล และชื่อผู้ใช้ที่กรอกค้างไว้ ให้กด **บันทึกข้อมูล** เพื่อบันทึกค่าอื่นในฟอร์ม |
| ยกเลิกก่อนมีผลสำเร็จ | กลับฟอร์มเดิมพร้อมค่าที่กรอกไว้ แถวเบอร์แสดงสถานะบัญชีที่ยืนยันได้ ตัวอย่างยังไม่มีเบอร์และมีปุ่มเพิ่มเหมือนตอนเริ่ม |
| ผลยังไม่ทราบ | ตรวจผลรายการเดิมตามขั้น SMS ใช้สถานะที่ยืนยันได้เมื่อกลับมาที่โปรไฟล์ |
| เซสชันหรือรอบแก้ไขสิ้นสุด | การคืนค่ามีขอบเขตในรอบแก้ไขที่ยังใช้งานได้ของบัญชีเดียวกัน การกลับเข้าหลังหมดเซสชันหรือโหลดใหม่อ้างอิงสถานะโปรไฟล์เดิมและกติกาที่รอสรุป [สถานะโปรไฟล์](../g2-r8-review/state-spec.md) |

การเพิ่มเบอร์ที่ยืนยันสำเร็จอัปเดตแถวเบอร์โดยตรง การกด **บันทึกข้อมูล** ในโปรไฟล์ใช้กับค่าที่แก้ค้างไว้ เมื่อยกเลิกฟอร์มโปรไฟล์ภายหลัง ให้แสดงเบอร์ล่าสุดที่ระบบยืนยันแล้วและกลับไปใช้ค่าข้อมูลส่วนตัวที่บันทึกไว้

เสนอให้โฟกัสที่แถวเบอร์หลังกลับมา เมื่อยังเพิ่มไม่สำเร็จให้คืนโฟกัสที่ปุ่ม **เพิ่มเบอร์โทร** ขั้นเลือกวิธีพิสูจน์สิทธิ์บัญชีแต่ละประเภทใช้ขอบเขตใน [Account Security G2-r1](../account-security-g2-r1-review/interaction-spec.md)
