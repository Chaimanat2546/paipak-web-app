# UID-005 · Toast บนหน้าโปรไฟล์ล่าสุด · G2-r10

20 พฤศจิกายน 2026 · ภาพและพฤติกรรมรอตรวจรับ

หลังระบบยืนยันว่าบันทึกสำเร็จ ให้กลับโหมดดู แสดงข้อมูลที่บันทึกแล้ว และขึ้นข้อความ **บันทึกข้อมูลส่วนตัวแล้ว** หนึ่งครั้ง ตัวอย่างใช้ [หน้าโปรไฟล์ที่มีเมนูการเข้าสู่ระบบ](../profile-phone-separation-g2-r1-review/README.md) และตำแหน่งจาก [ร่าง Toast G2-r9](../g2-r9-toast-review/README.md)

| ขนาดจอ | ตำแหน่งที่เสนอ | ภาพ |
| --- | --- | --- |
| เดสก์ท็อป 1440 × 900 | มุมขวาล่าง เว้นขวา 32 และล่าง 28 พิกเซล | [ดูภาพ](QhzrY.png) |
| มือถือ 390 × 844 | ด้านล่าง เว้นข้าง 24 พิกเซล เว้นจากพื้นที่ปลอดภัยด้านล่างอีก 16 พิกเซล ภาพใช้ตำแหน่งเลื่อน 88 พิกเซลหลังบันทึก | [ดูภาพ](p9Il7M.png) |

เสนอให้ปิดเองหลังแสดง **5 วินาที** ผู้ใช้กด **×** ปิดได้ทันที พักเวลาเมื่อชี้เมาส์ที่ Toast หรือมีโฟกัสใน Toast โปรแกรมอ่านหน้าจอประกาศผลโดยคงโฟกัสในหน้าโปรไฟล์ ข้อมูลที่บันทึกแล้วยังอ่านได้จากโหมดดูหลังข้อความปิด [แนวทางข้อความสถานะของ W3C](https://www.w3.org/WAI/WCAG22/Understanding/status-messages.html)

ข้อผิดพลาดและการตรวจผลที่ยังไม่ยืนยันอยู่ในฟอร์มตาม [ร่างสถานะโปรไฟล์ G2-r8](../g2-r8-review/README.md) ตำแหน่งขณะเลื่อนบนขนาดอื่นและการปิดอัตโนมัติยังต้องทดสอบในระบบ
