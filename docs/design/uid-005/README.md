# UID-005 · โปรไฟล์และการเข้าสู่ระบบ

ใช้ [G2-r12 ฉบับรวม](g2-r12-consolidated-review/README.md) สำหรับตรวจงานโปรไฟล์และความปลอดภัยของบัญชีใน [Pencil](../dsd-001/papaipak-ui.pen) ที่ Section **UID-005 · โปรไฟล์และการเข้าสู่ระบบ · G2-r12** (`Rf1ie`)

ในฉบับนี้มี 70 สถานะทั้งเดสก์ท็อปและมือถือ ครอบคลุมโปรไฟล์ เบอร์และ SMS การตั้งและเปลี่ยนรหัสผ่าน การเปลี่ยนอีเมล และการเชื่อม Google
