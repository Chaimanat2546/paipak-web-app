# โปรไฟล์ลูกค้า · สถานะการใช้งาน G2-r8

20 พฤศจิกายน 2026 · ชุดสถานะเสริมรอภูตรวจรับ

ชุดนี้ครอบคลุมทางเข้าโปรไฟล์ การโหลดข้อมูล การแก้ไข การกู้จากข้อผิดพลาด และการออกจากหน้าขณะมีค่าที่แก้ไว้ ใช้คู่กับ 8 สถานะเดิมของ G2-r7 ซึ่งมีหน้าดูข้อมูลครบและข้อมูลขาด ฟอร์มแก้ไข กำลังบันทึก บันทึกสำเร็จ ข้อผิดพลาดชื่อผู้ใช้ และบันทึกไม่สำเร็จ [ชุด G2-r7](../g2-r7-review/README.md) · [ข้อกำหนดสถานะและสิ่งที่ต้องตัดสินใจ](state-spec.md)
