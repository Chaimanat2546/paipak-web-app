# โปรไฟล์ลูกค้า · Toast ยืนยันการบันทึก G2-r9

20 พฤศจิกายน 2026 · ร่างรอภูตรวจรับ

เมื่อยืนยันว่าบันทึกสำเร็จ ให้กลับโหมดดูพร้อมค่าที่บันทึกแล้วและแสดง Toast **“บันทึกข้อมูลส่วนตัวแล้ว”** หนึ่งครั้ง ร่างนี้ใช้ Toast เป็นจุดแสดงข้อความสำเร็จของหน้าโปรไฟล์ ตัวอย่างใช้ไอคอนเครื่องหมายถูกและพื้นขาวจากแนวทางแจ้งเตือนที่เคยใช้กับการบันทึกที่พัก [อ้างอิงรูปแบบแจ้งเตือน](../../dsd-001/home-auth-favorite-return-g2-r28/review-manifest.json)

| ขนาดจอ | ตำแหน่งที่เสนอ | ภาพตรวจ |
| --- | --- | --- |
| เดสก์ท็อป 1440 × 900 | มุมขวาล่าง ห่างขวา 32 และล่าง 28 พิกเซล | [ตัวอย่าง](KK3lT.png) |
| มือถือ 390 × 844 | ด้านล่าง เว้นขอบข้าง 24 พิกเซล และเว้นจากพื้นที่ปลอดภัยด้านล่าง ภาพจำลองจุดเลื่อนหลังจากกดบันทึก | [ตัวอย่าง](n0lts.png) |

Toast มีปุ่มปิดขนาด 44 × 44 พิกเซล เสนอให้ประกาศข้อความผ่านโปรแกรมอ่านหน้าจอโดยคงโฟกัสตามเส้นทางกลับโหมดดู ระยะเวลาปิดเองและการวางตำแหน่งตอนเลื่อนบนจอขนาดอื่นอยู่ในรายการตรวจรับและทดสอบ

ข้อผิดพลาดที่แก้ได้แสดงใต้ช่องกรอกหรือใกล้ปุ่มบันทึก ส่วนกรณีผลยังไม่ยืนยันใช้สถานะตรวจผลตามที่เสนอใน G2-r8 [ชุดสถานะ G2-r8](../g2-r8-review/README.md)
