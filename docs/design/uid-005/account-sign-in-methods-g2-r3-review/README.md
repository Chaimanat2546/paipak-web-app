# UID-005 · วิธีเข้าสู่บัญชีเดียวกัน G2-r3

20 พฤศจิกายน 2026 · ร่างรอภูตรวจรับ

สมาชิกใช้ Google หรืออีเมลที่บัญชีเปิดให้ใช้เข้าสู่ระบบเพื่อเข้าถึงโปรไฟล์ รายการโปรด และข้อมูลการจองชุดเดียวกัน หน้าความปลอดภัยแสดงวิธีที่ใช้ได้ตามข้อมูลของบัญชี อีเมลในภาพตัวอย่างผ่านการยืนยันและใช้เข้าแบบ OTP ได้แล้ว
