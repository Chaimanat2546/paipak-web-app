# วิธีเข้าสู่บัญชี papaipak เดียวกัน

## กติกาบัญชี

- เมื่อเข้าสู่ระบบสำเร็จ ให้ใช้บัญชีสมาชิกเดียวกันสำหรับโปรไฟล์ ข้อมูลติดต่อที่ใช้จอง รายการโปรด และประวัติการจอง สิทธิ์และข้อมูลที่ต้องกรอกก่อนจองขึ้นอยู่กับสถานะของบัญชีและรายการจอง
- สมาชิกที่เริ่มด้วย Google ใช้อีเมลที่ยืนยันและมีสิทธิ์รับ OTP ของบัญชีเพื่อเข้าสู่บัญชีเดิมได้ การตั้งรหัสผ่านเป็นตัวเลือกเพิ่มเติม การเข้าใช้ด้วย Google ทุกครั้งใช้เส้นทางที่ตกลงไว้เดิม [กติกา Home Auth](../../dsd-001/home-auth-desktop-system-requirements.md)
- เมื่อบัญชีอีเมลเดิมยังไม่ได้เชื่อม Google ให้ใช้ทางเชื่อมบัญชีที่ตรงกับจุดเริ่มต้น จากหน้าความปลอดภัยให้ใช้เซสชันบัญชีปัจจุบันและขั้นยืนยันการเชื่อม จากหน้า Login หรือ Register เมื่อพบอีเมลตรงกับบัญชีเดิม ให้ยืนยันสิทธิ์ในบัญชีเดิมและขอความยินยอมก่อนเชื่อม เมื่อเชื่อมสำเร็จให้ Google พากลับเข้าบัญชีสมาชิกเดิม [เชื่อมจากหน้าความปลอดภัย](../account-google-link-g2-r2-review/interaction-spec.md) · [เชื่อมจาก Home Auth](../../dsd-001/home-auth-google-link-g2-r41/README.md)

## หน้าการเข้าสู่ระบบและความปลอดภัย

| แถว | ข้อมูลและปุ่ม |
| --- | --- |
| อีเมลบัญชี | แสดงอีเมลปัจจุบันและปุ่ม **เปลี่ยนอีเมล** ข้อความ **เข้าสู่ระบบได้ด้วยรหัส OTP ทางอีเมล** แสดงเฉพาะเมื่อบัญชีเปิดวิธีนี้ได้แล้ว |
| รหัสผ่าน | ยังไม่มีรหัสผ่านให้ใช้ **ตั้งรหัสผ่าน** และไปยังแบบขอลิงก์อีเมล G2-r2 มีรหัสผ่านแล้วให้ใช้ **เปลี่ยนรหัสผ่าน** ตามแบบหน้าความปลอดภัยเดิม |
| Google | เมื่อเชื่อมสำเร็จให้แสดง **เชื่อมแล้ว · ใช้เข้าสู่ระบบได้** เมื่อยังไม่ได้เชื่อมให้แสดงปุ่ม **เชื่อม Google** |
| เบอร์โทร | แสดง **เพิ่มเบอร์โทร** หรือ **เปลี่ยนเบอร์โทร** ตามข้อมูลในบัญชี ใช้ [ขั้นจัดการเบอร์ในหน้าความปลอดภัย](../profile-phone-separation-g2-r1-review/README.md) |

## เกณฑ์ตรวจร่าง

- เมื่อวิธีเข้าสู่ระบบที่เปิดใช้เหมือนกัน หน้าความปลอดภัยแสดงสถานะและปุ่มชุดเดียวกัน ประวัติการสมัครและวิธีที่เพิ่งใช้เข้าเว็บไม่มีผลกับหน้าสรุป
- ภาพตัวอย่างแสดงสามสถานะของวิธีเข้าใช้จากฐานอีเมลที่ยืนยันแล้ว การจัดการอีเมลที่ยังไม่มีสิทธิ์ใช้ OTP สิทธิ์ของลิงก์ตั้งรหัสผ่าน และการทดสอบเดินทางข้ามวิธีเข้าใช้ยังต้องสรุปในส่วนที่เกี่ยวข้อง
