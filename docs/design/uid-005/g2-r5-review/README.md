# โปรไฟล์ลูกค้า · โครงเต็มความกว้าง G2-r5

20 พฤศจิกายน 2026 · ร่างรอภูตรวจรับ

ส่วนกลางเริ่มจากหัวข้อและใช้แนวขอบเดียวกับหน้ารายการโปรด เดสก์ท็อปใช้ 4 คอลัมน์สำหรับชื่อจริง นามสกุล เบอร์โทร และอีเมล ส่วนมือถือเรียงข้อมูลลงมาในคอลัมน์เดียว วางเมนูบัญชีแนวนอนใต้หัวข้อและแสดงหน้าปัจจุบันด้วยเส้นใต้ ฟอร์มวางบนพื้นหน้าและใช้เส้นคั่นก่อนส่วนชื่อผู้ใช้ [หน้ารายการโปรด G4-r1](../../uid-006/g4-r1-review/README.md)

สิทธิ์การแก้ไขข้อมูลและกติกาการบันทึกใช้ตามขอบเขตที่อนุมัติแล้ว ส่วนตำแหน่งเมนูบัญชีและแนวคอลัมน์ใช้ตามร่างนี้ [ข้อมูลสำหรับจองและข้อกำหนดการใช้งาน](../g2-r2-review/interaction-spec.md)
