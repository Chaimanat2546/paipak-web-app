# UID-005 · เปลี่ยนอีเมลเมื่อเชื่อม Google · G2-r4

20 พฤศจิกายน 2026 · ภูตรวจรับภาพทั้ง 6 หน้าจอแล้ว [บันทึกตรวจรับ G2-r4](owner-g2-r4-visual-acceptance.json)

## จุดตรวจ

- อีเมลในแถว **อีเมลบัญชี** เป็นอีเมลที่ใช้รับ OTP เพื่อเข้าสู่ระบบ ส่วนแถว **Google** แสดงบัญชี Google ที่เชื่อมไว้ ตัวอย่างหลังเปลี่ยนแสดงสองที่อยู่อีเมลเพื่อให้เห็นความต่างของสองรายการ
- ระหว่างกรอกรหัสยืนยันอีเมลปลายทาง อีเมลบัญชีเดิมยังมีผล เมื่อยกเลิก รหัสผิด หมดอายุ ส่งไม่สำเร็จ หรือผลการเปลี่ยนยังไม่ยืนยัน ให้ยึดอีเมลเดิมตามสถานะจริง แบบฟอร์มและข้อผิดพลาดใช้ [ร่างความปลอดภัยเดิม](../account-security-g2-r1-review/README.md)
- เมื่อยืนยันผลสำเร็จ ให้กลับหน้าความปลอดภัย แสดงอีเมลใหม่และข้อความบอกว่าจะใช้อีเมลไหนรับ OTP ครั้งถัดไป โปรไฟล์ รายการโปรด และการจองอยู่ในบัญชีเดิมตาม [แบบบัญชีเดียวกัน](../account-sign-in-methods-g2-r3-review/README.md)
