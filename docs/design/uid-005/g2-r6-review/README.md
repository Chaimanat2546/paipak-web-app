# โปรไฟล์ลูกค้า · พื้นที่รูปโปรไฟล์ G2-r6

20 พฤศจิกายน 2026 · ร่างรอภูตรวจรับ

พื้นที่รูปโปรไฟล์อยู่ด้านซ้ายของข้อมูลบนเดสก์ท็อป และอยู่เหนือข้อมูลบนมือถือ ตัวอย่างใช้ตัวอักษรย่อหรือไอคอนสมาชิกเมื่อยังไม่มีรูป ข้อมูลสำหรับจองอยู่ด้านขวาเป็นแถวละสองช่องบนเดสก์ท็อป และเรียงลงมาบนมือถือ ใช้เส้นคั่นบางสำหรับแถวข้อมูลที่แสดงเพื่ออ่าน

สิทธิ์การแก้ไขข้อมูลและกติกาการบันทึกอ้างอิงขอบเขตเดิม พื้นที่รูปในร่างนี้เป็นองค์ประกอบสำหรับแสดงภาพแทน [ข้อมูลสำหรับจองและข้อกำหนดการใช้งาน](../g2-r2-review/interaction-spec.md)
