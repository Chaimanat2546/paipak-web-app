# การเพิ่มหรือเปลี่ยนเบอร์ด้วย SMS · ข้อกำหนด G2-r1

UID-005 · รอภูตรวจรับ · [มติขอบเขต SMS](owner-sms-scope-decision.json)

| ขั้น | สิ่งที่แสดงและทางไปต่อ |
| --- | --- |
| เปิดรายการ | ใช้ขั้นยืนยันสิทธิ์ในบัญชีตามแบบจัดการบัญชี เมื่อผ่านแล้วจึงแสดงฟอร์มเพิ่มหรือเปลี่ยนเบอร์ ขอ SMS เฉพาะจากการกดปุ่มของสมาชิก |
| กรอกเบอร์ | แสดงเบอร์ปัจจุบันหรือตำแหน่งที่ยังไม่มีเบอร์ ให้เลือกประเทศและกรอกเบอร์ใหม่ ปุ่ม **ส่งรหัส SMS** ใช้เบอร์ที่แสดงในฟอร์ม |
| เบอร์ใช้ไม่ได้ | ถ้าระบบยืนยันว่าใช้เบอร์นี้ไม่ได้ ให้แจ้งใต้ช่องและคงค่าให้แก้ไข ถ้อยคำของหน้าใช้ข้อผิดพลาดทั่วไปเกี่ยวกับเบอร์ที่กรอก |
| กำลังส่งหรือส่งล้มเหลว | ระหว่างส่งพักการกดซ้ำ เมื่อยืนยันว่าการส่งไม่สำเร็จให้คงเบอร์ใหม่และแสดงทางลองใหม่ ถ้ายังไม่ทราบผลให้ตรวจคำขอเดิมก่อนให้ส่งซ้ำ |
| กรอกรหัส | แสดงปลายทางแบบปิดบางหลักและทาง **แก้ไขเบอร์โทร** ตัวอย่างใช้ 6 ช่อง ตรวจเมื่อกรอกครบ และใช้ปุ่มส่งใหม่ตามเวลาที่กำหนดของรายการ |
| รหัสผิดหรือหมดอายุ | รหัสผิดแจ้งใต้ช่องแล้วคืนโฟกัสไปช่องแรก รหัสหมดอายุแสดงทางส่งรหัสใหม่เมื่อขอได้ ระหว่างส่งใหม่แสดงกำลังส่งและพักการกดซ้ำ |
| เปลี่ยนเบอร์ที่กำลังยืนยัน | เมื่อเลือกแก้เบอร์ ให้กลับไปฟอร์มและเริ่มขอรหัสสำหรับปลายทางใหม่ ผลการยืนยันผูกกับหมายเลขที่ขอในรายการนั้น |
| ผลยังไม่ทราบ | ให้ตรวจผลคำขอเดิมก่อนยืนยันหรือส่งซ้ำ ตัวอย่างมีปุ่ม **ตรวจสอบผล** สำหรับผลหลังกรอกรหัสที่ยังตรวจไม่ได้ |
| สำเร็จ | แสดงเบอร์ใหม่เมื่อทั้งการยืนยันเบอร์และการอัปเดตบัญชีสำเร็จแล้ว ระหว่างรอให้ใช้ค่าบัญชีล่าสุดที่ยืนยันได้ สำหรับบัญชีที่มีรหัสผ่าน การเข้าสู่ระบบด้วยเบอร์ยังใช้เบอร์คู่รหัสผ่าน |
| เซสชันหมดอายุหรือยกเลิก | กลับเส้นทางเข้าสู่ระบบหรือหน้าความปลอดภัยตามบริบท เมื่อกลับมาตรวจให้แสดงสถานะที่ระบบยืนยันได้ [สถานะหมดเซสชัน](../g2-r8-review/README.md) |

## จุดรอสรุป

รูปแบบรหัส 6 หลัก การตรวจทันทีเมื่อกรอกครบ อายุรหัส เวลารอก่อนส่งใหม่ โควตา การตรวจเบอร์ที่รองรับ และผู้ให้บริการ SMS ยังรอสรุปสำหรับรายการนี้ ภาพใช้รูปแบบช่องจาก Auth เป็นตัวอย่าง นโยบายของรหัสทางอีเมลอ้างอิงได้จาก [ข้อกำหนด Auth เดิม](../../dsd-001/home-auth-desktop-system-requirements.md)

ถ้าเปิดทางเพิ่มเบอร์จากหน้าโปรไฟล์ ให้ตรวจว่าจุดนั้นพาเข้าสู่การยืนยันหมายเลขเดียวกัน และสรุปการคืนค่าฟอร์มชื่อหรือชื่อผู้ใช้ที่กรอกค้างไว้ในรอบต่อไป [แบบโปรไฟล์ G2-r7](../g2-r7-review/README.md) · [แบบ Account Security](../account-security-g2-r1-review/interaction-spec.md)

## จุดตรวจรับ

- แยกการยืนยันสิทธิ์ในบัญชีออกจากการตรวจว่ารับ SMS ที่เบอร์ใหม่ได้
- สถานะเสร็จแสดงเบอร์ใหม่หลังมีผลยืนยันการอัปเดตบัญชี
- รหัสผิด หมดอายุ ส่งใหม่ และผลยังไม่ทราบมีทางไปต่อ
- การส่ง SMS จริง การตรวจรหัส การเปลี่ยนเบอร์ และการใช้งานคีย์บอร์ดยังรอทดสอบในระบบ
