# UID-005 · ตั้งรหัสผ่านครั้งแรก G2-r1

20 พฤศจิกายน 2026 · ร่าง Desktop และ Mobile รอภูตรวจรับ

สมาชิกที่ยังไม่มีรหัสผ่านของ papaipak เริ่มจาก **การเข้าสู่ระบบและความปลอดภัย** แล้วเลือก **ตั้งรหัสผ่าน** เมื่อยืนยันความเป็นเจ้าของบัญชีแล้ว จึงกรอกรหัสผ่านใหม่สองช่อง ระบบกลับมาที่หน้าความปลอดภัยพร้อมข้อความ **ตั้งรหัสผ่านแล้ว** และปุ่ม **เปลี่ยนรหัสผ่าน** เมื่อยืนยันผลสำเร็จ
