# การทำงานของการตั้งรหัสผ่านครั้งแรก

## ทางเข้าและการยืนยันบัญชี

- สมาชิกที่เข้าสู่ระบบและยังไม่มีรหัสผ่านของ papaipak เห็น **ตั้งรหัสผ่าน** ในแถวรหัสผ่านของหน้า **การเข้าสู่ระบบและความปลอดภัย** สมาชิกที่มีรหัสผ่านแล้วใช้ **เปลี่ยนรหัสผ่าน** ตาม [แบบหน้าความปลอดภัย](../account-security-g2-r1-review/README.md)
- ปุ่ม **ตั้งรหัสผ่าน** เปิดหน้ายืนยันว่าเป็นเจ้าของบัญชี ปุ่ม **ยืนยันตัวตน** เข้าสู่ขั้นยืนยัน และเปิดฟอร์มรหัสผ่านได้เมื่อยืนยันสำเร็จเท่านั้น วิธีและอายุการยืนยัน รวมถึงวิธีกู้การยืนยันที่หมดอายุ ยังรอข้อสรุป
- ผู้ใช้ออกจากหน้ายืนยันหรือยกเลิกก่อนส่งได้จากฟอร์ม เมื่อกลับออกไปให้ล้างค่ารหัสผ่านทั้งสองช่อง หากเซสชันเข้าสู่ระบบหมดอายุให้กลับไปเข้าสู่ระบบตาม [แบบสถานะเซสชัน](../g2-r8-review/README.md) ผู้ใช้เริ่มขั้นตั้งรหัสผ่านอีกครั้งหลังเข้าสู่บัญชี
- กฎเข้าสู่ระบบด้วย Google ยังคงใช้ตาม [ข้อตกลง Google](../account-google-link-g2-r2-review/README.md) ผู้ใช้เจอขั้นยืนยันในร่างนี้เมื่อเลือกตั้งรหัสผ่าน

## ฟอร์มและผลลัพธ์

| สถานะ | พฤติกรรมที่เสนอ |
| --- | --- |
| พร้อมกรอก | แสดงช่อง **รหัสผ่านใหม่** และ **ยืนยันรหัสผ่านใหม่** ซ่อนค่าทั้งสองช่องเป็นค่าเริ่มต้น แต่ละช่องมีปุ่มแสดงหรือซ่อนของตัวเองและพื้นที่กด 44 × 44 พิกเซล |
| ช่องว่างหรือค่าผิดเงื่อนไข | แสดงข้อผิดพลาดใต้ช่องที่เกี่ยวข้อง เมื่อกรอกสองช่องต่างกันให้แสดงข้อความใต้ช่องยืนยันและย้ายโฟกัสไปช่องนั้น กฎความยาวและเงื่อนไขของรหัสผ่านครั้งแรกยังรอข้อสรุป |
| ส่งแล้วกำลังรอ | แสดง **กำลังตั้งรหัสผ่าน…** ล็อกช่องกรอกและปุ่มส่งระหว่างรอ |
| ยืนยันว่าไม่สำเร็จ | แสดงข้อความใกล้ปุ่ม **ลองอีกครั้ง** ผู้ใช้แก้ค่าหรือลองอีกครั้งได้หากการยืนยันบัญชียังมีผล |
| ยังยืนยันผลไม่ได้ | ล็อกช่องกรอกและให้ **ตรวจสอบผล** จากสถานะของบัญชี หากยืนยันสำเร็จให้ไปหน้าสรุป หากยืนยันว่าไม่สำเร็จจึงเปิดให้ลองอีกครั้ง หากยังยืนยันผลไม่ได้ให้คงสถานะนี้ |
| ยืนยันว่าตั้งสำเร็จ | ล้างค่ารหัสผ่านในฟอร์ม กลับหน้าความปลอดภัย แสดงข้อความ **ตั้งรหัสผ่านแล้ว** หนึ่งจุดเหนือรายการ และเปลี่ยนปุ่มในแถวรหัสผ่านเป็น **เปลี่ยนรหัสผ่าน** |

ข้อความยืนยันผลในร่างนี้อยู่ในหน้าความปลอดภัย ส่วน [Toast G2-r9](../g2-r9-toast-review/README.md) ใช้กับการบันทึกข้อมูลส่วนตัว ร่างนี้เสนอให้โปรแกรมอ่านหน้าจอประกาศสถานะกำลังส่งและผลลัพธ์ รวมถึงตั้งชื่อปุ่มแสดงหรือซ่อนให้ระบุช่องได้

ขั้นยืนยัน ฟอร์ม การตรวจผล และการเปลี่ยนสถานะในชุดนี้เป็นสเปกออกแบบที่รอตรวจรับ
