# การตั้งรหัสผ่านครั้งแรกผ่านลิงก์อีเมล

1. ผู้ที่เข้าสู่ระบบแล้วและยังไม่มีรหัสผ่านของ papaipak เลือก **ตั้งรหัสผ่าน** จากหน้าความปลอดภัย
2. หน้าขอลิงก์แสดงอีเมลของบัญชีแบบปิดบังบางส่วน ผู้ใช้กด **ส่งลิงก์ตั้งรหัสผ่าน** เพื่อขอส่งไปที่อีเมลที่ผ่านการยืนยันของบัญชีเดิม ปลายทางมาจากบัญชีที่ใช้อยู่
3. ระหว่างส่งให้แสดงสถานะกำลังส่ง เมื่อได้รับผลว่าระบบรับคำขอส่งแล้วให้แสดง **ส่งลิงก์แล้ว** พร้อมทางขอส่งอีกครั้ง หากส่งไม่สำเร็จให้แสดงข้อความและปุ่มลองใหม่ กรณีผลการส่งยังไม่ชัดให้แสดงว่ายังยืนยันการส่งไม่ได้
4. อีเมลชื่อ **ตั้งรหัสผ่านบัญชี papaipak** มีปุ่ม **ตั้งรหัสผ่าน** ลิงก์หมดอายุได้และใช้ได้ครั้งเดียวสำหรับบัญชีที่ขอ
5. เปิดฟอร์มบน papaipak เมื่อยืนยันว่าลิงก์ยังใช้ได้ บัญชีที่เข้าสู่ระบบตรงกับผู้ขอ และบัญชียังไม่มีรหัสผ่าน หากออกจากระบบแล้ว ให้เข้าสู่บัญชีเดิมก่อนทำรายการต่อในเส้นทางจากลิงก์ที่ยังใช้ได้ หากบัญชีที่ใช้อยู่ต่างกัน ให้กลับไปเข้าสู่บัญชีเดิม การเข้าด้วย Google ใช้ตามแบบเดิม
6. ลิงก์หมดอายุหรือใช้แล้วให้กลับไปขอลิงก์ใหม่จากหน้าความปลอดภัยเมื่อบัญชียังมีสิทธิ์ตั้งรหัสผ่าน หากบัญชีตั้งรหัสผ่านแล้ว ผู้ใช้เข้าหน้าความปลอดภัยเพื่อเลือก **เปลี่ยนรหัสผ่าน**
7. รหัสผ่านใหม่และการยืนยันอยู่ในฟอร์มบนเว็บไซต์ เมื่อยืนยันว่าตั้งสำเร็จ ให้กลับหน้าความปลอดภัยและใช้สถานะตาม [ร่าง G2-r1](../account-password-setup-g2-r1-review/interaction-spec.md)

ชุดนี้ร่างเฉพาะเส้นทางตั้งรหัสผ่านจากอีเมล อายุลิงก์ เงื่อนไขส่งซ้ำ เกณฑ์อีเมลที่มีสิทธิ์ และเงื่อนไขรหัสผ่านยังรอข้อสรุป
