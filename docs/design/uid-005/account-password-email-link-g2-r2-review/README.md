# UID-005 · ตั้งรหัสผ่านผ่านลิงก์อีเมล G2-r2

20 พฤศจิกายน 2026 · ร่างรอภูตรวจรับ

สมาชิกที่ยังไม่มีรหัสผ่านเลือก **ตั้งรหัสผ่าน** ในหน้าความปลอดภัย แล้วกด **ส่งลิงก์ตั้งรหัสผ่าน** ระบบส่งอีเมลไปยังที่อยู่ที่ยืนยันแล้วของบัญชี ผู้ใช้เปิดอีเมล กด **ตั้งรหัสผ่าน** และกลับมากรอกรหัสผ่านใหม่สองช่องบน papaipak
