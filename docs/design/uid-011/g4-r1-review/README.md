## การใช้งาน

- หน้าแรกโหลด TikTok Embed Player เฉพาะคลิปที่เลือกและรอให้ผู้ชมกดเล่น ภาพก่อนเล่นมาจากตัวเล่น ปุ่ม **คลิปก่อนหน้า** และ **คลิปถัดไป** เปลี่ยนคลิปตามลำดับที่บันทึก พร้อมแสดงตำแหน่ง เช่น **2 / 6** ปิดปุ่มที่ปลายรายการ และซ่อนปุ่มเลื่อนกับตำแหน่งเมื่อมีคลิปเดียว
- ชื่อที่แสดงบนเว็บอยู่ใต้ตัวเล่น ใช้ชื่อจาก TikTok เติมให้เมื่อดึงได้และแก้ได้ หากดึงไม่ได้ให้ช่องชื่อว่างพร้อมข้อความบอกให้กรอก ชื่อที่บันทึกจะปรากฏเมื่อเลือกคลิปนั้น ตัวอย่างสถานะพร้อมบันทึกในชุดนี้ใช้ชื่อที่กรอกแล้ว
- แสดงเครดิตต้นทางใต้ตัวเล่นเมื่อมีข้อมูล หากดึงไม่ได้ให้ใช้ **ดูใน TikTok** ที่เปิดโพสต์ต้นทาง ปุ่ม **ดูบ้านพัก** แสดงเมื่อคลิปที่เลือกเชื่อมกับบ้านที่เปิดดูได้
- ถ้าโหลดตัวเล่นพลาดชั่วคราว ให้ใช้ **ลองใหม่** ในกรอบคลิปที่เลือก กรณียืนยันว่าเล่นไม่ได้ใช้ขั้นซ่อนคลิปและแจ้งเตือนตาม G4 เมื่อเหลือ 0 คลิปพร้อมแสดง ให้ยุบทั้งส่วน TikTok ตาม [สเปก G4](../g4-review/interaction-spec.md)

ภาพใน Pencil ใช้ภาพบ้านและข้อมูลตัวอย่างเพื่อแสดงตำแหน่งตัวเล่น ตัวควบคุมและภาพก่อนเล่นของจริงมาจาก TikTok การทดสอบบน HTTPS เห็นภาพปกและเครดิตในตัวเล่นก่อนกดเล่นทั้ง 5 คลิป ส่วนสถานะที่ใช้ยืนยันปัญหาภาพก่อนเล่นต้องตรวจเมื่อเชื่อมตัวเล่นจริง
