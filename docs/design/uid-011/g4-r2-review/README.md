# UID-011 · G4-r2 · ระบบจัดการคลิป TikTok บนหน้าแรก

เจ้าของตอบ **“อนุมัติ”** เมื่อ 13 พฤศจิกายน 2026 (Asia/Bangkok) หลังได้รับผลแก้และตรวจซ้ำทั้ง 8 flow ใน Pencil และขอให้จัด section ตามโครงมาตรฐานของโปรเจกต์ การอนุมัติครอบคลุมแบบและเส้นทางที่แสดงในชุดนี้ งานพัฒนาและทดสอบระบบจริงอยู่ในขั้นแยก

เปิด [Pencil](../../dsd-001/papaipak-ui.pen) ที่ section **UID-011 · คลิป TikTok หน้าแรก** (`FvFoc`) ไวร์เฟรม G2 (`rtD9Y`) อยู่ซ้าย แบบ G4-r2 (`SsGW1`) อยู่ขวา ชุด G3, G4, G4-r1 และเฟรมทดลองแรกอยู่ใน Archive (`H9Hti`) ใต้ section หลัก

ชุดหลักวาง Desktop ทางซ้ายและ Mobile ทางขวา 81 สถานะ ได้แก่ เส้นทางหลัก 10 สถานะ แก้ลิงก์คลิปเดิม 24 สถานะ ทางเลือกและผลลัพธ์ 32 สถานะ เมนูและการเลื่อน 10 สถานะ และผลบนหน้าแรกลูกค้า 5 สถานะ กลุ่มภาพอ้างอิงเพิ่มเติม (`ESxT8`) เก็บภาพมือถือ G4 และรายการก่อนเพิ่มสำหรับดูประกอบ

วันที่ 13 พฤศจิกายน 2026 เติมแบบ Mobile ให้ Desktop ที่ยังขาดคู่ 36 สถานะตามคำขอเจ้าของ ครอบคลุมการตรวจลิงก์และข้อมูล TikTok การแก้และนำคลิปออก การดูตัวอย่างและบันทึก การแจ้งเตือน และการจัดลำดับในรายการยาว บันทึกนี้เก็บชุดมือถือที่เติมสำหรับตรวจแบบต่อจากการอนุมัติ G4-r2 เดิม

ในหลังบ้าน ปุ่มสามจุดเปิดคำสั่งของแถวนั้นและใช้ **เลือกตำแหน่ง** เพื่อเข้าจัดลำดับได้ทันที จุดจับแสดงในโหมดจัดลำดับ รายการยาวเลื่อนในแผงซ้าย ตัวอย่างข้างฟอร์มแสดงคลิปที่เลือก ส่วน **ดูตัวอย่างหน้าแรก** แสดงชุดพร้อมเผยแพร่ตามค่าที่กำลังแก้ หน้าแรกลูกค้าใช้ลำดับที่บันทึกและปุ่มเปลี่ยนคลิปตาม G4-r1

ตรวจแบบจากภาพและเลเยอร์ โดยมีเอเจนต์สองตัวต่อ flow ตรวจซ้ำ และตรวจจุดแก้รอบสุดท้ายหลังปรับแบบ การบันทึกจริง การคืนโฟกัสและใช้คีย์บอร์ด การเลื่อนขณะลาก และการเล่น TikTok ยังต้องทดสอบในหน้าที่ทำงานได้ [สเปกการใช้งาน G4](../g4-review/interaction-spec.md) · [รายละเอียดตัวเล่น G4-r1](../g4-r1-review/README.md)
