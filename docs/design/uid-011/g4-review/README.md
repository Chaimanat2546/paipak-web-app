## ผลเทียบเกณฑ์ตรวจรับ

| ข้อ | ผลตรวจระดับแบบและสเปก |
| --- | --- |
| 1 · จัดการคลิป | มีภาพเพิ่ม แก้ เปิดหรือซ่อน เรียง ดูตัวอย่าง และยืนยันนำออกทั้งสองขนาด รวมการเลือกตำแหน่งโดยไม่ต้องลากใน UI-01 ถึง UI-05, UI-10, UI-21 และ G4-05 |
| 2 · ค่าที่แก้กับค่าที่บันทึก | UI-05, UI-07, UI-11, UI-19 และ UI-20 แสดงตัวอย่าง งานค้าง บันทึกพลาด กำลังบันทึก และสำเร็จ คู่ G4-01 กับ G4-02 ใช้ชุดคลิปเดียวกันเพื่อเทียบผลหลังบันทึก |
| 3 · ความพร้อมของคลิป | UI-17 ครอบคลุมลิงก์ผิด คลิปซ้ำ คลิปเปิดไม่ได้ และปกไม่พร้อม UI-12 ถึง UI-15 แสดงหลายคลิป คลิปเดียว ลองใหม่ และซ่อนทั้งส่วนเมื่อเหลือ 0 คลิป G4-03 แสดงคลิปที่ยืนยันแล้วว่าเล่นไม่ได้ |
| 4 · สิทธิ์และการเข้าถึง | สเปกระบุสิทธิ์ผู้ดูแลชุดเดียว ป้ายกำกับ ลำดับโฟกัส วิธีจัดลำดับด้วยคีย์บอร์ด และรายการตรวจตัวเล่นจริง G4-05 แสดงตัวเลือกตำแหน่งและปุ่มยืนยัน |
| 5 · เกณฑ์เตือน | G4-01 แสดง 6 คลิปพร้อมปุ่มบันทึก UI-06 แสดงคำเตือนที่ 7 พร้อมปุ่มกลับไปปรับรายการหรือบันทึกต่อ |
| 6 · ภาพปกและบ้านที่เชื่อม | UI-03 ค้นและเลือกได้หนึ่งหลัง UI-09 แสดงเมื่อปกโหลดไม่ได้ G4-04 แสดงปกกลับมาแต่ยังซ่อน UI-12 กับ UI-13 เทียบการแสดงปุ่มดูบ้านกับกรณีที่บ้านเปิดไม่ได้ |
| 7 · ชื่อและเครดิต | UI-01, UI-02, UI-13 และ UI-17 แสดงช่องชื่อที่แก้ได้ เครดิตต้นทาง และลิงก์ดูใน TikTok เมื่อดึงเครดิตไม่ได้ |
| 8 · การแจ้งเตือน | UI-08 แสดงแท็บทั้งหมด ยังไม่ได้อ่าน และสถานะอ่านครบ UI-09 กับ G4-03 แสดงหน้าปลายทางแยกตามสาเหตุทั้งสองขนาด |

ตัวเลือกตำแหน่งใช้ร่วมกันได้ทั้งมือถือและคีย์บอร์ด ตัวอย่าง 6 และ 7 คลิปช่วยให้เทียบจุดเริ่มเตือน และตัวอย่างหน้าแรกหลังบันทึกใช้คลิปชุดเดียวกับภาพก่อนบันทึก

ชุดตรวจมี 55 เฟรมใน 28 กลุ่ม การตรวจรอบนี้ครอบคลุมภาพส่งออก ขนาดเฟรม การจัดบอร์ด และความสอดคล้องกับข้อตกลง การดึงข้อมูลจาก TikTok การเล่น การบันทึก การส่งแจ้งเตือน และการเข้าถึงด้วยคีย์บอร์ดหรือโปรแกรมอ่านหน้าจอมี [รายการตรวจสำหรับหน้าที่ทำงานได้](interaction-spec.md#รายการตรวจเมื่อมีหน้าที่ทำงานได้)
