# UID-011 · สเปกการใช้งาน G4 ที่อนุมัติแล้ว

สเปกนี้ใช้คู่กับ [ภาพเดสก์ท็อปและมือถือ](README.md) และ [ข้อตกลง G0](../../../../tasks/design/UID-011.md) ผู้มีสิทธิ์ดูแลคลิปชุดเดียวใช้หน้าจัดการคลิป บันทึกการเปลี่ยนแปลงขึ้นหน้าแรก และรับแจ้งเตือนปัญหาผ่านกระดิ่งหลังบ้าน

## รายการและฟอร์มคลิป

1. เปิด **คอนเทนต์ › คลิป TikTok หน้าแรก** เดสก์ท็อปเห็นรายการทางซ้ายกับฟอร์มทางขวา มือถือเปิดรายการก่อน แล้วเปิดฟอร์มเต็มจอเมื่อเพิ่มหรือเลือกคลิป พร้อมคำสั่งบันทึกด้านล่าง
2. กด **เพิ่มคลิป** แล้ววางลิงก์ TikTok ทีละคลิป ช่องลิงก์แสดงสถานะกำลังตรวจและข้อความเฉพาะกรณีลิงก์ผิด คลิปซ้ำ หรือคลิปเปิดไม่ได้ เมื่อข้อมูลพร้อมให้เห็นตัวอย่างก่อนบันทึก
3. ใส่ชื่อ TikTok เป็นค่าเริ่มต้นในช่อง **ชื่อที่แสดงบนเว็บ** ผู้ดูแลแก้ชื่อนี้ได้ เครดิตใช้ข้อมูลต้นทาง หากดึงเครดิตไม่ได้ ให้แสดง **ดูใน TikTok** ที่ชี้ไปยังคลิปเดิม
4. ใช้ภาพปกจาก TikTok เมื่อภาพปกไม่พร้อม ให้แสดงสถานะที่ส่วนข้อมูลคลิปและซ่อนคลิปจากหน้าแรก ช่องภาพปกใช้ข้อมูลต้นทางแบบอ่านอย่างเดียว เมื่อปกกลับมาแล้ว ให้แสดงว่าคลิปยังซ่อนจนกว่าผู้ดูแลจะเปิดแสดงและบันทึก
5. **บ้านพักที่เชื่อม** เว้นว่างได้ หรือค้นด้วยชื่อบ้านหรือรหัส DV ตามหน้าจัดการหมวดหมู่ แสดงชื่อและรหัสในผลค้นหา เมื่อกด **เลือก** ให้กลับฟอร์มเดิมพร้อมบ้านหนึ่งหลัง ผู้ดูแลเปลี่ยนหรือล้างบ้านที่เลือกได้ การเปลี่ยนมีผลหลังบันทึก

แถวรายการอ่านชื่อ สถานะ และสาเหตุที่ซ่อนได้พร้อมกัน ชื่อยาวตัดด้วย … เมื่อพื้นที่แถวจำกัด และใช้ชื่อเต็มในฟอร์มกับป้ายกำกับที่โปรแกรมอ่านหน้าจออ่านได้

## จัดลำดับ ดูตัวอย่าง และบันทึก

| ขั้น | การตอบสนอง |
| --- | --- |
| จัดลำดับ | ลากจุดจับหรือเปิดตัวเลือกตำแหน่ง ระบุเลขปัจจุบันและเลขเป้าหมาย กด **ย้ายไปตำแหน่ง …** เพื่อย้ายในรายการที่กำลังแก้ กด **ยกเลิก** เพื่อปิดตัวเลือกและเก็บลำดับเดิม |
| ดูตัวอย่าง | เปิดได้จากฟอร์มและโหมดจัดลำดับ ใช้คลิปที่กำลังตั้งให้แสดงและพร้อมขึ้นหน้าแรกตามลำดับที่กำลังแก้ การกลับไปปรับรายการเก็บข้อมูลที่แก้ไว้ |
| บันทึกเมื่อพร้อมแสดง 0–6 คลิป | กด **บันทึก** เพื่อเข้าสู่สถานะกำลังบันทึกตามปกติ |
| บันทึกเมื่อพร้อมแสดงตั้งแต่ 7 คลิป | แสดงหน้าต่างยืนยันบนคอมและแผงด้านล่างบนมือถือ ระบุจำนวนและแจ้งว่าหน้าแรกอาจโหลดช้าลง **บันทึกต่อ** ส่งค่าที่แสดงในตัวอย่าง **กลับไปปรับรายการ** คืนข้อมูลที่กำลังแก้และหน้าแรกยังใช้ค่าที่บันทึกไว้ |
| กำลังบันทึก | แสดงสถานะกำลังบันทึกและพักการกดซ้ำ หน้าแรกยังใช้ชุดที่บันทึกไว้ |
| บันทึกสำเร็จ | แสดง Toast และใช้ลำดับ ชื่อ บ้านที่เชื่อม และสถานะแสดงผลจากค่าที่บันทึกสำเร็จ |
| บันทึกไม่สำเร็จ | แจ้งในบริเวณงานที่กำลังทำ คงค่าในฟอร์มหรือลำดับที่แก้ไว้และเปิดให้ลองบันทึกอีกครั้ง หน้าแรกยังใช้ชุดที่บันทึกไว้ |
| มีการแก้ไขค้าง | ก่อนเปลี่ยนคลิปหรือออกจากงานปัจจุบัน ให้เลือก **บันทึก**, **ทิ้งการแก้ไข** หรือ **แก้ต่อ** การบันทึกยังใช้เกณฑ์เตือนที่ 7 คลิป การทิ้งคืนชุดที่บันทึกไว้ การแก้ต่อกลับไปงานเดิม |
| นำคลิปออก | เปิดขั้นยืนยันพร้อมชื่อคลิป ยกเลิกเพื่อกลับฟอร์มเดิม เมื่อยืนยันและบันทึกสำเร็จ ให้นำคลิปออกจากรายการ papaipak และหน้าแรก หากบันทึกพลาด ให้คงรายการเดิมและเปิดให้ลองอีกครั้ง |

ตัวเลขที่ใช้เตือนนับเฉพาะคลิปที่เปิดแสดงและพร้อมขึ้นหน้าแรกในชุดที่จะบันทึก เทียบ [ตัวอย่าง 6 คลิป](GwnoN.png) กับ [ผลหลังบันทึก](xtobY.png) คลิปแรกคือ **พาชม Celuna Pool Villa** คลิปถัดไปคือ **ทริปครอบครัวใกล้ทะเล** ตามรายการเดียวกันทั้งบนคอมและมือถือ

## หน้าแรก

- แสดงทุกคลิปที่เปิดและพร้อมตามลำดับที่บันทึก เลือกปกก่อนแล้วกดเล่นเอง เล่นทีละคลิป และใช้ UI ของ TikTok สำหรับเล่น หยุด และกำลังบัฟเฟอร์
- แสดงชื่อ เครดิต และปุ่ม **ดูบ้านพัก** ใกล้คลิปที่เลือกภายนอกตัวเล่น ปุ่มนี้ปรากฏเฉพาะคลิปที่เชื่อมกับบ้านและเปิดหน้ารายละเอียดได้ เมื่อกดให้ไปที่หน้ารายละเอียดของบ้านหลังนั้นโดยตรง
- เมื่อมีคลิปเดียว แสดงคลิปกับข้อมูลของคลิปและซ่อนตัวควบคุมเลื่อน หากโหลดตัวเล่นพลาดชั่วคราว ให้คงคลิปที่เลือกไว้พร้อมปุ่ม **ลองใหม่**
- หากโหลดภาพปกไม่ได้หรือยืนยันแล้วว่าเล่นไม่ได้ ให้ซ่อนคลิปและแสดงคลิปที่พร้อมตามลำดับที่บันทึก เมื่อเหลือ 0 คลิป ให้ซ่อนส่วน TikTok ทั้งส่วน บทความต่อจากแถว Luxury บนเดสก์ท็อปและแถวสายปาร์ตี้บนมือถือในแบบ Home G4-r1

## กระดิ่งแจ้งเตือน

- แจ้งผู้ดูแลเมื่อคลิปถูกซ่อนเพราะภาพปกโหลดไม่ได้หรือยืนยันแล้วว่าเล่นไม่ได้ แต่ละแถวระบุชื่อคลิป เหตุที่ถูกซ่อน และเวลา ใช้ภาพปกหรือไอคอนแทนเมื่อภาพปกไม่พร้อม
- แท็บ **ทั้งหมด** แสดงกลุ่ม **ใหม่** และ **ก่อนหน้านี้** แท็บ **ยังไม่ได้อ่าน** แสดงเฉพาะรายการที่ยังไม่ได้เปิด แต่ละกลุ่มเรียงล่าสุดก่อน แสดงจุดสีน้ำเงินในรายการที่ยังไม่ได้อ่านและเลื่อนในแผงได้เมื่อรายการยาว
- เมื่อกดรายการและเปิดคลิปได้ ให้เข้าแบบฟอร์มของคลิปนั้นและนับว่าอ่านแล้ว การเปิดแผงหรือสลับแท็บคงสถานะอ่าน หากมีงานค้าง ให้ใช้ขั้นยืนยันก่อนออกจากคลิปเดิม เมื่ออ่านครบให้ซ่อนจุดบนกระดิ่งและยังเปิดรายการเดิมจาก **ทั้งหมด** ได้
- [กรณีปกโหลดไม่ได้](README.md#ภาพสำหรับตรวจ) และ [กรณียืนยันแล้วว่าเล่นไม่ได้](iZPSP.png) เปิดไปยังคลิปคนละรายการตามชื่อในแผง

## องค์ประกอบและการเข้าถึง

| องค์ประกอบ | ข้อกำหนดในแบบ |
| --- | --- |
| ตัวอักษรและสี | Mitr กรมท่า `#072D59` บนพื้นขาว ฟ้าอ่อน `#DBF2FC` สำหรับการเลือกหรือพื้นรอง ปุ่มหลักใช้ชมพูเข้ม `#C5375B` กับข้อความขาว สถานะผิดพลาดและการแสดงผลมีข้อความกำกับ |
| ปุ่มและสวิตช์ | ใช้ป้ายตามงาน เช่น **บันทึกคลิป**, **บันทึกลำดับ**, **ลองใหม่** และ **แสดงบนหน้าแรก** ปุ่มไอคอนมีชื่อที่อ่านได้ เช่น ปิดแจ้งเตือนและล้างบ้านที่เชื่อม สวิตช์สื่อสถานะเปิด ปิด หรือปิดใช้งาน |
| ฟอร์มและข้อผิดพลาด | ผูกป้ายชื่อกับช่องลิงก์และชื่อคลิป ข้อผิดพลาดเฉพาะช่องอยู่กับช่อง สถานะบันทึกประกาศให้โปรแกรมอ่านหน้าจอรับรู้โดยไม่ย้ายโฟกัสไปที่ Toast |

| หน้าต่างและแผง | ตั้งชื่อแผงตามหัวข้อ เมื่อเปิดให้ย้ายโฟกัสเข้าแผง เดินโฟกัสตามลำดับการอ่านในแผง ปิดหรือยกเลิกแล้วคืนโฟกัสให้ปุ่มที่เปิดแผง สำหรับแผงยืนยันให้ใช้ปุ่มยกเลิกหรือกลับไปแก้เป็นจุดเริ่มโฟกัส |
| ค้นบ้านและแจ้งเตือน | ค้นบ้านเริ่มจากช่องค้นหา แล้วเดินไปยังผลและปุ่มเลือก แผงแจ้งเตือนเดินจากปิดและแท็บไปยังแถว ระบุชื่อคลิป สถานะอ่าน และสาเหตุผ่านข้อความหรือชื่อที่โปรแกรมอ่านหน้าจอรับรู้ได้ |
| TikTok บนหน้าแรก | ลำดับควบคุมผ่านปุ่มเลื่อน เล่น เครดิต และดูบ้านพักตามบริบท แสดงวงโฟกัสที่เห็นบนพื้นกรมท่า ใช้ข้อความกำกับปุ่มเลื่อนและลองใหม่ และตรวจว่ากลับจากตัวเล่นไปยังส่วนที่เหลือของหน้าได้ |

## รายการตรวจเมื่อมีหน้าที่ทำงานได้

- ทดสอบการวางลิงก์จริง การตรวจซ้ำ การได้ชื่อและเครดิตจากต้นทาง ลิงก์ดูใน TikTok เมื่อเครดิตหาย และการหายหรือกลับมาของภาพปก
- ทดสอบการบันทึกที่ 6, 7 และมากกว่า 7 คลิป การยกเลิกจากคำเตือน การกดซ้ำระหว่างบันทึก บันทึกพลาดแล้วลองใหม่ และนำคลิปออกจากรายการ
- ทดสอบกดดูบ้านพักไปบ้านที่เชื่อมโดยตรง การซ่อนปุ่มเมื่อบ้านเปิดไม่ได้ และการคงลำดับหลังคลิปหนึ่งถูกซ่อน
- ทดสอบเลือกและเล่นจริงบนคอมกับมือถือ การเล่นทีละคลิป การลองใหม่หลังโหลดพลาดชั่วคราว การซ่อนเมื่อยืนยันว่าเล่นไม่ได้ และการยุบทั้งส่วนเมื่อเหลือ 0 คลิป
- ทดสอบผู้มีและไม่มีสิทธิ์ดูแลคลิป การได้รับแจ้งเตือนทั้งสองสาเหตุ การเปิดไปยังคลิปตามชื่อ การอ่านแล้ว และการกลับจากแผงโดยคงงานที่แก้ไว้
- ทดสอบคีย์บอร์ดและโปรแกรมอ่านหน้าจอในฟอร์ม ตัวเลือกตำแหน่ง แผงยืนยัน กระดิ่ง และตัวเล่นจริง รวมถึงชื่อยาว ข้อความขยาย และพื้นที่จอแคบ

การจำแนกข้อผิดพลาดของตัวเล่นจริง การดึงข้อมูลต้นทาง และความเร็วหน้าแรกเป็นจุดตรวจเมื่อมีการเชื่อม TikTok จริง ชุด G4 ใช้ภาพและข้อมูลตัวอย่างเพื่อรับรองแบบและข้อตกลงการใช้งาน
