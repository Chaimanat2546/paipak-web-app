# UID-011 · จัดลำดับคลิปจากรายการซ้าย G4-r3

**อนุมัติ G4-r3 และปิดงานออกแบบ** · 18 พฤศจิกายน 2026 · เดสก์ท็อป 1600 × 900

กด **จัดลำดับ** ที่หัวรายการซ้ายก่อน จากนั้นลากคลิปได้จากทั้งแถว จุดหกจุดเป็นไอคอนบอกว่าลากได้ ฟอร์มและตัวอย่างของคลิปที่กำลังแก้ยังเปิดอยู่ด้านขวา บันทึกหรือยกเลิกได้ที่ท้ายรายการซ้าย

เปิด section **UID-011 · คลิป TikTok หน้าแรก** (`FvFoc`) ใน [ไฟล์ Pencil หลัก](../../dsd-001/papaipak-ui.pen) ไวร์เฟรม G2 อยู่ซ้าย แบบเดสก์ท็อป G4-r3 อยู่ขวาในกลุ่ม `aQPs7` และชุด [G4-r2 ที่อนุมัติ](../g4-r2-review/README.md) อยู่ด้านล่างสำหรับอ้างอิงมือถือ หน้าแรก และเส้นทางเดิม
