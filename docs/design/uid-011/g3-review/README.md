## รายละเอียดที่เสนอให้ตรวจ

- หลังบ้านใช้โครงจากหน้าจัดการหมวดหมู่ พื้นขาวและฟ้าอ่อน ตัวอักษร Mitr สีกรมท่า และปุ่มบันทึกชมพูเข้ม สถานะในรายการมีข้อความกำกับ เพื่อให้เห็นได้ทันทีว่าคลิปแสดงอยู่หรือถูกซ่อนเพราะอะไร
- กระดิ่งเปิดแผงที่มีแท็บ **ทั้งหมด** และ **ยังไม่ได้อ่าน** แต่ละรายการแสดงชื่อคลิป สาเหตุที่ถูกซ่อน และเวลา รายการที่ยังไม่ได้อ่านมีจุดสีน้ำเงินและอยู่ในกลุ่ม **ใหม่** รายการที่อ่านแล้วอยู่ในกลุ่ม **ก่อนหน้านี้** แต่ละกลุ่มเรียงจากล่าสุด และเลื่อนดูภายในแผงได้เมื่อรายการยาวเกินพื้นที่
- การเปิดแผงหรือสลับแท็บคงสถานะการอ่านไว้ เมื่อเปิดคลิปจากรายการจึงนับว่ารายการนั้นอ่านแล้วและพาไปยังคลิปที่เกี่ยวข้อง หากมีการแก้ไขค้าง ให้ใช้ขั้นยืนยันเดิมก่อนออกจากคลิปปัจจุบัน เมื่ออ่านครบ จุดบนกระดิ่งหายและรายการเดิมยังเปิดดูได้จากแท็บ **ทั้งหมด**
- ตัวอย่างคลิปอยู่ในฟอร์มแก้ไข ส่วนตัวอย่างก่อนบันทึกแสดงลำดับคลิปที่จะขึ้นหน้าแรก หากจะแสดงตั้งแต่ 7 คลิป ทั้งหน้าต่างเดสก์ท็อปและแผงมือถือมีปุ่มกลับไปปรับรายการกับบันทึกต่อ
- บนหน้าแรก ปุ่ม **ดูบ้านพัก** ใช้พื้นขาวและอยู่ใต้ชื่อกับเครดิตของคลิปที่เลือก ปุ่ม **ดูที่พักทั้งหมด** ใช้ชมพูเข้มตามแบบหน้าแรก ผู้ชมจึงเห็นปลายทางสองอย่างจากตำแหน่งและชื่อปุ่ม
- แถวคลิปที่มีชื่อยาวใช้เครื่องหมาย … ในรายการ ชื่อเต็มอยู่ในฟอร์ม ตัวอย่างปุ่มบันทึกแสดงปกติ ชี้เมาส์ โฟกัส และพักการกด
- ภาพบ้านและชื่อบัญชีในแบบเป็นข้อมูลตัวอย่าง ภาพอ้างอิงนำมาจากไฟล์ภาพในโปรเจกต์ เช่น [Celuna](../../dsd-001/papaipak-ui-assets/uid-003/r3-category-editorial/villa-9-outside-1.webp) และ [RimLay](../../dsd-001/papaipak-ui-assets/uid-003/villa-55-11499.webp) ภาพปกบนระบบที่ใช้งานจริงใช้จาก TikTok ตามข้อสรุป G0

## ตัวอย่างหน้าแรกจาก Home G4-r1

- UI-12 ถึง UI-14 ใช้ Header หัวข้อ TikTok รูปแบบการวางปก ปุ่ม **ดูที่พักทั้งหมด** และขอบคลื่นจากหน้าแรกที่อนุมัติ แบบมือถือใช้ภาพตัดจากหน้าแรกขนาด 390 พิกเซล ชื่อ เครดิต ปุ่มดูบ้านพัก และสถานะลองใหม่เป็นเลเยอร์ใน Pencil [หน้าแรกเดสก์ท็อป](../../dsd-001/home-g4-r1/OmUC5.png) · [หน้าแรกมือถือ](../../dsd-001/home-mobile-g4-review-r1/dKjHl.png)
- UI-15 ซ่อนส่วน TikTok ทั้งส่วน บนเดสก์ท็อป บทความต่อจากแถว **พูลวิลล่า Luxury** บนมือถือ บทความต่อจากแถว **พูลวิลล่าสายปาร์ตี้** ตามลำดับเนื้อหาของหน้าแรกแต่ละขนาด
