## สเปกขั้นตอนใช้งานสำหรับตรวจ G2

### เพิ่มคลิปและเชื่อมบ้าน

1. จากรายการคลิป กด **เพิ่มคลิป** แล้ววางลิงก์ TikTok ระบบตรวจลิงก์และแสดงตัวอย่าง เมื่อพบลิงก์ผิด คลิปซ้ำ หรือคลิปเปิดไม่ได้ ให้แสดงข้อความที่ช่องลิงก์ ภาพปกที่โหลดไม่ได้มีข้อความในส่วนข้อมูลคลิป
2. ใช้ชื่อจาก TikTok เป็นค่าเริ่มต้น ผู้ดูแลแก้ **ชื่อที่แสดงบนเว็บ** ได้ เครดิตอิงต้นทาง ถ้าดึงไม่ได้ให้แสดง **ดูใน TikTok** ภาพปกใช้จาก TikTok
3. ผู้ดูแลเลือกเชื่อมบ้านได้หนึ่งหลังด้วยชื่อบ้านหรือรหัส DV ผลค้นหาแสดงชื่อและรหัส กด **เลือก** แล้วกลับฟอร์มเดิม ค่าบ้านที่เลือกเปลี่ยนหรือล้างได้ และใช้บนหน้าแรกเมื่อบันทึกสำเร็จ

### จัดลำดับและบันทึก

- **ดูตัวอย่าง** เปิดได้จากฟอร์มแก้คลิปและโหมดจัดลำดับ แสดงคลิปที่จะขึ้นหน้าแรกตามลำดับที่กำลังแก้ กลับไปปรับรายการได้โดยเก็บการแก้ไขไว้
- เดสก์ท็อปใช้รายการทางซ้ายและฟอร์มทางขวา มือถือเปิดฟอร์มจากแถวคลิป ใช้ปุ่มบันทึกด้านล่างและแผงยืนยันจากด้านล่าง จัดลำดับด้วยการลากหรือเปิดตัวเลือกตำแหน่ง ตัวเลือกตำแหน่งมีปุ่มย้ายและยกเลิก และต้องเปิดได้ด้วยแป้นพิมพ์
- เมื่อนับคลิปที่จะขึ้นหน้าแรกได้ 7 คลิปขึ้นไป ให้แสดงคำเตือนก่อนบันทึก **กลับไปปรับรายการ** คืนข้อมูลที่กำลังแก้และยังใช้รายการเดิมบนหน้าแรก **บันทึกต่อ** ส่งบันทึกตามที่แสดงในตัวอย่าง ตัวอย่าง 6 คลิปเข้าสู่การบันทึกตามปกติ
- ระหว่างบันทึกแสดงสถานะกำลังบันทึกและพักการกดซ้ำ เมื่อสำเร็จจึงใช้ค่าที่บันทึกบนหน้าแรก เมื่อพลาดให้เก็บข้อมูลและอยู่ที่เดิมเพื่อให้ลองใหม่ได้ การออกจากหน้าที่แก้ค้างมีทางเลือก **บันทึก** **ทิ้งการแก้ไข** และ **แก้ต่อ**
- การนำคลิปออกเปิดขั้นยืนยันพร้อมชื่อคลิปในหน้าที่แก้ การยืนยันส่งบันทึกการนำออกจากรายการ papaipak และอัปเดตหน้าแรกหลังบันทึกสำเร็จ

### หน้าแรกและการแจ้งเตือน

- หน้าแรกแสดงคลิปที่เปิดไว้และพร้อมแสดงตามลำดับที่บันทึก เลือกคลิปจากตัวเลื่อนแล้วกดเล่นเอง เล่นทีละคลิป สถานะเล่น หยุด และกำลังบัฟเฟอร์ใช้ UI ของ TikTok ตัวอย่างคลิปเดียวซ่อนตัวเลื่อน
- ชื่อ เครดิต และ **ดูบ้านพัก** อยู่ภายนอกตัวเล่นและอิงคลิปที่เลือก ปุ่มไปหน้ารายละเอียดบ้านหลังที่เชื่อมโดยตรง ถ้าคลิปไม่มีบ้านเชื่อมหรือหน้าบ้านเปิดดูไม่ได้ ให้คงคลิปและซ่อนปุ่ม
- ถ้าโหลดตัวเล่นพลาดชั่วคราว ให้คงคลิปพร้อม **ลองใหม่** ถ้ายืนยันแล้วว่าเล่นไม่ได้ หรือโหลดภาพปกไม่ได้ ให้ซ่อนคลิปตามกติกา G0 หากไม่มีคลิปพร้อมแสดงเหลือ ให้ซ่อนทั้งส่วน TikTok
- กระดิ่งแจ้งผู้มีสิทธิ์ดูแลคลิปเมื่อคลิปถูกซ่อนเพราะปกโหลดไม่ได้ หรือเมื่อยืนยันแล้วว่าเล่นไม่ได้ รายการบอกชื่อคลิปและปัญหา กดแล้วเปิดคลิปนั้นในหลังบ้าน เมื่อปกกลับมาใช้ได้ ผู้ดูแลเป็นคนเปิดแสดงและบันทึกอีกครั้ง
- กล่องยืนยันและแผงบนมือถือระบุปุ่มปิดและปุ่มยืนยันชัดเจน เมื่อยกเลิกให้คืนโฟกัสไปยังตัวควบคุมที่เปิดแผง สถานะการตรวจลิงก์ การบันทึก และข้อผิดพลาดใช้ข้อความกำกับ
