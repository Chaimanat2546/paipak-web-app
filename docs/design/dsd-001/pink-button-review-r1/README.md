# ปุ่มพื้นชมพู · รอบตรวจ 1

10 พฤศจิกายน 2026 · DSD-001 · เจ้าของรับคู่สีแล้ว [หลักฐานและผลปรับทั้งชุด](../pink-button-rollout-r1/README.md)

หลังดูปุ่มใน Google Link G3-r2 เจ้าของเลือกให้ “ปุ่มให้สีเข้มขึ้นแล้วกัน แล้วก็เอาไว้ปรับกับปุ่มที่มีพื้นหลังสีชมพูทั้งระบบนะ” ในแชตเสียง โดยคงตัวอักษรขาวและขอบเขตงานออกแบบ

[บอร์ดปุ่มกลาง](KPrMv.png) · [Header และ Search บน Home](Tc0D7.png) · [ส่วน TikTok](LBs4V.png) · [Google Link G3-r3](../home-auth-google-link-g3-r3/README.md)

## กติกากลาง

| บทบาท | สี | วิธีใช้ |
| --- | --- | --- |
| `action.pink.fill` | `#C5375B` | พื้นของปุ่มที่ใช้ชมพู เฉดเข้มขึ้นในโทนเดิมและมีระยะเหนือเกณฑ์ 4.5:1 |
| `action.pink.label` | `#FFFFFF` | ข้อความและไอคอนบนพื้นปุ่มชมพูเข้ม |
| `brand.pink` | `#FD6E88` | สีแบรนด์สำหรับโลโก้ ไอคอน จุดเน้น และตัวบอกสถานะที่ใช้สีนี้อยู่แล้ว |

ปกติ (Default/Active), Hover และ Pressed ใช้ `#C5375B` กับ `#FFFFFF` เท่ากัน ได้ **5.16:1** ทุกสถานะ กติกานี้คงการตอบสนองเดิม เช่น การย่อขณะกด ถ้ามี และคงตัวบอกโฟกัสเดิม หากสถานะกำลังดำเนินการยังใช้พื้นชมพู ให้ใช้คู่สีเดิมกับข้อความและไอคอน ตัวอย่างปุ่มส่ง OTP ที่ยังรอเวลาใช้พื้น `#F2FAFE` และข้อความ `#53657C` ตามเดิม ได้ 5.65:1 ปุ่มที่ปิดใช้งานจริงคงพฤติกรรมและการแสดงสถานะของตัวเอง

ค่าคอนทราสต์มาจากสีพื้นเรียบโดยเทียบค่าก่อนปัดเศษ คู่สีปุ่มที่เสนอนี้ผ่านเกณฑ์ข้อความขนาดปกติ 4.5:1 ของ [WCAG 2.2 SC 1.4.3](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) การตรวจนี้วัดคู่สีข้อความกับพื้นปุ่ม ส่วนขอบเขตปุ่ม ตัวบอกโฟกัส และผลในระบบจริงต้องตรวจตามบริบท [OPEN-001](../../../decisions/open-decisions.yaml) ยังเปิด

## จุดที่เปลี่ยนในรอบตัวอย่างก่อนปรับทั้งชุด

- เพิ่มตัวแปรสีสองตัวและคอมโพเนนต์ใช้ซ้ำ `BNWmw` ในบอร์ด `KPrMv` ตัวอย่าง Hover และ Pressed อ้างคอมโพเนนต์เดียวกัน
- ผูกตัวแปรกับปุ่มส่งรหัส เชื่อม Google และลองเชื่อมอีกครั้งใน Google Link G3-r3 รวมปุ่มบนภาพ Home ของแบบเดียวกัน
- ผูกตัวแปรกับปุ่มเข้าสู่ระบบ ปุ่มค้นหา และปุ่มดูที่พักทั้งหมดในสำเนาตรวจรับของ Home และ TikTok โดยเก็บโลโก้ ไอคอนเมนูหน้าแรก และจุดบอกตำแหน่ง TikTok ตามต้นฉบับ

รอบตัวอย่างเริ่มจากคอมโพเนนต์กลางแยกก่อน รายการเฟรม Auth, Search Mobile, Home และ Detail ที่ผูกตัวแปรในรอบถัดไปอยู่ใน [ผลปรับทั้งชุด](../pink-button-rollout-r1/README.md) ภาพในหน้านี้เป็นหลักฐานรอบตัวอย่าง
