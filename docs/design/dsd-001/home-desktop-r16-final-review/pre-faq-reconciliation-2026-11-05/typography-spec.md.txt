# DSD-001 — Typography specification

> เจ้าของรับแพ็กเกจ Home Desktop-r16 พร้อมข้อค้างเดิมแล้วเมื่อ5พฤศจิกายน2026 รวมHeroภาพสำเร็จรูป กรณีภาพเดียวและช่วงรอโหลด ดู [หลักฐานรับแพ็กเกจ](home-desktop-r16-final-review/owner-home-acceptance.json) ตัวบทก่อนรับเก็บใน [review archive](home-desktop-r16-final-review/approved-review-content) ไม่ปิด DSD-001ทั้งTaskหรือรับรองFrontend/runtime/จออื่น ส่วนOpen/Proposed/deferredที่ไม่รับยังคงเดิม


รุ่น foundation-3-desktop + hero-banner-carousel-1 · 5 พฤศจิกายน 2026 · Direction A / review-2

**สถานะ: ฐานDesktop Home-r15รับแล้วพร้อมข้อค้าง; Heroใหม่ใช้ภาพสำเร็จรูปและเลิกใช้web-text rolesเดิม Home-r16รับเฉพาะDesktopพร้อมข้อค้างเดิมแล้ว** Mobile พักไว้ ตารางนี้ไม่ใช่การอนุมัติ typography ของทุกหน้า ทุกขนาดจอ หรือ Frontend

## Family และขอบเขต

ใช้ Mitr สำหรับไทย Latin ตัวเลข ราคา และ interface copy ตามข้อสรุปเดิม Native variable font.primary มีค่า Mitr; อ่านค่าจาก Pencil และเก็บใน [observed evidence](foundation-3-desktop/observed-values.json) ไม่มี supplementary font ที่เพิ่มหรืออนุมัติในงานนี้

ไฟล์ Mitr400/500/600 และ OFL ใน [font source record](foundation-1/font-sources.json) เป็นหลักฐานเดิม ไม่ใช่ผล font-loading ในแอป ค่าของ Home-r15 อ่านผ่าน Pencil แบบ read-only หลังรับภาพรวมแล้ว ไม่อนุมาน weight จากภาพ raster

## การตัดบรรทัดและข้อมูลไม่ครบ

- ชื่อบ้านบน Home ใช้หนึ่งบรรทัดย่อด้วย … เพื่อให้ข้อมูลในแต่ละแถวอยู่แนวเดียวกัน ต่างจากร่าง B เดิมที่เสนอสองบรรทัด ชื่อเต็มต้องเข้าถึงได้จาก Detail และ accessible name; ไม่อาศัย hover อย่างเดียว
- ภาพตัวอย่างชื่อยาวเป็นข้อความย่อที่เขียนในแบบ ไม่ใช่การทดสอบ dynamic truncation ห้ามตัดสระ/วรรณยุกต์ไทย และต้องตรวจ text zoom ก่อนรับรองระบบจริง
- ไม่ย่อ metadata ราคา หรือข้อผิดพลาดที่จำเป็นจนอ่านไม่ได้เพื่อรักษาความสูงกล่องอ้างอิง เมื่อข้อความขยายต้องพิจารณา reflow โดยรักษากฎ UX
- Home ไม่ใช้ข้อความ “ยังไม่มีข้อมูลราคา” แทนการ์ดที่ข้อมูลไม่ครบ ให้ตัดการ์ดนั้นออกตามข้อสรุป [3A–3B](f01-ui-3/home-guided-review/README.md) บ้านนั้นยังค้นเจอได้ การแสดงข้อมูลไม่ครบใน Results ยังต้องมีข้อกำหนด/หลักฐานของหน้านั้น
- ราคาตัวอย่าง เช่น เริ่มต้น ฿8,900 / คืน เป็น fixture ไม่ใช่ quote, availability หรือส่วนลดจริง

## ไทย Latin และขอบเขตการอ่าน

ปกบทความเป็นไฟล์ภาพสำเร็จรวมตัวหนังสือจาก Photoshop/เครื่องมือภายนอก เว็บไม่กำหนดฟอนต์ ขนาด ตำแหน่งหรือแก้ข้อความในภาพ Rolesด้านบนใช้กับข้อความนอกภาพเท่านั้น ไม่สร้าง cover editor หรือให้ปกตัวอย่างของผู้จัดทำเป็นเงื่อนไขรับงาน

ชื่อเด่นสูงสุด2บรรทัด เรื่องรอง1บรรทัด มีellipsisและชื่อเต็มที่เข้าถึงได้ เนื้อหาสูงสุด2บรรทัด ความสูงตามเนื้อหาจริง ไม่จองบรรทัดว่าง หากไม่มี excerpt ใช้ข้อความจาก body ของบทความนั้น ไม่แต่งคำโปรย/AI summary ปัจจุบันใช้mock bodyตามขั้นงานที่เจ้าของยืนยัน ขาดปก/ชื่อ/ปลายทางอ่านให้ข้ามเรื่องบนHome ไม่ใช้text-only cardหรือปกplaceholderที่ไม่ได้เลือก

Letter spacing ของข้อความไทยใช้0 ไม่บีบความกว้างหรือใช้ uppercase/letter spacing เป็น decoration ข้อความ Pet Friendly, Outing, Luxury ใช้ Mitr ตาม role เดิม ไม่เพิ่ม font เพื่อแก้ baseline โดยไม่อนุมัติ

ชื่อเต็ม URL และข้อความยาวในเนื้อหาต้อง wrap อย่างปลอดภัย ข้อผิดพลาดต้องเป็นข้อความที่อ่านได้ ไม่พึ่งสีเพียงอย่างเดียว ไม่อ้างว่า Mitr ทุกไฟล์รองรับ tabular figures หากยังไม่มีหลักฐาน

สี interface สำคัญใช้ Navy; metadata ใช้ #6B7280 บนขาวตาม reference CTAขาวบนชมพูคงไว้เฉพาะ visual reference และ OPEN-001 ยังเปิด ดู [token sheet](token-sheet.md) ไม่ใช้การเพิ่มน้ำหนักหรือขนาดตัวอักษรเพื่ออ้างว่าแก้ contrast แล้ว

## สถานะ responsive และการตรวจ

Mobile พักไว้ ไม่เอาขนาด36/48/64pxของ B หรือภาพ Mobileเก่ามาเป็น current A approval รอบนี้ยืนยันเฉพาะ numeric reference ของ Desktop1440px การโหลดฟอนต์จริง, fallback, 200% text zoom, การตัดชื่อไทย, screen reader และขนาดจออื่นยังไม่ได้ทดสอบ

หลักฐานตัวอย่าง Home, card focus, long title และ Footer อยู่ใน [review manifest](f01-ui-3/review-manifest.json) เกณฑ์ตรวจเอกสารคือ family/weight/size traceกลับ native ได้, กฎหนึ่งบรรทัดและข้อมูลไม่ครบตรงคำตอบล่าสุด และไม่มีข้อความอ้างว่า foundation ทั้งชุดได้รับอนุมัติแล้ว


## Hero ภาพสำเร็จรูป: ข้อกำหนดปัจจุบันและประวัติ

ปัจจุบันใช้ภาพเดียวรวมพื้นหลังและตัวหนังสือต่อสไลด์ ไม่มี live text overlay สำหรับหัวเรื่อง/คำโปรย ดู [ข้อกำหนดที่เจ้าของเลือก](hero-banner-carousel-spec.md) ไม่เพิ่มฟอนต์เว็บเพื่อจำลองตัวหนังสือในภาพ ส่วน Search, controls และข้อความเว็บอื่นยังใช้ Mitrตามroleที่เกี่ยวข้อง ต้องเตรียมข้อความทดแทน/ความหมายหัวเรื่องสำหรับเทคโนโลยีช่วยอ่านแยกจากการวาดตัวอักษรทับภาพ; รายละเอียดและการทดสอบยังค้าง

ตารางต่อไปเป็นประวัติของ Home-r15 เท่านั้น เลิกใช้กับ Hero ใหม่ ไม่ใช่ active typography tokens:
