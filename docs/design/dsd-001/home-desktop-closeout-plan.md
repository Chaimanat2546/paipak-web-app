ใช้ Governance Kit v1.0 และรูปแบบ brief จาก [template 06](../governance/06-task-brief-template.md) ภายใน Task เดิม ไม่ขอ G0 ซ้ำสำหรับงานที่อนุญาตแล้ว

## งานที่ทำต่อได้โดยไม่ต้องให้เจ้าของเลือกซ้ำ

1. บันทึกแต่ละคำตอบใน decision log พร้อมคำถาม ตัวเลือกที่ตอบ ขอบเขต และภาพ/เวอร์ชันที่รับ แก้ canonical article specifications ให้ตรงกันหลังคำตอบนั้น
2. จัดชุดบทความ default และตัวอย่างจำนวน 1/2/3/0 ตามเงื่อนไขที่รับ รวมกรณีชื่อ/คำอธิบายยาวหรือขาดข้อมูล รูปยังโหลด รูปเสีย และโหลดรายการผิดพลาด ใช้เฟรมเดิมเมื่อยังตรงข้อสรุป ไม่สร้างซ้ำโดยไม่จำเป็น
3. ตรวจภาพที่มีข้อความบนปกด้วย study fixture เพื่ออธิบาย safe area หากยังไม่มีภาพจริงให้ระบุชัด ตรวจการบังภาพจากแผงซ้อนและการแสดงภาพตามข้อตกลง ไม่สรุปว่าทุกปกจริงผ่านแล้ว
4. รวม TikTok และบทความรุ่นล่าสุดลงใน Home review copy ใหม่ใน Pencil เก็บ Home เดิมและประวัติไว้ ส่วนอื่นที่รับแล้วคงเดิม ชื่อ frame และ manifest ต้องบอกแหล่งที่มาและเวอร์ชัน
5. ปรับตัวอย่าง motion ให้ตรงแบบบทความปัจจุบัน ตรวจทิศทางเอียง การยกรูป ขนาดที่เพิ่มเมื่อ hover และ caption ที่อ่านได้ คงพฤติกรรมที่เจ้าของเลือก แยกการขยายทั้งกรอบจากการซูมภาพภายใน และไม่ถือว่าร่าง motion เก่าเป็นหลักฐานของรุ่นรวมใหม่
6. ตรวจ hover/focus และ reduced-motion ที่จำเป็นร่วมกับ state inventory เดิม ปิดข้อที่ตรวจจริงได้และแยกรายการที่ยังต้องทดสอบใน implementation
7. Export ภาพเต็มและภาพช่วงบน/กลาง/ล่าง เทียบส่วนที่ต้องคงเดิม ตรวจช่องไฟ ขอบเขตข้อความ การทับกัน สัดส่วนภาพ และสถานะควบคุม เก็บหลักฐานจาก Pencil โดยตรง
8. Reconcile foundation specifications ทั้งสี่ให้ตรงกับค่าที่ใช้ใน Home รุ่นรวม ระบุค่าที่สังเกตได้/ที่เสนอ/ที่พักไว้ให้ชัด ไม่เปลี่ยน global tokens หรือถือว่าเจ้าของรับ foundation จากการรับหน้า Home
