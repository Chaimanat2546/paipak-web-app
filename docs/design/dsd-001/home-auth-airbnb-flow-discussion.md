# Home Auth · หารือ flow อ้างอิง Airbnb

5 พฤศจิกายน2026 · DSD-001/C2 · **เจ้าของเลือกทาง1แล้ว — ร่างLoginสองขั้นรอตรวจ**

เจ้าของเลือกCสำหรับตำแหน่งerror แล้วถาม “หรือจะใช้ flow ของ airbnb” จึงเก็บ [คำตอบC](home-auth-login-error-placement-g2-r2/owner-C-selection.json) และเปิดหารือเปรียบเทียบ ไม่ยกคำถามเป็นอนุมัติOTP/เปลี่ยนขอบเขตหรือรื้อแบบที่รับแล้ว

## สิ่งที่อ่านได้จากแหล่งทางการ

- [Airbnb initial Login](https://www.airbnb.com/login): เริ่มphone/email, Continue และคำอธิบายส่งรหัสยืนยัน ข้อจำกัดการตรวจภาพในรอบก่อนยังคงอยู่ ไม่อ้างว่าเดินflowจริงครบแล้ว
- [Airbnb existing-account help](https://www.airbnb.com/help/article/3530): เลือกวิธีเข้า ใส่ข้อมูลและตามขั้นตอน มีconfirmation codeทางข้อความ/โทร/อีเมล และทางใช้รหัสผ่านด้วย ไม่ใช่ทุกบัญชีมีแต่OTPอย่างเดียว
- [Airbnb forgotten-password help](https://www.airbnb.com/help/article/76): เข้าได้ด้วยวิธีอื่นก่อน แล้วจัดการรหัสผ่านในบัญชี จึงไม่ถือว่าเหมือนreset-linkที่papaipakเลือกไว้

อ่านวันที่5พฤศจิกายน2026ผ่านFirecrawl ไม่มีการส่งฟอร์ม/บัญชีจริง ข้อสังเกตเหล่านี้ไม่ระบุprovider/APIหรือยืนยันทุกregion/rollout มีหน้าจอเหมือนกัน

## ทางเลือกที่เสนอให้ตัดสินใจ

1. **ยืมการแบ่งเป็นขั้น แต่คงวิธีเดิม:** อีเมล/โทร → ต่อ → รหัสผ่าน และGoogleยังอยู่; สมัครแยกตามข้อมูลเดิม ไม่ตรวจว่าบัญชีมีอยู่แล้วเปิดเผยให้Guestโดยอัตโนมัติ ต้องตรวจโครงใหม่และตำแหน่งerrorให้สัมพันธ์ขั้น
2. **ใกล้flowอ้างอิงแบบใช้รหัสยืนยัน:** อีเมล/โทร → code → ไปต่อ พร้อมหารือทางรหัสผ่าน/Google หากเลือก ต้องทบทวนข้อกำหนดsignup/password/recoveryและstateใหม่ก่อนออกแบบ ไม่เพิ่มSMS/OTP/providerจริงโดยเงียบ
3. **คงflowที่รับแล้ว:** Loginอีเมลหรือโทร+รหัสผ่าน/Google, Registerตามfieldsปัจจุบัน, forgotผ่านemail link และerrorC

เอเจนต์เสนอ1หากต้องการรูปแบบทีละขั้นขณะรักษาช่องทางที่ตกลงไว้ ไม่ใช่การคัดลอกAirbnbทุกพฤติกรรมหรือการตัดสินแทนเจ้าของ ข้อ2ยังอยู่นอกวิธีAuthปัจจุบันจนเจ้าของเลือก/อนุมัติการปรับขอบเขตที่ต้องใช้

ยังไม่สร้างหน้าจอAuthแบบใหม่จากคำถามนี้ ไม่เริ่มUID-005/Profile/Mobile/backend/Frontend ไม่เปลี่ยนสถานะG2รวมหรือHigh-Fi และไม่อ้างว่ากฎusername/phone/password/recoveryที่รับแล้วถูกยกเลิก

## ผลหารือ

เจ้าของเลือก1ตาม [หลักฐาน](home-auth-two-step-login-decision.json) ให้แบ่งขั้นโดยคงวิธีรหัสผ่าน/Google สร้าง [Login G2-r4](home-auth-login-g2-r4/README.md) เพื่อรับโครงใหม่ ไม่เลือกOTPหรือflowAuthเต็มของAirbnb ข้อความก่อนหน้าว่ารอเลือกเป็นสถานะขณะเสนอ ไม่ใช่current status
