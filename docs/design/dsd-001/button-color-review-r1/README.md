## สีที่อนุมัติ

| หน้าที่ | พื้นและเส้นขอบ | ข้อความหรือไอคอน |
| --- | --- | --- |
| ปุ่มหลัก | ชมพูทึบ `#C5375B` จากคู่สีที่ภูอนุมัติ | ขาว `#FFFFFF` |
| ปุ่มรองและปุ่มไอคอนแบบมีกรอบ | ขาว `#FFFFFF` ขอบเทา `#6B7280` | กรมท่า `#072D59` |
| ลบหรือยกเลิกเผยแพร่ | แดง `#B91C1C` | ขาว |
| ปุ่มข้อความ | ใช้พื้นเดิมของบริบท | กรมท่าบนพื้นสว่าง ขาวบนพื้นกรมท่า |
| แท็บที่เลือก | ฟ้าอ่อน `#DBF2FC` ขอบกรมท่า | กรมท่า |
| ปักหมุดแล้ว | ชมพูอ่อน `#FFF5F7` ขอบชมพูเข้ม | ชมพูเข้ม `#C5375B` |
| ปุ่มไอคอนบนภาพ | พื้นขาว | กรมท่า |
| Google | พื้นขาว ขอบเดิม `#8093A8` | กรมท่าและโลโก้ต้นฉบับ |
| ปิดใช้งาน | เทาอ่อน `#E5E7EB` | เทาอมฟ้า `#53657C` |

ปุ่มหลักและปุ่มแดงคงสีพื้นตอนชี้และกดตามตัวอย่าง ปุ่มรองใช้ `#F2FAFE` ตอนชี้และ `#DBF2FC` ตอนกด ใช้กรอบโฟกัสกรมท่าบนพื้นสว่าง และขาวบนพื้นกรมท่า สถานะกำลังทำงานใช้ป้ายข้อความและไอคอนบนคู่สีของปุ่มเดิม

คู่สีที่วัดจากค่าในแบบ ได้แก่ ขาวบนชมพู 5.16:1 ขาวบนแดง 6.47:1 กรมท่าบนขาว 13.74:1 กรมท่าบนฟ้าอ่อน 11.85:1 และขอบปุ่มรองบนขาว 4.83:1 การชี้ กด โฟกัส และกำลังทำงานในชุดนี้เป็นภาพสถานะสำหรับตรวจสี

## ผลในไฟล์ Pencil

ปรับสีปุ่มและสถานะที่มีเลเยอร์แก้ไขได้ในหน้าแรก รายละเอียดบ้านพัก สมัครสมาชิกและเข้าสู่ระบบ และหลังบ้านจัดการหมวดหมู่ TikTok กับบทความ รวม 3,466 จุด ตรวจค่าที่แก้ในเลเยอร์รวม 4,244 รายการตรงกับชุดสีที่อนุมัติ ส่วน Header และ Footer ที่ใช้ร่วมกันผ่านการตรวจสีในแบบเดิม

- ปุ่มหลักที่เคยไล่เฉดใช้ชมพูทึบ ปุ่มรองแบบมีกรอบใช้ขอบเทา และแท็บที่เลือกใช้ฟ้าอ่อนกับกรมท่า ปุ่มยืนยันลบใช้แดง ส่วนคำสั่งลบแบบรองใช้ข้อความหรือไอคอนแดง
- ภาพเต็มหน้าอ้างอิง Home หกขนาดและเนื้อหาหน้าแรกมือถือ 360 px ที่ฝังเป็นภาพยังแสดงสีในภาพต้นฉบับ การตรวจครั้งนี้ใช้ค่าที่แก้ได้ใน Pencil การแสดงผลและโฟกัสในแอปจริงยังต้องตรวจ
