## การตัดสินใจในชุดนี้

- ใช้ข้อความและไอคอนกรมท่าบนปุ่มชมพูใน Header, Search และ Auth ของแบบรอตรวจ คู่สีนี้ได้ 5.08:1 จากค่าสีพื้นเรียบ แบบอ้างอิงเดิมยังใช้ข้อความขาวตาม [OPEN-001](../../../decisions/open-decisions.yaml) ปุ่มชมพูในส่วนอื่น เช่น TikTok ยังใช้แบบเดิม
- เมื่อ OTP หมดอายุ ช่องรหัสหยุดรับตัวเลข แต่ลิงก์ «ใช้รหัสผ่านแทน» สำหรับ Login และ «ใช้งานก่อน» สำหรับยืนยันอีเมลแสดงเป็นตัวเลือกที่ยังใช้งานได้
- เมื่อกลับมาบันทึกบ้าน ใช้สถานะกำลังบันทึกและบันทึกแล้วจาก [r28](../home-auth-favorite-return-g2-r28/owner-favorite-return-states-acceptance.json) บนการ์ดเดิม ตำแหน่งข้อความเสนอไว้ที่ซ้ายล่างใกล้การ์ดต้นทาง ระยะเวลาแสดงยังรอข้อสรุป
- เมื่อรายการทุกหมวดโหลดไม่ได้ครั้งแรก ให้แสดงข้อความตรงส่วนรายการและเก็บช่องค้นหากับทางลัดหมวดไว้ กรณีหน้าเดิมมีรายการให้ดูระหว่างอัปเดตให้คงแถว รูป และตำแหน่งเลื่อนในแบบ

ตรวจจำนวนเฟรมใน Pencil และตรวจภาพที่ส่งออก รวมถึงแถวรายการบ้านเดิมหลัง Auth, ลิงก์ในสถานะ OTP หมดอายุ, ช่อง OTP หกช่องที่ 360px และปุ่มท้ายฟอร์มบน Desktop จอเตี้ย การตรวจครอบคลุมการแสดงผลของแบบ สัญญาการเชื่อมต่อข้อมูลและผลการทำงานจริงแยกจากการตรวจรับชุดนี้
