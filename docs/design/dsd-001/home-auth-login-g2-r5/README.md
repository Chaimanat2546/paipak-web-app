อีเมลกดดำเนินการต่อเพื่อขอรหัสและเปิดหน้ากรอก OTP; เลือกใช้รหัสผ่านเองได้ เบอร์โทรยังใช้รหัสผ่าน ไม่มี SMS/phone OTP ส่วน Google และสมัครสมาชิกอยู่ขั้นแรก ย้อนกลับหรือแก้ไข identifier ได้ใน flow ต่อเนื่อง ปิดกลับต้นทางตามกฎเดิม การขอรหัสไม่ควรเปิดเผยว่าบัญชีมีอยู่หรือไม่

หน้า OTP มีช่องรหัสเดียว ปุ่มยืนยันและเข้าสู่ระบบ ส่งรหัสอีกครั้ง และใช้รหัสผ่านแทน ยังไม่กำหนดจำนวนหลัก อายุรหัส หรือช่วงรอส่งซ้ำ ภาพนี้เสนอการจัดวาง ไม่ยืนยันการส่งรหัสจริง ทางเลือกสลับกลับ email OTP แสดงเฉพาะสาขาอีเมล ไม่หาอีเมลแทนเบอร์โทรโดยอัตโนมัติ

[เจ้าของเลือก3](../home-auth-signup-password-retained-decision.json) ให้สมัครด้วยอีเมลยังบังคับ username/โทร/อีเมล/รหัสผ่าน/ยืนยันรหัสผ่าน ตั้งรหัสขั้นต่ำ8ตัวและ confirmation ตรงกัน การเลือกนี้คง email OTP เป็นค่าเริ่มต้น Login และไม่เพิ่ม OTP บังคับตอนสมัคร Google ไม่บังคับตั้งรหัสผ่านเว็บหรือเติมข้อมูลที่ขาดในขั้นสมัคร

Register/Recovery ที่รับรายจุดคงหลักฐานเดิม Login-r4 และ states หน้าเดียวเก็บเป็นประวัติ ยังต้องตรวจ required/loading/error/Google/verification และรับ G2 รวมก่อน High-Fi Main Home และ State library54รายการไม่เปลี่ยน ไม่มี Frontend/backend/commit/push/deploy

ตรวจภาพเทียบและทางเลือกรหัสผ่านแล้วไม่เห็นข้อความล้นหรือตัด แต่ diagnostic ขอบเขตของ Pencil รายงาน clipping บาง auto-layout child สวนทางกับภาพ จึงยังไม่รับรองผลตรวจ geometry ว่าสะอาด รายละเอียดอยู่ใน manifest
