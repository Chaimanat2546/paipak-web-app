## สถานะที่แสดง

เลือกวันเข้าแล้ว แต่ยังไม่เลือกวันออกและยังไม่กดค้นหา ช่องวันแสดง `12 ธ.ค. → …` วันเข้าในปฏิทินใช้Navy/White หัวแผงเขียน “เลือกวันออก” เป็นpromptปกติ ไม่มีerrorแดงหรือข้อความvalidationก่อนsubmit

Xในช่องวันทำหน้าที่ล้างเฉพาะวันที่ Xที่หัวปฏิทินปิดแผงโดยเก็บวันเลือกไว้ สถานที่/คน/petsเดิมไม่เปลี่ยน กติกาเหล่านี้อ้าง [Legacy-search-r5](../f01-ui-3/legacy-search-r5/README.md) ไม่ได้ทดสอบการกดจริงจากภาพนี้

เมื่อเลือกวันออกครบให้ต่อผู้เข้าพักตามflowเดิม ไม่มีบันทึก ส่วนการกดค้นหาขณะช่วงวันยังไม่ครบต้องตรวจเป็นvalidation stateแยกในC1.4 ไม่แสดงsubmit-errorจากต้นทาง `hyLBr` ก่อนผู้ใช้กดค้นหา
