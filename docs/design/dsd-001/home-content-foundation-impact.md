# DSD-001 / ผลตรวจผลกระทบจาก TikTok และบทความบน Home

4 พฤศจิกายน 2026 (Asia/Bangkok) · วิเคราะห์ขอบเขตเท่านั้น

บันทึกนี้เป็นผลวิเคราะห์ก่อนเจ้าของขอ “ออกแบบ ui เลยได้ไหม” ต่อมาได้เริ่ม [ร่างสองส่วนบน Home Desktop](home-media-ui-r1/README.md) ตามคำขอใหม่นั้น โดยยังคงผลตรวจเรื่อง foundation และข้อค้างเดิม ไม่ถือว่าการเริ่มร่างคือ final approval

เจ้าของเลือก1ยืนยัน [ความต้องการรวม](home-content-requirements.md) และให้ตรวจผลต่อ foundation ต่อ คำตอบนี้ไม่อนุมัติ UI เพิ่มหรือ foundation version ใด

## ผลตรวจ

ความต้องการที่ตกลงยังไม่มีเหตุให้เปลี่ยน Direction A, palette, Mitr หรือระบบ spacing/radii/elevation หลัก ทั้งสองส่วนใช้ foundation เดิมเป็นฐานได้ ส่วนที่ยังขาดเป็นข้อกำหนดสำหรับเนื้อหาชนิดใหม่และ component/state/page composition ซึ่งต้องมีขอบเขตและการตรวจรับแยก

การรับ Home Desktop-r8 ยังครอบคลุมภาพรุ่นเดิม ไม่รวม TikTok หรือบทความที่ยังไม่ได้ออกแบบ การตรวจครั้งนี้ไม่สร้าง token ค่าใหม่หรือแก้ deliverables ทั้ง4ชิ้น

## ขอบเขตระหว่างเว็บกับตัวเล่น TikTok

[TikTok Embed Player](https://developers.tiktok.com/docs/en/embed-player) อยู่ใน iframe และมี options/คำสั่งสำหรับ controls, play/pause และเหตุการณ์ playback/error การประเมินนี้อาศัยเอกสาร ไม่ได้เชื่อม player หรือทดสอบ browser ของ papaipak

Mitr และสีของเว็บใช้กับหัวข้อ ป้าย และข้อมูลที่ papaipak สร้างเอง การออกแบบต้องเผื่อ interface ของตัวเล่นภายนอก ไม่สัญญาว่าปรับตัวอักษรหรือ controls ทุกจุดภายใน player ให้เป็น tokens ของเว็บได้

แหล่งภาพปกที่ใช้ได้ ชื่อ/เครดิตผู้สร้าง และเงื่อนไขเมื่อคลิปไม่พร้อมยังต้องยืนยัน คลิปที่ถูกลบอาจดูผ่าน embed ไม่ได้ตาม [เอกสาร TikTok](https://developers.tiktok.com/docs/en/embed-videos) กฎซ่อนการ์ดบ้านที่เจ้าของเลือกก่อนหน้านี้ยังไม่ถูกขยายมาใช้กับคลิป/บทความโดยอัตโนมัติ

## ขอบเขตงานที่แนะนำ

1. ตรวจรับ foundation ตามขอบเขตและข้อค้างเดิม โดยบันทึกว่ายังไม่รวม specification ของสองส่วนใหม่
2. ใช้ความต้องการที่ยืนยันแล้วเป็น input ของ brief เพิ่มเติม แยกข้อกำหนด media/article จาก tokens หลัก เสนอแนวทางและภาพอ้างอิงที่ตรวจแล้วก่อนเลือกการจัดวาง
3. ขออนุมัติขอบเขตที่จะสร้างหรือแก้ UI เพิ่มอย่างชัดเจน แล้วตรวจแบบและ version ของส่วนเพิ่มอีกครั้ง

ยังไม่เริ่ม DSD-002, UID-001 หรือ Task อื่นจากการวิเคราะห์นี้ หากจะทำตัวอย่างเพิ่มภายใน DSD-001 ต้องระบุเป็นขอบเขตขยายให้เจ้าของอนุมัติก่อน ไม่ถือว่าขอบเขต F-01 เดิมอนุมัติ TikTok/บทความล่วงหน้า

## Acceptance และสถานะที่คงไว้

- [foundation-2-desktop](foundation-2-desktop/README.md) ยังคง pending_owner_review ไม่เปลี่ยนเป็น approved/complete
- OPEN-001 ยังเปิด; คง Pink #FD6E88 / White #FFFFFF ตาม visual choice เดิม การเพิ่มเนื้อหาไม่แก้ contrast issue
- Mobile ยังพัก Motion durations และ Desktop ขนาดอื่นยัง proposed/untested
- UXD-001 review-2 ยังเป็นฐานที่อนุมัติแล้ว และ UXD-002 review-5 ยังคงรอตรวจรับ
- ไม่มี Pencil design edits, application code, CMS/backend, TikTok integration หรือ deployment ในรอบตรวจนี้

ผลตรวจนี้เพียงพอให้แยกงานตรวจ foundation เดิมออกจากการออกแบบสองส่วนเพิ่ม ไม่รับรองว่า DSD-001 หรือ Home พร้อม Frontend
