| 1280 พิกเซล | [เดสก์ท็อปแคบ](FnZDR.png) | เมนูเดสก์ท็อป ช่องค้นหาบนภาพเปิด และการ์ดเต็มสี่ใบ |

ที่ 1440 พิกเซล ลำดับส่วนหลักตรงกับ [หน้าแรก r20 ที่รับแล้ว](../footer-contact-r5/ZRyFB.png) ชุดนี้ใช้ Header และ Footer r1 และคู่สีปุ่มล่าสุด ทางลัดเพิ่มตัวอย่างหมวดที่แปดตามกติกาหมวดที่อนุมัติแล้ว แบบ 1280, 1024 และ 768 พิกเซลปรับตำแหน่งช่องค้นหา การ์ด สื่อ และท้ายหน้าตามพื้นที่ โดยใช้เนื้อหาและภาพจากต้นฉบับเดิม

## ภาพสถานะประกอบ

| สถานะ | ภาพและกติกา |
| --- | --- |
| ทางลัดพอดีและเกินแปดหมวด | [เทียบสองกรณีที่ 768 พิกเซล](QRr6b.png) แถวบนมีแปดหมวดจริง แถวล่างมีเจ็ดหมวดกับ **หมวดอื่น ๆ** ที่ท้ายแถว [ภาพเดสก์ท็อปและมือถือที่รับแล้ว](../../admin-category-g4-r1/README.md#เปิดตรวจภาพ) |
| ค้นหาด้วยวันเข้าอย่างเดียว | ใช้วันเข้าที่เลือก โดยให้วันออกเป็นตัวเลือก [สถานะเดสก์ท็อปที่รับแล้ว](../search-checkin-only-home-r20-r1/fLKGL.png) · [แผงค้นหามือถือ](../home-auth-feature-review-r1/uCiqX.png) |
| โหลดรายการบ้าน | [กำลังโหลด](QQY68.png) · [โหลดครั้งแรกไม่สำเร็จและอัปเดตเบื้องหลัง](../home-auth-feature-review-r1/PDll2.png) หน้าแรกยังมีช่องค้นหาและทางลัดหมวด |
| แถวบ้านและดูทั้งหมด | แถวบ้านแสดงได้สูงสุดแปดหลังตามลำดับที่จัดไว้ จำนวนการ์ดที่เห็นเต็มขึ้นกับพื้นที่ แต่ละแถวมีทางเข้า **ดูทั้งหมด** [กติกาหมวดและลำดับบ้าน](../../admin-category-g4-r1/README.md#สิ่งที่ทีมต้องยึดตามแบบ) |

ตรวจภาพส่งออกตามความกว้าง ดูเมนู ช่องค้นหา ทางลัด และแถวบ้านในหน้าเต็ม พร้อมเทียบสื่อ บทความ คำถามที่พบบ่อย และท้ายหน้า การแสดงผลตามขนาดจอ การค้นหา การปัด และการเข้าถึงจริงอยู่ในรอบทดสอบหน้าใช้งาน
