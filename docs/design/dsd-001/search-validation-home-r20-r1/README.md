[คำสั่งล่าสุด](../search-checkin-only-home-r20-r1/owner-rule-change.json) แทนกฎขวางSearchเมื่อไม่มีวันออก ภาพ/ข้อความด้านล่างเก็บเป็นประวัติที่ไม่ได้รับอนุมัติ ไม่ใช้เป็นcurrent target Native `LFTu8` เก็บในArchive ไม่เปลี่ยนกฎวันจองหรือแก้โค้ดจริง

## สถานะและการแก้ไข

เกิดหลังผู้ใช้กดค้นหาหลักเมื่อมีวันเข้าแต่ไม่มีวันออกเท่านั้น ไม่แสดงerrorระหว่างเลือกวันครั้งแรก ไม่ส่งค้นหาหรือไปResults เปิดปฏิทินให้แก้และใช้ข้อความ “เลือกวันออก หรือกด X ในช่องวันเพื่อค้นหาแบบไม่ระบุวัน” พร้อมกรอบช่องวันที่ ข้อความไม่พึ่งสีอย่างเดียว

เลือกวันออกครบแล้วล้างdate errorและต่อผู้เข้าพักตามflowเดิม หรือใช้Xในช่องวันล้างทั้งrange/date errorแล้วค้นหาแบบไม่ระบุวันได้เมื่อกดค้นหาอีกครั้ง ไม่ล้างสถานที่/คน/petsและไม่submitเอง ไม่สับสนกับXปิดแผง ซึ่งเพียงปิดและเก็บค่าฟอร์ม

อ้างสัญญา `submit`, `chooseRange`, `clearDates` ใน `components/home-search.tsx` และ [Legacy-search-r5](../f01-ui-3/legacy-search-r5/README.md) อ่านเพื่อรักษาflowที่มี ไม่ใช่การนำAPI/query/adult-child/max50ของโค้ดเก่ามาใช้ ทางลัดหมวดไม่ส่งร่างSearchและไม่ใช้partial dateขวางทางเข้าหมวดตามguided review1Bที่รับแล้ว
