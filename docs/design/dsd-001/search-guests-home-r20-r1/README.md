## ข้อค้างที่ไม่อ้างผ่านจากภาพนี้

ภาพแสดงกรณีจำนวนปกติเท่านั้น ไม่กำหนดเพดาน50จากโค้ดเก่าหรือcapacityจริง กรณีพิมพ์ค่าว่าง ติดลบ ทศนิยม ตัวอักษร และค่าสูงสุดยังไม่ถูกตรวจรับจากภาพนี้ ต้องมีสัญญาinput/dataที่ชัดก่อนอ้างพร้อมพัฒนาครบทุกกรณี ไม่สร้างerrorหรือpolicyใหม่เองจากfixture

การรับภาพรอบนี้ไม่รับSearchทั้งชุด ไม่รับรองruntime/accessibility และไม่เริ่มFrontend/CMS/backend Mobileพัก OPEN-001เปิด Home-r20หลัก/State library50ภาพไม่เปลี่ยน
