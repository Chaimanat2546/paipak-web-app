# Search Desktop-r1 · ชุดตรวจรวม

> ประวัติก่อนแก้กรณีสถานที่: เจ้าของยืนยันว่าไม่เลือกคำแนะนำในกรณีข้อความไม่ครบ = ไม่ระบุสถานที่และค้นหาได้ ดู [Search Desktop-r2](../search-desktop-review-r2/README.md) ข้อความบังคับเลือกในหลักฐานเดิมไม่ใช่กฎปัจจุบัน

5 พฤศจิกายน 2026 (Asia/Bangkok) · DSD-001 · **รอเจ้าของตรวจรับภาพและเวอร์ชันรวม**

เจ้าของเลือก1รับสองภาพเว้นว่างแล้ว ตาม [หลักฐานเฉพาะจุด](../search-location-match-home-r20-r2/owner-empty-visual-acceptance.json) และให้รวบรวม Search ต่อ ชุดนี้ใช้ Home-r20 ที่1440px ไม่เปลี่ยน Home หลักหรือทิศทางที่รับแล้ว

## ภาพตรวจ

1. [เปิดช่องค้นหา](q8XTl.png): สถานที่แผง A, ปฏิทินสองเดือน และเลือกช่วงวันครบต่อผู้เข้าพัก ใช้ภาพที่รับรายจุดแล้ว
2. [เปลี่ยนและล้างค่า](KNJWD.png): ล้างเฉพาะวันที่, ปรับ/ปิดจำนวนโดยไม่บันทึก และวันเข้าอย่างเดียวพร้อมวันออกไม่บังคับ ใช้ภาพที่รับรายจุดแล้ว
3. [ค้นหาและทางลัดหมวด](EmhJ7.png): เว้นสถานที่/เว้นทุกช่อง, ชื่อตรง/ชื่อไม่ตรง และความต่างของ criteria ส่งต่อ ภาพชื่อตรง/ชื่อไม่ตรงกับ presentation ส่งต่อรอตรวจรวมในรุ่นนี้

[ดูบอร์ดรวม](vOXl6.png) · [ดูสี่กรณีกดค้นหา](IUAch.png) · [IDs, hashes และหลักฐาน](review-manifest.json)

Native board `vOXl6` ใน `papaipak-ui.pen` ผ่าน Pencil MCP; กลุ่ม `q8XTl`, `KNJWD`, `EmhJ7` เป็นเลเยอร์แก้ไขได้ การครอปแสดงเฉพาะ Search/popup เพื่อให้อ่านรายละเอียด ไม่เปลี่ยนขนาดหรือหน้าตา controls ภายใน ภาพ Home-r20 ยังคงใช้ Hero สำเร็จรูปและ white pool edge เดิม ไม่มี live title กลับมา

## สัญญาที่คงไว้

- ทุกช่อง optional; วันเข้าอย่างเดียวค้นหาได้ ไม่เติมวันออกหรือจำนวนคืน
- สถานที่ว่างใช้ criteria อื่นที่กรอกได้; ทุกช่องว่างค้นหาได้โดยไม่เติมเกณฑ์เอง
- พิมพ์ชื่อที่ระบบรู้จักตรงชื่อค้นหาได้; ข้อความไม่ตรง/บางส่วนต้องเลือกคำแนะนำก่อน ไม่เลือกตัวแรกเอง และไม่แจ้ง error ทุกตัวอักษรที่กำลังพิมพ์
- ปรับจำนวนหรือปิดแผงคงค่า ไม่มี Save/ล้างจำนวน แยกคนรวมกับสัตว์เลี้ยง
- ปุ่ม Search ส่งค่าที่กรอก; ทางลัด/ดูทั้งหมดของหมวดใช้เฉพาะหมวดทุกพื้นที่ ไม่ล้างฟอร์ม Home และ Back ใน flow ต่อเนื่องรักษาตำแหน่งแถว/section ตามเดิม
- ไม่แก้เงื่อนไขวันจอง ไม่กำหนด URL/query/ranking/วันว่าง/จำนวนผลจาก fixture

## ขอบเขตการรับ

ขอรับภาพและข้อกำหนดเฉพาะ Search Desktop-r1 บน Home-r20 ที่1440px รวมชื่อตรง/ชื่อไม่ตรง แล้วจึงแทนภาพ Search เก่าใน State library พร้อมโน้ต/แหล่งอ้างอิงหลังเจ้าของรับรุ่นนี้ ไม่ยกภาพ historical วันเข้าที่บังคับวันออกกลับมาใช้

C1.5/C1.6 ยังไม่ปิดจากการจัดบอร์ดนี้ ความพร้อม data/runtime/keyboard/accessibility, OPEN-001 และ Desktop ความกว้างอื่นยังค้าง Mobileพัก ไม่อนุมัติ Frontend/backend/Task อื่น/commit/push/deploy

## การตรวจของเอเจนต์

อ่านภาพส่งออกทั้งสามกลุ่มและบอร์ดรวม ตรวจขนาด/ตำแหน่งของแผงใน source ที่รับรายจุดแล้วและการไม่ซ้อนระหว่างบอร์ด ภาพนิ่งไม่ใช่การทดสอบ click, typing, keyboard, routing หรือ network จริง หลักฐานที่รับก่อนหน้ายังคง bytes/IDs เดิม
