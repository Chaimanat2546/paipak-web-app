# C1.2 · ภาพเปิดปฏิทินบน Home-r20

หลังเจ้าของเลือกAรับ [ภาพช่องสถานที่C1.1](../search-home-r20-r2/owner-location-acceptance.json) จึงทำข้อต่อไปตาม [เช็กลิสต์](../home-desktop-remaining-checklist.md) ครั้งนี้ตรวจเฉพาะภาพเปิดปฏิทิน ก่อนตรวจการเลือกช่วงวันและการล้างวัน ไม่ย้อนรับMonth-nav-r6ซ้ำหรือถือว่าการเลือกAอนุมัติแผงอื่นแล้ว

## สิ่งที่คงและสิ่งที่เสนอ

ภายในปฏิทินคงเดิมทั้งหมดจากMonth-nav-r6: สองเดือนพร้อมกัน ลูกศรย้อนริมเดือนแรก/ถัดไปริมเดือนที่สอง การเลื่อนเป็นคู่เดือนทีละ1เดือน ปุ่มปิด32px และโครงวันเดิม ไม่มีปุ่มบันทึก วันและเดือนในภาพเป็นfixtures ไม่ใช่availability/ราคาจริง

ข้อเสนอหน้าตารอบนี้เปลี่ยนเฉพาะกรอบภายนอก: x272/y550ในviewport (เว้น8pxใต้Search), radius20และเงา`#072D591F` offset0/8 blur24ให้เข้าชุดสถานที่A กว้าง720pxเดิม ใช้viewportสูง960เพื่อเห็นแผงครบโดยไม่ตัดขอบล่าง ไม่เปลี่ยนเป็นfixed page heightหรือรับรองจออื่น

กฎเลือกช่วงครบแล้วต่อผู้เข้าพัก และการล้างเฉพาะวันยังคงเดิม แต่ภาพสถานะเหล่านั้นยังไม่ได้ตรวจจากภาพเปิดปฏิทินนี้ การพักHeroเมื่อใช้Searchยังอ้างกฎที่รับแล้ว ไม่มีtimer/click/keyboardจริง

## จุดตัดสินใจ

คำถามเฉพาะภาพเปิดปฏิทิน: 1) รับภาพนี้แล้วตรวจช่วงวันที่เลือกต่อ 2) ปรับหน้าตาหรือตำแหน่งแผง 3) ดูภาพเลื่อนคู่เดือนก่อนตัดสินใจ ไม่รับSearchรวม/FrontendหรือC1.3จากคำตอบนี้
