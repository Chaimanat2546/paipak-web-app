# Home 2B.2 / Carousel-edges-r1

4 พฤศจิกายน 2026 · ภาพตรวจรูปแรก/กลาง/สุดท้าย · เจ้าของเลือก 1 “ใช้ตามภาพ” ในจุด 2B.2 ของ Home

การรับนี้ครอบคลุม appearance/behavior ของสามสถานะในภาพ รวมปุ่มย้อนจางและกดไม่ได้ที่รูปแรกตามข้อเสนอสมมาตร ไม่ใช่การอนุมัติ Home ทั้งหน้า, UXD-002 review-5 หรือผลทดสอบ runtime

[ภาพเทียบ](y3RjQf.png) · [native snapshot และค่าปุ่ม/dots](editable-snapshot.json)

Pencil root y3RjQf เป็นบอร์ด review ใหม่ ใช้สำเนาการ์ด HaKlB ที่ปรับ Photo-quiet-r1 แล้ว ไม่แก้ Main Home, Results, Mobile, UXD-002 หรือ historical boards

ตัวอย่างทั้งสามคงหน้าปุ่ม 28px และ target 44px ตามแบบที่เจ้าของตอบ “โอเคแล้วข้อต่อไป” ข้อ 2B.1:
- รูปแรก: ย้อนจาง 0.35 / ถัดไปใช้งานได้; dot แรก active
- ระหว่างทาง: ย้อนและถัดไปใช้งานได้; dot ที่สาม active
- รูปสุดท้าย: ย้อนใช้งานได้ / ถัดไปจาง 0.35 และหยุด; dot ที่ห้า active

การหยุดที่รูปสุดท้ายโดยยังแสดงลูกศรถัดไปแต่กดไม่ได้และไม่ autoplay เป็นกติกาเดิมที่เจ้าของยืนยันแล้วใน review-decisions Q-04/Q-05 ไม่เปิดใหม่ การปิดปุ่มย้อนที่รูปแรกเป็นข้อเสนอสมมาตร D-01 ซึ่งให้ตรวจในภาพนี้ ไม่อ้างว่า UXD-002 review-5 ได้รับอนุมัติแล้ว

ภาพแสดง controls ขณะ hover โดยใช้ภาพบ้านเดียวกันทั้งสามใบเพื่อเทียบปุ่มและ active dot ไม่ใช่การยืนยันว่าบ้านจริงมีห้ารูปหรือการทดสอบเปลี่ยนภาพจริง Main Home default ยังซ่อนลูกศร และ focus treatment แยกมีหลักฐานใน Photo-quiet-r1

อ่าน native ว่าปุ่มแต่ละทิศเป็น 44px, face 28px และ active dots เปลี่ยนตามตัวอย่าง ตรวจ PNG เต็มขนาดแล้วข้อความและการ์ดแสดงครบ Native visitor มี warnings ของ columns/notes ที่ไม่ตรงกับภาพ ลอง refresh fit_content แล้ว warnings ยังอยู่ จึงบันทึกตามจริง ไม่อ้าง native layout validation ผ่านทั้งหมด และไม่มี runtime click/keyboard test

คำถามรอบนี้เป็นการตรวจภาพสถานะ: คงตามภาพ / ปรับความชัดของปุ่มที่กดไม่ได้ / ปรับ active dots โดยคงการหยุดปลายทางและไม่ autoplay/loop ตามเดิม ภาพเดียว/ภาพเสียตรวจใน 3A ต่อไป
