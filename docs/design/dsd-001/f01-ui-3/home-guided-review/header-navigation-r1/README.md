# Home 4A.1 / Header logo and Home destination

ตรวจ Header Desktop awwwD ภายใต้ Main Home A1ks07 โดย export ภาพปัจจุบัน ไม่แก้ appearance, โลโก้สมมติ, ภาษา, ปุ่ม Login หรือ native nodes

ฐาน UXD-001 information-architecture ตารางทะเบียนเมนูจับคู่โลโก้ Header/Footer กับ Home แต่ source เดิมเป็น # และไม่ได้ยืนยัน routing จริง Header ปัจจุบันมีโลโก้ zVs7M กับหน้าแรก G6BW0h (รูปบ้าน) จึงตรวจ behavior เฉพาะจุด ไม่เปิดเรื่องรูปลักษณ์ที่รับแล้วใหม่

ปลายทางจากหน้าอื่นยังเป็น Home ตาม IA ที่รับไว้ ประเด็นที่ถามคือเมื่ออยู่ Home และเลื่อนลงมาแล้ว กดโลโก้หรือรูปบ้านจะไปตรงไหน: 1 บนสุด Home / 2 แถบค้นหา Home / 3 คงจุดปัจจุบันบน Home ทุกตัวเลือกไม่ล้างค่าค้นหาและไม่เปลี่ยนกฎ Browser Back จาก Results ที่คืน section/ตำแหน่งแถวเดิม

ยังไม่กำหนด URL/query, scroll animation, active-route implementation หรือ behavior ของลิงก์ค้นหาที่พัก/บทความจากคำถามนี้ ส่วนเหล่านั้นตรวจทีละจุดถัดไป Header awwwD เป็นภาพ static ไม่ใช่หลักฐานกดลิงก์ได้จริง โลโก้ยังเป็น asset สมมติและข้อความแจ้งชื่อบัญชียังเป็น placeholder เดิม ไม่มีการสร้าง contact/claim ใหม่

เจ้าของเลือก 1 ใน4A.1: โลโก้และรูปบ้านไปบนสุด Home โดยเก็บค่าค้นหา ไม่ใช่ full Header/Home approval หรือ Frontend authorization


4A.2 เจ้าของเลือก1 ให้เมนูค้นหาที่พักเปิด Results ที่พักทั้งหมดทั่วทุกพื้นที่ โดยไม่พาค่า Home หรือหมวดเดิมไปด้วยและไม่ล้างฟอร์ม Home/Booking Intent จุด4A.3 กำลังระบุปลายทางบทความ เนื่องจากยังไม่พบ destination ที่ยืนยันใน contracts ที่ตรวจ ไม่เริ่มหน้าเนื้อหา/CMS จากการตรวจ Header นี้
