[ภาพจุดตรวจล่าสุด](step-1a.png) · [Home เต็มหลังปรับ](A1ks07.png) · [ก่อน/หลังและผลตรวจ](verification.json)

ตั้ง Mitr 600 (Semi-bold) ที่ label เมนูหมวดเจ็ดรายการ H9DDs และหัวข้อพูลวิลล่าแนะนำ shJCO ใน Main Home A1ks07 รวมแปด text nodes ค่าเดิมใน native file เป็น 500 ไม่ใช่ 700 จึงบันทึกเป็น 500 → 600 ตามชื่อ weight ที่ขอ ไม่อ้างว่าเป็นการลดน้ำหนักจาก Bold จริง

ขนาด 18px ของ label และ 32px ของหัวข้อคงเดิม รวมทั้ง font family, สี, ไอคอน, spacing และตำแหน่ง ตรวจ snapshot แล้วเปลี่ยนเพียง fontWeight ในสอง subtree ที่เกี่ยวข้อง ดูทั้งหมดคง normal 14px และหัวข้อส่วนอื่น/Header/Hero/cards/studies ไม่ได้เปลี่ยนในคำขอเฉพาะจุดนี้

ตรวจ PNG เต็มขนาดของจุด 1A แล้ว ข้อความยังแสดงครบ เป็นการแก้แบบใน Pencil ไม่มี code/CSS/Mobile และยังไม่ถือว่า 1A หรือทั้ง Home ผ่านการตรวจรับ การปรับไปยังสำเนาสถานะ/ส่วนอื่นพิจารณาเมื่อเจ้าของรับน้ำหนักนี้และรวมชุดในขั้น 5
