# Home 3A / Image-availability-r2

เจ้าของยืนยันไม่แสดงบ้านที่ไม่มีรูปบน Home แต่ยังค้นเจอ และเลือก 1 ให้ข้ามรูปเสียโดยใช้รูปที่ดูได้แทน หากยังมีรูปใช้ได้ บ้านยังอยู่บน Home ภาพนี้เป็นร่างแก้ตาม behavior ที่ยืนยันแล้ว เจ้าของเลือก 1 รับเฉพาะภาพแก้จุด 3A แล้ว ไม่ใช่การอนุมัติ Home ทั้งหน้า

Native root MYD5A / section CoHJL ใน papaipak-ui.pen เดิม Copy จากแถว PANR1 ปัจจุบัน จำนวน 275 nodes บ้าน 02 เป็นกรณีสมมติไม่มีรูป จึง enabled=false ในสำเนา track ส่วนอีกเจ็ดใบเรียงต่อกัน กว้าง track 2342px แสดงบ้าน 01/03/04/05 เต็มสี่ใบ ไม่มีช่องว่าง ข้อมูล catalog จริงไม่ได้เปลี่ยน Main Home และ Results เดิมยังเป็น fixtures ที่มีภาพ

บ้าน 01 แสดงกรณีมีรูปเดียว ซ่อนลูกศร/dots บ้าน 03 ใช้ภาพที่แสดงได้เป็นตัวอย่างหลังข้ามรูปเสีย ลด dots จากห้าเป็นสี่และจัดกึ่งกลางใหม่ รูป/ข้อมูลตัวอย่างเดิมไม่ใช่หลักฐานว่ามีรูปจริงสี่รูป ไม่ใช้ภาพแทนที่พักอื่นเพื่อแก้ runtime error และไม่เพิ่ม autoplay/loop การเลื่อนแถวใช้ step สองหลังและ clamp ตามข้อสรุป 2C

บ้านที่ไม่มีรูปให้แสดงไม่อยู่ในแถว Home แต่ยังค้นเจอใน Results ไม่ใช่การลบหรือ unpublish บ้าน หากรูปทั้งหมดใช้งานไม่ได้ใช้หลักการไม่มีรูปให้แสดง ไม่คงการ์ด error บน Home ภาพ fallback ใน Results และกรณีทั้งหมวดว่างยังรอตรวจตามลำดับ ไม่ได้กำหนดการจัดอันดับหรือแหล่งข้อมูลจริงจาก fixtures

ตรวจ screenshot จาก Pencil และ PNG เต็มแล้ว ข้อมูลและกริดสี่ใบตรงกัน Snapshot ตรวจมีเจ็ด enabled cards ขนาด 314×362px และ track width ถูกต้อง Native bounds มี warnings ของ caption แม้ภาพ export แสดงครบ ส่วน track partially clipped เป็น clipping แนวนอนที่ตั้งใจ ไม่อ้างว่าทุก bounds ผ่าน เก็บร่าง UDzK9 เป็น HISTORY ไม่แก้ UXD-002, Mobile, application code, backend หรือ deploy ยังไม่มี image-load/keyboard/scroll runtime test
