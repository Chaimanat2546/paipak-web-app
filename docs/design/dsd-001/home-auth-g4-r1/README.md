## จุดที่ใช้ตรวจรับ

- **เข้าสู่ระบบ** ใช้ OTP ทางอีเมลเป็นทางหลัก มีทางเลือกอีเมลกับรหัสผ่าน เบอร์โทรกับรหัสผ่าน และ Google ตัวอย่างแสดงสถานะกำลังส่ง รหัสผิด หมดอายุ และส่งซ้ำ [กติกาการใช้งาน](../home-auth-interaction-contract.md)
- **สมัครสมาชิก** แสดงชื่อผู้ใช้ เบอร์โทร อีเมล รหัสผ่าน และยืนยันรหัสผ่าน ข้อผิดพลาดที่ระบุช่องได้แสดงใต้ช่องนั้น ผู้สมัครด้วยอีเมลเข้าใช้ก่อนและยืนยันอีเมลภายหลังได้ [แบบและหลักฐานรายส่วน](../home-auth-confirmed/README.md)
- **ทางกลับ** เดสก์ท็อปเปิดเป็นกล่อง มือถือเปิดเต็มจอ เมื่อปิดจะล้างข้อมูลฟอร์มและคืนบริบทหน้าแรกตามกติกาที่รับไว้ การกลับไปบันทึกบ้านใช้คำขอเดิมในขั้นตอนที่ต่อเนื่อง [กติกาการปิดและกลับหน้าเดิม](../home-auth-interaction-contract.md)

การอนุมัติครอบคลุมแบบสมัครสมาชิกและเข้าสู่ระบบพร้อมสถานะในชุดนี้ โปรไฟล์บัญชีอยู่ในขอบเขตตรวจแยก การเชื่อมต่อจริง การทดสอบการเข้าถึง และข้อกำหนดที่ยังเปิด เช่น รายชื่อประเทศและวิธียืนยันบัญชีเดิมกับ Google อยู่ใน [ข้อกำหนดระบบ](../home-auth-desktop-system-requirements.md#เรื่องที่ยังต้องตัดสินใจ)
