## OPEN-001 — ข้อเสนอ CTA รอบแรก (เก็บเป็นประวัติ)

| ตัวเลือก | พื้น / ข้อความ / ขอบ | Text ratio ประมาณ | Trade-off |
|---|---|---:|---|
| 1 · Pink + Navy | Pink / Navy / ไม่มีขอบที่จำเป็นต่อการรับรู้ label | 5.078:1 | ข้อเสนอรอบแรก; ไม่ใช่คู่สีที่เจ้าของเลือก |
| 2 · Navy + White | Navy / White / Navy | 13.738:1 | คอนทราสต์สูงกว่า แต่ปุ่มมีน้ำหนัก Navy มากขึ้น |
| 3 · White + Navy outline | White / Navy / Navy 2px | 13.738:1 | ดูเบาและใช้แบรนด์เดิม แต่ primary action เด่นน้อยกว่าปุ่มทึบ |

ทั้งสามเป็นข้อเสนอรอบแรก ไม่ใช่ current owner preference ไม่ใช้ White บน brand.pink `#FD6E88` เป็น normal-text treatment ที่รับรองแล้ว และไม่เปลี่ยนค่า brand.pink เพื่อแก้ contrast เอง ค่า ratio ตัดสินจากตัวเลขไม่ปัดเศษ; ต้องตรวจ states และบริบทใช้งานจริงแยก

ตัวเลือก 1 บนพื้นขาวมีพื้นปุ่ม Pink/White ต่ำกว่า 3:1 แต่ label Navy ทำให้ระบุ action ได้; [W3C 1.4.11](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html) ไม่กำหนดให้ขอบ hit area ต้องผ่าน 3:1 ทุกกรณีที่มีเนื้อหามองเห็นเพื่อระบุ control อยู่แล้ว Focus/state cues ที่จำเป็นยังต้องผ่านเกณฑ์ที่เกี่ยวข้อง

การเลือก Direction B ไม่ได้เลือก CTA โดยอัตโนมัติ OPEN-001 คงเปิดจนมี owner decision และหลักฐานตรวจ treatment ที่เกี่ยวข้อง ไม่รับรอง production accessibility จาก nominal pairs หรือภาพตัวอย่าง

### CTA-review-2 — ข้อเสนอเฉดเข้ม (ไม่ได้เลือก)

เจ้าของระบุในแชตนี้เมื่อ 3 พฤศจิกายน 2026 ว่าต้องการปุ่มชมพูข้อความขาว บันทึกเป็น **color-pair preference** แล้ว แต่ยังไม่ถือว่าอนุมัติเฉดใหม่หรือยอมรับ contrast ของ `#FD6E88` กับขาวที่ 2.705343:1

เพื่อรักษาคู่สีตามที่ต้องการ เสนอเฉดเข้มขึ้นเฉพาะ semantic action fill โดย **brand.pink ยังคง #FD6E88** ทุกเฉดด้านล่างเป็น candidate ที่ต้องขออนุมัติก่อนใช้ ไม่มีการแทนค่าแบรนด์เดิมหรือเลือก default ใหม่อัตโนมัติ

| ตัวเลือกที่ไม่ได้เลือก | Candidate action fill | Label | Text ratio ประมาณ | เหตุผล |
|---|---|---|---:|---|
| 1 · ชมพูสด | #D1385B | White #FFFFFF | 4.743:1 | เปลี่ยนจากชมพูเดิมน้อยที่สุดในสามเฉดที่เสนอ |
| 2 · ชมพูเข้ม | #C52B50 | White #FFFFFF | 5.475:1 | ข้อความมี contrast มากขึ้น |
| 3 · เบอร์รี | #AC244A | White #FFFFFF | 6.762:1 | เข้มที่สุดในสามตัวเลือก |

ผล nominal solid-color pairs ทั้งสามผ่าน normal-text threshold 4.5:1 โดยเปรียบเทียบตัวเลขไม่ปัดเศษ แต่ยังไม่ใช่ผลตรวจ hover/focus/pressed/disabled/loading หรือทุกบริบทจริง ดู [ภาพเปรียบเทียบ](foundation-1/pink-white-options.png) และ [หลักฐานคำนวณ](foundation-1/pink-white-contrast.json)

เฉดเข้มทั้งสามไม่ได้รับเลือก เก็บภาพและผลคำนวณไว้เป็นประวัติ ไม่ใช่ current recommendation หรือ token ที่อนุมัติ

### CTA-review-3 — เจ้าของยืนยันเฉดเดิม

เมื่อ 3 พฤศจิกายน 2026 เจ้าของตอบว่า “เอาแบบเดิมอ่ะฉันว่าสวยแล้ว” หลังเห็นภาพเทียบชมพูเดิมกับสามเฉดเข้ม จึงบันทึก **พื้น #FD6E88 / ข้อความ #FFFFFF** เป็น CTA visual reference ที่เลือก ไม่ปรับเฉดเข้ม ไม่เปลี่ยนสีข้อความกลับเป็น Navy และไม่สำรวจเฉดอื่นต่อโดยอัตโนมัติ

Nominal text contrast ของคู่สีนี้ยังเป็น **2.705343:1** ไม่ผ่านเกณฑ์ข้อความปกติ การเลือก visual reference ไม่ใช่การรับรอง AA หรืออนุมัติ accessibility exception ดู [selection record](foundation-1/cta-selection.json)

OPEN-001 คงเปิดและยังเป็น blocker ของ UI implementation acceptance / production accessibility gate ตาม decision log เดิม Final foundation version และ frontend ยังต้องอนุมัติแยก ไม่อ้างว่า DSD-001 เสร็จจากการเลือก CTA visual reference นี้

## Elevation

| ระดับ | Shadow specification | หน้าที่ |
|---|---|---|
| flat | ไม่มี shadow | พื้นหน้า ข้อความ รูป listing และ category shortcuts |
| raised | Navy 12%; offset (0, 6px); blur 20px | Floating hero search / ภาพ inset ที่ลอยจริง |
| overlay | Navy 18%; offset (0, 12px); blur 32px | Popover/dialog ที่อยู่เหนือเนื้อหา |

ไม่เพิ่ม shadow ให้ทุก card เพื่อสร้างมิติ ทิศทาง B ใช้ photography crop, hierarchy และ overlap เป็นหลัก เงาเป็นตัวสนับสนุนชั้นที่มีหน้าที่

## Focus / icons / motion

- Functional icon ใช้ Navy เป็นค่าเสนอ; Pink ไม่เป็น cue เดียวของ default/selected/error เพราะ Pink/White ประมาณ 2.705:1
- เสนอ icon family เดียวจากชุดที่โปรเจกต์มีอยู่ให้ DSD-002 จัด anatomy/variants ไม่ถือว่า raster icon แต่ละภาพเป็น asset ที่อนุมัติแล้ว
- Focus ring เสนอ Navy 2px พร้อมช่องว่าง White 2px; ต้องเห็นครบและไม่ถูก sticky/overlay บังในขั้นทดสอบจริง
- Target size เป้าหมายออกแบบ controls หลัก 44×44px หรือมากกว่า; เป็นมาตรฐานของข้อเสนอนี้ ไม่ใช่การกล่าวว่า WCAG AA กำหนด 44px ทุกกรณี [SC 2.5.8](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html) มี minimum 24×24px และข้อยกเว้นตามบริบท

| Motion token | ค่าเสนอ | หน้าที่ / reduced motion |
|---|---|---|
| motion.press | 120ms | Feedback สั้น; reduce ใช้สี/outline คงที่ |
| motion.color | 180ms | สี hover/selected; reduce ใช้สถานะปลายทางทันที |
| motion.overlay | 240ms | Opacity และการเคลื่อนสั้นไม่เกิน 8px; reduce เหลือ opacity หรือทันที |
| motion.image-intro | 400ms | Optional ครั้งเดียวเฉพาะภาพ hero ไม่ซ่อน content/search; reduce เป็นภาพนิ่ง |
| motion.ease | cubic-bezier(0.2, 0, 0, 1) | ไม่มี bounce/overshoot |

ไม่กำหนด autoplay, parallax, scroll hijacking หรือ animation บนราคาที่เปลี่ยนค่า การเปลี่ยนภาพด้วยการกระทำของผู้ใช้ต้องทำงานแม้ลด motion; interaction/state matrix เป็น DSD-002 ไม่ได้ส่งมอบใน Task นี้
