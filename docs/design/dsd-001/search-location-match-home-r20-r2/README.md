## ขอบเขตกติกาและภาพ

1. สถานที่ว่าง: ใช้วันเข้า12ธ.ค./คน12/pets1ที่กรอกไว้ได้ ไม่ต้องเลือกพื้นที่หรือเติมสถานที่เอง
2. ทุกช่องว่าง: ช่องสถานที่/วันที่/ผู้เข้าพักเป็นplaceholder ไม่มีXล้างวันหรือerror และปุ่มค้นหายังพร้อมใช้ เปิดรายการโดยไม่เพิ่มcriteriaเอง ไม่กำหนดranking/จำนวนผลจริงจากภาพ
3. ชื่อตรงพื้นที่ที่ระบบรู้จัก: ค้นหาได้โดยไม่ต้องกดคำแนะนำซ้ำ ตาม [คำตอบ3](../search-location-match-home-r20-r1/owner-location-rule.json)
4. กรอกสถานที่แล้วชื่อไม่ตรง/บางส่วน: จึงให้เลือกคำแนะนำก่อน ไม่เลือกตัวแรกแทนผู้ใช้ ไม่ใช้กฎนี้ขวางกรณีช่องว่าง

Date/Guest/ภาพHomeและแผงAใช้ฐานเดิม ไม่สร้างinputหรือSaveใหม่ กรณีชื่อจริง/alias/normalization/ชื่อซ้ำ/ไม่มีคำแนะนำ/query/rankingยังอยู่ในC5 โค้ดเก่าที่มีเงื่อนไขต่างจากข้อสรุปยังไม่ได้แก้ในรอบdesignนี้

## จุดตรวจถัดไป

รับเฉพาะภาพชุดที่เพิ่มกรณีเว้นว่างหรือไม่: 1) รับภาพชุดนี้แล้วรวบรวมSearchในC1.6 2) ปรับข้อความหรือหน้าตา 3) ดูกรณีไม่มีคำแนะนำก่อนตัดสินใจ ไม่ถามเลือกว่าจะอนุญาตเว้นว่างอีก และไม่รับSearchรวม/Frontendจากคำตอบนี้

ตรวจplaceholder/criteriaที่คงไว้ การไม่มีerror/Xวันที่เมื่อว่าง และปุ่มค้นหาที่ยังแสดงแล้ว ไม่ได้ทดสอบclick/route/input/keyboard/networkจริง Home-r20หลัก/State library50ภาพไม่เปลี่ยน Mobileพัก OPEN-001เปิด ไม่เริ่มTaskอื่น/code/CSS/backend/commit/push/deploy
