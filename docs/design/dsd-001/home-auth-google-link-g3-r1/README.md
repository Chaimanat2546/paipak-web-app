## ผลตรวจและขอบเขตที่รอสรุป

- ผ่านการตรวจภาพ PNG สำหรับลำดับ ป้ายปุ่ม ตำแหน่งข้อผิดพลาด และความครบถ้วนของข้อความในจอที่แสดง เฟรมบอร์ด `q8g9Si` และเฟรม Home `erVeY` แยกจากหลักฐาน G2-r41 และ Login G3-r1
- คำนวณจากสีพื้นเรียบ ตัวอักษรกรมท่า `#072D59` บนปุ่มชมพู `#FD6E88` ได้ 5.08:1 ผ่านเป้าหมายข้อความปกติ 4.5:1 ของเกณฑ์ตรวจชุดนี้ สีข้อความแจ้งข้อผิดพลาด `#B91C1C` บน `#FFF1F2` ได้ 5.89:1 การเลือกคู่สีปุ่มเป็นข้อเสนอเฉพาะชุดนี้ และ [OPEN-001](../../../decisions/open-decisions.yaml) ยังเปิด
- OTP และรหัสผ่านในภาพเป็นตัวอย่าง วิธีที่ใช้ยืนยันบัญชีเดิมได้จริงและอายุของขั้นยืนยันยังรอสรุป ทางกลับหลังยกเลิกหรือเชื่อมสำเร็จอ้าง [G2-r41](../home-auth-google-link-g2-r41/README.md) และ [Interaction Contract](../home-auth-interaction-contract.md) กรณีเชื่อมแล้วแต่ยังไม่ทราบผลให้ตรวจคำขอเดิมก่อนลองใหม่ รายการข้อกำหนดอื่นอยู่ใน [ข้อกำหนดระบบ](../home-auth-desktop-system-requirements.md)
- ผลตรวจรอบนี้เป็นภาพนิ่ง Desktop ส่วนพฤติกรรมคีย์บอร์ด การอ่านด้วยโปรแกรมอ่านจอ การแสดงผลบนจอขนาดอื่น และการเชื่อมบัญชีจริงต้องตรวจในขั้นที่เกี่ยวข้อง

ขอให้เจ้าของตรวจรับเฉพาะ **Google Link G3-r1** หรือระบุเฟรมที่ต้องการให้แก้ ก่อนเข้าสู่การรับแบบและเวอร์ชันสุดท้าย
