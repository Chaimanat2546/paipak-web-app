# หลังยืนยันตัวตนจากหัวใจบน Home

DSD-001/C2 · 5 พฤศจิกายน 2026 · เจ้าของเลือกข้อ1แล้วตาม [บันทึก](home-auth-favorite-return-decision.json); ตัวเลือกด้านล่างเก็บเป็นประวัติ

ฐานที่รับแล้ว: [UXD-001 E-16/Q-01](../uxd-001/edge-flows.md) กำหนด Favorites ต้องLogin ไม่มีGuest favoritesชั่วคราว และ [Home guided-review 2D/4B](f01-ui-3/home-guided-review/README.md) ใช้Login modalบนต้นทาง คงตำแหน่งHome/แถว/รูปในflowต่อเนื่อง ยกเลิกไม่บันทึกอะไร ทั้งสองส่วนไม่ได้เลือกการบันทึกบ้านหลังAuthสำเร็จ ส่วน [Signup flow-r22](home-auth-signup-flow-g2-r22/owner-signup-flow-acceptance.json) ระบุชัดว่าไม่อนุมัติauto-saveจากflowนั้น

กรณีตรวจ: Guestกดหัวใจของบ้านหนึ่งหลังบนHome → เปิดAuth → ยืนยันตัวตนสำเร็จในflowเดิม จากนั้นควรทำอย่างไร ไม่มีการเปลี่ยนกฎต้องLoginหรือออกแบบหน้ารายการโปรดใหม่

1. เสนอให้บันทึกบ้านที่กดไว้ทันทีหลังยืนยันLoginสำเร็จ แล้วกลับจุดเดิม ลดการกดซ้ำ การส่งต่อเก็บเพียงเจตนาจะทำรายการในflowที่ยังใช้ได้ ไม่สร้างGuest favorite หากบัญชีบันทึกบ้านนั้นอยู่แล้วให้คงบันทึกไว้ ไม่สลับเป็นยกเลิกจากเจตนาเริ่มต้นนี้
2. กลับHomeโดยยังไม่ทำรายการ ให้ผู้ใช้กดหัวใจอีกครั้ง ชัดว่าการบันทึกเกิดจากการกดหลังLogin แต่ต้องกดซ้ำ
3. กลับต้นทางพร้อมขอให้ยืนยันว่าจะบันทึกบ้านนี้ก่อน ควบคุมการทำรายการได้อีกชั้นแต่เพิ่มขั้นตอน

เดิมเอเจนต์แนะนำ1 ต่อมาเจ้าของเลือก1ตามบันทึกข้างต้น ไม่แสดงหัวใจsavedหรือข้อความบันทึกสำเร็จก่อนผลบันทึกที่ยืนยันได้ กรณีบันทึกไม่ได้/บ้านใช้ไม่ได้ต้องตรวจผลในขั้นstateถัดไป ไม่สมมติผลหรือเลือกbackend/APIจากคำหารือนี้

พิจารณาเฉพาะflowต่อเนื่องที่origin/เจตนายังใช้ได้ ไม่กู้หลังreload/tab close/expiry ไม่ขยายไปBooking/Profile/Mobile ไม่เริ่มFrontend/backend และไม่ถือว่าG2รวมผ่าน
