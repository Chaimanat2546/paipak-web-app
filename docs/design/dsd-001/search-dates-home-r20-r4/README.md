## ผลหลังล้างที่เสนอให้ตรวจ

กดXในช่องวัน: วันเข้าและวันออกถูกล้างพร้อมกัน ช่องวันกลับเป็น “เลือกวันภายหลัง” และXล้างวันหายไป พัทยา/12คน/สัตว์เลี้ยง1คงเดิม ไม่มีส่งค้นหาหรือresetฟอร์มทั้งชุด

อ้างสัญญา `clearDates()` ใน `components/home-search.tsx`: ล้างrange/date errorและคืนfocusที่ช่องวัน โดยhandlerนี้ไม่ได้สั่งเปิดปฏิทิน ภาพตัวอย่างใช้ทุกแผงปิดก่อนล้าง ไม่สรุปสถานะแผงอื่นที่กำลังเปิดอยู่หรือรับรองfocus/keyboardจริงจากภาพ ภาพนี้ไม่ได้เริ่มแก้โค้ดหรือทดสอบDOM

การล้างวันไม่เปลี่ยนGuest favorites, Booking Intent หรือข้อมูลbackend ตรวจเฉพาะpresentation/การคงค่าของSearchในflowต่อเนื่อง
