# DSD-001 / Article-availability-r1

4 พฤศจิกายน 2026 · ยืนยันการเลื่อนเรื่องถัดไป และตรวจรับหน้าตากรณี2เรื่องแล้ว

เจ้าของขอดูภาพสองเรื่องและตอบ “โอเคตกลงแบบนี้แหละ” ดู [หลักฐานตรวจรับ](../article-count-r1/owner-two-story-acceptance.json) รับเฉพาะappearanceของภาพที่แสดง ไม่ใช่functionalหรือarticleversionทั้งชุด

เจ้าของเลือก1ให้เลื่อนเรื่องถัดไปที่พร้อมเป็นเรื่องเด่น โดยคงลำดับคัดเองจาก [กติกาเนื้อหา](../article-content-rules.md)

ร่างจำลองเรื่องแรกไม่มีปกจึงไม่แสดง เรื่องที่สองย้ายเข้าบทบาทเรื่องเด่นโดยใช้ภาพ/ชื่อ/หมวด/คำโปรยของเรื่องเดิม เรื่องที่สามอยู่บทบาทรอง ไม่แสดงเรื่องที่สองซ้ำในแถวรอง ไม่เพิ่มรายการหรือจัดอันดับใหม่

คงปก16:9และsafe-area ชื่อเด่นสูงสุด2/รอง1บรรทัด คำโปรยทั้งสองสูงสุด2บรรทัด แผงWhiteสูงตามเนื้อหา Rolepromotionเป็นruleที่ยืนยันแล้ว แต่การจัดวางเมื่อเหลือสองเรื่องยังเป็นvisualdraftสำหรับตรวจ MainHomeและvariablesไม่เปลี่ยน
