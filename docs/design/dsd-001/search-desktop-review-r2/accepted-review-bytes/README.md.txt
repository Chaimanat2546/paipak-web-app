# Search Desktop-r2 · ไม่เลือกสถานที่ก็ค้นหาได้

5 พฤศจิกายน2026 · DSD-001 · **รับภาพกรณีไม่เลือกแล้ว รุ่นรวมยังรอตรวจ**

เจ้าของแก้กรณีท้ายว่าไม่เลือก = ไม่ใส่ ต้องค้นหาได้ ตาม [หลักฐาน](owner-location-correction.json) จึงถอนการบังคับเลือกคำแนะนำสำหรับข้อความไม่ครบ/ยังไม่ยืนยัน เก็บ r1 และหลักฐานเดิมเป็นประวัติ ไม่เปลี่ยนการรับย้อนหลัง

- กรณีพิมพ์ “พั” แต่ไม่เลือก: ส่งสถานที่เป็นไม่ระบุ ค้นหาด้วยวัน/คน/สัตว์เลี้ยงที่กรอกไว้ได้ ไม่ใช้ “พั” เป็นlocation query ไม่เลือกพัทยาเอง
- ภาพใหม่เอากรอบแดงและแผงบังคับเลือกออก ตัวอักษรที่ยังพิมพ์ค้างเป็นdraft ไม่ใช่criteriaที่ยืนยัน ภาพนี้ไม่สั่งให้ล้างdraftบนHome
- กรณีชื่อที่ตรงและระบบรู้จักยังคงกฎเดิม นอกขอบเขตกรณีท้ายที่เจ้าของแก้ครั้งนี้
- เว้นสถานที่หรือทุกช่องยังค้นหาได้ตามที่รับแล้ว; ไม่เปลี่ยนวันที่/จำนวน/ทางลัดหมวดหรือวันจอง
