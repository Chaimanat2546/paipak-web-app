# DSD-001 — Responsive visual guidelines

รุ่น foundation-2-desktop · 4 พฤศจิกายน 2026 · A / Holiday Panorama / review-2

**Desktop1440pxอ้าง Home-r8ที่รับด้านหน้าตาแล้ว; widthอื่นยังไม่รับรอง** เจ้าของพักMobileเพื่อโฟกัสDesktop จึงไม่สร้างหรือปรับMobile/Tablet screensใหม่ และไม่ใช้matrixหรือcompositionของBเป็นcurrent A approval

## Frameและdensityปัจจุบัน

ที่1440px Headerสูง124pxและHero470px ตามด้วยcategory strip94px เนื้อหาแถวบ้านมีขอบซ้ายขวา56px =1328px การ์ด314px/gap24px แสดงเต็ม4ใบในแต่ละviewportแนวนอน แถวหนึ่งไม่wrapเป็นหลายแถวเพียงเพราะtrackมีหลายใบ

เจ็ดหมวดคงเดิม: แนะนำ ใกล้ทะเล สายปาร์ตี้ ราคาพิเศษ Outing Pet Friendly Luxury แถวPet Friendlyมี6fixtures ส่วนแถวอื่น8fixturesเพื่อศึกษา ไม่ใช่จำนวนcatalogจริง

## A heroและHeader

- ใช้ภาพpanoramicบ้าน/สระกับหัวเรื่องสองบรรทัดบนพื้นที่ที่อ่านได้ ขอบสระโค้งและsearchกลางHero ไม่มีB inset/collage/rotation
- Reference Hero1440×470, หัวเรื่อง96/600ทั้งสองบรรทัด, supporting22/500, search1040×88 อ้างค่าและline-heightใน [typography-spec](typography-spec.md)
- Headerใช้outer gutter56pxและกลุ่มbrand/navigationตามภาพ1440 ขนาดคงที่ของกลุ่มในnativeไม่พิสูจน์ว่าHeaderจะพอดี1280 ต้องตรวจพื้นที่กลุ่ม/notice/ภาษา/ติดต่อ/ปุ่มก่อนรับจออื่น ไม่ลดfont/พื้นที่กดเพื่อแก้ล้นเงียบ ๆ
- Category stripที่1440มีpaddingแนวนอน200pxซึ่งต่างจากlisting gutter56px เป็นการจัดจังหวะเฉพาะA ห้ามใช้200pxเป็นglobalouter gutterทุกviewport
- หากwidthแคบลง ต้องตรวจcropและmeasureของข้อความใหม่ก่อนอนุมัติ ไม่ย่อDesktopทั้งภาพเป็นMobile และไม่ย้ายSearchหรือทำวัน/loginเป็นเงื่อนไขเพื่อให้layoutพอดี

## Listing rail, cardและcontent extremes

| เรื่อง | ข้อสรุปที่ใช้ |
| --- | --- |
| Cardที่1440 | 314×362px รูป210px ข้อมูล152px radius16; cropประมาณ3:2 |
| เลื่อนแถว | ทีละ2หลัง; ที่referenceเท่ากับ676px;ท้ายtrackclampพอดี ไม่loop/autoplay |
| จำนวนไม่ลงตัว | ตัวอย่าง7หลังจบที่บ้าน4–7; ระยะสุดท้ายอาจน้อยกว่า2หลังเพื่อไม่เว้นช่องว่าง |
| Photo carousel | ทำงานเฉพาะใบ ไม่เปิดDetailตาม ปุ่มซ่อนdefault/เปิดเมื่อhoverหรือfocus;รูปเดียวซ่อนลูกศร/dots |
| รูปเสียบางรูป | ข้ามและใช้รูปที่ดูได้ ไม่มีภาพปลอมแทนบ้านจริง |
| ไม่มีรูป/ข้อมูลไม่ครบ | Homeไม่แสดงการ์ด แต่ยังค้นหาเจอ;Resultsfallbackยังต้องตรวจของหน้านั้น |
| ชื่อยาว | หนึ่งบรรทัดย่อด้วย…;ชื่อเต็มต้องเข้าถึงได้ ไม่กลับไปใช้ข้อเสนอสองบรรทัดของB |
| หมวดว่างหลังโหลดสำเร็จ | ซ่อนทั้งsection ให้ส่วนถัดไปเลื่อนขึ้น แต่ทางลัด7หมวดยังอยู่ |
| Initial loading | ใช้skeleton4ใบตามreference ไม่เป็นข้อมูลจริง/ไม่มีinteraction |
| โหลดหมวดล้มเหลว | ซ่อนsectionตามคำตอบล่าสุด;ไม่ใช้error panelที่เสนอแล้วไม่ได้เลือก |

ที่text zoomต้องตรวจราคา/metadata/ภาษาไทยไม่ถูกตัด เสนอปรับreflow/จำนวนที่เห็นก่อนลดตัวอักษรหรือเปลี่ยนกฎการ์ด การรับstatic normal zoomไม่ใช่ผลทดสอบ200% หากทุกหมวดโหลดล้มเหลวหรือbackground refreshยังต้องสรุปrecoveryแยก ไม่สร้างretry/timeout/cachepolicyเอง

## Overlaysและการนำทาง

แผงภาษา224×152pxและติดต่อ280×176pxอยู่ใต้triggerและรักษาขอบจอ ปุ่มปิด44px/ธง22pxคงเดิม เมื่อresizeต้องตรวจตำแหน่งไม่บังcontrolsและเปิดทีละแผง ไม่เปลี่ยนlocale/currencyหรือเชื่อมLINE/โทรจากการทำlayoutนี้

Search expanded statesอ้าง [Legacy-search-r5/Month-nav-r6](f01-ui-3/legacy-search-r5/README.md): สถานที่ใช้inputบนแถบ ปฏิทินสองเดือนมีลูกศรครอบทั้งคู่ ผู้เข้าพักเป็นคนรวมกับpetsแยก ไม่มีปุ่มบันทึก/ล้างจำนวนที่ไม่ได้เลือก และmissing-checkoutต้องแสดงvalidationตามflowเดิม

LoginDesktopเป็นmodalทับหน้าต้นทาง ไม่เปลี่ยนหน้า;ปิดแล้วรักษาcontextที่ยังใช้ได้ ไม่เพิ่มการกู้Booking Intentหลังreload/ปิดแท็บ/หมดอายุ ทางลัดหมวดส่งเฉพาะหมวด ส่วนHeaderค้นหาที่พักเริ่มที่พักทั้งหมด รายละเอียดปลายทางและBackดู [guided review](f01-ui-3/home-guided-review/README.md)

## Footerและภาพประกอบ

ใช้Footer-detail-r3ที่เจ้าของส่งภาพเลือกกลับมา: ขอบโค้ง48px พื้นฟ้า1440×348px ขอบ56px โลโก้/ข้อความแบรนด์ กลุ่มเมนูพร้อมลูกศร ปุ่มติดต่อและกลับขึ้นด้านบน ไม่ใช้r4ที่มีไอคอน/คำอธิบายรายลิงก์ ลิงก์เนื้อหาเปิดหน้าในเว็บแท็บเดิม ContactFooterbehavior/ข้อมูลLINEและเบอร์โทรจริงยังรอ ไม่ตีความappearance acceptanceว่าอนุมัติbackendหรือหน้าเนื้อหา

Hero/card/footerภาพที่มีอยู่เป็นstudy assetsและโลโก้สมมติ การเลือกcropต้องตรวจรายภาพ ไม่สร้างrating/review/availabilityหรืออ้างว่าเป็นบ้านจริงจากภาพที่สร้างขึ้น ดูOPEN-002/005และreference inventory
