# DSD-001 — Token sheet

รุ่น foundation-2-desktop · 4 พฤศจิกายน 2026 · A / Holiday Panorama / review-2

**สถานะ: จัด role ให้ตรงกับ Home Desktop-r8 และ states ที่รับด้านภาพแล้ว; รอ final foundation approval** เป็น design specification ไม่ใช่ CSS หรือการย้าย tokens เข้าแอป Mobile ยังพักไว้

## วิธีอ่านสถานะ

- Locked: brand, Mitr และข้อกำหนดผลิตภัณฑ์ที่อนุมัติแล้ว
- Home reference: ค่าที่อ่านจาก native Home1440px หรือ appearance state ที่เจ้าของเลือก ใช้กับขอบเขตนั้น ไม่แทนการรับ shared design system ทั้งหมด
- Proposed: role mapping หรือค่าที่ยังไม่มีการตรวจรับเฉพาะ เช่น motion
- Open/deferred: ข้อจำกัดที่ยังไม่ผ่านหรือยังไม่ได้ตรวจ ไม่ตีความเป็น approved

เก็บร่าง B เดิมใน [archive](foundation-1/pre-a-alignment-2026-11-04/README.md) ใช้ [หลักฐานปัจจุบัน](foundation-2-desktop/README.md) แทน composition ของ B

## OPEN-001 — คงชมพูเดิมกับข้อความขาว

เจ้าของเลือกข้อ3เมื่อ4พฤศจิกายน2026: คง #FD6E88 / #FFFFFF และให้ OPEN-001 เปิดต่อ ยืนยันความชอบเดิม ไม่เลือก Pink/Navy หรือ Navy/White ไม่ปรับเฉดหรือถามเลือกสีซ้ำโดยอัตโนมัติ ดู [owner choice](f01-ui-3/home-guided-review/cta-brand-contrast-r1/owner-choice.json)

| คู่สี | Nominal ratio | สถานะ |
| --- | ---: | --- |
| White / Pink ที่เลือก | 2.705343217728925:1 | ไม่ผ่าน4.5:1และ3:1; OPEN-001ยังเปิด |
| Navy / Pink | 5.077980501367648:1 | หลักฐานคู่สีทางเลือก ไม่ได้รับเลือก |
| White / Navy | 13.737680109134693:1 | คู่สี solid ผ่านเฉพาะการคำนวณ ไม่ใช่ primary CTAที่เลือก |

ใช้ค่าไม่ปัดเศษก่อนเทียบ threshold ตาม [W3C SC1.4.3](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum) การเก็บ visual reference ไม่ใช่ accessibility exception, final CTA sign-off หรือ implementation acceptance ไม่ปิด issue จากการรับ Home/เอกสารนี้

## ขอบเขตข้อมูลและhandoff

Homeซ่อนการ์ดข้อมูล/รูปไม่ครบแต่บ้านยังค้นเจอ ข้ามรูปเสียเมื่อมีรูปใช้ได้ ขณะโหลดครั้งแรกใช้skeleton หมวดที่ไม่มีบ้านพร้อมหรือโหลดล้มเหลวซ่อนทั้งส่วน กฎนี้ไม่แปลงerrorเป็นemptyในข้อมูลภายใน และไม่เปลี่ยนerror recoveryของResults/Auth

ชื่อเต็ม ราคา แหล่งข้อมูลจริง contact destinations และassetsยังมีข้อค้างตาม [review](foundation-2-desktop/README.md) Full component/state contractsหรือหน้าอื่นไม่ถูกอนุมัติแทนจากrole mappingนี้ Final foundation versionยังต้องให้เจ้าของตรวจรับและOPEN-001ยังblockacceptanceที่เกี่ยวข้อง ไม่มีproductionCSS, tokensเข้าแอป, backend, Mobileใหม่หรือTaskอื่นในงานนี้
