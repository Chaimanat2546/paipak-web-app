# Article-secondary-interaction-r3

5 พฤศจิกายน 2026 · บทความทั้งหมดเป็นลิงก์ปกติ · เอฟเฟกต์พักไว้

เจ้าของระบุ “ตรงปุ่มบทความทั้งหมดทิ้งไว้ก่อนเอาให้มันกดไว้เฉยเฉยไม่ต้องมีอนิเมชั่นเดี๋ยวค่อยทำทีหลัง” จึงใช้ลิงก์เดิม เปิดปลายทางตามปกติโดยไม่เด้ง ไม่แผ่สี ไม่ขยับลูกศร/hover และไม่มีการรอ 420ms ข้อเสนอดีไซน์เอฟเฟกต์ของลิงก์นี้พักไว้ ไม่ถือว่าต้องปิดก่อนตรวจบทความตามขอบเขตปัจจุบัน

เรื่องรองคงการเด้งอย่างเดียว 420ms ที่รับใน r2 และ hover r8 เรื่องเด่นยังใช้ press-r4 ไม่เปลี่ยน รักษาหลักฐาน/prototype ที่รับแล้วตาม hash เดิม คำสั่งล่าสุดแทนเฉพาะส่วน index ในการรับ r2 ก่อนหน้า

ตัวอย่างใหม่มีลิงก์บทความทั้งหมดที่กดแล้วแจ้งจังหวะเปิดทันทีเพื่อแยกจากการเด้งของเรื่องรอง ตัวอย่างยังไม่เปิดหน้าจริง ไม่มี route หรือปลายทางจริงที่เชื่อมแล้ว ไม่ถือว่าฟีเจอร์บทความหรือ navigation ในแอปทำงานแล้ว

ตัดชั้นสีและข้อเสนอพื้นเข้มที่ถอนแล้วของ secondary/index ออกจากตัวอย่างปัจจุบัน ไม่เลือก custom keyboard focus ใหม่แทน คง browser focus ปกติสำหรับลิงก์และไม่อ้างว่าตรวจ keyboard/accessibility ทั้งชุดแล้ว

Pencil review `lnXuU`/index `P1rDEJ` และ default review `L4FBX`/index `uPq42` ระบุ context ลิงก์ปกติไม่เคลื่อนไหวแล้ว รูปทรง default ไม่เปลี่ยน ไม่สร้าง mock หน้าอ่าน/หน้ารวมบทความ
