หน้าตรวจแบบมี 72 ตัวอย่าง ผูกกับ [รายการอ้างอิง G2 ทั้ง 57 รายการ](../home-auth-consolidated-g2-r40/inventory.md) ตัวอย่างบางรายการรวมหลายข้ออ้างอิงที่ใช้หน้าตาเดียวกัน เช่น กลับจาก Google เมื่อยกเลิก และมีคำอธิบายกรณีที่ดูจากภาพเดียวไม่ได้ เช่น การวาง OTP และลำดับ Backspace

## จุดที่ต้องตรวจรับ

- สีชมพูและข้อความขาวจากภาพต้นทางมีคอนทราสต์ 2.71:1 ตามค่าที่คำนวณจากสีพื้นเรียบ เปิดสวิตช์ด้านบนเพื่อเทียบกับข้อความกรมท่าบนชมพู 5.08:1 การเลือกแบบปุ่มยังรอคำตัดสิน [OPEN-001](../../../decisions/open-decisions.yaml)
- ตำแหน่งข้อความ “บันทึกบ้านแล้ว” มุมขวาล่างเป็นข้อเสนอสำหรับหน้าเต็ม อิง [ตัวอย่างหัวใจและข้อความที่รับแล้ว](../home-auth-favorite-return-g2-r28/owner-favorite-return-states-acceptance.json) ระยะเวลาแสดงข้อความยังเปิดอยู่
- กรอบโฟกัส ปุ่มปิด และฟอร์มเลื่อนบน Desktop 1440 × 640 เป็นตัวอย่างสำหรับตรวจแบบ รายชื่อประเทศ หมายเลข และเวลา OTP ใช้ข้อมูลตัวอย่าง
- สถานะชุดนี้คือรอตรวจ G3 ส่วนการตรวจรับ G4 และการทดสอบ Auth จริงยังแยกจากชุดแบบนี้

## ผลตรวจแบบ

เปิดไฟล์ใน Chrome ตรวจว่าเปลี่ยนดูได้ครบ 72 ตัวอย่าง โหลด Mitr ได้ และไม่พบ JavaScript exception ในตัวดูแบบ ตรวจภาพตัวอย่าง 9 ภาพที่ครอบคลุม Login, OTP, สมัคร, กู้รหัสผ่าน, บริบท Home และหน้าตรวจแบบที่กว้าง 390px ตรวจว่าบนแบบจอเตี้ยสามารถเลื่อนจนเห็นปุ่มสมัครและลิงก์ท้ายฟอร์มได้ โดยหัวโมดัลและปุ่มปิดยังอยู่ที่เดิม ตรวจตัวดูแบบที่กว้าง 1440, 768 และ 390px สำหรับกรณีตัวอย่าง การตรวจนี้ครอบคลุมตัวดูแบบและการจัดวาง Desktop
