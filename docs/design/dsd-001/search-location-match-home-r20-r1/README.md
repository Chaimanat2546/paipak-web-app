1. พิมพ์ “พัทยา” ตรงชื่อพื้นที่ในfixture: ใช้เป็นพื้นที่ค้นหาได้ ไม่ต้องกดเลือกsuggestionซ้ำ ภาพใช้แถบSearchเดิมจาก `QLHzT` และคงวันเข้า12ธ.ค./คน12/pets1
