# Hero carousel-r3 · ภาพสำรองมาตรฐาน

สถานะล่าสุด: เจ้าของรับและปิดรอบออกแบบ [Home Desktop-r16พร้อมข้อค้างเดิม](../home-desktop-r16-final-review/owner-home-acceptance.json) แล้ว รวมกรณีภาพเดียวและช่วงinitial-loadingที่อธิบายในfinal review ข้อความเสนอ/รอตรวจด้านล่างเก็บเป็นลำดับประวัติก่อนการรับแพ็กเกจ ไม่ย้อนเปิดข้อที่รับแล้ว

อัปเดตรูปเสียบางส่วน: เจ้าของเลือก1ให้ข้ามรูปเสีย ใช้เฉพาะรูปพร้อม และใช้fallbackเดิมเมื่อไม่มีรูปพร้อมเหลือ ดู [หลักฐาน](owner-partial-image-decision.json) ไม่แทนรูปเสียทุกใบด้วยfallbackซ้ำ

อัปเดตcontrols: เจ้าของเลือก1รับหน้าตาdefaultหลายสไลด์ที่แสดงในG1nPutแล้ว ดู [หลักฐาน](owner-multislide-controls-acceptance.json) ไม่รวมhoverที่แสดงแยกหรือความเร็ว/นโยบายเล่นต่อ ซึ่งยังรอตรวจ

5 พฤศจิกายน2026 (Asia/Bangkok) · เจ้าของยืนยันนโยบายและรับหน้าตาภาพสำรองที่แสดงแล้ว

เจ้าของตอบ “โอเคตกลงแบบนี้แหละ” หลังเห็นภาพHZP8Rในแชต รับเฉพาะfallbackรุ่นนี้: ภาพปัจจุบัน ขอบโค้งขาว Searchเดิม และไม่มีcontrolsเมื่อแสดงภาพสำรองหนึ่งภาพ ดู [หลักฐานรับแบบพร้อมhash](owner-fallback-appearance-acceptance.json) ไม่ขยายไปอนุมัติcontrolsหลายสไลด์ initial-loading หรือHomeทั้งรุ่น

เจ้าของยืนยันว่าเมื่อไม่มีภาพ Hero ให้ใช้ภาพปัจจุบันแทน และเตรียมไว้เป็นภาพมาตรฐานในระบบ จึงถอนข้อเสนอแถบค้นหาสั้นที่ไม่มีภาพในr2 ไม่ยุบHeroหรือเปลี่ยนเป็นพื้นฟ้าเปล่าสำหรับกรณีนี้

## ข้อกำหนดปัจจุบัน

- มีภาพ Hero ที่กำหนดไว้และพร้อมแสดง: ใช้ภาพนั้นตามจำนวนและกติกาcarouselเดิม
- ไม่มีภาพที่กำหนดไว้หรือไม่มีภาพพร้อมแสดงเหลือ: ใช้ภาพปัจจุบันเป็นภาพสำรองมาตรฐาน รวมพื้นหลังและตัวหนังสือในไฟล์เดียว ไม่สร้างข้อความเว็บซ้ำ
- จัดเตรียมภาพสำรองเป็นassetมาตรฐานของเว็บไซต์ เพื่อไม่ให้ขึ้นกับการมีรายการภาพจากระบบจัดการเนื้อหา นี่เป็นข้อกำหนดส่งต่อ ยังไม่ได้บรรจุassetเข้าแอปหรือเชื่อมbackend
- คงHero470px ขอบโค้งสีขาว และSearch1040×88ตำแหน่งเดิมในบริบท1440px ไม่ยุบเป็นแถบ136px
- แสดงfallbackหนึ่งภาพโดยซ่อนลูกศร/dots/pause หน้าตาfallbackที่แสดงได้รับอนุมัติแล้ว ส่วนcontrolsของหลายสไลด์และUIทั้งชุดยังแยกตรวจ

ภาพสำรองที่อ้างในร่างคือ [Y3vc2.png](../hero-banner-carousel-r1/banner-assets/Y3vc2.png) เป็นไฟล์ภาพรวมที่ส่งออกจากภาพและข้อความเดิม ไม่เปลี่ยนชนิดเป็นข้อความเว็บในขั้นfallback

## Pencil

Native state `HZP8R` เปลี่ยนเป็น `REVIEW · Hero carousel-r3 · standard current-banner fallback` และHero `GHufD` ดู [ภาพตรวจ](HZP8R.png) Header/หมวด/Search/ขอบสระคงต้นทางเดิม รูปกรณีcompactที่ส่งในr2เก็บเป็นประวัติข้อเสนอที่ไม่ใช้ ไม่ใช่current fallback

สถานะinitial-loading `QHSWV` แสดงfallbackภาพเดียวกันระหว่างรอภาพที่กำหนดไว้ เป็นข้อเสนอการแสดงช่วงโหลดเพื่อให้หน้าไม่ว่าง; เวลาการโหลด/เปลี่ยนเข้าภาพจริงยังไม่ได้ทดสอบหรืออนุมัติเพิ่มจากคำตอบเรื่องไม่มีภาพ
