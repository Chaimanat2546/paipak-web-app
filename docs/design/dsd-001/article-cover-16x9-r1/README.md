## ผลตรวจที่ยังต้องตัดสินใจ

การเปลี่ยนframeเป็น16:9แก้การcropจากกรอบเรื่องรองจัตุรัส แต่แผงเรื่องเด่นยังซ้อนปกล่าง76pxจาก391.5px (~19.4%) จึงยังอ้างว่าเห็นองค์ประกอบบนปกครบไม่ได้ ถ้ามีข้อความอยู่แถบนี้จะถูกบัง แม้sourceจะเป็น16:9เหมือนกัน
