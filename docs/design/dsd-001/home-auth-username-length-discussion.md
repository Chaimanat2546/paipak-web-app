# ความยาวชื่อที่แสดงในช่อง Username

DSD-001/C2 · 5 พฤศจิกายน 2026 · เจ้าของเลือกข้อ1 ช่วง3–20ตัวแล้วตาม [บันทึก](home-auth-username-length-decision.json); ตัวเลือกด้านล่างเป็นประวัติ

เจ้าของเลือก [อังกฤษและตัวเลขเท่านั้น](home-auth-username-format-decision.json) แล้ว คงชื่อแสดงซ้ำได้ ไม่ใช้Username Login ไม่เพิ่มการเช็กชื่อถูกใช้แล้ว ไม่กำหนดว่าต้องมีทั้งตัวอักษรและตัวเลข

คำถามเฉพาะช่วงความยาว:

1. เสนอ3–20ตัว ให้ตั้งชื่อที่กระชับโดยมีพื้นที่สำหรับชื่อกับตัวเลข คำแนะนำเอเจนต์ ยังไม่ใช่คำตัดสินและไม่อ้างว่าเป็นข้อกำหนดprovider
2. 3–30ตัว เพิ่มพื้นที่สำหรับชื่อยาวขึ้น โดยยังมีขั้นต่ำ3ตัว
3. 1–20ตัว ให้ตั้งชื่อสั้นเพียงตัวเดียวได้ และคงเพดาน20ตัว

ตัวเลขทั้งสามเป็นข้อเสนอUI contract ไม่ได้มาจากระบบAuthที่เชื่อมแล้ว เมื่อเจ้าของเลือกจึงรวมปรับhelper/validation/English fixtureในRegister revisionเดียว เก็บภาพอนุมัติเดิมเป็นประวัติ ไม่แก้bytesย้อนหลัง การนับชุดอักขระอังกฤษและตัวเลขตามที่เลือกไม่เพิ่มกฎcase/ความซ้ำหรือAccount/Profileใหม่
