# Home Auth ที่ยืนยันแล้ว

10 พฤศจิกายน 2026 · DSD-001 / C2 · เจ้าของรับหน้าตา Home Auth Desktop และ Mobile แล้ว

[ภาพรวม Home และ Hi-Fi Auth](section-r4/ysmkc.png) · [ดูเฉพาะชุด Auth](section-r4/izim4.png) · [เปิด Pencil](../papaipak-ui.pen) · [หลักฐานการตรวจรับ](owner-hifi-acceptance.json)

เจ้าของตอบ “ฉันตรวจรับหมด” หลังดูชุด Hi-Fi ปัจจุบัน ขอบเขตการรับคือหน้าตาของ Home Auth ในชุดตรวจแบบ r1 รวม Google Link G3-r3 และบริบท Home ที่เกี่ยวกับ Auth โดยหน้า Home-r22 และ Search ที่ตรวจแยกยังใช้สถานะเดิม

## ข้อกำหนดระบบที่เจ้าของเลือก

[ข้อกำหนดและหลักฐานจากชีต](../home-auth-desktop-system-requirements.md) ครอบคลุม OTP อายุ 5 นาที รอส่งซ้ำ 60 วินาที ขอได้ 10 ครั้งต่อชั่วโมง และจำกัดการกรอกผิด 20 ครั้งต่อชั่วโมง เมื่อออกรหัสใหม่สำเร็จ รหัสก่อนหน้าจะใช้ไม่ได้ ลิงก์กู้รหัสมีอายุ 1 ชั่วโมงและใช้ได้จนกว่าจะหมดอายุหรือตั้งรหัสสำเร็จ เซสชันหมดอายุเมื่อไม่ได้ใช้งาน 3 วัน และต้องเข้าใช้ใหม่หลังตั้งรหัสผ่านใหม่

บัญชีอ้างอิงอีเมล เบอร์โทรเป็นทางเข้าใช้บัญชีเดิมด้วยรหัสผ่าน อีเมลหรือเบอร์ที่ซ้ำตอนสมัครให้แจ้งใต้ช่องและกลับไปเข้าใช้บัญชีเดิม ชื่อประเทศใช้ “ไทย” สำหรับไทยและภาษาอังกฤษสำหรับประเทศอื่นตาม G2

เจ้าของตอบ “โอเค เอาตามที่คุณว่าได้เลย” สำหรับห้ากรณีต่อไปนี้ การรับส่วนนี้เป็นกติกาของระบบ

| กรณี | กติกาที่รับ |
| --- | --- |
| OTP มาช้าหรือไม่ถึง | ตรวจอีเมลและโฟลเดอร์สแปม ส่งซ้ำเมื่อรอครบ ใช้รหัสล่าสุดเมื่อออกใหม่สำเร็จ |
| Google ตรงกับบัญชีเดิม | ยืนยันสิทธิ์ในบัญชีเดิม ขอความยินยอมแยก และผูกด้วยรหัสประจำบัญชี Google ที่คงที่ |
| เน็ตหลุดหลังส่งคำขอ | ตรวจผลคำขอเดิมก่อนลองซ้ำ การลองซ้ำต้องได้ผลเท่ากับส่งคำขอเดิมครั้งเดียว |
| ผลกลับมาหลังปิดกล่อง | คงกล่องปิด เปิดใหม่ด้วยฟอร์มเปล่า แสดงสถานะเข้าใช้ที่ยืนยันแล้ว และจบคำขอบันทึกบ้านที่รออยู่เมื่อปิด |
| ยังไม่ทราบผลบันทึกบ้าน | ตรวจสถานะจริงก่อนแสดงว่าบันทึกแล้ว บ้านที่บันทึกอยู่แล้วต้องคงสถานะเดิม |
