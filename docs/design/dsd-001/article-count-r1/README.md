- **2เรื่อง:** [เรื่องเด่น1+เรื่องรอง1](../article-availability-r1/RFule.png) ใช้stateที่มีอยู่แล้ว ไม่สร้างซ้ำ
- **0 เรื่องในคลังที่ใช้ได้จริง:** เจ้าของเลือก `1` ใน closeout Q2 ให้ซ่อนส่วนทั้งหมด ไม่แสดงหัวข้อหรือพื้นที่ section ว่าง กรณีนี้แยกจากชุดคัดว่างที่ยังมี latest ให้ใช้ ดู [หลักฐานการตัดสินใจ](owner-zero-story-decision.json) ภาพการต่อส่วนข้างเคียงยังต้องตรวจใน Home รุ่นรวม
