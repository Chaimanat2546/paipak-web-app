# Home Auth Desktop · Google Link G3-r2

ตรวจภาพส่งออกทั้ง 8 ไฟล์ ขนาดภาพแต่ละคู่ตรงกับ G3-r1 จุดที่เปลี่ยนในหน้าจออยู่ที่ข้อความบนปุ่มหลักชมพู ส่วนบอร์ดรวมอัปเดตป้ายเวอร์ชันและหมายเหตุเรื่องคอนทราสต์

สีขาว `#FFFFFF` บนชมพู `#FD6E88` ได้คอนทราสต์ **2.71:1** จากค่าสีพื้นเรียบ ต่ำกว่าเกณฑ์ 4.5:1 สำหรับข้อความขนาดปกติ คู่สีนี้ใช้สำหรับตรวจหน้าตาตามคำขอ ส่วน [OPEN-001](../../../decisions/open-decisions.yaml) ยังเปิดสำหรับเกณฑ์ตรวจรับแบบสุดท้าย
