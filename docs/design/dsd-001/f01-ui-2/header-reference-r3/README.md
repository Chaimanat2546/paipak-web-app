## สิ่งที่ปรับและเหตุผล

- ใช้เมนูสั้นใต้ trigger ตามรูปแบบ Support ของ Traveloka เพื่อให้เลือกสองรายการได้โดยยังเห็นหน้า Home เก็บ modal จาก Booking.com เป็นทางเลือกอ้างอิงซึ่งรองรับรายการจำนวนมาก
- ภาษา: ธงไทยวงกลม 22px, ชื่อไทย/English, พื้น #DBF2FC และ check แสดงภาษาปัจจุบัน ตามหลัก selected state ที่ตรวจเห็นใน Booking.com ไม่มีตัวเลือกสกุลเงิน
- ติดต่อ: ไอคอนวงกลม 44px แยก LINE OA/โทร, ชื่อช่องทางเด่นกว่าคำอธิบายการเปิดแอป และลูกศรออกภายนอก นำหลักการแยกช่องทาง/การกระทำจากหน้า Contact Us ของ Traveloka มาใช้ ไม่มีบัญชี LINE เบอร์โทร หรือเวลาบริการสมมติ
- คง Mitr, palette และ Guest Header-r11 ที่อนุมัติไว้ ใช้สีอ่อนเฉพาะ trigger ที่กำลังเปิดและรายการภาษาที่เลือก ไม่มีฉากหลังมืด

ข้อแลกเปลี่ยน: popup รบกวนการสำรวจน้อยกว่า modal แต่ต้องจัดขอบจอและ focus ในขั้น implementation รายการติดต่อใช้พื้นที่มากกว่ารุ่นแรกเพื่อบอกว่าจะเปิดแอปใด

## การตรวจและข้อจำกัด

| รายการตรวจ | ผล |
|---|---|
| Native frames/text/icons แก้ไขได้ | ผ่านจาก layer snapshot; ไม่แปะรูป popup สำเร็จเป็น UI |
| ภาพหลังปรับ | ตรวจภาพรวม 1472×674 แล้ว ข้อความ/ไอคอนแสดงครบ แผงสัมพันธ์กับ trigger ไม่ทับ nav |
| Main Home-r7, R1 และ R2 เดิม | ข้อมูล subtree รวม geometry ตรงกันก่อน/หลังทั้งหมด |
| Contrast ของข้อความใหม่ | Navy/ขาว 13.74:1, Navy/พื้นฟ้า 11.85:1, คำอธิบาย #53657C/ขาว 5.97:1; เป็นการคำนวณสี ไม่ใช่รับรอง accessibility ทั้งระบบ |
| Keyboard, focus, เปลี่ยนภาษา, LINE/โทรจริง | ยังไม่ทดสอบ; Pencil เป็น static |
| Mobile | ไม่แก้ในรอบตรวจ Desktop นี้ |
| การอนุมัติ | รอเจ้าของตรวจ Header-reference-r3; ยังไม่อนุมัติ Home/F01 ทั้งชุด |

ข้อกำหนดการทำงานที่ต้องต่อในขั้นที่ได้รับอนุญาต: เปิดทีละแผง, ปิดด้วย X/คลิกนอก/Esc และคืน focus ที่ trigger; แถวภาษาเลือกแล้วปิด แถวติดต่อใช้ปลายทางที่ยืนยันภายหลัง ไม่เริ่มระบบ i18n/Auth/backend/Frontend หรือ Task อื่น OPEN-001 ข้อความขาวบนชมพูยังเปิด

แบบและเวอร์ชันต้องได้รับอนุมัติจากเจ้าของก่อน Frontend แยกอีกขั้น
