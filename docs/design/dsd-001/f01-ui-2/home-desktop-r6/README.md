## สิ่งที่ปรับ

- พื้นอ่อนร่วมของส่วนบ้านแนะนำใช้ #F2FAFE ซึ่งเป็น tint ของ Light Blue ไม่ใช่สีแบรนด์ใหม่หรือ token ที่ได้รับอนุมัติเพิ่ม
- การ์ดขาวกว้าง 314px สูง 362px, gap 24px เห็นเต็ม 4 ใบ ภาพสูง 210px ต่อกับพื้นที่ข้อมูลสีขาว 152px เป็นรูปทรงเดียว มุม 16px
- ชื่อบ้าน 18px/500, ทำเลและคุณสมบัติ 14px แยกแถว ราคาอยู่กลุ่มของตัวเอง ใช้เฉพาะจำนวนเงิน 22px/500 ส่วนเริ่มต้นและหน่วยต่อคืน 13px ลดการแย่งน้ำหนักจากภาพ
- เอาฐานราคาสีฟ้าออกจากทุกใบ ราคาเป็นข้อมูลในตัวการ์ด ไม่ใช่ปุ่มหรือแถบ action
- เก็บหัวใจเส้นขาว, ลูกศรรูปที่ออกแบบให้แสดงเมื่อ hover/focus, dots และปุ่มเลื่อนรายการข้างหัวข้อเดิม ดูทั้งหมดอยู่ข้างหัวข้อ ไม่มีตัวนับรายการ
- แถวมี 8 fixtures เดิม ไม่เพิ่มคะแนนรีวิว ส่วนลด หรือข้อมูลจริงที่ยังไม่มี บอร์ดท้ายแถวแสดงบ้าน 5–8 และปุ่มถัดไปปิดใช้งาน

## สถานะและข้อจำกัด

Home Desktop-r6 ยังต้องให้เจ้าของตรวจรับ “จัดมา” เป็นคำสั่งให้ทำรอบนี้ ไม่ใช่การอนุมัติเวอร์ชันที่ยังไม่ได้เห็น Header-r11 ที่อนุมัติแล้วคงเดิม ไม่แก้มือถือ Results หรือ Detail ในรอบนี้

เป็น native editable static design ภาพ hover/focus และชื่อยาวเป็น state samples ไม่ใช่ prototype ที่ทำงานจริง ชื่อยาวสำหรับตัวอย่างใช้ข้อความย่อด้วย …; การทำ truncation และให้เข้าถึงชื่อเต็มเป็นข้อกำหนดของ Frontend ในขั้นที่ได้รับอนุญาตเท่านั้น

ภาพบ้านเป็น AI study, ข้อมูลเป็น fixtures, โลโก้ยังเป็น placeholder และ OPEN-001 ยังเปิด ไม่มีการรับรอง AA, runtime หรือการทำงานจริง ไม่มี Frontend/backend/deploy และ DSD-001 ยังไม่เสร็จทั้ง Task
