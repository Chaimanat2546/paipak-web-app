# Home card row study-4 · แยกข้อมูลกับฐานราคา

4 พฤศจิกายน 2026 · เก็บเป็นประวัติหลังเจ้าของทักคุณภาพรอบนี้ · ไม่ปรับใช้

รุ่นปัจจุบันคือ [Home Desktop-r6](../home-desktop-r6/README.md) เจ้าของให้ “จัดมา” หลังรับทราบว่าจะกลับไปตรวจด้วย Taste Skill และทำจากภาพรวมทั้งหน้า รุ่นใหม่เอาฐานราคาฟ้าออกและปรับบน Home ตัวหลัก แต่ยังรอตรวจรับ

แยกราคาออกจากบรรทัดจำนวนคน/ห้องนอน เพื่อไม่ให้ข้อมูลแย่งพื้นที่กัน ใช้พื้น Light Blue เฉพาะฐานราคาและจัดข้อมูลเป็นสามบรรทัด ขณะดูพร้อมกัน 4 ใบยังมีแนวภาพ ชื่อ และราคาตรงกัน

[แถวบ้าน](lAXMr.png) · [ข้อเสนอใน Home เต็ม](kJSyu.png) · [Native snapshot](layer-snapshot.json) · [ผลตรวจ](verification.json)

- คง 4 การ์ดเต็ม ใบละ 314px / gap 24px และ 8 fixtures ใน track 2680px เดิม
- เพิ่มพื้นที่ภาพเป็น 198px; คงหัวใจเส้นขาวและลูกศรภาพที่ซ่อนในสถานะปกติ ปรับตำแหน่ง dots ตามความสูงภาพ
- ชื่อ 18px/500, ทำเล 14px และจำนวนคน/ห้องนอน 14px อยู่คนละบรรทัดในพื้นที่ข้อมูลสูง 110px, padding 14px ไม่เอาราคามาเบียดในบรรทัดคุณสมบัติ
- ฐานราคาแยกสูง 56px สี #DBF2FC มุมล่างต่อกับการ์ด คำว่าเริ่มต้นอยู่ซ้าย จำนวนเงิน 22px/600 กับหน่วยต่อคืนอยู่ขวา เป็นข้อมูล ไม่ใช่ปุ่มเพิ่มอีกหนึ่งปุ่ม
- การ์ดสูง 364px เท่ากันทั้งแถว ไม่เพิ่ม badge, คะแนนรีวิว หรือรายละเอียดบ้านที่ไม่มีข้อมูล

รูปแบบนี้ใช้ชื่อหนึ่งบรรทัดเพื่อให้ชื่อ–ทำเลอยู่ใกล้กันและไม่ต้องเว้นพื้นที่ว่างสำหรับชื่อสั้น ข้อกำหนดสำหรับขั้น Frontend ที่ได้รับอนุญาตคือ ellipsis เมื่อชื่อยาวเกินพื้นที่และอ่านชื่อเต็มได้ใน Detail; ยังไม่มี truncation ที่ทำงานจริงใน Pencil

Native Home proposal `kJSyu`, section `lAXMr`, track `SonVQ` อยู่ใน `C:/Users/chaym/.pencil/documents/5738e270-25e4-4bf2-9d22-fad4c0b58275/papaipak-ui.pen` ตรวจภาพทั้งแถวแล้ว ข้อมูลและราคาไม่ทับกัน ตรวจ schema ว่าทั้ง 8 ใบกว้าง/สูงตรงกัน Main Home `A1ks07` ยังเป็น r5 และเทียบก่อน/หลังตรงทุก field รวม IDs

เครื่องมือมี warning ชั่วคราวหลังย้ายข้อมูลออกจาก parent เดิม ตรวจ IDs ที่รายงานแล้วไม่อยู่ใน candidate อีกและภาพแสดงครบ ไม่แก้ nodes อื่นเพื่อกลบ warning เป็น native static proposal ไม่ใช่ functional prototype และไม่อนุญาต Frontend หรือปิด OPEN-001
