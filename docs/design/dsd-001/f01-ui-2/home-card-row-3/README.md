4 พฤศจิกายน 2026 · เจ้าของให้ปรับต่อเพราะ “มันเบียดและเรียบไป” · เก็บเป็นประวัติ ยังไม่แทน Home ตัวหลัก

ข้อเสนอที่ปรับต่อคือ [row study-4](../home-card-row-4/README.md) แยกฐานราคาออกจากบรรทัดคุณสมบัติและเพิ่มพื้นที่ข้อมูล

เจ้าของระบุ “ไม่ได้สักอย่างต้องคำนึงว่ามันเรียงเป็นแถวด้วยสิ่” จึงออกแบบใหม่เป็นแถวจริง 4 ใบในสำเนาหน้า Home พร้อมแถวทดสอบชื่อสั้นและชื่อสองบรรทัด ไม่ใช้พื้นหรือแผงลอยแยกใบแบบข้อเสนอที่ไม่รับ

## รูปแบบใหม่

- กว้างใบละ 314px, gap 24px, เห็นเต็ม 4 ใบใน 1328px และเก็บแถวตัวอย่าง 8 ใบเดิม
- รูป 314×184px เหมือนกันทุกใบ คงหัวใจเส้นขาวและรูปแบบ carousel ปกติจาก Home-r5
- ชื่อบ้าน Mitr 17px/500 ใช้ช่องสูง 48px รองรับสองบรรทัด ระยะข้อมูลด้านล่างไม่เปลี่ยนตามความยาวชื่อ ในขั้น Frontend ต้องกำหนด truncation สำหรับชื่อที่เกินสองบรรทัด ยังไม่ได้ implement ใน Pencil
- ทำเลแยกเป็นแถว 21px จากนั้นแถวล่างสูง 30px วางคน/ห้องนอนทางซ้ายและราคาทางขวา ข้อมูลรอง 14px ราคา 20px/600 คำว่าเริ่มต้นและหน่วยต่อคืน 12px
- รูป ชื่อ ทำเล และราคาใช้แนวตำแหน่งเดียวกันทั้งแถว ไม่มีตัวนับ และดูทั้งหมดยังคงข้างหัวข้อ ปุ่มเลื่อนรายการคงด้านขวา

ชื่อยาวในภาพทดสอบเป็นข้อความจำลองเพื่อทดสอบ layout เท่านั้น ไม่ใช่การเปลี่ยนชื่อใน fixtures หรือ catalog ไม่เพิ่มคะแนนรีวิว ส่วนลด หรือข้อมูลธุรกิจอื่น
