# ข้อเสนอจัดวางการ์ดบ้าน 3 แบบ

4 พฤศจิกายน 2026 · เจ้าของไม่รับทั้งสามแบบ · เก็บเป็นประวัติ ไม่ปรับใช้ใน Home

ผลตรวจ: เจ้าของระบุ “ไม่ได้สักอย่างต้องคำนึงว่ามันเรียงเป็นแถวด้วยสิ่” จึงยุติการเลือก A/B/C และทำ [ข้อเสนอใหม่ในแถวจริง](../home-card-row-3/README.md) ข้อความคำแนะนำด้านล่างเป็นหลักฐานของข้อเสนอที่ไม่รับ ไม่ใช่แนวทางปัจจุบัน

เจ้าของต้องการเปลี่ยน “การจัดวางข้อมูลและรูปแบบ” หลังเห็นตัวอย่างที่เปลี่ยนเพียงลำดับน้ำหนักตัวอักษร จัด native card proposals สามแบบ โดยใช้ข้อมูลบ้านตัวอย่าง 01 และภาพศึกษาเดิมเดียวกัน ขนาดกว้าง 314px เพื่อคงความเป็นไปได้ของ 4 การ์ดเต็มใน Home Desktop

[เปรียบเทียบ A/B/C](VXvII.png) · [A](P6SZXC.png) · [B](m6sz8h.png) · [C](Z6TKG.png) · [สำเนา layers](layer-snapshot.json)

- A ราคาแยกทางขวา: ชื่อเต็มแถว ทำเลและคน/ห้องนอนอยู่ฝั่งซ้าย ราคาเป็นคอลัมน์ขวา พื้นเปิดโปร่ง แนะนำเป็นจุดเริ่มต้นเพราะเทียบข้อมูลกับราคาได้ง่ายและกินความสูงน้อย
- B ข้อมูลบนพื้นสีฟ้า: รวมภาพกับพื้นข้อมูล #DBF2FC เป็นการ์ดเดียว แยกทำเล คน/ห้องนอน และราคาที่ฐาน อ่านขอบเขตของแต่ละบ้านได้ชัด แต่ใช้ความสูงมากกว่า A
- C แผงข้อมูลซ้อนขอบภาพ: แผงขาวโค้งมนซ้อนขอบล่างภาพเล็กน้อย ใช้ราคานำก่อนชื่อบ้าน แล้วตามด้วยทำเลและคน/ห้องนอน ย้าย dots ให้อยู่เหนือแผงเพื่อไม่บดบังการเลื่อนรูป

ทั้งสามใช้ Mitr, Navy, Light Blue และภาพ/ข้อมูลชุดเดิม คงหัวใจเส้นขาวและภาพปกติที่ไม่มีปุ่มลูกศรจาก r4 ไม่เพิ่มคะแนนรีวิว ส่วนลด สถานะว่าง หรือคุณสมบัติที่ไม่มีข้อมูล อ้างอิงหลักการแบ่งข้อมูลและความสำคัญของภาพจาก local Awesome DESIGN.md / Airbnb โดยคงแบรนด์ papaipak เดิม
