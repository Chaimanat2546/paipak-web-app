## แบบและพฤติกรรมที่เสนอ

- แถวบ้านเป็น horizontal rail ยังเห็นเต็ม 4 ใบ กว้างใบละ 314px ระยะห่าง 24px มี viewport 1328px และตัวอย่าง 8 หลังใน track 2680px จำนวน 8 เป็น fixtures สำหรับตรวจ ไม่จำกัด catalog ไว้เท่านี้
- ปุ่มก่อนหน้า/ถัดไปของรายการอยู่ข้างหัวข้อ แยกจากปุ่มบนรูป พื้นที่กด 44px มีช่วงรายการที่เห็นและ “ดูทั้งหมด” ปุ่มเลื่อนรายการทีละหนึ่งใบ ระยะ 338px; รองรับการเลื่อนแนวนอนแล้ว snap ตามการ์ดในขั้น implementation ที่ได้รับอนุญาต
- ต้นแถวปิดใช้งานก่อนหน้า ท้ายแถวปิดใช้งานถัดไป ไม่ autoplay และไม่วน loop ตัวอย่างสถานะในแบบคือ 1–4, 3–6 และ 5–8 จาก 8 หลัง แต่ละแถวในอนาคตใช้สถานะเลื่อนของตัวเองได้โดยไม่เพิ่มหมวดใหม่ในรอบนี้
- ปุ่มบนรูปเปลี่ยนเฉพาะรูปของบ้านใบนั้น ไม่เลื่อนรายการหรือเปิด Detail ลดหน้าตาปุ่มจาก 44 เป็นวงกลม 32px แต่คงพื้นที่กด 44px ไอคอน 18px และ dots เดิม ปิดใช้งานก่อนหน้าเมื่ออยู่รูปแรก รักษากฎรูปสุดท้าย/รูปเดียว/รูปเสียเดิม
- การโฟกัสปุ่มเลื่อนรูปและปุ่มเลื่อนรายการต้องทำงานแยกกัน ไม่แย่งเหตุการณ์กัน รูป/ชื่อบ้านยังมีทางเข้า Detail ตามกฎเดิม Favorites ของ Guest ยังต้อง Login
