# Home Desktop-r4 · ลดความเด่นของปุ่มบนภาพ

3 พฤศจิกายน 2026 · รอเจ้าของตรวจรับหน้า Home Desktop

เจ้าของระบุว่าปุ่มบนรูปและหัวใจแย่งจุดโฟกัส ยอมรับปุ่มเลื่อนแถวข้างหัวข้อ แต่เห็นว่า “ดูทั้งหมด” ขัด และไม่ต้องการตัวนับรายการ จึงปรับเฉพาะส่วนบ้านแนะนำใน Home Desktop ดังนี้

- สถานะปกติซ่อนลูกศรบนรูป ให้แสดงเมื่อชี้เมาส์ที่การ์ดหรือมี keyboard focus ภายใน ปุ่มยังมีพื้นที่กด 44px หน้าปุ่ม 32px ตามเดิม และมีภาพสถานะแสดง focus ที่ชัดเจน
- หัวใจเป็นเส้นขาว 22px ไม่มีพื้นวงกลมขาว ใช้เงาเฉพาะไอคอนช่วยแยกจากรูป คง target 44px และกฎ Guest ต้อง Login ไม่สร้างสถานะ Guest favorite
- ลด dots เหลือ 5px เพื่อให้ภาพบ้านนำสายตา
- เอาตัวนับรายการออก คงปุ่มเลื่อนแถวข้างหัวข้อทุก field ตามรุ่นก่อนที่เจ้าของโอเค
- ย้าย “ดูทั้งหมด” ไปเป็นลิงก์เดี่ยวกึ่งกลางท้ายแถว แยกจากการเลื่อนรายการ ไม่เอาทางไปดูรายการทั้งหมดออก
