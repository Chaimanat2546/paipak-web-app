# UID-001 · จำนวนห้องน้ำบนการ์ดหน้าแรก · r1

20 พฤศจิกายน 2026 · ภูรับแบบเดสก์ท็อปและมือถือ · Pencil บอร์ด `xUNLB` ภายใต้ `Y4TBa` · [บันทึกคำอนุมัติ](owner-r1-acceptance.json)

- แสดงไอคอนและจำนวนห้องน้ำถัดจากห้องนอนเมื่อจำนวนมากกว่า 0 เมื่อข้อมูลขาดหรือจำนวนเป็น 0 ให้ยุบชุดข้อมูลห้องน้ำทั้งไอคอนและข้อความ
- ภูยืนยันให้ใช้ [กติกาเดียวกันกับการ์ดบ้านพักในหน้าอื่น](../../uid-002/card-bathroom-visibility-r1/README.md)
- แบบเดสก์ท็อป 1440 พิกเซลตรวจการ์ดตัวอย่างทั้ง 54 ใบใน 7 แถวตามกติกานี้
- มือถือ 390 และ 360 พิกเซลใช้ภาพเต็มหน้า G4-r1 เป็นฐาน และวางแถวข้อมูลที่แก้ไขได้ใน Pencil บนการ์ดใบแรกที่เห็นเต็มในแต่ละแถวทั้ง 3 แถว
- [ข้อมูลตัวอย่างเดิมของหน้าแรก](../f01-ui-1/fixtures.json) ไม่มีจำนวนห้องน้ำ การ์ดชุดนี้จึงแสดงข้อมูลถึงห้องนอน ส่วนการ์ดเปรียบเทียบ **บ้านสวนพัทยา** แสดง **4 ห้องน้ำ** ตาม [ข้อมูลตัวอย่างหน้าค้นหา](../../uid-002/g3-r7-review/review-manifest.json)
