# ข้อมูลฟอร์มเมื่อปิดแล้วเปิด Home Auth ใหม่

DSD-001/C2 · 5 พฤศจิกายน 2026 · เจ้าของเลือกข้อ2 ล้างทั้งหมดแล้วตาม [บันทึก](home-auth-reopen-draft-decision.json); ตัวเลือกด้านล่างเป็นประวัติ

เจ้าของเลือก [คลิกพื้นที่มืดนอกAuthแล้วปิดได้](home-auth-modal-dismissal-decision.json) แล้ว กฎเดิมรักษาค่าSearch/ตำแหน่งHome แต่ไม่ได้เลือกว่าจะจำข้อมูลในฟอร์มLogin/Registerเมื่อปิดแล้วเปิดใหม่เพียงใด ไม่ใช้การคงoriginเป็นการอนุมัติจำรหัสผ่านหรือOTPเอง

คำถามนี้เฉพาะปิดAuthแล้วเปิดใหม่ในHomeเดิม โดยยังไม่reload/ปิดแท็บ/หมดอายุ ไม่เพิ่มremember-me/localStorage/cookie persistence หรือกู้เจตนาบันทึกบ้านที่ถูกยกเลิก

1. เสนอให้จำข้อมูลทั่วไปที่กรอกไว้ ได้แก่Username/เบอร์โทร/อีเมลภายในflowHomeต่อเนื่อง แต่ล้างรหัสผ่าน/confirmation/OTPเมื่อปิด เมื่อกลับมาเลือกฟอร์มที่เกี่ยวข้องไม่ต้องพิมพ์ข้อมูลทั่วไปซ้ำ คำแนะนำเอเจนต์ ยังไม่ใช่คำตัดสิน
2. ล้างข้อมูลAuthทั้งหมดเมื่อปิด เปิดใหม่เป็นฟอร์มว่าง กติกาชัดและไม่เหลือข้อมูลฟอร์มเดิม แต่ต้องพิมพ์ใหม่หากปิดพลาด
3. จำเฉพาะidentifierอีเมลหรือเบอร์ที่ใช้Login ล้างข้อมูลสมัครอื่นรวมถึงรหัสผ่าน/confirmation/OTP ฟอร์มสมัครเริ่มใหม่ ลดข้อมูลที่คงไว้โดยยังสะดวกตอนLogin

ไม่มีตัวเลือกใดทำให้Login/OTP/ส่งคำขอ/บันทึกบ้านอัตโนมัติเพียงเพราะเปิดหน้าต่างใหม่ ไม่กลับเข้าstateสำเร็จจากข้อมูลที่จำไว้ การคงข้อมูลระหว่างย้อนกลับหรือสลับวิธีในmodalที่ยังเปิดอยู่เป็นคนละกรณีกับการปิดแล้วเปิดใหม่ รูปแบบOTP/inputที่รับแล้วยังคงเดิม

เจ้าของเลือกให้ล้างข้อมูลฟอร์มทั้งหมดเมื่อปิดและเปิดใหม่เป็นฟอร์มว่าง ไม่เพิ่มหน้าต่างถามยืนยันปิด ไม่อ้างการทำงานจริงหรือรับwholeG2/High-Fi/Frontend/backend
