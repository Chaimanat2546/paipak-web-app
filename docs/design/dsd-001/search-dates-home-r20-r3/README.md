ค่าสถานที่และผู้เข้าพักจากภาพก่อนหน้ายังunset ไม่ยกค่าตัวอย่าง12คน/pets1ของ `S366d` มาเติมเอง จึงใช้counter0/0ตามความหมายSearchเดิมว่า “ยังไม่ระบุ” ไม่ใช่จำนวนคนที่จองจริง ปุ่มลดจางเมื่อ0 หนึ่งแถวคนรวมและอีกแถวpets ช่องตัวเลข/+−ตามแบบเดิม ไม่มีแยกผู้ใหญ่/เด็ก Save ล้างจำนวน หรือhelperเพิ่มในแผง

ค่าที่มีอยู่ต้องคงไว้เมื่อเปิดผู้เข้าพัก; Xที่หัวแผงปิดและเก็บค่าฟอร์ม แต่ยังไม่ได้ทดสอบการกด/พิมพ์/keyboardจริง ภาพนี้ตรวจเฉพาะช่วงวันครบและการต่อแผง ภาพcounterรายละเอียดอยู่ในC1.3 การล้างวันยังเป็นจุดถัดไปในC1.2
