# รูปแบบชื่อที่แสดงในช่อง Username

DSD-001/C2 · 5 พฤศจิกายน 2026 · เจ้าของระบุ “อังกฤษ ตัวเลข” แล้วตาม [บันทึก](home-auth-username-format-decision.json); ตัวเลือกด้านล่างเป็นประวัติ

คง [ชื่อแสดงซ้ำได้](home-auth-username-role-decision.json) และrequiredของlocal email signup ไม่เปลี่ยนเป็นUsername Login ไม่เช็กชื่อถูกใช้แล้วหรือเติมsuffix กฎที่ยังเปิดในspecคือรูปแบบและความยาว ไม่ใช่roleหรือความซ้ำ

คำถามถัดไปเฉพาะรูปแบบที่พิมพ์ได้:

1. เสนอภาษาไทย/อังกฤษ ตัวเลข และเว้นวรรค เช่น “ตะวัน 01” เหมาะกับชื่อที่แสดงของผู้ใช้ไทย คำแนะนำเอเจนต์ ยังไม่ใช่คำตัดสิน
2. อังกฤษ/ตัวเลข จุดและขีดล่าง เช่น “tawan_01” ไม่ใช้ภาษาไทยหรือเว้นวรรค ได้รูปแบบชื่อบัญชีที่สม่ำเสมอแต่จำกัดชื่อที่ตั้งได้
3. ใช้ได้อิสระรวมอีโมจิและสัญลักษณ์ ให้ตกแต่งชื่อได้มากขึ้น ต้องตรวจการแสดงผลชื่อที่หลากหลายในขั้นออกแบบที่เกี่ยวข้อง

เจ้าของเลือกเฉพาะอังกฤษและตัวเลข ไม่รวมจุด/ขีดล่าง/เว้นวรรค/ภาษาไทย/อีโมจิ ส่วนเพดานความยาวยังไม่เลือก ไม่มีการใช้fixture “ตะวัน” เป็นคำตัดสินกฎใหม่ กฎความยาว/การจัดการช่องว่างและเทคนิคUnicodeจะต้องแยกจากชุดอักขระที่เจ้าของเลือก ไม่สร้างกฎชื่อซ้ำหรือเริ่มAccount/Profileจากคำหารือนี้

ขอบเขตยังDSD-001/C2 Home Auth Desktop ไม่มีbackend/Frontend/High-FiหรือการรับwholeG2จากการเริ่มคำถามนี้
