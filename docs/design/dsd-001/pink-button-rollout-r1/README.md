# ปรับปุ่มพื้นชมพูในระบบออกแบบ

10 พฤศจิกายน 2026 · DSD-001 · เจ้าของรับคู่สีและให้ใช้ในเฟรมที่ใช้งานอยู่

หลังดู Google Link G3-r3 และตัวอย่างบน Home เจ้าของตอบ “รับครับ” สำหรับคู่สีปุ่ม แล้วสั่ง “ไม่ต้องอ่ะ ทำทั้งหมดเลย ด่วน” ให้ปรับทั้งชุด การรับรอบนี้ครอบคลุมสีพื้นและสีข้อความหรือไอคอนของปุ่มพื้นชมพู ส่วนการรับหน้าจอและขั้นออกแบบอื่นอ้างหลักฐานของงานนั้นตามเดิม [บันทึกการอนุมัติและรายชื่อเฟรม](review-manifest.json)

| กลุ่ม | จำนวนปุ่มที่ผูกสี |
| --- | ---: |
| Home, State Library และ Search มือถือ | 80 |
| Auth เดสก์ท็อป มือถือ และภาพในบริบท Home | 81 |
| Detail และ Gallery | 26 |
| รวม | 187 |

ตรวจกลุ่มระดับบน 116 กลุ่มในไฟล์ Pencil ปรับ 119 จุดในเฟรมงานปัจจุบัน และอีก 68 จุดในฉบับสีใหม่ของ Home State Library `slXLZ` และ Home Desktop `dewqT` เพื่อเก็บต้นฉบับที่ใช้เป็นหลักฐาน ตรวจซ้ำทั้ง 30 กลุ่มที่ปรับแล้วว่าปุ่มทั้ง 187 จุดกับข้อความหรือไอคอน 300 จุดอ้างตัวแปรกลาง และไม่เหลือปุ่มพื้นชมพูเดิมในกลุ่มที่ปรับ

เฟรมเวอร์ชันเก่า แผงที่ซ่อน ไวร์เฟรม และภาพหลักฐานเดิมยังใช้สีของเวอร์ชันนั้น ตัวดูแบบ Auth แบบ HTML 72 ตัวอย่างเป็นหลักฐานจากรอบก่อนและอยู่นอกงาน Pencil นี้ ป้าย โลโก้ ไอคอน แถบรูปย่อที่เลือก และจุดเน้นคงบทบาทสีเดิม ปุ่มที่ปิดใช้งานคงการแสดงสถานะเดิม

คู่สีปุ่มที่รับแล้วมีคอนทราสต์ 5.16:1 ในแบบ สีปุ่มจึงมีข้อสรุปแล้ว ส่วน [OPEN-001](../../../decisions/open-decisions.yaml) ยังเปิดสำหรับตรวจการแสดงผลจริง สถานะโฟกัส และเกณฑ์การเข้าถึงก่อนใช้งานจริง
