# Foundation-3 Desktop · ฉบับก่อนเปลี่ยน Hero

เก็บเอกสารที่เผยแพร่หลังอนุมัติ foundation-3-desktop ทั้งสี่ไฟล์แบบ byte-for-byte ก่อนเพิ่ม Hero ภาพสำเร็จรูปเมื่อ5พฤศจิกายน2026 ค่าSHA-256ตรงกับ `published_deliverables` ใน [หลักฐานอนุมัติเดิม](../owner-foundation-acceptance.json) ดู [archive manifest](archive-manifest.json)

ไฟล์ในโฟลเดอร์นี้เป็นประวัติที่ตรึงไว้ ลิงก์ภายในยังคงข้อความเดิมและอาจอ้างตำแหน่งเดิม จึงไม่ใช้เป็นเอกสารนำทางปัจจุบัน ฉบับใช้งานทั้งสี่อยู่ในโฟลเดอร์ DSD-001 พร้อมหมายเหตุ Hero ล่าสุด ดู [การจัดเอกสารรอบนี้](../../hero-banner-carousel-r1/document-reconciliation.json)

การอนุมัติเดิมไม่ขยายไปครอบคลุม UI/states ของ Hero ใหม่ ไม่มีการแก้หลักฐานอนุมัติย้อนหลัง
