นำเส้นน้ำสีชมพู PGRbi จาก Hero มาใช้ใต้หัวข้อและเป็นเส้นน้ำบางหลังคลิป พร้อมขอบสระ SoKpn ปิด section เข้าสู่บทความ จึงใช้รูปทรงเดียวกับส่วนเดิมของเว็บ ไม่สร้างทิศทางใหม่

ขยายหัวข้อเป็น Mitr40/400 และคลิปหลัก320×568 จัดมุมคลิปด้านหลังให้ต่างกันเล็กน้อย แทนป้ายกรอบด้วยไอคอน TikTok และเพิ่มลูกศรที่ปุ่มดูที่พัก ตัวเลขและ geometry ใหม่นี้ยังเป็นข้อเสนอของร่าง ไม่ย้ายเข้า global tokens

เปรียบเทียบ source แล้ว บทความและทุกส่วนของ Home นอก TikTok ตรงกับ r4 รวมถึง variables; current native node eMYWM ถูกแก้ในตำแหน่งเดิม ส่วน snapshot/PNG รุ่นก่อนเก็บไว้

ภาพและเนื้อหาเป็นตัวอย่าง ไม่มีคลิปจริงหรือ motion runtime ขอบโค้ง/เส้นน้ำเป็น native paths ที่ copy จากแบบเดิม ภาพในกองยังแก้เลเยอร์ได้ OPEN-001, Mobile และ final foundation/UI approval คงสถานะเดิม ไม่มี Frontend หรือ Task อื่นในรอบนี้
