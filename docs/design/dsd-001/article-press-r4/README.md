# Article-press-r4

5 พฤศจิกายน 2026 · สีแผ่จากจุดกดพร้อมเด้ง · รอตรวจตัวอย่าง

เจ้าของขอ “เอาให้มันพอดีกับเด้งอ่ะก่อนที่มันจะเปลี่ยนหน้าแล้วก็อยากให้มันเปลี่ยนสีจากจุดที่กด” จึงปรับจากการเปลี่ยนสีทั้งแผง 500ms ใน focus-r3 เป็นตัวอย่าง activation ที่สีแผ่ออกจากตำแหน่งคลิกพร้อมการเด้ง 420ms ตาม press-r3 ที่รับแล้ว ดู [คำขอ](owner-revision-request.json)

สี Navy แผ่เป็นวงจากตำแหน่งคลิกจริงและจำกัดอยู่ในแผงข้อมูล คำนวณระยะถึงมุมไกลสุดเพื่อให้คลุมครบแม้กดริมกรอบ หากกดบนรูปซึ่งอยู่นอกแผง วงยังมีต้นทางตามจุดจริงและเผยให้เห็นเฉพาะส่วนที่เข้าถึงแผง ไม่เปลี่ยนสีหรือซูมรูปปก ใช้ผิวข้อมูลพร้อมข้อความสองชุดที่สีต่างกัน เปิดเผยผิว Navy/ข้อความขาวและ Light Blue ผ่านวงเดียวกัน ข้อความสำเนาเป็น aria-hidden และไม่มีลิงก์/Tab stop เพิ่ม

การเด้ง +3/-4/0px และวงสีเริ่มพร้อมกันหลังรับ activation ใช้เวลา 420ms และ easing เดียวกัน cubic-bezier(.22,1,.36,1) เด้งครั้งเดียว ไม่เปลี่ยน press entry 140ms หรือ featured hover r7 ที่รับแล้ว ตัวอย่างคงภาพปลายทางไว้และแจ้งจังหวะเปิดบทความหลังสอง animation จบ ไม่มีหน้าบทความจำลองหรือ navigation จริง

คำขอล่าสุดให้ feedback เกิดก่อนเปลี่ยนหน้า จึงแทนข้อเสนอเดิมที่ไม่รอ animation สำหรับการเปิดบทความในแท็บเดิม ข้อเสนอรอบนี้คือเปิดหลัง 420ms โดยไม่เพิ่มเวลารออีก เมื่อใช้ reduced motion หรือไม่รองรับ animation ให้ใช้สีปลายทางและเดินทางต่อทันที ไม่หน่วงเทียม การเปิดแท็บใหม่/คลิกพร้อมปุ่ม modifier ต้องรักษาพฤติกรรม browser ตามปกติในงานพัฒนาภายหลัง ขณะนี้เป็น design specification และยังรอตรวจ ไม่ใช่ authorization ให้ทำ navigation ในแอป

ยังคงหน้าตา keyboard focus แบบพื้นข้อมูลเข้มที่เจ้าของเลือก แยกจาก activation; เสนอเวลา focus 420ms ให้สอดคล้องกัน เมื่อใช้ Enter จุดเริ่ม activation ใช้กึ่งกลางแผง ไม่มีพิกัดเมาส์สมมติ หาก focus ทำให้แผงเข้มแล้ว สีอาจไม่มีการเปลี่ยนเพิ่ม แต่ยังมีการเด้ง การตรวจ keyboard focus ทั้งชุดและการปรับเรื่องรอง/ลิงก์ทั้งหมดคงเป็นงานค้าง

Native `qV3Kf` เป็นภาพปลายทางเดิมและปรับ context ให้ตรงรอบนี้ [ภาพ](qV3Kf.png) · [Snapshot](editable-snapshot.json) · [Manifest](review-manifest.json) ไม่อ้างภาพนิ่งว่าพิสูจน์วงสี จังหวะ หรือ navigation จริง
