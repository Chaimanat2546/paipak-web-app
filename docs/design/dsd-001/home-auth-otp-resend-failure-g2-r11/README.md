เสนอเฉพาะกรณีขอรหัสใหม่แทนรหัสที่หมดอายุแล้วคำขอไม่สำเร็จ: คงอีเมลและพักช่องที่ยังไม่มีรหัสใช้ได้ หยุดโหลด คืนปุ่ม “ลองส่งอีกครั้ง” และทางเลือกใช้รหัสผ่าน ปิด/ย้อนกลับ/แก้ไขอีเมลยังได้ กดลองเองจึงกลับสถานะpendingเดิม ไม่ส่งซ้ำวนหรืออ้างว่ามี/ไม่มีบัญชี และไม่สรุปจากความล้มเหลวที่กำกวมว่าอีเมลไม่ถูกส่งแน่นอน

ไม่ใช้กรณีนี้ไปยกเลิกรหัสเดิมที่ยังใช้ได้ในบริบทอื่น ไม่กำหนดจำนวนลอง/อายุ/cooldown/providerเอง หากระบบไม่อนุญาตให้ลองทันทีต้องใช้stateตามpolicyที่จะกำหนด ไม่ตีความปุ่มนี้เป็นการรับunlimited retries
