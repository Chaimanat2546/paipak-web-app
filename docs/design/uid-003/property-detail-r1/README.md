## กฎแสดงข้อมูลที่ใช้ในแบบ

ใช้ป้ายและแถวข้อมูลสำหรับค่าที่มีความหมายชัด เช่น จำนวนห้อง ความจุ เวลา และสิ่งอำนวยความสะดวกจากฟิลด์ที่รองรับ ใช้ย่อหน้าหรือรายการตามรูปแบบต้นฉบับเมื่อข้อความรวมหลายเงื่อนไข ยุบเฉพาะส่วนที่ขยายได้เป็นกลุ่ม โดยรักษาลำดับและคำขยายความ ตัวอย่าง In2 เปิดรายละเอียดเป็นรายห้อง ส่วน Madaguscar ซ่อนหัวข้อที่เว้นว่างและคงค่าบริการกับเงื่อนไขสัตว์เลี้ยงที่มี [กฎแสดงข้อมูลและ Field Mapping ฉบับเต็ม](data-presentation.md)

ราคา ฿16,900 ต่อคืนของ RimLay เป็นราคาเริ่มต้นที่แค็ตตาล็อกแสดง ณ วันที่ตรวจ แบบใช้กล่องข้อมูลราคาอ้างอิงคงที่ ภาพที่พักใช้ crop ในตารางและรักษาสัดส่วนในตัวดูรูป ปุ่มดูรูปทั้งหมดและตัวนับใช้ชุดรูปเดียวกัน [หน้าสาธารณะ RimLay](https://www.pmheevilla.com/villas/55)

## ข้อจำกัดและงานส่งต่อ

- `h_extra` ต้องยืนยันที่มาก่อนใช้ เพราะข้อมูลแค็ตตาล็อกอาจเติมจำนวนเตียงเสริมในคีย์ที่ตัวแปลงเดิมอ่านเป็นค่าคนเสริม แบบ RimLay จึงแสดงเฉพาะค่าใช้จ่ายที่ยืนยันความหมายได้ เงื่อนไขเช็กเอาต์ล่าช้ากับค่าปรับออกเกินเวลาแสดงเป็นคนละเรื่อง
- เมื่อข้อความจากเจ้าของบ้านขัดกัน ให้แสดงข้อเท็จจริงที่ยืนยันได้และส่งข้อมูลให้ตรวจ เช่น AB5 มีข้อความสองทางเรื่องสไลเดอร์ ควรพักป้ายยืนยันสถานะไว้ [หน้าสาธารณะ AB5](https://www.pmheevilla.com/villas/1353)
- ส่วนวิดีโอใช้ลิงก์ YouTube ที่ตรวจรูปแบบแล้ว และแสดงสถานที่ใกล้เคียงจาก Devil ที่มีชื่อจริง การเล่นวิดีโอและการเปิดปลายทางยังรอตรวจจริง
- ตรวจภาพส่งออกทั้งสองขนาด ค่าของ component instances จำนวนรูป 69 ที่ตรงกัน และภาพที่ใช้จริง 7 ไฟล์ ก่อนพัฒนาให้ทดสอบโฟกัส คีย์บอร์ด โปรแกรมอ่านหน้าจอ การขยายข้อความ และการเปิดรูปจริง แยกการตรวจราคาตามวันที่เข้าพักออกจากราคาเริ่มต้น
