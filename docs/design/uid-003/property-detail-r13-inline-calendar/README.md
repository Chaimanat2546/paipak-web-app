# UID-003 · Property Detail r13 — ปฏิทินบนหน้า

ต่อจาก [r12](../property-detail-r12-system/README.md) ตามคำขอให้เห็นปฏิทินในหน้ารายละเอียดทันที Desktop วางปฏิทินใต้ราคาเริ่มต้นในกล่องขวา มือถือวางใต้ราคาในกล่องเดียวกันก่อนส่วนรายละเอียดบ้าน ปฏิทินและปุ่มเปลี่ยนเดือนแสดงอยู่บนหน้า โดยไม่มีปุ่มเปิดหรือปิดปฏิทิน

| แบบใน Pencil | เฟรม | ภาพตรวจแบบ |
| --- | --- | --- |
| Desktop 1440 | `xU9u5` | [เต็มหน้า](desktop-full.png) |
| Mobile 390 | `vP7jt` | [เต็มหน้า](mobile-full.png) |
| กล่องปฏิทินบนมือถือ | `zbwEv` | [ภาพขยาย](mobile-calendar.png) |

เมื่อแตะวันที่เลือกได้ ให้เปิดเฉพาะ [รายละเอียดของวันที่เลือก](../property-detail-r12-system/calendar-and-day.png) ปิดรายละเอียดแล้วกลับที่วันเดิมบนหน้ารายละเอียดและคงเดือนที่กำลังดู วันที่ติดจองและรอชำระกดไม่ได้ ส่วนสถานะกำลังโหลด โหลดไม่ได้ และไม่มีราคา ใช้ [แบบ r12](../property-detail-r12-system/calendar-states.png) ในพื้นที่ปฏิทินเดิม ติดต่อแอดมินเพื่อยืนยันช่วงเข้าพักและราคาสุดท้าย

ภาพใช้ตัวอย่างปฏิทินย้อนหลังของ RimLay จาก r12 ราคาและสถานะในภาพใช้ตรวจแบบเท่านั้น รุ่นนี้แก้ใน Pencil โดยยังไม่ได้ต่อปฏิทินเข้ากับระบบจริง
