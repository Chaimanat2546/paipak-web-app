## กติกาในแบบ

- ใกล้ทะเล สายปาร์ตี้ และ Pet Friendly ใช้ข้อเท็จจริงที่ยืนยันได้ พร้อมข้อจำกัดที่เกี่ยวข้อง RimLay จึงแสดงติดทะเล คาราโอเกะคู่กับเวลาใช้เสียง และการรับสุนัขกับแมวคู่กับค่าบริการ
- แนะนำ Outing และ Luxury ใช้การจัดหมวดที่ papaipak ยืนยัน ความจุยังแสดงเป็นข้อมูลหลักของทุกบ้านที่มีค่า ราคาพิเศษอยู่ในกล่องราคาเมื่อมีราคาและช่วงเวลาที่ตรวจสอบได้
- รายการรูปเต็มใช้ตัวนับชุดเดียวกับปุ่มดูรูปและตัวกรอง แสดงเฉพาะหมวดรูปที่มีข้อมูล รูปเดียวใช้ปุ่มเปิดภาพโดยตรง สถานะไม่มีรูปและโหลดรูปไม่สำเร็จแสดงต่างกันตาม [ชุดสถานะรูป](../property-detail-r1/aDKdF.png)
- เมื่อฟิลด์ว่าง ให้เว้นหัวข้อนั้นและคงข้อมูลที่อ่านได้ ราคาเริ่มต้นว่างใช้ข้อความตรงจุด ส่วนเนื้อหายาวรักษาลำดับ ข้อยกเว้น และหน่วยไว้ในกลุ่มเดิม [เคสจริงกฎบ้านยาวและแกลเลอรีว่าง](../property-detail-audit-r2/cFInj.png) · [Field Mapping](../property-detail-r1/data-presentation.md)
