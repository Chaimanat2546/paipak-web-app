## ข้อมูลที่แสดง

| ส่วน | แหล่งและวิธีแสดง |
| --- | --- |
| ชื่อ รหัส จำนวนห้อง และความจุ | ใช้ข้อมูลแค็ตตาล็อกของบ้านเดียวกัน สำหรับ RimLay (`DV-55`) คือ 5 ห้องนอน 5 ห้องน้ำ พักได้สูงสุด 20 คน ตัวเลข 20 คือความจุของบ้าน ส่วนจำนวนคนที่ราคาวันนั้นรองรับมาจากปฏิทิน |
| ทำเล เวลา และรายละเอียด | ใช้ผลรวมจากแค็ตตาล็อกและ Devil ตามลำดับที่ตรวจไว้ใน [Field Mapping r1](../property-detail-r1/data-presentation.md) RimLay ใช้หาดบางเสร่ เช็กอิน 14:00 น. เช็กเอาต์ 11:00 น. บ้านอื่นซ่อนแถวที่ไม่มีค่า ไม่เติมเวลาเริ่มต้นเอง |
| ราคาเริ่มต้น | ใช้ `listing.price` เมื่อเป็นราคาที่แค็ตตาล็อกส่งมา RimLay ฿16,900 ต่อคืน กรณีไม่มีราคาให้ซ่อนจำนวนเงินแต่ยังเปิดปฏิทินได้ถ้าบ้านมีข้อมูลปฏิทิน |
| ราคาของวัน | ใช้ `price` และ `guestCapacity` ของวันที่เลือกจากปฏิทิน แสดงจำนวนคนที่ราคานั้นรองรับเมื่อมีค่า วันหยุดหรือโปรโมชันแสดงป้ายและข้อความเงื่อนไขเมื่อแหล่งส่งมา ห้ามนำราคาเริ่มต้นมาทดแทนราคาวันที่ขาดแล้วแสดงว่าเป็นราคาวันนั้น |
| รูปบ้านพัก | ป้ายจำนวนรูปนับจากชุดที่จะเปิดจริง RimLay มีรูปบ้าน 69 รูปและรูปหมวดรีวิว 10 รูปจากรายการรวม 79 รูปในผลตรวจเดิม รูปรีวิวแยกจากตัวนับรูปบ้าน เปิดดูได้เมื่อมีชุดรูปและปิดแล้วคืนโฟกัสให้ปุ่มที่เปิด เคส 0, 1 และหลายรูปใช้ [กติกา r1](../property-detail-r1/data-presentation.md#แกลเลอรีและสถานะรูป) และ [ผลตรวจรายบ้าน r2](../property-detail-audit-r2/README.md) |
| เนื้อหาตามข้อมูลที่มี | แสดงเฉพาะหัวข้อที่มีข้อมูลและให้เมนูย่อยไปยังหัวข้อที่มีจริง ข้อความยาวขยายในส่วนเดิมโดยคงลำดับ รายการ หน่วย และเงื่อนไข r12 ซ่อนตัวอย่างวิดีโอและสถานที่ใกล้เคียงบน RimLay เพราะยังตรวจยืนยันรายการพร้อมใช้ในหน้าต้นทางรอบนี้ไม่ได้ บ้านที่มีลิงก์วิดีโอหรือข้อมูลสถานที่ที่ผ่านการตรวจยังใช้หัวข้อเดิมได้ |
| ค่าใช้จ่ายและกฎ | คงค่าประกันและค่าใช้จ่ายแยกตามเงื่อนไขของบ้าน `h_extra` ต้องรู้ที่มาก่อนตีความเป็นค่าคนเสริม ตัวเลขเหล่านี้ไม่รวมเป็นยอดจองในแผงปฏิทิน |

ใช้กติกาเดียวกันกับบ้านทั้งเจ็ดหมวด ป้ายของหมวดขึ้นกับการจัดกลุ่มของ papaipak และหลักฐานเฉพาะบ้าน โปรโมชันที่หมดช่วงแล้วใช้เป็นตัวอย่างย้อนหลังได้โดยไม่แสดงว่าเป็นข้อเสนอปัจจุบัน ดู [ผลเทียบหมวด](../property-detail-r3-categories/README.md)

## เมื่อผู้ใช้กดหรือระบบส่งข้อมูลกลับ

| เหตุการณ์ | การตอบสนองที่แบบกำหนด |
| --- | --- |
| เปิดรายละเอียด | เปิดดูบ้านและปฏิทินได้โดยไม่ต้องเข้าสู่ระบบ แผงสีชมพูแสดงราคาเริ่มต้นและปุ่ม `ดูปฏิทินราคาและวันว่าง` ไม่มีช่องเลือกช่วงวันหรือกรอกจำนวนคนในขั้นนี้ |
| เปิดปฏิทิน / เปลี่ยนเดือน | เปิดปฏิทินเป็นแผงบนหน้ารายละเอียดเพื่อคงตำแหน่งอ่าน ปุ่มเดือนก่อน เดือนถัดไป และ `วันนี้` ใช้เปลี่ยนเดือนตามขอบเขตของระบบเดิม เปิดดูรายละเอียดได้ครั้งละหนึ่งวัน วันที่ย้อนหลังและวันที่อยู่นอกเดือนที่เปิดอยู่กดไม่ได้ |
| เลือกวันที่เปิดให้ดูรายละเอียด | แสดงวันที่ ราคา จำนวนคนที่ราคานั้นรองรับ และข้อความเงื่อนไขที่มากับวันนั้น ถ้ามี โปรดติดต่อแอดมินเพื่อยืนยันช่วงเข้าพัก ราคาสุดท้าย และเงื่อนไข การปิดรายละเอียดกลับไปเดือนเดิม การปิดปฏิทินกลับไปแผงราคาเดิม |
| วันที่ติดจอง / รอชำระ | ใช้สถานะคนละป้าย ทั้งสองกรณีปิดการเลือกวัน ใช้ข้อความประกอบสีเพื่อให้เข้าใจสถานะได้ |
| กำลังโหลด | รอข้อมูลของเดือนที่เปิดอยู่ ระหว่างนั้นปิดการเลือกวันและไม่เอาราคาเดือนอื่นมาแสดง |
| โหลดไม่ได้ / ยังตรวจสอบไม่ได้ | แสดงข้อความและ `ลองใหม่` สำหรับเดือนเดิม เก็บราคาเริ่มต้นแยกบนหน้าหลัก แสดงทางติดต่อที่ใช้ได้เมื่อมี การอ่านรายละเอียดบ้านสำเร็จไม่ใช่หลักฐานว่าวันใดว่าง |
| วันที่ไม่มีราคา | แสดง `ไม่มีข้อมูลราคา` และให้สอบถามแอดมินเมื่อมีช่องทางติดต่อ ขีดในภาพย้อนหลังหมายถึงไม่มีตัวเลขในภาพต้นทาง จึงไม่สรุปสถานะของวันจากขีดอย่างเดียว |
| ติดต่อทีม | ใช้ LINE, Messenger หรือเบอร์โทรเฉพาะรายการที่กำหนดให้แบรนด์ papaipak ปุ่ม `ดูช่องทางติดต่ออื่น` แสดงเมื่อมีช่องทางเพิ่มเติม หากมีช่องทางเดียวให้ใช้ปุ่มเดียว ไม่ยกเบอร์หรือบัญชีของเว็บอ้างอิงมาใช้โดยอัตโนมัติ |
| แชร์ | ใช้ลิงก์หน้ารายละเอียดของบ้านที่กำลังดู เปิดเมนูแชร์ของอุปกรณ์เมื่อรองรับ หรือคัดลอกลิงก์เมื่อไม่มีเมนูแชร์ แจ้งเมื่อคัดลอกสำเร็จ ผู้ใช้เปิดแชร์ได้ทั้ง Desktop และมือถือ |
| บันทึกที่พัก | ใช้กติกา Favorites ของ papaipak: Guest เข้าสู่ระบบก่อน เก็บเจตนาบันทึกเฉพาะการใช้งานที่ต่อเนื่องและแสดงว่าบันทึกแล้วเมื่อได้รับผลสำเร็จจริง ปิด Auth แล้วกลับหน้ารายละเอียดได้ตามเดิม ดู [UXD-001](../../uxd-001/edge-flows.md) |

ภาพปฏิทินใช้ข้อมูลย้อนหลังเดือนสิงหาคม 2569 ที่อ่านได้จาก [หน้ารายละเอียด RimLay ของระบบเดิม](https://www.pmheevilla.com/villas/55) ตัวอย่างวันที่ 21 แสดง ฿16,900 สำหรับ 14 คน จึงใช้เทียบกับความจุ 20 คนได้ ภาพนี้ไม่ใช่ราคาเสนอหรือสถานะวันว่างปัจจุบัน ส่วนสถานะติดจอง รอชำระ วันหยุด และโปรโมชันตรวจจาก [ตัวแปลงข้อมูลปฏิทินเดิม](/C:/Users/chaym/Projects/baan-pool-villa/lib/villas/booking-calendar.ts:348) และ [แผงปฏิทินเดิม](/C:/Users/chaym/Projects/baan-pool-villa/components/villas/detail/booking-calendar-panel.tsx:39)

ระบบเดิมมีบางทางที่ใช้ราคาเริ่มต้นเติมลงปฏิทินเมื่อขาดข้อมูลรายวัน รุ่นนี้คงราคาเริ่มต้นบนหน้าหลักและเว้นราคาของวันตามกติกา [UID-003](../../../../tasks/design/UID-003.md) เพื่อไม่ให้ราคาจากคนละแหล่งดูเป็นยอดเดียวกัน การอ่านผลปฏิทินจริง แหล่งที่ใช้ยืนยันราคาสุดท้ายและวันว่าง และปลายทางติดต่อของ papaipak ยังต้องยืนยันก่อนเชื่อมระบบ ดู `OPEN-007` ใน [รายการที่ยังเปิด](../../../decisions/open-decisions.yaml) งาน Checkout การถือคิว และการชำระเงินแยกจากแบบนี้
