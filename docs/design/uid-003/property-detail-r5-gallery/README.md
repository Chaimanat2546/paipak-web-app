# UID-003 · แกลเลอรี r5 · เดินชมบ้าน

แบบใน Pencil สำหรับตรวจรับ เทียบ Desktop 1080 px กับมือถือ 390 px [ไฟล์ Pencil](../../dsd-001/papaipak-ui.pen)

แกลเลอรีเริ่มจากภาพจริงที่บอกลักษณะของบ้าน แล้วให้เลือกดูตามพื้นที่ สำหรับ LYYA VILLA ใช้ภาพริมสระตอนค่ำเป็นภาพเปิด และใช้ภาพแนวตั้งจากหมวดห้องนอนเปลี่ยนจังหวะการดู หน้าเปิด Desktop วางสารบัญข้างภาพ มือถือวางปุ่มดูรูปทั้งหมดและเลือกหมวดต่อจากภาพ [หน้าที่พัก LYYA](https://www.pmheevilla.com/villas/3178)

ศึกษาการสลับภาพกว้างกับภาพรายละเอียดจาก The Modern House และการจัดหมวดตามพื้นที่จริงจาก The Warehouse Hotel ใช้แนวภาพหลักคู่คอลัมน์สารบัญจาก Taste Skill แล้วปรับให้เข้ากับ Mitr สีกรมท่า ฟ้าอ่อน และชมพูของ papaipak ใช้ภาพที่พักจริงตามผลตรวจรายบ้าน [The Modern House](https://themodernhouse.com/journal/open-house-spruce-house) · [The Warehouse Hotel](https://www.thewarehousehotel.com/gallery/) · [ผลตรวจรายบ้าน](../property-detail-audit-r2/README.md)
