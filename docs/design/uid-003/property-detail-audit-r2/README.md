## สิ่งที่ตรวจ

ใช้รหัสบ้านตัวเลขจาก sitemap เป็นรายการตั้งต้น เทียบรายละเอียดสาธารณะกับหน้า `/villas/{id}` ทีละหลัง ตรวจรายการรูปเต็มที่หน้าเดิมส่งมา และเก็บผลใน Excel หนึ่งแถวต่อรหัส ใช้แผ่นรายบ้านกรองตามโซน แถว Home ราคา รูป หรือฟิลด์ที่ควรตรวจเพิ่ม ส่วนแผ่นสรุปฟิลด์แสดงความครอบคลุม รูปแบบ และค่าที่เหมาะกับการทดสอบหน้าจอ [Sitemap](https://www.pmheevilla.com/sitemap.xml) · [ตัวอย่างหน้าเดิม](https://www.pmheevilla.com/villas/55) · [ตัวอย่างรายละเอียดสาธารณะ](https://www.pmheevilla.com/api/villas/55)

ตรวจซ้ำกับ API หน้าค้นหาครบ 47 หน้า พบ 1,128 แถวและ 1,128 รหัสไม่ซ้ำ รหัสตรงกับ sitemap ทุกตัว และ sitemap รอบปิดงานยังมีชุดรหัสเดิม ใช้ตัวกรองราคาเพดาน 100,000 บาทเพื่อให้ผลค้นหาครบตามยอดที่ API รายงาน [หน้าค้นหา API ที่ใช้เทียบ](https://www.pmheevilla.com/api/houses?guests=1&bedrooms=1&maxPrice=100000&limit=24&page=1) · [Sitemap](https://www.pmheevilla.com/sitemap.xml)

รายละเอียดสาธารณะเป็นข้อมูลที่ระบบเดิมผสาน Devil กับแค็ตตาล็อก ค่าที่แค็ตตาล็อกเติมได้ยังมีประโยชน์เมื่อ Devil ไม่มีข้อมูล การนับรูปใช้รายการและหมวดจากหน้าเดิม แยกรูปบ้านออกจากรูปรีวิว ส่วนความยาวของ Textbox วัดจากข้อความที่แปลงขึ้นบรรทัดแล้วและอาจต่างจากจำนวนอักขระใน HTML [กติกาอ่านแหล่งข้อมูลและ Field Mapping](../property-detail-r1/data-presentation.md)

## แกลเลอรีและข้อความที่แบบต้องรองรับ

- แกลเลอรีมี 82,858 รายการ เป็นรูปบ้าน 69,671 และรูปรีวิว 13,187 หมวดที่พบมีภาพปก ภายนอก ภายใน ห้องนอน ห้องน้ำ ครัว ที่จอดรถ และรีวิว ให้แสดงเฉพาะหมวดที่มีรูปในบ้านนั้น และนับรูปรีวิวแยกจากแกลเลอรีบ้าน
- พบ 9 หลังไม่มีรูปบ้าน 3 หลังมีหนึ่งรูป และ 1,116 หลังมีอย่างน้อยห้ารูป ใช้ภาพเดียวเต็มพื้นที่เมื่อมีหนึ่งรูป ใช้ตารางภาพนำและเปิดชุดเต็มเมื่อมีหลายรูป พร้อมคืนโฟกัสเมื่อปิดตัวดูรูป ชุดที่มีรูปบ้านมากที่สุดมี 261 รูป จากรายการ 301 รูปที่รวมรีวิวแล้ว [ตัวอย่างหนึ่งรูป The Chelonia 2 (B18)](https://www.pmheevilla.com/villas/3209) · [LYYA VILLA](https://www.pmheevilla.com/villas/3178)
- ฟิลด์ภาพรวมมีข้อมูล 1,094 หลัง มีรูปประกอบใน Textbox 74 หลัง และพบข้อความถึง 66 บรรทัด รายละเอียดห้องมีข้อมูล 1,118 หลัง ยาวสุด 37 บรรทัด ให้เก็บรูปที่มากับข้อความไว้ในส่วนนั้น และรักษาหัวข้อกับบรรทัดต่อเนื่องในรายละเอียดห้อง [Na-tree pool villa Pattaya](https://www.pmheevilla.com/villas/1933) · [กฎจัดข้อความ r1](../property-detail-r1/data-presentation.md)
- กฎบ้านมีข้อความ 276 หลัง ส่วนค่าใช้จ่ายเพิ่มเติมมี 914 หลัง ใช้หัวข้อแยกกัน ให้ค่าบริการและค่าปรับอยู่กับเงื่อนไขเดิม เว้นหัวข้อเมื่อไม่มีข้อมูลในกลุ่มนั้น เกณฑ์ 600 อักขระหรือ 12 บรรทัดใน Excel ใช้คัดตัวอย่างเพื่อตรวจแบบ การยุบเนื้อหาในหน้าจอให้ยึดโครงเรื่องและพื้นที่อ่าน

## ขอบเขตของหลักฐาน

การตรวจทุกหลังในชุดนี้เป็นการตรวจข้อมูลและรายการรูป ภาพตัวอย่างที่ใช้ใน Pencil ตรวจเปิดไฟล์ที่นำมาใช้จริง การทดสอบไฟล์รูปครบทั้งแค็ตตาล็อก การวัดการอ่านบนอุปกรณ์จริง และการทดสอบคีย์บอร์ดกับโปรแกรมอ่านหน้าจอเป็นงานตรวจเมื่อพัฒนา สถานะงานออกแบบ r2 คือรอตรวจรับ [UID-003](../../../../tasks/design/UID-003.md)
