# UID-003 · Property Detail r31

เจ้าของรับ UI r31 เมื่อ 10 พฤศจิกายน 2569 ทั้ง Desktop และมือถือ แบบครบ 8 เคสอยู่ใน **หน้าที่ยืนยันแล้ว · Home, Auth และ Property Detail** (`ysmkc`) กลุ่ม Property Detail (`oO6XU`) มีบอร์ด **โน้ตสำหรับตอนเขียนโค้ด** (`CXQxy`) และบอร์ดสถานะกับแผนผังฟิลด์ (`PVEB9`) การรับครั้งนี้อยู่ในขอบเขต UI [บันทึกการรับแบบ](owner-ui-acceptance.json)

ใช้เช็กลิสต์ของเจ้าของเป็น brief และเกณฑ์ตรวจแบบสำหรับทุกหลัง ชุดนี้ใช้ 7 บ้านตัวอย่างจากหมวดเดิมและ DV-1945 สำหรับกรณีรายละเอียดต้นทางไม่พร้อม ตรวจข้อมูลสาธารณะรอบนี้เมื่อ 10 พฤศจิกายน 2569 ส่วนฐานสำรวจ 1,128 หลังอยู่ใน [r27](../property-detail-r27-catalog/README.md)

DV-9 เก็บคลิป 3 รายการ สถานที่ 16 แห่ง รูปกติกาเจลกัน 2 รูป และรายละเอียดค่าใช้จ่ายจาก r30 ส่วน DV-55 คงกฎยาว สถานที่ 1 แห่ง และเดือนที่ทั้ง 30 วันติดจอง DV-1945 เคยพบ De Ville ตอบ 404 ในการสำรวจเดิม API สาธารณะรอบนี้ตอบ HTTP 200 พร้อม `detailStatus: unavailable` จึงใช้ข้อมูลแคตตาล็อกและปฏิทินที่อ่านแยกได้ หากหาไม่พบทั้งรายละเอียดและแคตตาล็อกให้ใช้สถานะไม่พบที่พัก

ตรวจภาพส่งออกทั้ง Desktop และมือถือและเปิดตัวอย่างปลายทางของ DV-9 บน Google Maps กับ YouTube ได้โดยตรง การเล่นคลิปฝัง การเลือกวันที่ การเปิดตัวดูรูป และการติดต่อแบบครบเส้นทางยังต้องตรวจในหน้า Frontend ที่เชื่อมข้อมูลจริง บ้านทั้ง 7 ตัวอย่างยังไม่มีแผนที่ตัวบ้านและรีวิวจาก API ส่วนช่องทางติดต่อในบอร์ดเป็นตัวอย่างตามเงื่อนไขตั้งค่า
