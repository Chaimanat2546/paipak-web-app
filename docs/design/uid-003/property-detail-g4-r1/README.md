# ชุดตรวจแบบสุดท้าย G4 · หน้ารายละเอียดบ้านพัก

**รุ่นตรวจรับ** G4-r1 · UID-003 · 11 พฤศจิกายน 2026  
**แบบอ้างอิง** Property Detail r31 ที่เจ้าของรับหน้าตาเมื่อ 10 พฤศจิกายน 2026  
**สถานะ** เจ้าของอนุมัติ G4-r1 แล้วเมื่อ 11 พฤศจิกายน 2026 [บันทึกอนุมัติ G4-r1](review-manifest.json) · [บันทึกการรับแบบ r31](../property-detail-r31-checklist/owner-ui-acceptance.json)

## จุดที่ใช้ตรวจรับ

| จุดตรวจ | ผลที่ตรวจได้จากชุดแบบ |
| --- | --- |
| โครงหน้าและแกลเลอรี | ภาพหลักและข้อมูลบ้านอยู่ช่วงต้น เดสก์ท็อปวางรายละเอียดทางซ้ายและกล่องจองทางขวา มือถือเรียงเป็นคอลัมน์เดียวตามลำดับในภาพ ใช้โครงเดียวกันกับทุกบ้าน |
| ราคาและวันว่าง | ภาพแยกราคาเริ่มต้นอ้างอิงออกจากราคาตามวันที่เลือก และแยกว่าง รอชำระ ติดจอง ผ่านวันแล้ว กำลังโหลด โหลดไม่สำเร็จ ไม่มีวันว่าง และเลือกข้อมูลไม่ครบ |
| การยืนยันการจอง | สเปคกำหนดให้ตรวจราคาและวันว่างใหม่ก่อนจอง และแสดงสถานะจองสำเร็จเมื่อระบบยืนยันการจองแล้ว การทำงานจริงอยู่ในรอบทดสอบ |
| รายละเอียดต้นทางไม่พร้อม | DV-1945 แสดงข้อมูลที่แคตตาล็อกยืนยันได้ พร้อมข้อความว่ารายละเอียดบางส่วนยังไม่พร้อม และใช้สถานะปฏิทินแยกจากสถานะรายละเอียด |
| บล็อกตามข้อมูล | แสดงแผนที่ รีวิว คลิป ช่องทางติดต่อ และส่วนเสริมตามข้อมูลและการตั้งค่า เมนูข้ามส่วนอิงบล็อกที่แสดงจริง [บอร์ดส่วนเสริม](../property-detail-r31-checklist/conditional-blocks.png) |
| ปุ่มและการเข้าถึง | มีภาพตำแหน่งและข้อความปุ่มบนมือถือทั้งกรณีพร้อมและเลือกข้อมูลไม่ครบ การเข้าถึงจริงยังต้องตรวจด้วยคีย์บอร์ด โปรแกรมอ่านหน้าจอ การขยายตัวอักษร และการแตะบนเครื่องจริง |

## ประเด็นส่งต่อ

- **ระบบจองและแหล่งข้อมูลจริง** ต้องสรุปเวลาถือสิทธิ์จองและการล็อกห้องเมื่อมีคำขอพร้อมกัน (OPEN-006) รวมถึงแหล่งราคา วันว่าง และสิทธิ์ยืนยันข้อมูลแคตตาล็อก (OPEN-007) [ทะเบียนประเด็นเปิด](../../../decisions/open-decisions.yaml)
- **จอขนาดกลางและการเข้าถึง** ตรวจการจัดวางระหว่างความกว้างอ้างอิง โดยรักษาลำดับข้อมูลและการเข้าถึงปุ่มจอง ตรวจโฟกัส คอนทราสต์ การซูม และป้ายสถานะบนปฏิทินในหน้าที่ทำงานได้
- **เส้นทางใช้งานจริง** ตรวจตัวดูรูป คลิปฝัง แผนที่ ช่องทางติดต่อ การเลือกวัน จำนวนผู้เข้าพัก และการตรวจราคากับวันว่างใหม่ก่อนจอง ใช้ DV-9, DV-55 และ DV-1945 เป็นชุดทดสอบหลักควบคู่กับตัวอย่างที่เหลือ

เจ้าของอนุมัติให้ใช้ **Property Detail r31 เป็นชุดแบบ G4-r1** ครอบคลุมเดสก์ท็อปและมือถือครบทั้ง 8 ตัวอย่าง พร้อมสถานะกล่องจองที่อยู่ในชุดตรวจ ภาพและเอกสารอ้างอิงตรงกับชุดที่ส่งตรวจ ประเด็นระบบจองและแหล่งข้อมูลราคาและวันว่างยังอยู่ในงานพัฒนาและทดสอบตามรายการข้างต้น [ขั้นตอนตรวจรับ G4](../../governance/05-design-workflow.md)
