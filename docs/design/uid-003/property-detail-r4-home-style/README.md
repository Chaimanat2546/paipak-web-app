# UID-003 · Property Detail r4 · สไตล์ Home

แบบใน Pencil สำหรับตรวจรับ

ใช้ Home Desktop r22 `eJBTs` เป็นภาพอ้างอิงหลัก ฝั่งมือถือใช้ร่าง Home Mobile `PiA4h` สำหรับแถบภาษาและเมนู แล้วปรับให้ใช้โลโก้จริงจาก r22 [Home Desktop r22](../../dsd-001/home-auth-feature-review-r1/eJBTs.png) · [ไฟล์ Pencil](../../dsd-001/papaipak-ui.pen)

- หัวเว็บ Desktop ใช้ชิ้นส่วนจาก `tnDNO` ปุ่มเข้าระบบชมพูตัวอักษรกรมท่า และปรับไอคอนหน้าแรกเป็นลิงก์กลับ สำหรับภาพเทียบ 1080 px จัดชิ้นส่วนเดิมใหม่ให้พอดีกับความกว้าง
- ท้ายเว็บมือถือใช้ขอบคลื่นจาก `SEY6M` และพื้นฟ้าจาก Home จัดวางโลโก้และข้อความให้เหมาะกับหน้าจอ 390 px
- ใช้มุม 16 px จากการ์ด Home ปุ่มขอบมน และจัดตัวเลขราคาสีกรมท่าคู่กับหน่วยสีเทาตาม `KXUaZ` ราคาทั้งหมดยังคงเป็นราคาเริ่มต้นอ้างอิง
- บอร์ดหมวดใช้ไอคอนจาก `QoWjj` และพื้นเฉพาะหมวดจาก Home ได้แก่ ฟ้าอ่อนของแนะนำ ชมพูอ่อนของราคาพิเศษ และกรมท่าของ Luxury บนส่วนตัวอย่างที่รอข้อมูลยืนยัน ชื่อบ้าน รูป และเงื่อนไขรายบ้านอ้างอิง [ชุดตรวจแบบ r3](../property-detail-r3-categories/README.md)
