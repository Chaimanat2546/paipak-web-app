# UID-003 · Property Detail r17 — ปฏิทิน Celuna

ใช้ Celuna Pool Villa (DV‑9) เป็นตัวอย่างบ้านที่มีทั้งวันว่างและวันติดจองในเดือนเดียวกับ RimLay ปฏิทินอ่านจากหน้า Celuna ที่เผยแพร่เมื่อ 10 พฤศจิกายน 2569 ตรวจเทียบช่องวันที่ในหน้าต้นทางทั้งสองขนาดจอแล้วได้สถานะและราคาตรงกันครบ 30 วัน [หน้า Celuna ต้นทาง](https://www.pmheevilla.com/villas/9)

| สถานะ | วันที่ในเดือนพฤศจิกายน 2569 |
| --- | --- |
| ว่างและกดเลือกได้ | 10, 13, 18, 23–25, 30 |
| ติดจองแล้ว | 1, 4–5, 7, 9, 11–12, 14–17, 19–22, 26–29 |
| ผ่านมาแล้ว | 2, 3, 6, 8 |

วันที่ 13 แสดงราคา 13,900 บาทต่อคืน วันที่ว่างอีก 6 วันแสดง 9,900 บาทต่อคืนตามปฏิทินต้นทาง แบบใส่สถานะเป็นข้อความในช่องวันที่ และใช้สีฟ้าสำหรับวันว่าง ชมพูสำหรับวันติดจอง และเทาสำหรับวันที่ผ่านมาแล้ว ข้อมูลที่พักและรูปเป็นของ Celuna จากหน้าเดิมและหลักฐานรูปที่ใช้ในแบบ r3 [หลักฐานภาพและรายละเอียด Celuna](../../dsd-001/papaipak-ui-assets/uid-003/r3-category-editorial/source-record.json)
