# UID-003 · Property Detail r16 — ปฏิทิน RimLay

สถานะรายวันในแบบมาจากปฏิทินที่แสดงบนหน้าสาธารณะของ RimLay Beachfront Pool Villa (DV‑55) เมื่อ 10 พฤศจิกายน 2569 เวลา 14:14 น. ตามเวลาไทย วันที่ 1–30 พฤศจิกายน 2569 แสดง `booking_confirmed` และปิดการเลือกทุกวัน ทั้งสองขนาดจอของต้นทางให้ผลตรงกัน และหน้าเว็บที่อ่านผ่าน Firecrawl ในรอบเดียวกันแสดงสถานะเดียวกันครบ 30 วัน [หน้าปฏิทิน RimLay](https://www.pmheevilla.com/villas/55)

ตรวจด้วยปุ่มเดือนถัดไปบนหน้าเดิมตั้งแต่ธันวาคม 2569 จนถึงพฤศจิกายน 2570 ซึ่งเป็นเดือนสุดท้ายที่ปฏิทินเปิดให้ดู ทุกวันในช่วงที่ตรวจแสดงติดจอง ณ เวลาที่เปิดดู ภาพใน Pencil ใช้เดือนพฤศจิกายน 2569 และใส่สถานะลงในช่องวันที่จริงทุกช่อง
