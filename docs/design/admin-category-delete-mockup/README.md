ปุ่มลบใช้ตำแหน่งเดิมของปุ่มยกเลิกในหน้าแก้หมวด ตัวอย่างลบ **บ้านสำหรับครอบครัว** จากรายการหมวด 9 รายการ เหลือ 8 รายการ บ้านพักและหมวดอื่นของแต่ละหลังยังอยู่ ปุ่มยกเลิกในหน้ายืนยันกลับฟอร์มเดิมพร้อมข้อมูลที่แก้ค้าง เมื่อยืนยันให้พักการกดซ้ำจนทราบผล ลิงก์เดิมของหมวดที่ลบพาไปหน้าแรกตามสเปค

ภาพเป็นม็อกอัปสำหรับตรวจหน้าตาและลำดับใช้งาน การลบข้อมูล การอัปเดตหน้าแรก และพฤติกรรมลิงก์ตรงยังรอทดสอบในระบบจริง

วันที่ 11 พฤศจิกายน 2026 เจ้าของตอบ “โอเคแล้่ว” หลังตรวจแผงยืนยันจากด้านล่างบนมือถือและภาพกรณีลบไม่สำเร็จในแผงเดียวกัน ฉบับที่รับใช้ปุ่ม **ลบหมวดหมู่** ข้าง **บันทึกหมวด** ในหน้าแก้หมวดทั้งสองขนาด
