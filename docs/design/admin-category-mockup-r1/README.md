# UID-010 ม็อกอัปเดสก์ท็อป r1

**ต้นฉบับ** บอร์ดแก้หมวด `cmzlg` บอร์ด Toast `yKNTY` และบอร์ดตัวอย่างสถานะ `DeFWF` ใน [Pencil ของโปรเจกต์](../dsd-001/papaipak-ui.pen)  
**ฐานอ้างอิง** [ไวร์เฟรม r2 ที่เจ้าของรับแล้ว](../admin-category-wireframe-r2/README.md) · [ขอบเขตม็อกอัปที่อนุมัติ](../admin-category-management-brief.md#9-ข้อเสนอขอบเขตม็อกอัป)

Toast ฉบับนี้อิงภาพที่เจ้าของส่งมา กล่องกว้าง 390 พิกเซล มีแถบสีด้านซ้าย ไอคอนวงกลม และข้อความสองระดับ [ตัวอย่างสีของ Toast ทั้งสี่แบบ](DeFWF.png) เป็นตัวอย่างส่วนประกอบแยกจากหน้าจอแก้หมวด กติกาข้อผิดพลาดในฟอร์มใช้ตามสเปคเดิม

วันที่ 11 พฤศจิกายน 2026 เจ้าของยืนยัน “แบบนี้แหละ” หลังตรวจ Toast กำลังบันทึกและบันทึกหมวดหมู่สำเร็จบนเดสก์ท็อปตามภาพข้างต้น

ภาพแถบสถานะในฟอร์มเป็นแบบก่อนปรับ [กำลังบันทึก](lDxGE.png) · [บันทึกหมวดแล้ว](X2Zzvc.png)

ใช้ Mitr ตัวอักษรกรมท่า พื้นฟ้าอ่อนสำหรับแถวและตัวเลือกที่เลือก กับปุ่ม **บันทึกหมวด** สีชมพูเข้มตามคู่สีที่เจ้าของรับไว้ ปุ่มสร้างหมวด จัดลำดับ และเพิ่มบ้านใช้เส้นขอบเพื่อให้ปุ่มบันทึกเด่นในจังหวะแก้หมวด [หลักฐานคู่สีปุ่ม](../dsd-001/pink-button-rollout-r1/review-manifest.json)

ชื่อบ้าน รหัส ทำเล และภาพในชุดนี้เป็นข้อมูลตัวอย่างสำหรับตรวจการจัดวาง ตรวจภาพส่งออกที่ขนาดเดสก์ท็อปแล้ว การกด การลาก การใช้แป้นพิมพ์ และการบันทึกจริงยังรอทดสอบในหน้าจอที่ใช้งานได้ [ม็อกอัปมือถือและหน้าที่เหลือ](../admin-category-mockup-r2/README.md) · [สเปครูปทางลัด](../admin-category-management-interaction-spec.md#5-ประเด็นที่ยังต้องกำหนด)
