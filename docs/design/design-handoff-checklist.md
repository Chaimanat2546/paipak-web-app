# Design Handoff Checklists

## Definition of Ready
- Linked approved decisions exist; unresolved matters listed explicitly.
- Prerequisite design artifacts exist and are reviewed.
- Target page/components, variants, states and viewport scopes are specified.
- The current task has a designated reviewer.

## Definition of Done (Design)
- Desktop and mobile designs plus relevant tablet adaptation specified.
- Interaction/empty/error/loading states included when applicable.
- Accessible labels, focus, contrast and reduced-motion considerations annotated.
- Source files and export links identified.
- Approved visual refs recorded with version, owner, approval date and supersession chain.
- Any unresolved CTA contrast remains OPEN and blocks only affected visual signoff.

## Definition of Ready (Implementation)
- Approved specific visual design/version is linked for UI-dependent work.
- Related data/contracts exist when the task needs them.
- Allowed paths, tests and reviewers defined.
