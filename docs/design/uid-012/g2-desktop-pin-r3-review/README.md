แบบนี้ปรับเฉพาะปุ่มในตารางและข้อความกำกับที่เกี่ยวข้อง ตัวอย่างหน้ามือถือและสเปกการจัดลำดับเปิดได้จาก [G2-r2](../g2-list-r2-review/README.md) ขั้นตอนเขียนและเผยแพร่อยู่ใน [G2-r1](../g2-review/README.md)
