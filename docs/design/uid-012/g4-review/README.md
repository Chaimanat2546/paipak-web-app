# UID-012 · แบบ G4-r1 ระบบจัดการบทความที่อนุมัติ

**18 พฤศจิกายน 2026 · ภูอนุมัติ G4-r1 ครบสามเฟรมมือถือและปิดงานออกแบบ** [บันทึกอนุมัติ](owner-G4-r1-acceptance.json)

รอบนี้ใช้ [High-Fi G3-r1 ที่ภูอนุมัติ](../g3-r1-review/owner-G3-r1-acceptance.json) และ [Wireframe G2-r18](../g2-consolidated-r18-review/owner-G2-r18-acceptance.json) เป็นฐาน ตรวจแบบหลังบ้านและผลในส่วนบทความบนหน้าแรกตาม [ขอบเขตที่อนุมัติ](../../../../tasks/design/UID-012.md) สเปกหน้าอ่าน หน้ารวมบทความ และการพัฒนาระบบเป็นงานแยก

- [Pencil](../../dsd-001/papaipak-ui.pen) เปิดชุด UID-012 ที่ `qVhG8` แผง G4-r1 `BrM0R` อยู่ขวาของ High-Fi G3-r1 `YTGEC` ชุดสุดท้ายใช้ [ฐาน G3-r1 ทั้ง 138 คู่](../g3-r1-review/review-manifest.json) โดยใช้เฟรมมือถือ G4-r1 สำหรับ F-29, F-86 และ F-140
- [สเปกการใช้งาน](interaction-spec.md) รวมข้อสรุปที่กระจายอยู่ใน G2, G3 และสเปกหน้าแรก โดยใช้คำสั่งและกติกาล่าสุดของแต่ละเส้นทาง
- ตรวจเรขาคณิตทุกคู่ใน Pencil และดูภาพตัวอย่างตามเส้นทางในตารางด้านล่าง การตรวจขอบเขตเลเยอร์ไม่พบกรอบหรือข้อความล้น parent แต่พบแถบล่างบังปุ่มที่เป็นเลเยอร์ข้างกันเมื่อวัดตำแหน่งและดูภาพ

## ผลแก้และตรวจซ้ำบนมือถือ

## การอ่านและการเข้าถึง

- สีและลำดับสายตาอ้างอิงหลังบ้าน UID-010/011 ใช้ Mitr, Navy `#072D59`, ปุ่มยืนยันหลักชมพูเข้ม และสถานะที่อ่านได้จากข้อความร่วมกับสี ตรวจจากหน้าแรกของรายการ หน้าเขียน แผงหมุด และหน้าลองใหม่ทั้งสองขนาด
- คำนวณจากสีใน Pencil ข้อความขาวบนปุ่มหลัก `#C5375B` ได้ 5.16:1 ปุ่มเพิ่มบทความแบบไล่สีได้ 4.99:1 และ 7.03:1 ที่ปลายทั้งสอง ส่วนปุ่มยกเลิกเผยแพร่ `#B91C1C` ได้ 6.47:1 ป้ายเขียวตัวอย่างได้ 6.36:1 ผลนี้ครอบคลุมคู่สีที่วัดเท่านั้น
- เส้นขอบช่องค้นหาและช่องกรอกตัวอย่างเทียบพื้นขาวได้ 1.60:1 และ 1.40:1 ต้องตรวจในหน้าที่ทำงานจริงว่าขอบเขตช่องและ focus มองเห็นได้ โดยเฉพาะช่องที่พื้นใกล้เคียงกับแผงรอบข้าง
- ยังต้องเทียบขั้นตอนกับหลังบ้านเดิมจากหลักฐานการใช้งานจริง และทดสอบ keyboard, screen reader, zoom/reflow, การเลื่อนใต้แถบล่าง การอัปโหลด การบันทึกและลองใหม่ รวมถึงผลที่คงอยู่เมื่อมีการแก้ไขพร้อมกัน
