# UID-012 · สเปกการใช้งานประกอบแบบ G4-r1

อ้างอิง [ขอบเขตงาน](../../../../tasks/design/UID-012.md), [G2-r18](../g2-consolidated-r18-review/README.md), [High-Fi G3-r1](../g3-r1-review/README.md) และ [กติกาบทความบนหน้าแรก](../../dsd-001/article-content-rules.md) รหัส F ในเอกสารนี้ตรงกับ [รายการเฟรมใน Pencil](../g3-r1-review/review-manifest.json)

## รายการ ค้นหา และตัวกรอง

- เข้า **คอนเทนต์ › บทความ** แล้วเลือกเพิ่มหรือแก้บทความ เดสก์ท็อปแสดงรายการคู่กับแผงปักหมุด ใช้ปุ่มรายแถว มือถือใช้แท็บสลับแผงและเมนูสามจุดของแต่ละเรื่อง ป้ายในรายการแสดงสถานะที่บันทึกแล้ว เปลี่ยนสถานะเผยแพร่จากหน้าแก้ไข (F-01, F-74, F-87, F-129)
- ค้นด้วยชื่อบทความและกรองด้วยสถานะหรือช่วงวันที่เผยแพร่ ช่วงวันที่รวมวันเริ่มและวันสิ้นสุด การยกเลิกการเลือกวันเก็บค่าที่ใช้อยู่ มือถือกลับไปแผงตัวกรองแล้วกดใช้ครั้งเดียว เมื่อใช้ตัวกรองจากหน้าถัดไปให้กลับหน้าหนึ่งของผลกรอง (F-114–115, F-118, F-153–154, F-162)
- ปักหรือถอนหมุดแล้วกลับรายการโดยเก็บคำค้นและตัวกรองเดิม รวมกรณีส่งไม่สำเร็จ หากยกเลิกเผยแพร่แล้วเรื่องออกจากชุดผลกรอง ให้ล้างตัวกรองโดยเก็บคำค้นเพื่อเปิดร่าง (F-73, F-117, F-144, F-146–147) การแบ่งหน้าใช้ปุ่มก่อนหน้า/ถัดไป เลขหน้าและช่วงรายการ โดยปิดปุ่มที่พ้นขอบ (F-01, F-151–152, F-163)

## หน้าเขียนและข้อมูลประกอบ

- กรอกชื่อ เนื้อหา รูปปก และคำโปรยถ้ามี เดสก์ท็อปเปิดสถานะกับข้อมูลประกอบข้างพื้นที่เขียน มือถือเปิด **สถานะและรายละเอียด** จากหน้าเขียน เลือก **ฉบับร่าง**, **เผยแพร่** หรือ **ปิด** ตามสถานะเดิมของเรื่อง ปุ่มหลักเปลี่ยนคำตามตัวเลือกและบริบท (F-21–23, F-111–113, F-119)
- รูปปกใช้สัดส่วน 16:9 รับ JPG, PNG หรือ WebP ไม่เกิน 10 MB มีทางเลือก เปลี่ยน และลบรูป ตรวจข้อกำหนดก่อนใช้รูปและแสดงคำแนะนำข้างตัวเลือก (F-24, F-43, F-95–96) [ข้อกำหนดรูปปก](../../dsd-001/article-cover-spec.md)
- ค้นบ้านพักด้วยชื่อหรือรหัส DV แสดงบ้านที่แนบไว้พร้อมจำนวน และแสดงป้าย **แนบแล้ว** แบบอ่านอย่างเดียวในผลค้นหา เมื่อกด **เสร็จสิ้นการแนบบ้านพัก** ให้กลับไปแก้บทความต่อ การแนบมีผลเมื่อบันทึกบทความสำเร็จ ส่งพลาดแล้วยังลองใหม่โดยใช้ข้อมูลเดิมได้ (F-26, F-92–94, F-158–161)

## บันทึกร่าง เผยแพร่ และยกเลิกเผยแพร่

| คำสั่ง | ก่อนส่งและเมื่อได้ผล |
| --- | --- |
| **บันทึกฉบับร่าง** | เก็บร่างเมื่อกดบันทึก สามารถเก็บงานก่อนเพิ่มรูปปก เมื่อเรื่องมีฉบับเผยแพร่อยู่ หน้าเว็บและลำดับบทความล่าสุดยังใช้ฉบับเผยแพร่เดิม ส่วนหลังบ้านแสดงว่ามีฉบับร่าง (F-23, F-30, F-97–100, F-156–161) |
| **ออกจากหน้าที่แก้ค้าง** | ให้เลือกบันทึกร่างแล้วออก ทิ้งการแก้ไข หรือเขียนต่อ หากบันทึกพลาดให้คงค่าที่แก้ไว้ (F-31, F-59, F-55, F-100) |
| **เผยแพร่ / เผยแพร่การแก้ไข** | ตรวจชื่อ รูปปก และเนื้อหา แจ้งข้อมูลที่ขาดใกล้จุดกรอก แสดงชื่อเรื่องในขั้นยืนยัน ระหว่างส่งใช้ข้อมูลเผยแพร่เดิม หากส่งพลาดให้คงฟอร์มและค่าหมุดที่รอเปลี่ยน หากสำเร็จจึงใช้ฉบับใหม่และเปลี่ยนหมุดที่ขอไว้จากหน้าเขียน (F-28, F-32–35, F-49–52, F-84–86, F-137–141) |
| **ยกเลิกเผยแพร่** | เมื่อเลือก **ปิด** และกดปุ่มหลัก ให้ยืนยันชื่อเรื่อง เมื่อสำเร็จให้นำเรื่องออกจากหน้าแรก เก็บร่างล่าสุดที่บันทึกไว้ หรือเก็บฉบับเผยแพร่เดิมเป็นร่างเมื่อไม่มีร่าง ถอนหมุดถ้ามี และเลื่อนลำดับเรื่องที่เหลือขึ้นตามลำดับเดิม เมื่อส่งพลาด สถานะเผยแพร่และหมุดเดิมยังอยู่ พร้อมทางกลับไปแก้หรือลองอีกครั้ง (F-37, F-56, F-101–102, F-119–127, F-143, F-148–149) |

Toast แสดงระหว่างส่งและเมื่อสำเร็จ Desktop อยู่มุมขวาบน Mobile อยู่ใต้แถบหัว ข้อผิดพลาดที่ต้องแก้หรือลองใหม่อยู่ในฟอร์ม แผง หรือกล่องของคำสั่งเดิม คำสั่งเดียวกันต้องพักการกดซ้ำระหว่างรอผล

## ปักหมุด จัดลำดับ และผลบนหน้าแรก

1. ปักหรือถอนทีละเรื่องจากหน้าจัดการแล้วส่งคำขอทันที เมื่อสำเร็จจึงใช้หมุดใหม่บนหน้าแรก หากพลาดให้แสดงผลเดิมและเปิดให้ลองใหม่ การเปลี่ยนหมุดจากหน้าเขียนรอจนเผยแพร่การแก้ไขสำเร็จ (F-42, F-45–47, F-75–76, F-84–86, F-130–132, F-137–142)
2. แผงเก็บได้สูงสุด 10 หมุด เรื่องลำดับเกินสามรอคิว เมื่อพยายามปักเรื่องที่ 11 ให้แจ้งว่าหมุดเต็มและคงจำนวนเดิม มือถือมีทางเข้าจัดการหมุด (F-10, F-155, F-116)
3. เข้าโหมด **จัดลำดับ** ก่อนย้ายเรื่อง จะลากหรือเลือกเลขปลายทางจากจุดจับก็ได้ ต้องกดบันทึกในโหมดนี้ ระหว่างรอหน้าแรกใช้ลำดับเดิม หากพลาดให้คงลำดับที่แก้เพื่อลองใหม่ การยกเลิกการย้ายกลับไปใช้ลำดับที่บันทึกไว้ (F-15–20, F-48, F-60, F-91)
4. หน้าแรกแสดงเรื่องที่ปักและพร้อมแสดงตามลำดับก่อน จากนั้นเติมจากฉบับเผยแพร่ล่าสุดตามวันที่แก้ไขให้ได้สูงสุดสามเรื่องโดยไม่ซ้ำ เมื่อไม่มีหมุดพร้อม ใช้ล่าสุดทั้งหมดตามกติกาเดียวกัน ข้ามเรื่องที่ถอนหมุดจนกว่าจะปักใหม่สำเร็จ เรื่องที่ยังเผยแพร่อยู่เปิดอ่านได้ตามเดิม (F-108, F-133–135, F-145)
5. เรื่องที่พร้อมแสดงต้องมีปก ชื่อ และลิงก์อ่าน เมื่อคำโปรยว่างใช้ต้นเนื้อหาฉบับเผยแพร่ไม่เกินสองบรรทัด กรณีมีเพียงหนึ่งหรือสองเรื่องใช้ผังตามจำนวนจริง เมื่อไม่มีเรื่องพร้อมหรือโหลดรายการล้มเหลวให้ซ่อนส่วนบทความและบันทึกข้อผิดพลาดภายในเฉพาะกรณีโหลดล้มเหลว ปกที่โหลดพลาดให้ข้ามเฉพาะการแสดงผลครั้งนั้น (F-38–41 และ [สเปกหน้าแรก](../../dsd-001/article-content-rules.md))

## รายการตรวจเมื่อระบบทำงานได้

- ทดสอบชื่อที่โปรแกรมอ่านหน้าจออ่านสำหรับปุ่มไอคอน สถานะเมื่อใช้ตัวกรอง ข้อความผิดพลาด และผลหลังบันทึก ตรวจลำดับ Tab, focus ที่มองเห็นได้, การคืน focus เมื่อปิดเมนูและกล่อง รวมถึงการย้ายตำแหน่งด้วยคีย์บอร์ด
- ทดสอบมือถือหน้าจอแคบและตัวอักษรขยาย ฟอร์มยาว แป้นพิมพ์บนจอ และปุ่มที่อยู่ใกล้แถบคำสั่ง โดยใช้ [ผลตรวจ G4-01](README.md#ผลแก้และตรวจซ้ำบนมือถือ) เป็นกรณีทดสอบ
- ตรวจการเก็บฉบับร่างเดิม การกดซ้ำ การลองใหม่ และผลที่คงอยู่หลังรีเฟรช ยืนยันวิธีจัดการเมื่อการเผยแพร่และการเปลี่ยนหมุดชนกับการแก้ไขของผู้ดูแลอีกคน รวมถึงเกณฑ์เรียงเมื่อวันที่แก้ไขฉบับเผยแพร่เท่ากัน
- เทียบกับขั้นตอนในหลังบ้านเดิมจากหลักฐานที่เข้าถึงได้ และทดสอบไฟล์รูปปกจริงกับการแสดงบนหน้าแรก
