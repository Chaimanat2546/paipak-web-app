# UID-012 · สวิตช์แสดงบทความปักหมุด G2-r7

ปุ่มท้ายแถวในแผงปักหมุดเป็นสวิตช์พร้อมข้อความ **เปิด** หรือ **ปิด** แต่ละเรื่องยังอยู่ในลำดับเดิมและนับในขีดจำกัด 10 เรื่องแม้ปิดการแสดง กด **บันทึกการจัดหน้าแรก** เพื่อใช้ค่าที่แก้บนหน้าแรก

- **เปิด** ให้เรื่องมีสิทธิ์ขึ้นหน้าแรกตามลำดับและความพร้อม สูงสุด 3 เรื่อง ลำดับที่เกินยังรอลำดับ
- **ปิด** พักการแสดงและเก็บหมุดไว้ที่เดิม ในตัวอย่างปิดเรื่องลำดับ 1 เรื่องลำดับ 4 จึงจะได้ขึ้นแทนหลังบันทึกสำเร็จ เมื่อเปิดลำดับ 1 กลับมาและบันทึก เรื่องลำดับ 4 กลับไปรอลำดับ ถ้าเรื่องพร้อมยังไม่ครบสามจึงใช้กติกาเติมเดิม
- ข้อเสนอเดิมสำหรับสวิตช์คือเรื่องที่ปิดจะถูกข้ามทั้งตอนเลือกจากหมุดและตอนเติมอัตโนมัติ ส่วน **ถอนหมุด** คืนช่องปักหมุดและให้เรื่องกลับเป็นตัวเลือกเติมได้ถ้ายังพร้อมแสดง [กติกาที่เสนอใน G2-r2](../g2-list-r2-review/README.md)
- การปรับสวิตช์มีผลบนหน้าแรกเมื่อบันทึกสำเร็จ หากบันทึกล้มเหลวให้คงค่าที่แก้ไว้เพื่อลองอีกครั้ง [สถานะบันทึกล้มเหลวและการจัดลำดับใน G2-r6](../g2-desktop-reference-r6-review/README.md)

ตรวจทั้งสี่เฟรมที่ 1440 × 900 พิกเซล การสลับและบันทึกจริงรอทดสอบในระบบ
