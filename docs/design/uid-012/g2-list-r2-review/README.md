## พฤติกรรมที่เสนอให้ตรวจ

- รายการค้นหาตามชื่อ กรองสถานะและวันที่เผยแพร่ และเปลี่ยนหน้าได้ ปุ่มปักหมุดอยู่ในแถวบทความ ฉบับร่างที่ยังไม่เผยแพร่ปักหมุดไม่ได้ เรื่องที่มีฉบับเผยแพร่พร้อมร่างแก้ไขจะใช้ข้อมูลจากฉบับเผยแพร่ในการจัดหน้าแรก
- ปักหมุดได้สูงสุด **10 เรื่อง** ข้อเสนอสำหรับสวิตช์คือเมื่อปิด เรื่องยังอยู่ในรายการปักหมุดและนับใน 10 เรื่อง แต่จะข้ามเรื่องนั้นทั้งในชุดที่จัดเองและตอนเติมอัตโนมัติ กดถอนหมุดเพื่อคืนตำแหน่ง เรื่องที่ถอนหมุดกลับไปเป็นตัวเลือกเติมอัตโนมัติได้เมื่อยังพร้อมแสดง
- หน้าแรกแสดงสูงสุด **3 เรื่อง** ตามลำดับหมุดที่เปิดและพร้อมแสดง เรื่องแรกเป็นเรื่องเด่น หากมีเรื่องปักหมุดที่ใช้ได้ไม่ครบ ให้เติมบทความพร้อมแสดงตามวันที่แก้ไขของฉบับเผยแพร่ล่าสุดโดยไม่ซ้ำ สถานะ **ขึ้นหน้าแรก** และ **รอลำดับ** ในแผงสะท้อนผลจากชุดที่กำลังจัด
- ใช้จุดจับลากเพื่อจัดลำดับ หรือใช้ปุ่มขึ้นลงจากแถวที่กำลังจัด คงโฟกัสกับเรื่องเดิมหลังย้ายและประกาศตำแหน่งใหม่ ตัวอย่างขีดจำกัดมีทางเปิดตำแหน่ง 4–10 เพื่อให้เห็นและจัดเรื่องที่รอลำดับได้
- ปักหมุด ถอนหมุด เปิดหรือปิด และเปลี่ยนลำดับในชุดที่กำลังแก้ได้ก่อนกด **บันทึกลำดับ** การสลับแท็บคงค่าที่แก้ไว้ ดูตัวอย่างได้ก่อนบันทึก ถ้าบันทึกไม่สำเร็จให้คงค่าที่แก้และใช้ชุดเดิมบนหน้าแรก

ภูยืนยันขีดจำกัดทั้งสองด้วยข้อความ “ปักหมุดได้ 10 เรื่อง และแสดงหน้าแรกสูงสุด 3 เรื่อง” ตัวกรองหมวดหมู่ จำนวนบ้านพักที่แนบ และคำสั่งหลายรายการในภาพอ้างอิงยังรอการกำหนดขอบเขต ชุดนี้ใช้ข้อมูลจำลองและตรวจที่ระดับไวร์เฟรม

ชุดนี้ใช้แทนเส้นทางหน้ารายการและหน้าจัดบทความแยกใน G2-r1 ภาพหน้าเขียน การเผยแพร่ และผลหน้าแรก 0–3 เรื่องดูได้ใน [ชุด G2-r1](../g2-review/README.md)
