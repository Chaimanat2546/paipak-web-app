## กติกาที่ใช้ตรวจ

- เมื่อเลือก **ปิด** ในหน้าแก้ไข ปุ่มหลักเปลี่ยนเป็น **ยกเลิกเผยแพร่** การกดปุ่มเปิดกล่องยืนยันของบทความเดิม เมื่อสำเร็จระบบเก็บร่างล่าสุดหรือใช้ฉบับเผยแพร่เดิมเป็นร่าง และถอนหมุดถ้าปักอยู่ เมื่อพลาดสามารถลองใหม่หรือกลับไปแก้ไขได้ [F-119 Desktop](gZ1uF.png) · [F-119 Mobile](zkZeJ.png) · [กำลังดำเนินการ Mobile](xz2dZ.png) · [ลองใหม่ Mobile](NBjab.png)

- Desktop วางแก้ไข ปักหรือถอนหมุด และยกเลิกเผยแพร่ตรงท้ายแถว บทความฉบับร่างมีปุ่มแก้ไขปุ่มเดียว Mobile ใช้เมนูรายบทความ หน้ารายการเป็นอีกทางเข้าไปยกเลิกเผยแพร่
- ผลค้นบ้านแสดงบ้านที่แนบแล้วพร้อมป้าย «แนบแล้ว» แบบกดไม่ได้ รายการบ้านที่แนบแสดงรายชื่อและจำนวนในหน้าค้นหา

- ใช้ Toast หลังบ้านรูปแบบเดียวกับ UID-010/011 เป็นข้อความกำลังบันทึกเพียงจุดเดียว แม้กล่องยืนยันยังเปิดอยู่ ปุ่มคงข้อความเดิมและพักการกดซ้ำ หลังบันทึกสำเร็จใช้ Toast ยืนยันผล Desktop แสดงมุมขวาบน Mobile แสดงใต้แถบหัว [กำลังยกเลิกเผยแพร่ Desktop](o9bq94.png) · [Mobile](XhQ8o.png) · [ยกเลิกเผยแพร่แล้ว Desktop](fZJLU.png) · [Mobile](F0tbeH.png)
- เมื่อหมุดครบ 10 เรื่องให้ตัวนับแสดง 10/10 และแสดง Toast เตือนเมื่อกดปักเรื่องที่ 11และคงทางไปจัดการหมุดบน Mobile ข้อผิดพลาดที่ต้องลองใหม่ยังมีข้อความและปุ่มอยู่ในแผง ฟอร์ม หรือกล่องยืนยันของคำสั่งเดิม [หมุดเต็ม Mobile](SZGm7.png) · [ลองถอนหมุดใหม่ Mobile](MADzA.png)

- ภูเลือกปักและถอนหมุดทีละเรื่องทั้งจากหน้าจัดการบทความและหน้าเขียน หน้าจัดการส่งคำขอทันทีเมื่อปัก ถอน หรือเปิด–ปิดสวิตช์ หน้าแรกเปลี่ยนเมื่อบันทึกสำเร็จ การเปลี่ยนหมุดจากหน้าเขียนมีผลเมื่อเผยแพร่การแก้ไขสำเร็จ
- ภูเลือกถอดตัวกรองหมวดหมู่บทความ หน้ารายการทั้งสองขนาดค้นหาด้วยชื่อและกรองด้วยสถานะหรือวันที่เผยแพร่ได้
- ตัวกรองวันที่ใช้วันเริ่มและวันสิ้นสุดรวมขอบทั้งสองวัน การล้างช่วงวันที่เก็บคำค้นและสถานะ การยกเลิกในปฏิทินเก็บช่วงที่ใช้ก่อนหน้า
- เลือก **ฉบับร่าง / เผยแพร่** จากตัวเลือกในส่วนสถานะบทความ เรื่องที่เผยแพร่อยู่มีตัวเลือก **ปิด** เหนือสวิตช์ **ปักหมุดบนหน้าแรก** ตามภาพอ้างอิงล่าสุด Desktop ใช้แผงข้างหน้าเขียน Mobile เข้า **สถานะและรายละเอียด** แล้วเลือกและบันทึกในหน้านั้นได้ ปุ่มหลักปุ่มเดียวเปลี่ยนเป็น **บันทึกฉบับร่าง**, **เผยแพร่**, **เผยแพร่การแก้ไข** หรือ **ยกเลิกเผยแพร่** ตามที่เลือก
- การเลือกสถานะมีผลเมื่อกดปุ่มหลักและดำเนินการสำเร็จ การแตะสวิตช์หมุดคงตัวเลือกสถานะไว้ บทความที่เผยแพร่อยู่ยังแสดงสถานะที่บันทึกไว้ใต้สวิตช์
- ตัวอย่างเผยแพร่ครั้งแรก F-99 → F-112 → F-32 → F-49–51 ใช้บทความ **ทริปชลบุรีสำหรับวันหยุด** โดยเพิ่มรูปปกก่อนเผยแพร่ หมุดเดิมทั้ง 4 เรื่องยังอยู่ และบทความใหม่ยังไม่ได้ปักหมุด [F-51 Desktop](F5Wi2.png) · [F-51 Mobile](lxuAs.png)
- ฉบับร่างบันทึกเมื่อกดปุ่มเท่านั้น เมื่อจะออกจากหน้าเขียนโดยมีการแก้ไขที่ยังไม่ได้บันทึก F-31 ให้เลือก **บันทึกฉบับร่างแล้วออก**, **ทิ้งการแก้ไข** หรือกลับไปเขียนต่อ ถ้าบันทึกพลาดให้คงการแก้ไขไว้เพื่อลองใหม่
- ภูเลือกให้เขียนบทความในฟอร์มหลักทั้งสองขนาด และพักฟังก์ชันดูตัวอย่างบทความไว้ ปุ่มและเฟรมดูตัวอย่างถูกถอดออกจากชุดนี้
- หน้าค้นบ้านบน Desktop ใช้พื้นที่ทำงานเต็มความกว้าง ฝั่งซ้ายค้นด้วยชื่อหรือรหัส DV และเลือกแนบจากผลค้น ฝั่งขวาแสดงบ้านที่อยู่ในบทความและปุ่ม **เสร็จสิ้นการแนบบ้านพัก** เมื่อค้นไม่พบยังเห็นบ้านที่แนบอยู่

- เมนูของ **พักพูลวิลล่าอย่างไรให้คุ้มค่า** เปิดแก้ไข จัดการหมุด หรือยกเลิกเผยแพร่ของเรื่องเดียวกัน การยกเลิกสำเร็จคืนเรื่องเป็นร่างและคงหมุดของเรื่องอื่น
- คำสั่งจาก F-87/F-88 ใช้บทความที่เลือกจากแถวเป็นเป้าหมาย กล่องยืนยันยกเลิกเผยแพร่ใช้ชื่อเรื่องนั้น หากเรื่องที่เลือกไม่มีร่าง ให้ใช้ฉบับเผยแพร่เดิมเป็นร่าง และถอนหมุดเมื่อสำเร็จตามกติกาที่ภูยืนยัน F-70–72 ใช้ขั้นตอนยืนยัน กำลังดำเนินการ และลองใหม่จากหน้ารายการของบทความที่เลือก F-73 แสดงผลเมื่อมีตัวกรอง F-37/F-101 แสดงผลและเปิดร่างของเรื่องที่ปักหมุดและมีร่าง ส่วน F-56/F-102 แสดงกรณีปักหมุดและไม่มีร่าง
- ระหว่างส่งคำขอ แบบแสดงค่าที่กำลังบันทึกและพักปุ่มจัดลำดับ เมื่อปักหรือถอนพลาดให้คืนจำนวนเดิม 4 หมุด เมื่อปิดหรือเปิดพลาดให้คืนสวิตช์เดิม ปุ่ม **ลองอีกครั้ง** ส่งคำสั่งเดิม ในโหมดจัดลำดับให้พักคำสั่งที่แก้หมุดจากแถวและสวิตช์จนกว่าจะบันทึกหรือยกเลิก หากบันทึกลำดับพลาดให้ลองใหม่หรือยกเลิกได้
- หน้าเขียนแสดงหมุดที่รอถอนจนเผยแพร่สำเร็จ การเผยแพร่พลาดเก็บค่าที่แก้ไว้ หน้าเว็บยังใช้ฉบับและหมุดที่บันทึกไว้ ผู้ใช้เลือกบันทึกร่างก่อนกรอกครบได้ การยกเลิกเผยแพร่เก็บร่างล่าสุดหรือใช้ฉบับเผยแพร่เดิมหากไม่มีร่าง [กติกาที่ภูยืนยัน](../g2-consolidated-r16-review/owner-publication-rules.json)
- หน้าแรกแสดงเรื่องพร้อมสูงสุด 3 เรื่อง การเติมบทความล่าสุดและกรณีไม่มีหมุดที่พร้อมใช้ [แบบและกติกา Homepage](../../dsd-001/article-content-rules.md) เมื่อถอนหมุดสำเร็จ ให้ข้ามเรื่องนั้นตอนเติมจากฉบับเผยแพร่ล่าสุดจนกว่าจะปักหมุดใหม่สำเร็จตาม F-108 เมื่อบันทึกปิดสวิตช์ ให้เก็บหมุดและลำดับเดิมไว้ ข้ามเรื่องนั้นทั้งตอนเลือกจากหมุดและตอนเติมจากฉบับล่าสุดจนกว่าจะเปิดและบันทึกสำเร็จตาม F-109 บทความที่ยังเผยแพร่เปิดอ่านได้ตามเดิม
