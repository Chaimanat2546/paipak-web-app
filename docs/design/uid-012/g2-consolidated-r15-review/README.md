## เส้นทางหลัก

- **รายการบทความ** เดสก์ท็อปเห็นรายการและแผงปักหมุดคู่กัน มือถือใช้แท็บสลับ ค้นจากชื่อ กรอง และจัดการรายเรื่องหรือเลือกหลายเรื่องตามแบบ ปักหมุดได้สูงสุด 10 เรื่อง
- **จัดการหมุด** ปักหรือถอนหมุดจากรายการและเปิด–ปิดการแสดงจากแผง เมื่อมีการแก้ไขให้บันทึกจากแผงโดยตรง จุดจับปรากฏหลังเข้าจัดลำดับ ลากหรือเลือกเลขปลายทางได้ รายการยาวเลื่อนในแผงเดิม กด **บันทึกลำดับ** ในโหมดจัดลำดับ บันทึกสำเร็จจึงกลับมุมมองปกติ หากบันทึกพลาดให้คงการแก้ไขไว้
- **หน้าเขียน** เรียงชื่อ → รูปปก → เนื้อหา ข้างรูปปกระบุ 16:9, JPG/PNG/WebP และไม่เกิน 10 MB หน้าเขียนมีแท็ก แนบบ้านพัก และดูตัวอย่างฉบับร่างเต็มจอ การบันทึกร่างของเรื่องที่เผยแพร่แล้วคงฉบับเดิมบนเว็บจนเผยแพร่การแก้ไขสำเร็จ
- **หน้าแรก** แสดงเรื่องปักหมุดที่เปิดและพร้อมก่อนตามลำดับ สูงสุด 3 เรื่อง เติมจากฉบับเผยแพร่ที่แก้ไขล่าสุดโดยไม่ซ้ำเมื่อมีช่องว่าง แสดงตามจำนวนจริงหรือยุบส่วนเมื่อไม่มีเรื่องพร้อมแสดง [กติกาบทความบนหน้าแรก](../../dsd-001/article-content-rules.md)

## สิ่งที่ต้องตรวจต่อ

- คำสั่งแบบกลุ่มและเมนูรายเรื่อง แหล่งข้อมูลหมวดหมู่ และกติกาแนบบ้านพักเป็นข้อเสนอสำหรับตรวจในชุดนี้
- จังหวะบันทึกร่างอัตโนมัติ การเก็บฉบับหลังยกเลิกเผยแพร่ การได้ลิงก์อ่านจริง และวิธีตรวจไฟล์ต้องสรุปก่อนพัฒนา ตัวอย่างสวิตช์ปักหมุดในหน้าเขียนยังใช้ข้อเสนอจาก [G2-r13](../g2-editor-reference-r13-review/README.md)
- ผลปิดการแสดงเป็นพฤติกรรมที่เสนอไว้ใน [G2-r7](../g2-desktop-pin-switch-r7-review/README.md) การลาก การคืนโฟกัส การอัปโหลด และการบันทึกจริงต้องทดสอบในระบบที่ใช้งานได้

ตรวจการจัดวางใน Pencil และภาพส่งออกตามขนาดทั้งสอง ชุดตรวจนี้ใช้ข้อมูลจำลองและรออนุมัติ G2
