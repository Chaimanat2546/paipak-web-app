# UID-012 · เข้าโหมดจัดลำดับ G2-r8

**สถานะ** รอตรวจไวร์เฟรม · 13 พฤศจิกายน 2026 (เวลาไทย)  
**ต้นฉบับ** [Pencil](../../dsd-001/papaipak-ui.pen) · section `dziD6` · [รายการเฟรม](review-manifest.json)

ใช้ [G2-r9](../g2-desktop-order-save-r9-review/README.md) สำหรับขั้นบันทึกลำดับในโหมดตามที่ภูยืนยันล่าสุด ชุด G2-r8 เก็บเป็นหลักฐานก่อนแก้

1. ในมุมมองปกติ สวิตช์เปิด–ปิดใช้ได้ และกด **จัดลำดับ** ที่หัวแผงปักหมุดเพื่อเริ่มย้ายบทความ
2. เมื่อเข้าโหมด จุดจับจะปรากฏ ให้ลากหรือกดจุดจับเพื่อเลือกเลขปลายทาง รายการยาวยังเลื่อนในแผงเดิม
3. กด **เสร็จสิ้น** เพื่อกลับมุมมองปกติพร้อมเก็บลำดับที่แก้ไว้ หน้าแรกจะใช้ลำดับใหม่เมื่อ **บันทึกการจัดหน้าแรก** สำเร็จ
