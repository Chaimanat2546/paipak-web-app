## พฤติกรรมสำหรับตรวจ

- **ตัวแก้ไขเนื้อหา** แสดงหัวข้อ ตัวหนา เอียง ขีดเส้นใต้ รายการ ลิงก์ รูป วิดีโอ ข้อความอ้างอิง โค้ด และขยายตัวแก้ไข มือถือเก็บเครื่องมือรองไว้ในเมนูเพิ่มเติม รูปปกหน้าแรก 16:9 และคำโปรยยังมีช่องแยกจากรูปที่แทรกในเนื้อหา
- **ฉบับร่างและเผยแพร่** แถบคำสั่งมี **ดูตัวอย่างแบบเต็มหน้าจอ**, **บันทึกฉบับร่าง** และ **เผยแพร่** หรือ **เผยแพร่การแก้ไข** ตามสถานะ การดูตัวอย่างใช้ค่าที่กำลังแก้ เว็บไซต์ยังใช้ฉบับเดิมจนเผยแพร่การแก้ไขสำเร็จ ถ้าเผยแพร่ไม่สำเร็จให้คงค่าที่แก้ไว้
- **ปักหมุดบนหน้าแรก** แบบเสนอให้เปิดใช้เมื่อบทความมีฉบับเผยแพร่ที่พร้อมแสดง และให้การเปลี่ยนในหน้าเขียนมีผลเมื่อเผยแพร่ฉบับที่แก้สำเร็จ ใช้กติกาเดิมที่ปักได้ 10 เรื่องและขึ้นหน้าแรกสูงสุด 3 เรื่อง แผงปักหมุดและการบันทึกโดยตรงอ้างอิง [G2-r12](../g2-pin-direct-save-r12-review/README.md)
- **แท็กและแนบบ้านพัก** พิมพ์แท็กแล้วกด Enter เอาแท็กออกได้จากป้าย กด **เพิ่มบ้านพัก** เพื่อค้นจากชื่อหรือรหัส DV และเลือกแนบหลายหลัง เรื่องที่แนบแล้วมีสถานะกำกับและเอาออกจากฉบับที่กำลังแก้ได้ เดสก์ท็อปมีตัวอย่างขยายจากสามรายการเป็นแปดรายการ มือถือเปิดรายละเอียดจากหน้าเขียนและมีทางเข้าแนบบ้านพักจากหน้านั้น

ข้อความบันทึกฉบับร่างอัตโนมัติ เวลา แท็ก รูป และรายชื่อบ้านพักเป็นตัวอย่างในไวร์เฟรม จังหวะบันทึกอัตโนมัติ การตั้งค่าตัวแก้ไข และสัญญาการจัดเก็บข้อมูลยังต้องสรุปก่อนพัฒนา สถานะตรวจข้อมูลไม่ครบ บันทึกร่างไม่สำเร็จ และยกเลิกเผยแพร่ดูได้จาก [ชุด G2-r1](../g2-review/README.md)
