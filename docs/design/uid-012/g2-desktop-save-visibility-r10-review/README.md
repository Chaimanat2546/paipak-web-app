การย้ายบทความใช้ **บันทึกลำดับ** ในโหมดจัดลำดับตาม [G2-r9](../g2-desktop-order-save-r9-review/README.md) เมื่อบันทึกสำเร็จ หน้ากลับมุมมองปกติและแสดง **ดูตัวอย่าง** ใต้รายการ
