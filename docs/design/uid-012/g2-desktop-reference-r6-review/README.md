## องค์ประกอบและพฤติกรรม

- **รายการบทความ** มีปุ่มเพิ่มบทความ ค้นหาชื่อ กรองสถานะ หมวดหมู่ และวันที่เผยแพร่ และแบ่งหน้า แต่ละแถวมีช่องเลือก รูปปก ชื่อ สถานะ วันที่และเวลาเผยแพร่ จำนวนบ้านพักที่แนบ ปุ่มปักหรือถอนหมุด ปุ่มแก้ไข และเมนูสามจุด
- **เลือกหลายรายการ** ตัวอย่างมีสถานะเลือกบางแถว ล้างการเลือก และแสดงจำนวนเรื่องที่ปักเพิ่มได้ แถวที่ปักอยู่แล้วไม่นับเป็นหมุดใหม่ เรื่องที่ยังไม่เผยแพร่และกรณีครบ 10 เรื่องใช้เงื่อนไขเดียวกับการปักจากแถว
- **แผงปักหมุด** แสดงจำนวนที่ปักจาก 10 เรื่อง มีรูปปก ชื่อ ลำดับ สวิตช์ และคำอธิบายสั้น เลื่อนเฉพาะรายการในแผง ลากจากจุดจับหรือเปิดตัวเลือกเลขปลายทาง กดดูตัวอย่างได้และใช้ชุดใหม่เมื่อบันทึกสำเร็จ หน้าแรกแสดงสูงสุด 3 เรื่องตามกติกาเดิม
- **เมนูหลังบ้าน** แสดงทางเข้าคอนเทนต์และบทความ บัญชีผู้ดูแล กระดิ่ง และทางไปดูเว็บไซต์เป็นส่วนประกอบของหน้าหลังบ้าน

ตัวเลือกคำสั่งกลุ่มและรายการในเมนูสามจุดเป็นข้อเสนอสำหรับตรวจแบบ ข้อมูลหมวดหมู่ จำนวนบ้านพัก และวันเวลาเป็นตัวอย่าง การกำหนดแหล่งข้อมูลหมวดหมู่และวิธีแนบบ้านพักในหน้าเขียนยังรอสรุป การเลื่อน การลาก การเลือก และการบันทึกจริงต้องตรวจเมื่อพัฒนา
