## การเลื่อนและจัดลำดับตามแบบเดิม

- ใช้จุดจับลากหรือปุ่ม **ขึ้น / ลง** ในแถวที่กำลังจัด ปุ่มที่เลื่อนเกินขอบรายการปิดใช้งาน หลังย้ายให้โฟกัสอยู่กับบทความเดิมและแจ้งตำแหน่งใหม่ [เปรียบเทียบแบบเดิม G2-r2](../g2-list-r2-review/oJpA1.png)
- เมื่อรายการเต็ม ใช้ **ดูตำแหน่ง 4–10** เพื่อจัดเรื่องลำดับถัดไป แล้วใช้ **กลับไปตำแหน่ง 1–3** ได้ การกลับจากหน้าดูตัวอย่างให้เก็บลำดับที่กำลังแก้ไว้ และหน้าแรกใช้ชุดใหม่เมื่อกด **บันทึกลำดับ** สำเร็จ [ตำแหน่ง 4–10](../g2-list-r2-review/MXZG9.png) · [ดูตัวอย่างก่อนบันทึก](../g2-list-r2-review/qWZK9.png)

ตรวจองค์ประกอบแผงปักหมุดใน Pencil เทียบกับ G2-r2 ครบทั้งสี่เฟรมเดสก์ท็อป การลากและการกดจริงจะตรวจบนระบบที่ใช้งานได้

ตรวจทั้งสี่เฟรมว่ามีตัวเลขครบทั้งสองส่วนและไม่มีแถบแท็บบนเดสก์ท็อป ตัวเลขเป็นข้อมูลจำลองตามแบบ ขีดจำกัดหลังบ้าน 10 เรื่อง และหน้าแรก 3 เรื่องตามที่ภูยืนยัน
