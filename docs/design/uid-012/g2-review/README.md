## สเปกขั้นตอนใช้งาน

### รายการ เขียน และดูตัวอย่าง

- แอดมินเข้าที่ **คอนเทนต์ → บทความ** ค้นจากชื่อหรือกรองสถานะได้ รายการระบุชื่อ ปก สถานะการเผยแพร่ และบทบาทบนหน้าแรก ได้แก่ คัดไว้ เติมอัตโนมัติ หรือยังไม่แสดง ถ้าค้นไม่พบ ให้คงคำค้นและมีทางล้างตัวกรอง ถ้าคลังว่าง ให้เริ่มที่ **สร้างบทความ** ตาม WF-02
- หน้าเขียนเดสก์ท็อปให้พื้นที่หลักกับชื่อและเนื้อหา วางรูปปกและคำโปรยด้านข้าง มือถือเรียงชื่อ เนื้อหา รูปปก และคำโปรยลงมา แล้ววางคำสั่งบันทึกและเผยแพร่ในแถบล่าง เมื่อเนื้อหายาว ให้พื้นที่ฟอร์มเลื่อนถึงช่องท้ายได้โดยแถบปุ่มไม่บังโฟกัส
- **ดูตัวอย่างฉบับร่าง** ใช้ค่าที่กำลังแก้ในฟอร์ม มีป้ายว่าเป็นตัวอย่างสำหรับแอดมิน เมื่อกลับมาให้คงค่าที่กรอกไว้ ปกหน้าแรกใช้สัดส่วนไฟล์ 16:9 และรักษาภาพเต็มตาม [กติกาปก](../../dsd-001/article-cover-spec.md)
- ข้อเสนอ G2 คือให้เก็บร่างที่ยังกรอกไม่ครบได้ ตรวจชื่อและเนื้อหาก่อนเผยแพร่ และแสดงข้อผิดพลาดตรงช่องที่แก้ รูปปกและลิงก์อ่านที่ใช้ได้เป็นเงื่อนไขของการขึ้นหน้าแรก ข้อกำหนดไฟล์และวิธีได้ลิงก์อ่านจริงยังรอสเปก
- ถ้าออกจากหน้าเขียนระหว่างที่มีค่าที่ยังไม่ได้บันทึก ให้เลือก **แก้ต่อ**, **ทิ้งการแก้ไข** หรือ **บันทึกฉบับร่างแล้วออก** การทิ้งมีผลเฉพาะค่าที่แก้ตั้งแต่บันทึกสำเร็จครั้งล่าสุด ถ้าบันทึกไม่สำเร็จให้คงฟอร์มและค่าที่กรอก

### เผยแพร่และยกเลิกเผยแพร่

- **บันทึกฉบับร่าง** เก็บงานในหลังบ้าน หน้าเว็บและลำดับบทความล่าสุดบนหน้าแรกยังอิงฉบับเผยแพร่เดิม **เผยแพร่** ครั้งแรกและ **เผยแพร่การแก้ไข** มีขั้นยืนยันเพื่อบอกผลต่อหน้าเว็บ เมื่อสำเร็จจึงอัปเดตสถานะและใช้ฉบับใหม่
- ระหว่างส่งคำสั่ง แสดงสถานะกำลังทำรายการและป้องกันการกดซ้ำ หากบันทึกหรือเผยแพร่ไม่สำเร็จให้คงฟอร์มและค่าที่กรอก คำสั่งเผยแพร่ที่ล้มเหลวไม่สลับฉบับบนเว็บ หากยกเลิกเผยแพร่ไม่สำเร็จให้คงสถานะเดิมและเปิดให้ลองอีกครั้ง
- **ยกเลิกเผยแพร่** มีขั้นยืนยัน เมื่อสำเร็จให้นำเรื่องออกจากชุดพร้อมแสดงและคำนวณผลบนหน้าแรกใหม่ การจัดการเนื้อหาที่เก็บอยู่หลังยกเลิกเผยแพร่ยังต้องสรุปก่อนออกแบบละเอียด

### คัดเรื่องขึ้นหน้าแรก

- เลือกจากฉบับเผยแพร่ที่พร้อมแสดง ป้องกันการเลือกเรื่องเดิมซ้ำ ปุ่ม **ขึ้น** และ **ลง** ใช้ได้ด้วยคีย์บอร์ดหรือการแตะ และปิดตามขอบรายการ หลังย้ายให้โฟกัสยังอยู่กับเรื่องเดิมและประกาศตำแหน่งใหม่ การ **นำออก** จากชุดคัดจะยังปล่อยให้เรื่องนั้นมีสิทธิ์ถูกเติมอัตโนมัติถ้ายังพร้อมแสดง
- **ดูตัวอย่างหน้าแรก** ใช้ลำดับที่กำลังจัด แยกเรื่องที่คัดเองจากเรื่องที่ระบบเติม และใช้ชื่อ ปก และข้อความจากฉบับที่เผยแพร่ เมื่อกดบันทึกสำเร็จจึงใช้การคัดและลำดับใหม่ ถ้าบันทึกไม่สำเร็จให้เก็บลำดับที่แก้ไว้และคงผลเดิมบนหน้าแรก
- กติกาผู้ชมคือคงลำดับเรื่องคัดที่พร้อมแสดงก่อนแล้วเติมเรื่องที่พร้อมจากวันแก้ไขล่าสุดของฉบับเผยแพร่ให้ครบสูงสุดสามเรื่องโดยไม่ซ้ำ เมื่อรูปปกโหลดล้มเหลว ให้ข้ามเรื่องนั้นในการแสดงครั้งนั้น หากไม่มีเรื่องพร้อมแสดงให้ยุบทั้งส่วน ถ้าโหลดรายการล้มเหลวให้ยุบเช่นกันและบันทึกปัญหาภายใน ผลลัพธ์ที่โหลดสำเร็จแต่ไม่มีเรื่องไม่นับเป็นข้อผิดพลาด ระหว่างรอใช้ Skeleton เดิมตาม [กติกาหน้าแรก](../../dsd-001/article-content-rules.md)
- ถ้าไม่มีคำโปรย ให้ใช้ช่วงต้นของเนื้อหาเรื่องนั้นสูงสุดสองบรรทัดบนหน้าแรก ลิงก์อ่านและบทความทั้งหมดในภาพเป็นจุดอ้างอิงของ Home และใช้ข้อมูลจำลองสำหรับตรวจแบบ
