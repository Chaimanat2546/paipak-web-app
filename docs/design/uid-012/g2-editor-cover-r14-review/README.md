- **รูปปก** แสดงตัวอย่างพร้อม **เปลี่ยนรูป** และปุ่มลบ เมื่อยังไม่มีรูปหรือเพิ่งลบ ให้แสดง **เลือกรูปปก** การนำรูปออกมีผลกับฉบับที่กำลังแก้ ส่วนหน้าเว็บยังใช้ฉบับเผยแพร่เดิมจนเผยแพร่การแก้ไขสำเร็จ
- **ข้อกำหนดรูปปกที่ภูยืนยัน** ใช้สัดส่วน **16:9** รับไฟล์ **JPG, PNG หรือ WebP** ขนาด **ไม่เกิน 10 MB** ข้อความอยู่ข้างรูปปกและช่องว่างเมื่อยังไม่มีรูป ทั้งบนเดสก์ท็อปและมือถือ [กติกาปก](../../dsd-001/article-cover-spec.md)
- **ตัวแก้ไข** เพิ่ม **เลิกทำ / ทำซ้ำ** ในแถบเครื่องมือ คงคำโปรยและทางเข้า **ดูตัวอย่างแบบเต็มหน้าจอ** ในหน้าเขียน
