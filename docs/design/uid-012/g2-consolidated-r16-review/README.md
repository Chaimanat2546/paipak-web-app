## กติกาการเผยแพร่ที่ภูยืนยัน

- ทั้งการเผยแพร่ครั้งแรกและเผยแพร่การแก้ไขต้องมีชื่อ รูปปก และเนื้อหา รูปปกใช้ 16:9 ไฟล์ JPG, PNG หรือ WebP ขนาดไม่เกิน 10 MB บันทึกฉบับร่างได้ก่อนกรอกข้อมูลครบ
- เว็บแสดงฉบับเผยแพร่เดิมต่อไปจนเผยแพร่การแก้ไขสำเร็จ เวลาและลำดับล่าสุดบนหน้าแรกอ้างอิงฉบับเผยแพร่
- ยกเลิกเผยแพร่สำเร็จแล้วให้เก็บฉบับร่างล่าสุดที่บันทึกไว้ หากยังไม่มีให้ใช้ฉบับเผยแพร่เดิม ถอนหมุดพร้อมเลื่อนลำดับที่ตามขึ้น และคำนวณชุดหน้าแรกจากค่าที่บันทึกแล้วอีกครั้ง หากทำรายการล้มเหลว ให้คงฉบับที่แสดง ร่าง และหมุดไว้เพื่อลองใหม่ [คำยืนยันของภู](owner-publication-rules.json)

## พฤติกรรมที่ใช้ในชุดตรวจ

- เดสก์ท็อปเห็นแผงรายการและแผงปักหมุดคู่กัน มือถือใช้แท็บสลับ เมื่อปักหรือถอนจากรายการ มือถือเปิดแท็บปักหมุดพร้อมข้อความบอกตำแหน่งบันทึก การปัก ถอน และเปิด–ปิดมีผลเมื่อบันทึกจากแผงสำเร็จ
- ข้อเสนอใน r16 ให้บันทึกค่าหมุดหรือสวิตช์ที่ค้างก่อนกดจัดลำดับ และพักการแก้หมุดหรือสวิตช์ระหว่างจัดลำดับ เข้าโหมดแล้วกลับได้ทันทีถ้ายังไม่ย้าย หากย้ายแล้วให้บันทึกในโหมดหรือยืนยันยกเลิกการย้าย เมื่อบันทึกพลาดให้คงลำดับที่แก้ไว้ การกดจุดจับเปิดตัวเลือกตำแหน่งด้วยคีย์บอร์ดได้ ปิดตัวเลือกแล้วคืนโฟกัสที่จุดจับ และแจ้งตำแหน่งใหม่เมื่อย้าย
- หน้าแนบบ้านและภาพตัวอย่างกลับไปฉบับที่กำลังเขียนพร้อมข้อมูลเดิม ขยายรายการบ้านพักได้และเลือกบ้านที่แนบแล้วซ้ำไม่ได้ เมนูรายการเปิดตัวอย่างของฉบับร่างที่บันทึกไว้เมื่อเรื่องนั้นมีร่าง หน้าเขียนเปิดตัวอย่างจากค่าที่กำลังแก้ได้โดยตรง
- หน้าแรกแสดงหมุดที่เปิดและพร้อมก่อนตามลำดับ สูงสุด 3 เรื่อง แล้วเติมจากฉบับเผยแพร่ที่แก้ไขล่าสุดโดยไม่ซ้ำ เรื่องที่ขาดชื่อ ปก หรือลิงก์ หรือปกโหลดล้มเหลวจะถูกข้าม หากไม่มีคำโปรยใช้ต้นเนื้อหาของฉบับเผยแพร่ไม่เกินสองบรรทัด [ตัวอย่างข้อมูล F-61](dew7P.png) · [กติกาหน้าแรก](../../dsd-001/article-content-rules.md)
- ระหว่างโหลดให้คงหัวข้อและลิงก์ของส่วนบทความ ใช้โครงโหลดในตำแหน่งเดียวกับการ์ดและให้ส่วนอื่นใช้งานได้ เมื่อไม่มีเรื่องพร้อมหรือโหลดรายการล้มเหลว ใช้ผัง F-41 เหมือนกัน เก็บบันทึกภายในเฉพาะกรณีโหลดล้มเหลว
