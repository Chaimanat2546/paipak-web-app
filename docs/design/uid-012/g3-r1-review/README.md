## สิ่งที่ปรับใน G3

- ตารางบทความแบ่งหน้าด้วยปุ่มก่อนหน้าและถัดไป พร้อมเลขหน้าและช่วงรายการ ตัวอย่างแสดง 6 เรื่องต่อหน้าบน Desktop และ 4 เรื่องต่อหน้าบน Mobile
- ใช้ Mitr โลโก้กรมท่าและโครงสีจากหลังบ้าน UID-010/011 ปุ่มหลักใช้ชมพูเข้ม คำสั่งยกเลิกเผยแพร่ใช้แดง และป้ายสถานะใช้ทั้งข้อความและสี
- ปรับหน้ารายการและสถานะที่ใช้โครงเดียวกัน 53 คู่ตามภาพอ้างอิงของภู ใช้พื้นฟ้าไล่เฉด การ์ดขาวเงาเบา รูปปกใหญ่ขึ้น และเน้นสถานะด้วยไอคอนกับข้อความ Desktop ใช้ปุ่มรายแถวเดิม ส่วน Mobile ใช้เมนูสามจุด
- ใช้ภาพปกตามชื่อบทความในรายการ แผงปักหมุด และผลบนหน้าแรก รูปบ้าน DV-162 ตรงกันในหน้าค้นหาและผลแนบสำเร็จทั้งสองขนาด
- Toast บน Desktop ซ้อนทับบริเวณกระดิ่งและเมนูผู้ดูแลที่มุมขวาบนตามแบบ UID-011 โดยเว้นขอบบน 9 px และขอบขวา 24 px เมนูทั้งสองอยู่ตำแหน่งเดิมระหว่างแสดง Toast ส่วน Mobile มีพื้นที่เฉพาะใต้แถบหัว การแจ้งข้อผิดพลาดและลองใหม่อยู่ในหน้าที่ทำรายการ
- F-48 เอาคำแนะนำให้ลากออกในระหว่างบันทึก ผังแสดง F-65 สำหรับจัดรูปแบบ และอ้างภาพร่วมสำหรับ F-111 Desktop กับ F-23 และ F-93 Mobile กับ F-25
- F-99 แสดงผลเมื่อสร้างฉบับร่างใหม่สำเร็จ F-51 เผยแพร่จากฉบับร่างที่อยู่ในรายการแล้ว จึงใช้จำนวนรวมเดิม
- เปลี่ยนสถานะเผยแพร่ในหน้าแก้ไขบทความผ่านตัวเลือกสถานะและปุ่มหลักของฟอร์ม เลือก **ปิด** แล้วกด **ยกเลิกเผยแพร่** เพื่อเปิดขั้นยืนยัน รายการแสดงป้ายสถานะเพื่ออ่านและมีคำสั่งจัดการหมุดแยกตามสิทธิ์ของบทความ
- **ปักหมุดบนหน้าแรก** เลือกบทความให้ขึ้นหน้าแรกตามลำดับ หน้าแรกแสดงสูงสุด 3 เรื่อง แผงปักหมุดแสดงลำดับและผลที่อ่านได้ ถอนหมุดเมื่อต้องการเอาเรื่องออกจากหน้าแรก ตัด 8 คู่ที่มีไว้สำหรับสวิตช์แสดงผลแยกและผลจากสวิตช์นั้น
- บทความที่เปิดจากผลกรองใช้ F-110 → F-74 → F-129 → F-70–73 เมื่อกลับมาที่รายการ คำค้นและตัวกรองยังอยู่ และ F-117 แสดงฉบับร่างหลังล้างตัวกรอง
- Pet Friendly ใช้ F-87 → F-128 → F-123–127 เมื่อยกเลิกเผยแพร่สำเร็จจะเก็บฉบับเดิมเป็นร่างและลดจำนวนหมุดจาก 4 เป็น 3 ผลบนหน้าแรกใช้ลำดับเดียวกับ F-103
- ค้น Pet Friendly ใน F-136 ก่อนเปิดคำสั่ง F-87 ถอนหมุดแล้วกลับผลค้นหา F-144 โดยบทความยังเผยแพร่ ส่วน F-126 แสดงฉบับร่างหลังยกเลิกเผยแพร่ คำค้นและจำนวนผลลัพธ์ต่อเนื่องทั้งสองขนาด
- ปักเมื่อมี 2 หมุดใน F-130 → F-131 → F-132 แล้วขึ้นหน้าแรกลำดับ 3 ใน F-133 หากพลาด F-142 คืนหมุดเดิมและลองใหม่ได้ ตัวอย่าง F-42 เข้าคิวลำดับ 5
- ปักจากหน้าเขียนใน F-137–141 มีผลเมื่อเผยแพร่การแก้ไขสำเร็จและใช้ผล F-133 ระหว่างรอหรือเมื่อพลาดหน้าแรกใช้ชุดเดิม
- F-134, F-145 และ F-135 แสดงการเติมบทความล่าสุดเมื่อมีหมุด 0, 1 และ 2 เรื่องตามลำดับ F-108 แสดงการข้ามเรื่องที่ถอนหมุดแม้มีที่ว่าง
- F-110 → F-75 คงคำค้น สถานะ และช่วงวันที่ตลอดการปักหมุด จาก F-42 หรือ F-76 กลับผลกรองเดิมผ่าน F-146 หรือ F-147 ตามผลที่ได้รับ ตัวอย่างครบ 10 หมุดใช้ F-10 → F-155 → F-116
- F-150 เปิดตัวกรองจากรายการครั้งแรก F-151–154 และ F-162–163 แสดงหน้าถัดไป หน้าสุดท้าย ย้อนหน้า และเลือกตัวกรองบนหน้า 2 แล้วกลับหน้า 1 ของผลกรอง F-04 ใช้ล้างคำค้นเมื่อคำค้นไม่มีผลลัพธ์
- F-156 แสดงร่างแรกพร้อมบันทึก และ F-157 แสดงร่างเรื่องเดิมที่เติมรูปปกกับเนื้อหาพร้อมเผยแพร่ หลังแนบ DV-162 ใน F-92 กลับหน้าเขียนผ่าน F-158 แล้วบันทึก ลองใหม่ หรือบันทึกสำเร็จใน F-159–161 โดยคงบ้านที่แนบไว้ 9 หลัง
- F-143 → F-148 → F-56 → F-102 ใช้บทความ **10 บ้านพักติดทะเล ชลบุรี** เรื่องเดียวกันตั้งแต่ยืนยัน รอผล ไปจนเปิดร่างที่เก็บไว้ F-149 คงสถานะเดิมและให้ลองยกเลิกเผยแพร่อีกครั้ง
- ผลบนหน้าแรกใช้โครงและกติกาที่รับไว้ใน Homepage [กติกาบทความบนหน้าแรก](../../dsd-001/article-content-rules.md)

## ผลตรวจรอบนี้

- ให้เอเจนต์สองตัวตรวจซ้ำต่อเส้นทางทั้ง 6 เส้นทางบน Desktop และ Mobile ตรวจขนาด ตำแหน่ง และการตัดขอบครบ 138 คู่ใน Pencil
- ตรวจภาพตัวอย่างของรายการ หน้าเขียน ค้นบ้านพัก ลองใหม่ สถานะปิด และผลหน้าแรกทั้งสองขนาด
- ตรวจภาพหลังปรับสไตล์ทั้งรายการ แผงปักหมุด ตัวกรองวันที่ เมนูรายบทความ และผลหลังบันทึก ตรวจขนาดและการตัดขอบครบทั้ง 53 คู่ที่ปรับ
- การเทียบหลังบ้านเดิม การใช้คีย์บอร์ดและโปรแกรมอ่านหน้าจอ และการกด ลาก อัปโหลด หรือบันทึกจริง ยังต้องตรวจในระบบที่ทำงานได้
