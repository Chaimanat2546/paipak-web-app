## พฤติกรรมของแบบรอบนี้

- เดสก์ท็อปเห็นรายการและหมุดคู่กัน มือถือใช้แท็บ รายการบนมือถือเปิดแก้ไขได้จากชื่อเรื่องหรือเมนูรายบทความ โหมดเลือกหลายรายการใช้ช่องเลือกประจำแถว ตัวกรองใช้ค่าที่กดใช้ล่าสุดและล้างได้ในแผง
- ปัก ถอน หรือเปิด–ปิดจากหน้ารายการมีผลเมื่อบันทึกการจัดหน้าแรกสำเร็จ ระหว่างมีรายการค้างให้บันทึกก่อนเข้าโหมดจัดลำดับ เมื่อเริ่มจัดลำดับพักการแก้หมุดและสวิตช์ไว้ หากบันทึกไม่สำเร็จให้คงค่าที่แก้ไว้พร้อมคำสั่งลองใหม่
- เปิดตัวอย่างจากหน้าเขียนด้วยค่าที่กำลังแก้ จากหน้ารายการใช้ร่างล่าสุดที่บันทึกเมื่อมีร่าง หรือใช้ฉบับเผยแพร่ของเรื่องที่เลือกเมื่อมีเฉพาะฉบับนั้น การกลับจากตัวอย่างและหน้าค้นบ้านพักคืนไปยังจุดที่เปิดมา
- ข้อความเวลาบันทึกสื่อถึงการบันทึกที่สำเร็จครั้งล่าสุด ก่อนเริ่มบันทึกใน F-66 ร่างล่าสุดบันทึกเมื่อ 10:24 น. หากล้มเหลว F-29 คงเวลาและค่าที่แก้ไว้ หากสำเร็จ F-30 แสดง 10:31 น. หน้าเว็บยังแสดงฉบับเผยแพร่เดิมระหว่างบันทึกร่างหรือเปิดดูตัวอย่าง
- ต้องมีชื่อ รูปปก 16:9 และเนื้อหาก่อนเผยแพร่ รูปปกใช้ JPG, PNG หรือ WebP ขนาดไม่เกิน 10 MB การบันทึกร่างทำได้ก่อนกรอกข้อมูลครบ เมื่อยกเลิกเผยแพร่สำเร็จให้เก็บร่างล่าสุดที่บันทึกไว้ หรือใช้ฉบับเผยแพร่เดิมเมื่อยังไม่มีร่าง แล้วถอนหมุดและขยับลำดับที่เหลือ [กติกาที่ภูยืนยัน](../g2-consolidated-r16-review/owner-publication-rules.json)
- หน้าแรกแสดงสูงสุด 3 เรื่องจากหมุดที่เปิดและพร้อมแสดง แล้วเติมจากฉบับเผยแพร่ล่าสุดที่พร้อมโดยใช้ชื่อ ปก และลิงก์อ่านของฉบับนั้น เมื่อคำโปรยว่างใช้ต้นเนื้อหาสูงสุดสองบรรทัด [ข้อมูลตัวอย่าง F-61](iJePR.png)

## จุดที่ยังต้องยืนยัน

- ใช้ข้อสรุปของ UID-012 และภาพอ้างอิงที่บันทึกไว้เป็นฐานสำหรับรอบนี้ การเทียบขั้นตอนกับระบบเดิมต้องมีภาพหรือข้อมูลการใช้งานจริงเพิ่มเติม
- จังหวะบันทึกอัตโนมัติยังเปิดอยู่ รอบนี้แสดงการกดบันทึกและเวลาที่บันทึกสำเร็จในไวร์เฟรม
- รอบนี้ตรวจขนาดเฟรม การตัดขอบ และความต่อเนื่องของข้อมูลตัวอย่างใน Pencil การกด ลาก โฟกัส อัปโหลด การบันทึกจริง และลิงก์หน้าอ่านต้องทดสอบเมื่อพัฒนา
