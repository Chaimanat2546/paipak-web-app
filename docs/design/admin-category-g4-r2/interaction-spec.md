# UID-010 · สเปกประกอบ G4-r2

ขอบเขตคือการจัดลำดับหมวดจากรายการข้างฟอร์มบนเดสก์ท็อปตามคำขอของภู อ้างอิง [กติกาของหมวดและบ้านในหมวด](../admin-category-management-interaction-spec.md) และ [รูปแบบการใช้จุดจับของ FAQ](../uid-013/g4-r2-review/interaction-spec.md)

- แสดงจุดจับขนาด 44 × 44 px ทางซ้ายของแต่ละหมวดเมื่อมีรายการให้เรียง แอดมินลากจุดจับเพื่อย้ายหรือกดจุดจับเพื่อเปิดตัวเลือกตำแหน่ง ชื่อสำหรับโปรแกรมอ่านหน้าจอระบุหมวด และเปิดตัวเลือกได้ด้วย Enter หรือ Space
- การใช้จุดจับเก็บหมวดที่เปิดแก้และค่าที่กรอกในฟอร์มด้านขวา การกดชื่อหมวดยังคงเปิดฟอร์มตามเดิม เมื่อย้ายให้แจ้งตำแหน่งใหม่และคืนโฟกัสไปที่จุดจับของหมวดที่ย้าย
- หลังย้ายแสดง **ยกเลิก** และ **บันทึกลำดับ** ใต้รายการซ้าย ยกเลิกจะคืนลำดับที่บันทึกไว้ ส่วนบันทึกลำดับจะส่งลำดับหมวดและใช้กับทางลัดและแถวบ้านบนหน้าแรกเมื่อสำเร็จ ฟอร์มด้านขวาใช้ **บันทึกหมวด** เพื่อบันทึกชื่อ สื่อ การแสดงผล รายชื่อบ้าน และลำดับบ้านภายในหมวด
- แสดง Toast ขวาบนระหว่างบันทึกลำดับและเมื่อสำเร็จ ระหว่างส่งให้พักการย้ายและการส่งซ้ำ เมื่อพลาดให้คงลำดับที่กำลังแก้ไว้และแสดงข้อผิดพลาดในรายการซ้ายให้ลองใหม่
- เมื่อต้องออกจากหน้าที่ยังมีการแก้ค้าง ให้ใช้การถามก่อนออกตามสเปกเดิม ฝั่งมือถือใช้โหมดจัดลำดับใน G4-r1

ตอนพัฒนาระบบให้ตรวจการลากเมื่อรายการยาว การเลือกตำแหน่งด้วยคีย์บอร์ด การคงโฟกัสและข้อมูลในฟอร์ม ความเป็นอิสระของปุ่มบันทึกสองส่วน และผลบนหน้าแรกเมื่อบันทึกสำเร็จหรือพลาด
