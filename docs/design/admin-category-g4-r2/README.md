# UID-010 · จัดลำดับหมวดจากรายการซ้าย G4-r2

**อนุมัติ G4-r2 และปิดงานออกแบบ** · 18 พฤศจิกายน 2026 · เดสก์ท็อป 1440 × 900

ในหน้าแก้หมวด ลากจุดจับหรือกดเลือกตำแหน่งจากรายการหมวดทางซ้ายได้ทันที ฟอร์มหมวดและรายการบ้านด้านขวายังอยู่กับหมวดที่เปิดแก้ เมื่อย้ายแล้ว **บันทึกลำดับ** และ **ยกเลิก** จะแสดงใต้รายการหมวด

เปิด section **UID-010 · จัดการหมวดหมู่บ้านพัก** (`jNYEs`) ใน [Pencil ณ รุ่นที่ตรวจ](https://github.com/Chaimanat2546/paipak-web-app/blob/1d56ac968e6ac2be5943a102917222d51fdb028c/docs/design/dsd-001/papaipak-ui.pen) แบบเดสก์ท็อป G4-r2 ที่อนุมัติ 17 เฟรมอยู่ในกลุ่ม `Zt8h0` ใต้ G4-r3 ส่วนแบบมือถือและหน้าแรกอ้างอิง [ชุด G4-r1](../admin-category-g4-r1/README.md)

**บันทึกลำดับ** ใช้ลำดับหมวดใหม่กับทางลัดและแถวบ้านบนหน้าแรกเมื่อสำเร็จ ส่วน **บันทึกหมวด** ใช้กับข้อมูลหมวดและลำดับบ้านในหมวด หากบันทึกลำดับหมวดไม่สำเร็จ ให้เก็บลำดับที่แก้ไว้และแจ้งในรายการซ้ายเพื่อให้ลองใหม่ได้

ตรวจขอบเขตเลเยอร์และเทียบเนื้อหาด้านขวากับเฟรมต้นฉบับทั้ง 17 เฟรม ตรวจจุดจับขนาด 44 × 44 px และตรวจว่าหมวดที่เปิดแก้ยังถูกเลือกหลังเปลี่ยนตำแหน่ง การลากจริง การใช้คีย์บอร์ด และการบันทึกอยู่ในรอบทดสอบระบบ
