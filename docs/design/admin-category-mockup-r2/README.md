ในภาพค้นหาตัวอย่างใช้คำว่า **บ้าน** ทั้งก่อนและหลังเพิ่ม **บ้านมะพร้าว** เข้าไปอยู่ในลำดับที่ห้าของฟอร์มและหายจากผลค้นหาเดิม ส่วน **บ้านมองดาว** ยังกดเพิ่มได้ ตัวอย่างเลือกไอคอนใช้ชุดเดียวกัน 48 แบบ

มือถือวาง Toast ลอยใต้แถบหัวเพื่อให้ปุ่มย้อนกลับยังมองเห็น ฟอร์มอยู่ตำแหน่งเดิม ใช้แถบสี ไอคอน ข้อความสองระดับ และแถบเวลาตามตัวอย่างเดสก์ท็อปที่เจ้าของรับ

## ขอบเขตผลตรวจ

ตรวจภาพที่กว้าง 1440 และ 390 พิกเซล และเทียบผลค้นหาก่อนและหลังเพิ่ม การแสดงช่องท้ายของทางลัด และจำนวนตัวเลือกไอคอนกับสเปคแล้ว ภาพเป็นม็อกอัปสำหรับตรวจหน้าตา การปัด ลาก แตะเลือกตำแหน่ง การบันทึกจริง และการใช้แป้นพิมพ์ยังรอทดสอบในหน้าจอที่ใช้งานได้ ชนิดและขนาดไฟล์รูป สัดส่วน การครอป และค่าพิกเซลที่ใช้เปลี่ยนรูปแบบแถบทางลัดยังรอกำหนด

วันที่ 11 พฤศจิกายน 2026 เจ้าของตอบ “โอเคแล้ว” หลังตรวจม็อกอัป r2 ทั้ง 28 ภาพ การรับแบบครอบคลุมหน้าตาเดสก์ท็อป มือถือ และตัวอย่างทางลัดหน้าแรก เจ้าของขอเพิ่มการลบหมวดหลังจากรับชุดนี้ [ขั้นตอนการลบหมวด](../admin-category-management-brief.md#10-การลบหมวดหมู่)
