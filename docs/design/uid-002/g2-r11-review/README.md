# สถานะโหลดหน้าค้นหา · UID-002 G2-r11

19 พฤศจิกายน 2026 · แบบก่อนเลือกใช้ Skeleton · Pencil section `YULCt` · [ชุดปัจจุบัน G2-r12](../g2-r12-review/README.md)

เจ้าของแก้จากภาพ Mobile ให้กด **ใช้ตัวกรอง** แล้วปิดแผง และแสดงกำลังโหลดบนหน้าผลค้นหา พร้อมจัดข้อความโหลดไม่สำเร็จให้อยู่กึ่งกลาง รุ่นนี้ใช้ร่วมกับหน้าผลค้นหาและตัวกรอง [ชุดฐาน G2-r9](../g2-r9-review/README.md)

- เมื่อส่งตัวกรองบน Mobile ให้ปิดแผงทันทีและแสดงกำลังค้นหาเหนือการ์ดเดิม ข้อความในแถบสถานะระบุว่ากำลังแสดงผลเดิม 36 หลัง จำนวนผลและสรุปเงื่อนไขอัปเดตพร้อมรายการเมื่อได้ผลใหม่ [ดู Mobile](ZS7iu.png)
- เมื่อค้นหาด้วยตัวกรองล้มเหลว ให้ข้อความกับ **ลองใหม่** อยู่เหนือรายการเดิม ค่าที่ส่งครั้งนั้นยังใช้สำหรับลองใหม่ได้ ผู้ใช้เปิดแผงเพื่อแก้เงื่อนไขต่อได้ [ดู Mobile](q10cvk.png)
- บน Desktop สถานะโหลดและคำสั่งลองใหม่อยู่ในพื้นที่ผลค้นหา ปุ่มหลักในแถบข้างใช้คำว่า **ใช้ตัวกรอง** [กำลังค้นหา](aI5Qz.png) · [ค้นหาไม่สำเร็จ](ia4sR.png)
- เมื่อโหลดข้อมูลครั้งแรกไม่สำเร็จ กล่องข้อความอยู่กึ่งกลางพื้นที่ผลค้นหาหลังหัวข้อ ไอคอน ข้อความ และปุ่มวางกึ่งกลางแนวนอนเดียวกัน [ดู Mobile](O8XZFT.png) · [Desktop และ Mobile](KV8fM.png)

แผง Mobile ปิดหลังส่งค่าที่เลือก และคืนโฟกัสมายังปุ่มเปิดตัวกรองขณะข้อความสถานะประกาศให้ทราบ การแก้ตัวกรองก่อนส่งครั้งต่อไปใช้ค่าที่ส่งล่าสุดเป็นจุดเริ่มต้น สรุปเงื่อนไขเหนือผลเดิมยังสัมพันธ์กับรายการที่เห็น ปุ่มใช้ตัวกรองที่กำลังส่งป้องกันการส่งซ้ำ

การประกาศสถานะ โฟกัส คำขอล่าสุด รูปที่จองพื้นที่ไว้ และการลดการเคลื่อนไหวอ้าง [ข้อกำกับสถานะโหลด G2-r10](../g2-r10-review/README.md#เงื่อนไขที่กำกับแบบ) โดยรุ่นนี้ใช้พฤติกรรมปิดแผงแล้วแสดงสถานะบนหน้าผลค้นหาตามคำแก้ล่าสุด

ตรวจขอบเขตเลเยอร์ 18 หน้าจอ การปิดแผง Mobile ใน L-02/L-06 ตำแหน่งข้อความโหลดไม่สำเร็จ และการส่งออก PNG การกด การเคลื่อนไหว การส่งคำขอ และเครื่องอ่านหน้าจอต้องตรวจในงาน implementation
