## กติกาของหน้า

- เมนู **ค้นหาที่พัก** เปิดรายการทั้งหมด ทางลัดหมวดและ **ดูทั้งหมด** บน Home เปิดหมวดที่เลือกในทุกพื้นที่ ปุ่ม **ค้นหา** ใช้เงื่อนไขที่ยืนยันเมื่อกด [กติกาทางเข้าจาก Home](../../dsd-001/visual-direction.md)
- พิมพ์สถานที่เพื่อดูคำแนะนำ เลือกชื่อจากรายการหรือใช้ชื่อที่ตรงกับพื้นที่ที่ระบบรู้จักอยู่แล้ว ถ้าพิมพ์ค้างแล้วระบบระบุไม่ได้ ให้ถือว่าสถานที่ว่างและค้นหาด้วยเงื่อนไขอื่น ค้นหาได้ทั้งเว้นวันและเลือกเฉพาะวันเข้า โดยเก็บวันออกว่างไว้ [กติกาสถานที่](../../dsd-001/search-desktop-review-r2/owner-location-correction.json) · [กติกาวันเข้า](../../dsd-001/search-checkin-only-home-r20-r1/owner-rule-change.json)
- เดสก์ท็อปเปิดตัวเลือกชิดช่องที่กด ปฏิทินแสดงสองเดือน มือถือรวมช่องในแผง **แก้ไขการค้นหา** และแสดงปฏิทินทีละเดือน ทั้งสองขนาดนับผู้เข้าพักรวมและแยกสัตว์เลี้ยง
- คำค้นแนะนำเป็นทางลัดไปยังผลที่เกี่ยวข้อง ตัวกรองที่ใช้อยู่แสดงใกล้รายการบ้านและแก้ได้จากแผงตัวกรอง **ล้างค่า** ล้างค่าร่าง เมื่อต้องการใช้ค่าที่แก้ให้กด **ใช้ตัวกรอง** ถ้าปิดแผงมือถือก่อนกดใช้ ให้คืนค่าที่ใช้ล่าสุดและคืนโฟกัสที่ปุ่มเปิดแผง [กติกาตัวกรองที่ยืนยัน](../../uxd-002/review-decisions.md)
- URL เก็บเงื่อนไขที่ใช้และเลขหน้าไว้สำหรับเปลี่ยนหน้า ย้อนกลับ หรือลิงก์ตรง F-10 และ F-11 ย่อรายการเพื่อให้เห็นบริบทกับตัวเปลี่ยนหน้าในภาพเดียว จำนวนบ้านและเลขหน้าที่แสดงใช้ประกอบการตรวจ [ข้อกำหนดการนำทาง](../../uxd-002/interaction-specification.md)
- การ์ดให้เห็นภาพ ชื่อ ทำเล จำนวนคน ห้องนอน และราคาเริ่มต้น ทางเปิดรายละเอียดแยกจากปุ่มบันทึกและตัวควบคุมรูป กติกาภาพเดียว รูปเสีย ขอบภาพ และข้อกำหนดเข้าสู่ระบบเมื่อบันทึก อ้างชุดข้อสรุปเดิม [พฤติกรรมการ์ดและรายการโปรด](../../uxd-002/interaction-specification.md)

**ข้อเสนอสำหรับตรวจ G2** เมื่อกดค้นหาหรือใช้ตัวกรองชุดใหม่ ให้เริ่มที่หน้า 1 เมื่อย้อนจากหน้ารายละเอียด ให้กลับช่วงรายการเดิมและคืนโฟกัสที่การ์ดต้นทางเมื่อใช้คีย์บอร์ด ปิดแผง **แก้ไขการค้นหา** บนมือถือเพื่อกลับผลชุดที่ใช้ล่าสุด ส่วน **ปรับตัวกรอง** จากหน้าผลว่างให้พาไปแผงเดิมโดยคงค่าไว้

## ผลตรวจแบบ

- ตรวจขอบเขตเลเยอร์ครบ 24 เฟรม ที่ Desktop 1440 × 844 และ Mobile 390 × 844 ใน Pencil พบจุดตัดขอบ 0 จุด
- ตรวจภาพแถบค้นหา ปฏิทิน ตัวนับ แผงตัวกรอง ผลหลังใช้ ผลว่าง และตัวเปลี่ยนหน้า ภาพทั้งหมดใช้ข้อมูลตัวอย่างกับพื้นที่รูปเทาเพื่อให้ตรวจลำดับและพฤติกรรมได้
- สถานะการโหลดและความล้มเหลวของข้อมูลจะยึดงานออกแบบสถานะ `UID-007` ส่วนขนาดจออื่น รายชื่อสถานที่จริง ราคาและความจุจากแคตตาล็อก ตลอดจนการใช้งาน URL คีย์บอร์ดและการแตะจริง ยังต้องตรวจในขั้นที่เกี่ยวข้อง
