## ความหมายของผล

คำขอใหม่โหลดสำเร็จแต่ได้ 0 หลัง จึงแสดง **พบที่พัก 0 หลัง** และ **ไม่พบที่พักตามเงื่อนไขใหม่** ใช้ไอคอนค้นหาไม่พบ บ้าน 36 หลังที่ยังแสดงด้านล่างเป็นผลก่อนเปลี่ยนตัวกรอง โดยมีป้ายกำกับแยกชัดเจน ไม่ถือว่าเป็นรายการที่ตรงเงื่อนไขใหม่

ใช้ช่วงราคา 1,000–2,000 บาทและห้องนอน 5–6 ห้องเป็นข้อมูลจำลองตามกรณีผลว่างเดิม เพื่อให้แตกต่างจากการ์ดเก่าที่แสดงราคา 8,900 บาท ไม่เปลี่ยนค่าจริงหรือกำหนดนโยบายข้อมูลจากตัวอย่างนี้

กด **เปลี่ยนตัวกรอง** เปิดแผงเดิมพร้อมเงื่อนไขใหม่ที่ใช้อยู่ แก้ร่างแล้วกด **ใช้ตัวกรอง** จึงส่งคำขอ แสดง Skeleton และเริ่มหน้า 1 โดยอัปเดตจำนวนผลกับรายการพร้อมกันเมื่อสำเร็จ การเปิดแผงอย่างเดียวไม่ส่งค้นหา

ชุดนี้แก้ความหมายของ G2-r20 และแทนกรณีหลังเปลี่ยนตัวกรองที่มีผลก่อนหน้าใน G2-r21 รูปแบบการเปิดแก้และรูปลักษณ์ที่เจ้าของรับยังคงเดิม ไม่ถือว่าการรับ G2-r20 เดิมเป็นการรับข้อความหรือแนวทางโหลดข้อมูลล้มเหลวจริงอีกต่อไป สถานะการเชื่อมต่อล้มเหลวต้องตรวจแยกจากผล 0 หลัง

ตรวจจำนวนผลใหม่ 0 หลัง ป้ายผลก่อนหน้า 36 หลัง และช่วงราคาใหม่ตรงกันครบ 4 เฟรม ไม่พบข้อความโหลดตัวกรองไม่สำเร็จในชุดนี้ พบเพียงเนื้อหาแผงที่ครอบเพื่อเลื่อน 3 จุด ตรวจภาพ Mobile แล้ว ปุ่มกับข้อความอยู่ครบ ยังเป็นไวร์เฟรมนิ่งและไม่ได้ตรวจ runtime
