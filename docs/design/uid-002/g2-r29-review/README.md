## การทำงานที่คงไว้

สถานที่ ปฏิทิน และจำนวนผู้เข้าพักอยู่ในแผงตัวกรองชุดเดียวกัน Desktop ใช้รายการหรือ picker ข้างแผง Mobile คลี่ตัวควบคุมในเนื้อหาที่เลื่อนได้ หมวดบ้านพักและสิ่งอำนวยความสะดวกยังอยู่ถัดลงไป คำสั่งใช้ตัวกรองคงที่ท้ายแผง

การพิมพ์ เลือกคำแนะนำ เลือกวัน หรือเพิ่มจำนวนเปลี่ยนเฉพาะร่าง ยังไม่ส่งผลใหม่จนกด **ใช้ตัวกรอง** Suggested Search ของจำนวนและใกล้ทะเลใช้หลักเดียวกัน ปิดแผงโดยไม่ใช้ให้ทิ้งสิ่งที่แก้และคืนค่าที่ Apply ล่าสุดตาม Q-08 เดิม ไม่เพิ่ม popup ยืนยัน

### สถานที่

ตัวอย่างพิมพ์ “พั” และมีคำแนะนำพัทยากับพัทยาเหนือ เลือกรายการจึงได้สถานที่ที่ระบุได้ หากยังเป็นข้อความบางส่วนที่ระบุสถานที่ไม่ได้และไม่ได้เลือกคำแนะนำ ไม่ใช้ร่างนั้นเป็นเงื่อนไขสถานที่ สามารถค้นด้วยเงื่อนไขอื่นได้ตามคำยืนยันเดิม ไม่เลือกคำแนะนำแทนผู้ใช้

### วันและจำนวน

เลือกวันเข้าอย่างเดียวได้ ไม่บังคับวันออกและไม่อนุมานจำนวนคืน ตัวอย่าง 12 ธ.ค. 2569 ยังเว้นวันออก จำนวนคนเป็นยอดรวมเดียวกับสัตว์เลี้ยงแยกอีกช่อง ไม่มีการแยกผู้ใหญ่/เด็ก ไม่กำหนดเพดานจาก catalog ที่ยังไม่ได้ตกลง

### ตรวจราคาและล้างค่า

เมื่อราคาต่ำสุด 12,000 บาทเกินสูงสุด 8,000 บาท ให้แจ้ง **ราคาต่ำสุดต้องไม่เกินราคาสูงสุด** ใกล้ช่องราคาและยังไม่ส่งค่าผิด ใช้ปุ่มที่กดไม่ได้จนแก้ช่วงถูกต้อง ไม่สลับราคาอัตโนมัติหรือเพิ่มข้อความเตือนซ้ำเหนือแผง

กดล้างค่าแล้วสถานที่ วัน และจำนวนกลับเป็นช่องว่าง ตัวกรองเพิ่มเติมกลับค่าเริ่มต้น แต่ผลด้านหลังยังเป็นพัทยา 12 ธ.ค. 8 คนและสัตว์เลี้ยง 1 ตัวที่ยืนยันไว้ก่อนหน้า กดใช้จึงค้นด้วยร่างที่ล้างแล้ว การค้นแบบไม่ระบุเงื่อนไขยังทำได้

### ไม่พบตั้งแต่เข้าครั้งแรก

โหลดสำเร็จได้ 0 หลังและยังไม่มีผลเก่า จึงแสดงจำนวน 0 เงื่อนไขที่ใช้ และ **เปลี่ยนตัวกรอง** กึ่งกลางพื้นที่ผล โดยไม่มีการ์ดเก่า กรณีมีผลก่อนหน้าใช้ [G2-r22 ที่รับแล้ว](../g2-r22-review/README.md) ส่วนกรณีดึงข้อมูลไม่ได้ใช้ G2-r25/G2-r26 ตามที่รับแล้ว

## ผลตรวจ

ตรวจแผงทั้ง 10 ภาพที่เปิดแก้ยังมีหมวดและทางเข้าสิ่งอำนวยความสะดวก ตรวจล้างร่างแล้วค่าช่องว่างและเงื่อนไขผลเดิมแยกกัน ตรวจข้อความผิดช่วงราคาเป็นข้อความที่ช่องราคา ตรวจขอบเขตทั้งชุด พบเฉพาะหน้าเต็มตาม viewport 10 จุดกับเนื้อหาแผงที่เลื่อน 11 จุด ภาพรวม Mobile มีสำเนาที่ครอบเหมือนต้นฉบับอีก 10 จุด ไม่มีส่วนอื่นล้นกรอบ

เปิดดู Mobile สถานที่ ปฏิทิน และราคาผิดลำดับแล้ว วันในปฏิทินและความสามารถเลือกวันออกยังเป็นตัวอย่างสื่อรูปแบบ ไม่ใช่ข้อมูลว่างจริง รูปบ้านและข้อมูลทั้งหมดเป็น mock การกด การพิมพ์ validation จริง คีย์บอร์ด scroll/focus และ screen reader ต้องตรวจใน runtime
