## ลำดับและไอคอน

| กลุ่ม | ไอคอนที่ช่วยอ่าน |
| --- | --- |
| เงื่อนไขเข้าพัก | ปฏิทินที่หัวกลุ่ม พร้อมหมุด ปฏิทิน และผู้เข้าพักที่แต่ละช่อง |
| ลองค้นหา | แว่นขยาย พร้อมตัวเลือกที่มีขนาดสม่ำเสมอในแต่ละขนาดจอ |
| ระยะจากทะเล | หมุดที่ช่องระยะ |
| งบประมาณ | กระเป๋าเงิน ช่วงราคาต่ำสุด–สูงสุดวางข้างกัน |
| ขนาดบ้าน | เตียงที่หัวกลุ่ม ช่วงห้องนอนต่ำสุด–สูงสุดวางข้างกัน และอ่างอาบน้ำที่แถวห้องน้ำ |
| หมวดบ้านพัก | ตารางหมวด พร้อมชื่อหมวดที่เลือกและลูกศรเปิดรายการ |
| สิ่งอำนวยความสะดวก | เก้าอี้ พร้อมข้อความและลูกศรเปิดรายการ |

ข้อความกำกับและค่าที่เลือกใช้น้ำหนักปกติ หัวข้อ **ตัวกรองเพิ่มเติม** อยู่ก่อนระยะและราคา กลุ่มหลักเว้นระยะและมีเส้นแบ่ง ส่วนหัวแผงกับคำสั่ง **ล้างค่า** และ **ใช้ตัวกรอง** อยู่กับขอบแผง

ทุกกลุ่มเป็นเนื้อหาต่อเนื่องชุดเดียวกัน การเลื่อนเก็บค่าร่าง กดใช้ยืนยันทั้งชุด ปิดแผง Mobile แล้วแสดง Skeleton ตาม [G2-r12](../g2-r12-review/README.md) ตัวอย่างเริ่มจากพัทยา วันเข้า 12 ธ.ค. ผู้เข้าพัก 8 คน สัตว์เลี้ยง 1 ตัว และตัวกรองเพิ่มเติมเป็นค่าเริ่มต้น

ไอคอนมีข้อความกำกับให้เข้าถึงได้และใช้เป็นส่วนตกแต่งในงาน implementation คำค้นแนะนำ หมวด สิ่งอำนวยความสะดวก และการกลับจากผลว่างใช้กติกาเดิม [เนื้อหาแผงรวม](../g2-r14-review/README.md) · [หน้าไม่พบที่พัก](../g2-r13-review/README.md)

ตรวจความครบของทั้ง 8 แผง ไอคอน ช่องสองคอลัมน์ และปุ่มใช้ตัวกรองหนึ่งจุดต่อแผง ภาพขนาดจอมีการครอบเนื้อหาที่เลื่อนโดยตั้งใจ 6 จุด ตรวจขอบเขตส่วนอื่นแล้ว ภาพคลี่เต็มแสดงทุกกลุ่ม การเลื่อน การแตะ และโฟกัสต้องตรวจในงาน implementation
