Desktop เปิดตัวเลือกข้างแผง ตัวเลือกบน Mobile คลี่ใต้ช่องในแผงและเลื่อนไปพร้อมเนื้อหา ปุ่ม **ใช้ตัวกรอง** อยู่ท้ายแผง การพิมพ์หรือเลือกค่าแก้ร่างจนกว่าจะกดใช้

- พิมพ์ “พั” จะแสดงคำแนะนำพัทยาและพัทยาเหนือ ตัวอย่างนี้ยังไม่ได้เลือกรายการ
- ปฏิทินแสดงวันเข้า 12 ธ.ค. และเว้นวันออก ปุ่มล้างวันที่อยู่ในปฏิทิน
- ผู้เข้าพัก 8 คนและสัตว์เลี้ยง 1 ตัวเป็นคนละช่อง ปุ่มเพิ่มและลดขนาด 44 × 44 พิกเซลในภาพทั้งสองขนาด

การ์ดหน้าค้นหาก่อนหน้านี้ใช้ข้อมูลบรรทัดย่อจากไวร์เฟรม รอบนี้ใช้โครงการ์ดหน้าแรกจาก Pen โหนด `fOxmF` โดยตรง ทั้งสัดส่วนประมาณ 3:2 มุมภาพ รายการไอคอน ขนาดตัวอักษร และแถวราคา ปรับความกว้างตามกริดหน้าค้นหาและใช้ 15 หลังต่อหน้า ตัวอย่างหน้าค้นหาแสดงรูปสี่รูปตามข้อมูลตัวอย่างของชุดเดิม

หน้าปกติและตัวเลือกใน G3-r6 ใช้การ์ดชุดนี้ ภาพ G3-r1 ถึง G3-r5 เก็บเป็นหลักฐานแต่ละรอบ เมื่อนำพฤติกรรมจากชุดเดิมมาใช้กับแบบปัจจุบัน ให้อ้างอิงรูปทรงและขนาดการ์ดจาก G3-r6

แบบอยู่ใน Pen กลุ่ม `Liv9M` ตรวจเลย์เอาต์ 10 เฟรม ขนาดการ์ด จำนวนหลัง และปุ่มใช้ตัวกรองแล้ว การพิมพ์ การกด การเลื่อน และการคืนโฟกัสรอตรวจเมื่อระบบทำงาน
