เก็บ SVG ต้นฉบับ MDI ทั้งแปดและ Phosphor disco-ball ใน `icons/` และนำ path เดิมเข้า Pencil โดยเปลี่ยนเฉพาะกรอบแสดงผลกับสี [นโยบายสิทธิ์ของ Pictogrammers](https://pictogrammers.com/docs/general/license/) ระบุไอคอน MDI เป็น Apache 2.0 เก็บ [สำเนาใบอนุญาต](icons/LICENSE-APACHE-2.0.md) จาก [Apache](https://www.apache.org/licenses/LICENSE-2.0) และ [ใบอนุญาต MIT ของ Phosphor](icons/LICENSE-PHOSPHOR-MIT.txt) จาก [ต้นฉบับ](https://github.com/phosphor-icons/core/blob/main/LICENSE) ส่วน Lucide ใช้ native icon nodes

ตรวจครบ 6 แผง แผงละ 15 ไอคอนไม่ซ้ำ กรอบขนาดเดียวกัน หัวกลุ่มครบและตัวปกติสีเทา ตรวจภาพ Desktop เต็มกับ Mobile ส่วนกิจกรรมแล้ว ตรวจขอบเขตพบเพียงเนื้อหาเลื่อนที่ครอบโดยตั้งใจ 4 จุด ไอคอนในเกมแสดงเป็นรูปอุปกรณ์ การแตะ การเลื่อน โฟกัส และเครื่องอ่านหน้าจอยังต้องตรวจเมื่อ implementation

ใช้กับ [แผงตัวกรอง G2-r15](../g2-r15-review/README.md) และ [Skeleton G2-r12](../g2-r12-review/README.md) การรับครั้งนี้จำกัดที่รูปลักษณ์ไอคอนสิ่งอำนวยความสะดวก ยังไม่ใช่การรับไวร์เฟรมหน้าค้นหาทั้งชุด
