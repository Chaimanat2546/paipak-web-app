# UID-002 · ย้อนกลับจากรายละเอียดบ้าน · G3-r12

[ภาพ Desktop](MjRcQ.png) · [ภาพ Mobile](aFAPz.png)

เทียบก่อนเปิดบ้านพักชมสวนกับหลังย้อนกลับ ทั้งสองฝั่งใช้พัทยา วันเข้า 12 ธ.ค. ผู้เข้าพัก 8 คน สัตว์เลี้ยง 1 ตัว หน้า 2 และรูปที่ 3 ของบ้านหลังเดิม

Desktop การ์ดอยู่ที่ 183px จากขอบบนทั้งสองภาพ และแถบตัวกรองอยู่ที่ตำแหน่งเลื่อนภายใน 192px เท่ากัน Mobile การ์ดอยู่ที่ 105px ทั้งสองภาพ ตัวกรองในภาพอยู่ในสถานะปิด

กลุ่ม `sTGLK` ใน Pen ใช้ภาพจาก G3-r7 และแสดงเฉพาะบริเวณที่ตรวจ การคืนข้อมูลเมื่อกดย้อนจริงรอตรวจบนเว็บ
