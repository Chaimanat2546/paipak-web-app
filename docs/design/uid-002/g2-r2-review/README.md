# ไวร์เฟรมหน้าผลค้นหาที่พัก · UID-002 G2-r2

18 พฤศจิกายน 2026 · ชุดภาพ 13 คู่ก่อนเติมตัวกรอง · [ชุดตรวจปัจจุบัน G2-r3](../g2-r3-review/README.md) · [ไฟล์ Pencil กลาง](../../dsd-001/papaipak-ui.pen) section `xganW`

ภูตอบ “ปรับใช้” หลังตรวจผลวิจัยเรื่องคำค้นแนะนำ รอบนี้ใช้ **Desktop B** และ **Mobile A** ตามที่เลือกไว้ รายละเอียดแถบค้นหา ตัวกรอง และการเปลี่ยนหน้าอยู่ใน [กติกาจาก G2-r1](../g2-r1-review/README.md#กติกาของหน้า)

## คำค้นแนะนำตามบริบท

- แถบ **ลองค้นหา** แสดงได้สูงสุดสามคำ เลือกจากเงื่อนไขที่ใช้ล่าสุดและรายการที่เข้าเงื่อนไข หากคำนั้นใช้อยู่แล้วหรือใช้ร่วมกับเงื่อนไขเดิมไม่ได้ ให้เลือกคำอื่นที่ใช้ได้ แสดงน้อยกว่าสามเมื่อมีตัวเลือกที่ตรงน้อยกว่า
- ตอนเปิดดูที่พักทั้งหมดใช้ **ใกล้ทะเล · พาสัตว์เลี้ยงได้ · บ้านสำหรับกลุ่ม** ในภาพตัวอย่าง เมื่อระบุสัตว์เลี้ยงแล้วให้ใช้ตัวเลือกอื่น เช่น **สายปาร์ตี้** หากเข้าได้กับเงื่อนไขเดิม
- เมื่อกด **ใกล้ทะเล** จากผลพัทยา ให้ค้นต่อด้วยพัทยา วันเข้า 12 ธ.ค. ผู้เข้าพัก 8 คน และสัตว์เลี้ยง 1 ตัว แล้วเพิ่มใกล้ทะเลผ่านตัวกรองที่มีอยู่ แสดงใกล้ทะเลใน **ตัวกรองที่ใช้** และใช้คำอื่นในแถว **ลองค้นหา** การแก้ค่าร่างในแผงตัวกรองใช้ปุ่ม **ใช้ตัวกรอง** ตามกติกาเดิม [เทียบก่อนกด](DeMag.png) · [ดูผลหลังแตะ](vNHIb.png)
- หน้าผลว่างในภาพนี้เสนอ **ปรับช่วงราคา** เพื่อพาไปส่วนราคาในแผงตัวกรองเดิม ราคาและเงื่อนไขอื่นยังอยู่จนกว่าผู้ใช้จะแก้และกดใช้ ทางเลือก **ดูทุกทำเล** ใช้ได้กับกรณีที่การขยายพื้นที่เป็นทางไปสู่ผลที่เกี่ยวข้อง [ดูผลว่าง](tAXFU.png)
- **บ้านพักหรู** และ **ราคาพิเศษ** เป็นคำสำรองเมื่อมีรายการรองรับ ส่วนสไลเดอร์ คาราโอเกะ และโต๊ะพูลเป็นคำสำหรับพิจารณาเมื่อมีข้อมูลรายบ้านที่ใช้ค้นได้ คำและจำนวนผลในชุดนี้เป็นข้อมูลตัวอย่าง [หมวด papaipak](../../../design/approved-ux-ui-scope.md) · [ตัวอย่างคำที่ใช้กับพูลวิลล่า](https://baanpuck.com/pool-villa-pattaya/) · [งานวิจัยทางเลือกเมื่อไม่พบผล](https://baymard.com/research-articles/no-results-page)
