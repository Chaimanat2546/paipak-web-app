# ไวร์เฟรมหน้าผลค้นหาที่พัก · UID-002 G2-r7

18 พฤศจิกายน 2026 · แบบแผงตัวกรองรวมก่อนลดปุ่ม · Pencil section `SAqKc` · [ชุดตรวจล่าสุด G2-r8](../g2-r8-review/README.md)

- บน Desktop สถานที่ วันเข้าพัก–วันออก จำนวนผู้เข้าพัก สัตว์เลี้ยง และคำค้นแนะนำอยู่ในแผงตัวกรองด้านซ้ายร่วมกับราคา ขนาดบ้าน หมวด และสิ่งอำนวยความสะดวก บน Mobile เปิดแผงเดียวจากปุ่ม **ตัวกรอง** ข้างผลค้นหา เหนือรายการแสดงหัวข้อ จำนวนผล และสรุปเงื่อนไขที่ใช้อยู่ [ดูทั้งสองขนาด](FwiOK.png) · [ดูเมื่อเลื่อนลงไปที่ตัวกรองเพิ่มเติม](AYjeb.png)
- การพิมพ์หรือเลือกในแผง รวมถึงการแตะ **15 คน** หรือ **ใกล้ทะเล** จะเปลี่ยนค่าร่าง เมื่อกด **ใช้ตัวกรอง** จึงอัปเดตผลด้วยเงื่อนไขทั้งหมดพร้อมกัน ในตัวอย่าง ค่าร่าง 15 คนยังแสดงผลเดิมของ 8 คนจำนวน 36 หลัง พอกดใช้จึงแสดง 15 คนและผลตัวอย่าง 22 หลัง [ก่อนกดใช้](WvEpE.png) · [หลังกดใช้](yKWD2.png) · [ผลหลังใช้หมวดใกล้ทะเล](ew0jK.png)
- **ล้าง** ล้างค่าร่างทั้งแผงแล้วรอกดใช้ การปิดแผง Mobile ระหว่างแก้ไขจะยกเลิกค่าร่าง ค้นด้วยวันเข้าอย่างเดียวได้ และถ้าพิมพ์สถานที่ค้างโดยยังไม่ได้ระบุสถานที่ที่ระบบรู้จัก ให้ใช้เงื่อนไขที่เหลือ [ดูล้างค่าร่าง](IiPCB.png) · [ค้นด้วยวันเข้าอย่างเดียว](FwiOK.png) · [ใช้เงื่อนไขอื่นโดยเว้นสถานที่](n2VR3P.png)

หมวดบ้านพักในตัวกรองอ้างอิงจากหน้าแรก ส่วนจำนวนคนในคำแนะนำอ้างอิงตามความจุที่ตรวจไว้ในรุ่นก่อน [ที่มาของหมวดและจำนวนคน](../g2-r6-review/README.md)
