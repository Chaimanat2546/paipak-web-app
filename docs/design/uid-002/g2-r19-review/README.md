# ใช้ตัวกรองแล้วโหลดไม่สำเร็จ · UID-002 G2-r19

ประวัติข้อเสนอ คำสั่งปัจจุบันใช้ **เปลี่ยนตัวกรอง** ตาม [G2-r20](../g2-r20-review/README.md) เจ้าของแก้ให้เปิดแผงแก้เงื่อนไขแทนการค้นหาซ้ำ

19 พฤศจิกายน 2026 · รอเจ้าของตรวจ 1 คู่ Desktop/Mobile · Pencil section `ayHEB` · [ภาพคู่](ayHEB.png) · [Desktop](B9t8R.png) · [Mobile](NqFlG.png)

เจ้าของแจ้งว่า L-06 เดิมแยกสถานะไม่ออก ข้อความ “ค้นหาไม่สำเร็จ” กับผลบ้านที่ยังปรากฏไม่ชัดว่าชุดไหนเป็นเงื่อนไขเก่าและชุดไหนเพิ่งขอโหลด รุ่นนี้แก้เฉพาะการสื่อสารสถานะหลังใช้ตัวกรองล้มเหลว

- ใช้หัวข้อ **โหลดผลตามตัวกรองใหม่ไม่สำเร็จ** พร้อมไอคอนแจ้งปัญหา
- ระบุ **รายการด้านล่างยังเป็นผลก่อนปรับตัวกรอง** และแสดงตัวกรองใหม่ที่ลองใช้ในกรอบเดียวกัน
- ปุ่ม **ลองใช้ตัวกรองอีกครั้ง** ส่งเงื่อนไขชุดที่ล้มเหลว ไม่ส่งค่าผลเดิมแทน
- เหนือการ์ดมีป้าย **ผลก่อนปรับตัวกรอง · 36 หลัง** และจำนวนด้านบนระบุว่าเป็นผลเดิม

ตัวอย่างผลเดิมคือพัทยา 12 ธ.ค. ผู้เข้าพัก 8 คน สัตว์เลี้ยง 1 ตัว จำนวน 36 หลัง ตัวกรองใหม่ที่ลองใช้คือราคาเริ่มต้นต่อคืน 5,000–10,000 บาทและห้องนอน 3–5 ห้อง แผง Desktop ใช้โครงล่าสุดและเก็บร่างตามค่าที่ลองใช้ Mobile ปิดแผงตามกติกาเดิม

การลองใหม่เข้าสู่ Skeleton L-02 ตาม [G2-r12](../g2-r12-review/README.md) เมื่อสำเร็จจึงอัปเดตจำนวนผล สรุปเงื่อนไข และรายการพร้อมกันโดยเริ่มหน้า 1 หากสำเร็จแต่ไม่มีผลใช้ [G2-r13](../g2-r13-review/README.md) โหลดครั้งแรกไม่สำเร็จยังใช้ L-05 เดิมที่ไม่มีผลก่อนหน้า

ตรวจ Native พบเฉพาะเนื้อหาตัวกรองที่ครอบเพื่อเลื่อน 1 จุด ไม่มีข้อความหรือปุ่มล้น เปิดดูภาพ Mobile และ Desktop แล้ว ป้ายผลเดิม ตัวกรองที่ล้มเหลว และคำสั่งลองใหม่อยู่แยกกันอย่างชัดเจน ชุดนี้ยังเป็นไวร์เฟรมนิ่ง ไม่ได้ตรวจคำขอ โฟกัส หรือเครื่องอ่านหน้าจอใน runtime

แทน L-06 เดิมของ G2-r12 เพียงคู่เดียว ส่วน [หน้าเต็ม G2-r18 ที่รับแล้ว](../g2-r18-review/README.md) และไอคอน G2-r17 คงเดิม
