# ไวร์เฟรมหน้าผลค้นหาที่พัก · UID-002 G2-r5

18 พฤศจิกายน 2026 · ชุดภาพก่อนเชื่อมหมวดหน้าแรกและคำค้นตามจำนวนคน · [ชุดตรวจปัจจุบัน G2-r6](../g2-r6-review/README.md) · [ไฟล์ Pencil กลาง](../../dsd-001/papaipak-ui.pen) section `wdUMo`

ภูขอ “จัดเรียงดีๆ” จึงจัดลำดับและจัดแนวแผงตัวกรองทั้ง Desktop B และ Mobile A [เทียบแผงก่อนจัด](../g2-r4-review/vPrqW.png) · [แผงที่จัดใหม่](Nspdg.png)

1. **งบประมาณ** แสดงฐานราคาเหนือช่องต่ำสุดกับสูงสุดที่วางคู่กัน เมื่อช่วงราคากลับด้านให้แจ้งใต้ทั้งคู่ [ตัวอย่างกรอกช่วงสลับกัน](zsMjo.png)
2. **ขนาดบ้าน** วางห้องนอนต่ำสุดและสูงสุดคู่กัน แล้ววางห้องน้ำอย่างน้อยในแถวถัดมา
3. **ลักษณะบ้าน** เรียงรับสัตว์เลี้ยง ใกล้ทะเล และพื้นที่สำหรับกลุ่มให้ช่องเลือกตรงแนวเดียวกัน
4. **สิ่งอำนวยความสะดวก** ใช้แถวเต็มความกว้างพร้อมจำนวนที่เลือก ใต้กลุ่มสระและพักผ่อนให้ระบบสระอยู่ติดกับสระว่ายน้ำ บนมือถือแผงหลักและแผงรายการเต็มใช้ขอบบนกับแถบปุ่มล่างระดับเดียวกัน [แผงสิ่งอำนวยความสะดวก](qqJqr.png) · [ตัวเลือกระบบสระ](lBhWG.png)

ปุ่ม **ล้างค่า** และ **ใช้ตัวกรอง** อยู่ท้ายแผง โดยให้พื้นที่ปุ่มใช้ตัวกรองมากกว่า กติกาค่าร่างและตัวเลือกอ้าง [ตัวกรอง G2-r3](../g2-r3-review/README.md) · [ห้องน้ำและระบบสระ G2-r4](../g2-r4-review/README.md)
