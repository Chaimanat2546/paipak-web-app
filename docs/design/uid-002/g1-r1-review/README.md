# หน้าผลค้นหาที่พัก · UID-002 G1-r1

18 พฤศจิกายน 2026 · ภูเลือก **Desktop B** และ **Mobile A** [บันทึกการเลือก](owner-G1-r1-acceptance.json) · [ไวร์เฟรม G2-r1](../g2-r1-review/README.md)

| ทางเลือก | Desktop | Mobile |
| --- | --- | --- |
| **A · เห็นบ้านเร็ว** | แถบค้นหาแถวเดียวด้านบน วางหัวข้อ จำนวนผล และคำค้นแนะนำเหนือการ์ด มีตัวกรองด้านซ้ายแบบพับแยกกลุ่ม | ย่อเงื่อนไขเป็นแถบเดียว กด **แก้ไข** เพื่อเปิดช่องค้นหา เห็นบ้านแรกตั้งแต่ช่วงบนของจอ |
| **B · เห็นเงื่อนไขครบ** | ให้หัวข้อและช่องสถานที่ วันเข้าพัก ผู้เข้าพักอยู่เป็นชุดเหนือรายการ เปิดกลุ่มราคากับห้องนอนให้เห็นในแผงตัวกรองด้านซ้าย | วางสามช่องพร้อมปุ่มค้นหาให้กดแก้ได้ทันที รายการบ้านเริ่มต่ำลง |

เสนอ **A** เพราะหน้าผลค้นหามีหน้าที่หลักให้เทียบและเลือกบ้าน คนที่เพิ่งค้นจากหน้าแรกเห็นบ้านเร็วขึ้น ส่วน **B** เหมาะถ้าต้องการให้คนแก้เงื่อนไขทันทีบ่อย ๆ บนมือถือ

ทั้งสองทางใช้ Header กลาง, Mitr, สี papaipak และปุ่มจาก DSD-002 r1 ตัวอย่างใช้ภาพจากชุดออกแบบรายละเอียดบ้านพักกับชื่อ ราคา และจำนวนผลสมมติ แสดงหน้าแรกของผลค้นหาเพื่อเทียบลำดับสายตา
