ช่วงโหลดใช้ Skeleton ขนาดเดียวกับการ์ดในหน้าผลค้นหา เมื่อใช้ตัวกรองบนมือถือ แผงปิดแล้วจึงเห็น Skeleton ที่รายการ จำนวนผลกับรายการใหม่เปลี่ยนพร้อมกันเมื่อได้ผล ยึด 15 หลังต่อหน้า

ผล 0 หลังใช้ **เปลี่ยนตัวกรอง** กรณีมีผลเดิมจะแสดงแยกใต้ป้าย **ผลก่อนเปลี่ยนตัวกรอง** กรณีเข้าครั้งแรกยังไม่มีการ์ดเดิม

โหลดครั้งแรกไม่สำเร็จใช้ **ลองโหลดอีกครั้ง** โหลดผลจากตัวกรองใหม่ไม่สำเร็จเก็บผลเดิมและแสดงเงื่อนไขที่ส่ง พร้อม **ลองโหลดผลล่าสุด** ถ้าโหลดหน้า 2 ไม่สำเร็จให้คงหน้า 1 และมี **ลองโหลดหน้า 2 อีกครั้ง** ใกล้ตัวเปลี่ยนหน้า

พฤติกรรมอ้างอิง G2-r30 และภาพหน้าปกติ G3-r1 ใช้ Header ฟอนต์ Mitr สีของ papaipak และการ์ดชุดเดียวกับหน้าปกติ แบบอยู่ใน Pen กลุ่ม `cAtDl` ผลตรวจ native พบเฉพาะการครอบของขอบภาพจอและพื้นที่เลื่อนตัวกรอง แบบรอบนี้ใช้ตรวจรูปลักษณ์และข้อความ ส่วนพฤติกรรมจริงรอตรวจในระบบ
