# UID-002 · การ์ดบ้านแบบหน้าแรกทุกสถานะ G3-r7

19 พฤศจิกายน 2026 · แบบปัจจุบันสำหรับตรวจ Desktop และ Mobile

การ์ดผลค้นหาใช้โครงหน้าแรกและแสดง **จำนวนห้องน้ำ** ถัดจากห้องนอน ทั้งหน้า 1–3 ผลเดิมหลังใช้ตัวกรอง และการ์ดเมื่อรูปกำลังโหลดหรือโหลดไม่ได้ จำนวนห้องน้ำในภาพเป็นข้อมูลตัวอย่างของบ้าน 36 หลัง ค่าของแต่ละหลังตรงกันทั้งสองขนาดและทุกสถานะ

Skeleton ใช้ขนาดเดียวกับการ์ดจริงและมีโครงทำเล คน ห้องนอน ห้องน้ำ และราคา เมื่อโหลดรูปอย่างเดียว ข้อมูลบ้านยังอ่านได้ หน้าค้นหายังคงแบ่ง 15 / 15 / 6 หลัง กรณีย้อนกลับตัวอย่างยังอยู่หน้า 2 ตรงบ้านพักชมสวนและภาพที่ 3
