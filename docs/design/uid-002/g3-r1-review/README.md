## สิ่งที่เปลี่ยนและเหตุผล

ใช้ Header r1 และ Footer r1 จาก Home ที่รับไว้ เพื่อให้หน้าค้นหาต่อเนื่องกับเว็บเดิม ใช้ Mitr สีกรมท่าและฟ้าอ่อนของ papaipak และคู่สีปุ่มชมพูเข้ม/ขาวที่รับไว้ใน [pink-button-rollout-r1](../../dsd-001/pink-button-rollout-r1/README.md)

ภาพบ้านเป็นภาพตัวอย่างที่สร้างไว้ใน Home เดิม ใช้สี่ภาพวนประกอบรายการจำลอง 15 หลัง ชื่อ ความจุ ราคา และจำนวนผลเป็น fixtures สำหรับตรวจแบบ ไม่ใช่ข้อมูลบ้านจริง ไม่เพิ่มคะแนน รีวิว ส่วนลดหรือข้อความเร่งจอง

คงลำดับและพฤติกรรม G2-r30: ตัวกรองชุดเดียว ใช้เมื่อกด **ใช้ตัวกรอง** คำแนะนำ 10 คน / 15 คน / ใกล้ทะเลแก้เพียงค่าร่าง และใช้ 15 หลังต่อหน้า Desktop มีแผงเลื่อนสูง 660px พร้อมแถบคำสั่งอยู่ด้านล่าง Mobile ใช้แผงสูง 664px ที่เลื่อนเฉพาะเนื้อหา ภาพตัวกรองเต็มใช้ตรวจช่องที่อยู่ใต้แนวพับ

Header จริงสูงกว่าตัวแทนในไวร์เฟรม จึงเลื่อนเนื้อหา Desktop ลง 62px และ Mobile 13px ส่วน Footer ใช้ความสูงจริงตามแบบที่รับ การ์ดคงสัดส่วนภาพและข้อมูลสามบรรทัด เพิ่มขนาดราคาเป็น 18px และ metadata เป็น 13px เพื่ออ่านและเทียบได้ง่าย พื้นที่กดบันทึกบ้านและรูปถัดไปมีกรอบ native 44×44px

## ผลตรวจและงานที่ยังเหลือ

หน้าเต็มทั้งสองขนาดมีการ์ดและภาพ 15 ใบตรงกัน ตรวจ native bounds พบการครอบ 56 จุดจากภาพจอและช่องเลื่อนตามตั้งใจ ไม่พบส่วนล้นผิดปกติ ดู [หลักฐาน native](native-verification.json) และ [รายการแบบ/แหล่งอ้างอิง](review-manifest.json)

G3 รอบนี้ตรวจรูปลักษณ์หน้าแสดงผลปกติและตัวกรองหลักก่อน หมวดบ้านพัก สิ่งอำนวยความสะดวก popover สถานะโหลด/ไม่พบ/โหลดไม่สำเร็จ รูปผิดพลาด การเปลี่ยนหน้า/ย้อนกลับ และ hover/focus ยังต้องปรับเป็น Hi-Fi ตามกติกาที่รับใน G2 ตรวจ runtime, keyboard, screen reader และ responsive ขนาดอื่นในขั้นที่เกี่ยวข้อง ยังไม่ถือว่าผ่านจากภาพเหล่านี้

## เกณฑ์ตรวจรอบนี้

| เกณฑ์ | ผล |
| --- | --- |
| หน้าเต็ม Desktop และ Mobile มี 15 หลัง | ผ่านจาก native inventory |
| พฤติกรรมและลำดับข้อมูลอ้างอิง G2-r30 | คงไว้ในแบบและบันทึก ไม่ใช่ทดสอบระบบจริง |
| ใช้สี ฟอนต์ Header และ Footer ที่รับไว้ | ผ่านการเทียบแหล่งอ้างอิง |
| ปุ่มใช้ตัวกรองอยู่ในแถบคำสั่ง แยกกับส่วนเลื่อน | ผ่านการตรวจโครง native |
| Hi-Fi ทุกสถานะตามขอบเขต UID-002 | ยังไม่ครบในรอบนี้ |
| เจ้าของรับ G3 / G4 | รอตรวจ |
| Frontend / backend / runtime | ยังไม่เริ่มจากคำสั่งนี้ |

การตัดสินใจที่ขอในรอบนี้: รับรูปลักษณ์หน้าปกติและตัวกรองหลัก G3-r1 หรือระบุจุดปรับ ก่อนใช้รูปแบบนี้กับสถานะที่เหลือ ไม่มีการขอเริ่ม Frontend
