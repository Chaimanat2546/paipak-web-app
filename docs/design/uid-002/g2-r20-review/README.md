# เปลี่ยนตัวกรองหลังโหลดไม่สำเร็จ · UID-002 G2-r20

เจ้าของชี้แจงภายหลังว่าภาพนี้หมายถึงไม่พบที่พักตามเงื่อนไข การจัดเป็นโหลดล้มเหลวเป็นการตีความของ Agent ที่คลาดเคลื่อน ใช้ [ข้อความแก้ความหมาย G2-r22](../g2-r22-review/README.md) เป็นปัจจุบัน โดยคง Layout และคำสั่งเปลี่ยนตัวกรองที่รับแล้ว

19 พฤศจิกายน 2026 · เจ้าของรับแบบและการเปิดแก้ตัวกรองด้วยข้อความ “โอเคเอาแบบนี้แหละ” · 2 คู่ Desktop/Mobile รวม 4 เฟรม · Pencil section `HoV5L` · [บันทึกการรับ](owner-filter-change-acceptance.json) · [ภาพรวม](HoV5L.png)

เจ้าของแก้ว่า “มันต้องเป็นการเปลี่ยนไม่ใช่ค้นหาซ้ำ” จึงเปลี่ยนคำสั่งในสถานะ L-06 เป็น **เปลี่ยนตัวกรอง** เปิดแผงเดิมให้แก้เงื่อนไขก่อนกดใช้ โดยยังคงการแยกผลเดิมกับตัวกรองใหม่จาก G2-r19

## การทำงาน

- **เปลี่ยนตัวกรอง** เปิดแผงบน Mobile ส่วน Desktop เลื่อนและย้ายโฟกัสไปแผงด้านข้าง ชุดภาพแสดงบริเวณราคาและห้องนอนตามเงื่อนไขที่ล้มเหลว
- เริ่มร่างจากค่าที่ส่งล่าสุด ตัวอย่างคือราคา 5,000–10,000 บาทต่อคืนและห้องนอน 3–5 ห้อง ไม่ล้างค่าทิ้งเมื่อกลับมาแก้
- กดเปิดแผงอย่างเดียวไม่ส่งคำขอ ผลเดิม 36 หลังและเงื่อนไขเดิมคงไว้ระหว่างแก้
- กด **ใช้ตัวกรอง** จึงส่งร่างปัจจุบัน ปิดแผง Mobile และใช้ Skeleton L-02 เมื่อสำเร็จจึงอัปเดตจำนวนผล สรุปเงื่อนไข และรายการพร้อมกัน เริ่มหน้า 1
- ปิดแผงก่อนใช้ให้กลับมาผลเดิมตามกติกาปิดแผงที่ใช้อยู่ ไม่มีการส่งค้นหาอัตโนมัติ

ข้อแก้นี้แทนคำสั่งลองใช้ตัวกรองอีกครั้งของ G2-r19 เฉพาะ L-06 ไม่เปลี่ยนปุ่มลองใหม่ของการโหลดครั้งแรกหรือการเปลี่ยนหน้าใน [G2-r12](../g2-r12-review/README.md) และคง [หน้าเต็ม G2-r18 ที่รับแล้ว](../g2-r18-review/README.md)

ตรวจภาพ Mobile ก่อนและหลังเปิดแผง ค่าราคาและห้องนอนตรงกับเงื่อนไขที่ล้มเหลว ภาพก่อนเปิดยังแสดงการ์ดเดิม ตรวจข้อความไม่พบคำสั่งค้นหาซ้ำในชุดนี้ การกดจริง คำขอ โฟกัสและเครื่องอ่านหน้าจอยังต้องตรวจใน runtime
