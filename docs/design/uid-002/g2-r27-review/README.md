คงขนาดการ์ดและโครงหน้าเดิม Desktop พื้นที่ข้างแผงมี 3 คอลัมน์ตามภาพที่รับ Mobile เป็น 1 คอลัมน์ หน้าเต็ม Desktop คลี่แผงเพื่อใช้ตรวจเนื้อหาตามชุดเดิม ภาพ Mobile ต่อเนื้อหาถึง Footer ไม่ยืดแถวสุดท้ายเพื่อให้เต็มจำนวนคอลัมน์

ตัวเปลี่ยนหน้าเลือกเลขที่กำลังแสดง ปุ่มก่อนหน้าใช้ไม่ได้ที่หน้าแรก ปุ่มถัดไปใช้ไม่ได้ที่หน้าสุดท้าย ถ้าผลรวมไม่เต็ม 16 หน้าสุดท้ายแสดงเฉพาะบ้านที่มี ช่วงผลกับจำนวนรวมสัมพันธ์กันทั้งสองขนาด

กติกาการยืนยันหน้าเมื่อโหลดสำเร็จและการย้อนจากรายละเอียดตาม [G2-r23 ที่รับแล้ว](../g2-r23-review/README.md) คงเดิม ภาพตัวอย่าง 12 หลังของ G2-r23 ไม่ใช้เป็นข้อกำหนดจำนวนต่อหน้าอีกต่อไป
