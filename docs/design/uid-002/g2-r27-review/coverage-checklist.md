## เกณฑ์ของ Task Packet

- Suggested Search เป็นทางลัดแก้ร่าง ไม่ปะปนกับชิปตัวกรองที่ใช้แล้ว ผลเปลี่ยนเมื่อกดใช้ตัวกรองตาม WIRE-010
- สถานที่ วัน จำนวนผู้เข้าพัก และตัวกรองเพิ่มเติมอยู่ในแผงเดียว ไม่มีปุ่มค้นหาอีกชุดเหนือรายการ
- เลขหน้าและเงื่อนไขที่ยืนยันเก็บกับ URL ตาม WIRE-008 ส่วนการย้อนคืนตำแหน่งและภาพที่ดูไว้ตาม G2-r23
- Desktop/Mobile ใช้ขนาดการ์ดที่อ่านได้ตามหน้าเต็มที่รับ ตัวอย่างจำนวนต่อหน้าปรับเป็น 16 ตามคำตอบล่าสุด

## ขอบเขตที่ยังไม่ถือว่าผ่านจากไวร์เฟรม

การรับภาพไม่ยืนยัน runtime, URL/history, คำขอซ้อน, ข้อมูลแคตตาล็อกจริง, keyboard/focus, screen reader, zoom/reflow หรือความพร้อม Workers งานนี้ยังไม่เริ่ม Frontend และยังไม่ใช่ High-Fi ของหน้าค้นหา

ภาพและบันทึกเวอร์ชันก่อนหน้าคงไว้เป็นประวัติ โดยเฉพาะการเคยเรียกแบบ G2-r20 ว่าโหลดล้มเหลว ซึ่งเจ้าของแก้ความหมายเป็นไม่พบตามเงื่อนไขและรับ G2-r22 แล้ว ให้แยกออกจากการดึงข้อมูลไม่สำเร็จจริงใน G2-r25/G2-r26
