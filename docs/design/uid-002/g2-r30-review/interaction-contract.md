# กติกาไวร์เฟรมหน้าค้นหา · G2-r30

เอกสารนี้รวมกติกาที่ตกลงใน UID-002 และการแก้ล่าสุด เจ้าของรับเป็นส่วนหนึ่งของ G2-r30 ทั้งชุดแล้วตามบันทึกการรับ ยังไม่ได้ยืนยัน runtime

## เข้าและค้นหา

- เปิดดูบ้านได้โดยไม่ระบุวันและไม่ Login ใช้เงื่อนไขเท่าที่ระบุ
- เลือกวันเข้าอย่างเดียวได้ ไม่บังคับวันออก ไม่อนุมานจำนวนคืน
- สถานที่เป็นช่องพิมพ์พร้อมคำแนะนำ ข้อความบางส่วนที่ยังระบุสถานที่ไม่ได้และไม่ได้เลือกคำแนะนำไม่เป็นเงื่อนไขสถานที่ ไม่เลือกให้เอง
- คนเป็นยอดรวมเดียว สัตว์เลี้ยงแยก ไม่มีผู้ใหญ่/เด็ก
- วัน คน หมวด ระยะทะเล ราคา ห้องนอน ห้องน้ำ และสิ่งอำนวยความสะดวกอยู่ในแผงร่างชุดเดียว ไม่มีปุ่มค้นหาส่งแยกด้านบน

## ร่างและ Apply

- เลือกหรือพิมพ์ในแผงและ Suggested Search เปลี่ยนร่าง ยังไม่เปลี่ยนรายการ
- หมวดบ้านพักใช้รายการจากหน้าแรก เลือกหนึ่งหมวดหรือทุกหมวด สิ่งอำนวยความสะดวกเลือกหลายข้อได้และมีระบบสระ
- ล้างค่าคืนค่าเริ่มต้นในร่าง ผลที่ยืนยันยังคงเดิมจนกดใช้ การค้นโดยไม่กรอกเงื่อนไขทำได้
- ปิดแผงโดยไม่กดใช้ทิ้งการแก้ร่างและเก็บค่าที่ Apply ล่าสุดตาม Q-08 ถ้าคำขอล่าสุดโหลดไม่สำเร็จให้เก็บภาพผลเก่ากับเงื่อนไขที่ลองส่งแยกกัน
- ช่วงราคาผิดลำดับแจ้งที่ช่องและไม่ส่งค่าผิด ไม่สลับราคาเอง ภาพไม่กำหนดเพดานหรือการตรวจข้อมูลจาก catalog จริง
- กดใช้ส่ง snapshot ของร่างทั้งชุด เริ่มหน้า 1 ปิดแผง Mobile และแสดง Skeleton ที่รายการ ผล สรุป และจำนวนเปลี่ยนพร้อมกันเมื่อสำเร็จ

## จำนวนและหน้า

- ใช้ 15 หลังต่อหน้า Desktop/Mobile หน้าสุดท้ายเท่าจำนวนที่เหลือ
- ตัวอย่าง 36 หลังแบ่งเป็น 1–15, 16–30 และ 31–36 ไม่มีการทำซ้ำหรือทำหายเพื่อให้ครบหน้า
- หน้าแรกใช้ปุ่มก่อนหน้าไม่ได้ หน้าสุดท้ายใช้ปุ่มถัดไปไม่ได้
- เปลี่ยนหน้าเก็บเงื่อนไขที่ยืนยัน ช่วงรอใช้ Skeleton และป้องกันส่งซ้ำ หน้าที่ยืนยัน เลขหน้าใน URL และรายการเปลี่ยนพร้อมกันเมื่อโหลดสำเร็จ
- หน้าใหม่สำเร็จเริ่มต้นรายการของหน้านั้น การแก้และใช้ตัวกรองเริ่มหน้า 1
- ย้อนจากรายละเอียดในการนำทางต่อเนื่องคืนเงื่อนไข เลขหน้า scroll ของหน้า/แผง และภาพที่ดู ไม่เริ่มหน้า 1
- การเปิด URL ใหม่หรือ reload ใช้เงื่อนไขและหน้าที่รองรับใน URL ยังไม่สัญญาว่าคืนทุกภาพและทุก scroll แบบการย้อนกลับ

## ผลว่างและความล้มเหลว

- โหลดสำเร็จแต่ได้ 0 หลังจึงใช้ข้อความไม่พบตามเงื่อนไข มีปุ่มเปลี่ยนตัวกรอง
- ถ้ายังไม่มีผลก่อนหน้าไม่แสดงการ์ดเก่า ถ้ามีผลก่อนหน้าให้แยกป้ายว่าเป็นผลก่อนเปลี่ยนตัวกรอง ไม่ถือว่าเป็นบ้านตรงเงื่อนไขใหม่
- โหลดข้อมูลไม่สำเร็จยังบอกไม่ได้ว่าผลใหม่เป็น 0 หลัง กรณีเข้าครั้งแรกใช้ลองโหลดอีกครั้ง
- โหลดหน้าใหม่ไม่สำเร็จคงหน้าที่สำเร็จล่าสุดและระบุหน้าที่ขอโหลด ปุ่มลองโหลดหน้าที่ขอใช้หน้าและเงื่อนไขเดิม
- โหลดผลหลังส่งตัวกรองไม่สำเร็จเก็บผลก่อนหน้า ระบุว่าตรวจผลใหม่ไม่ได้และเงื่อนไขที่ส่ง ปุ่มลองโหลดผลล่าสุดส่ง snapshot ที่ล้มเหลว
- ไม่ยืนยันสาเหตุเป็นเครือข่ายหรือ provider ถ้ายังระบุไม่ได้ ไม่เพิ่มเวลารอหรือ auto retry จาก mock

## รูปและการเข้าถึง

- ข้อมูลบ้านได้แล้วแต่รูปรอให้ Skeleton เฉพาะรูป รูปโหลดไม่ได้ใช้ไอคอนกับข้อความเฉพาะภาพ ขนาดการ์ดไม่ยุบ
- รูปโหลดไม่ได้ยังเปิดรายละเอียดหรือเลื่อนไปภาพอื่นได้ ไม่มีปุ่มลองรูปใหม่ตาม Q-07
- Carousel ไม่ autoplay ถึงรูปท้ายหยุด ภาพเดียวซ่อนลูกศรและจุดตาม Q-04 ถึง Q-06
- ไอคอนสิ่งอำนวยความสะดวกผสมชุดตามที่รับ หัวกลุ่มเป็นข้อความตัวปกติสีจาง
- แผง/picker ต้องมี label และการคืน focus ที่เหมาะสม Skeleton เป็นการตกแต่งและมีสถานะให้เทคโนโลยีช่วยเหลือ ข้อกำหนดนี้ยังไม่ได้ตรวจ runtime

## ขอบเขตถัดไป

ความพร้อมข้อมูลจริง เพดานตัวเลข การ normalize/validate input, request concurrency, cache/history restoration, keyboard/screen reader และ responsive ช่วงกลางต้องตรวจในสเปกคอมโพเนนต์และ implementation ที่ได้รับอนุญาต ภาพนี้ไม่รับรอง backend, Auth, booking, payment หรือ Workers
