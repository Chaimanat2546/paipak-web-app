## สิ่งที่รวมและเหตุผล

รวมหน้าเต็ม แผง ตัวควบคุม สถานะผลค้นหา และการย้อนกลับที่เจ้าของรับแยกไว้ ให้เป็นเวอร์ชันอ้างอิงเดียว ใช้ **15 หลังต่อหน้า** ทั้งสองขนาด และผลจำลอง 36 หลังแบ่งเป็น **15 / 15 / 6** โครง Desktop คง 3 คอลัมน์ในพื้นที่ข้างแผง Mobile คง 1 คอลัมน์

ภาพที่เคยใช้ข้อมูล 12 หลังเป็นประวัติ ในชุดรวมได้ปรับภาพสถานะรูป การโหลดหน้าใหม่ และการย้อนกลับให้ใช้รายการ 15 หลังปัจจุบัน โดยคงรูปแบบและพฤติกรรมที่รับแล้ว ไม่มีปุ่มค้นหาอีกชุดแยกจากแผงตัวกรอง

## ข้อแลกเปลี่ยนและสิ่งที่ตรวจภายหลัง

คงขนาดการ์ดเดิมเพื่อให้สแกนข้อมูลได้ตามแบบที่รับ Mobile จึงเป็นรายการยาว 15 หลังและมีตัวเปลี่ยนหน้าท้ายรายการ ภาพบ้าน ชื่อ ราคา จำนวนผล และวันที่เป็น mock สำหรับตรวจโครง ไม่ใช่ข้อมูลจองจริง

ชุดนี้ยังเป็น Low-Fi ไม่ยืนยันสีและ assets ของ High-Fi หรือ runtime การส่งคำขอ URL/history การคืน scroll/ภาพจริง การเข้าถึง keyboard/focus/screen reader, zoom/reflow และ Workers ยังต้องตรวจเมื่อมี implementation โดยงานนี้ยังไม่อนุญาต Frontend/backend/deploy

## ผลการตัดสินใจ

เจ้าของตอบรับคำขอให้รับ **ไวร์เฟรมหน้าค้นหา G2-r30 ทั้งชุด** เป็นฐานสำหรับขั้น UI แบบละเอียดแล้ว ตาม [G2 ในขั้นตอนรีวิวโครงการ](../../governance/05-design-workflow.md) G3 ยังไม่เริ่ม และการรับครั้งนี้ไม่อนุญาต implementation
