# ไวร์เฟรมหน้าผลค้นหาที่พัก · UID-002 G2-r9

รอตรวจไวร์เฟรม 29 คู่ · Pencil section `UGfaM` · [เปิดไฟล์ Pencil](../../dsd-001/papaipak-ui.pen)

สถานะโหลดและลองใหม่อยู่ใน [ชุดเสริมปัจจุบัน G2-r12](../g2-r12-review/README.md)

ตัวอย่างผลว่าง F-09 ใช้ [หน้าไม่พบที่พัก G2-r13](../g2-r13-review/README.md)

แผงตอนเปิดและตอนเลื่อนใช้ [Layout ตัวกรองพร้อมไอคอน G2-r15](../g2-r15-review/README.md)

รายการสิ่งอำนวยความสะดวกใช้ [ชุดไอคอน G2-r17](../g2-r17-review/README.md)

ข้อความในหัวข้อย่อย ค่าที่เลือก คำค้นแนะนำ สรุปเงื่อนไข และ **ล้างค่า** ใช้น้ำหนักปกติ จุดที่เลือกยังเห็นจากวงกลม ช่องติ๊ก หรือเส้นขอบของคำแนะนำ [แผงตัวกรอง](RV3iS.png) · [สรุปผลหลังใช้](P7IRe.png)

| กลุ่ม | ตัวเลือกในแผง |
| --- | --- |
| เงื่อนไขเข้าพัก | สถานที่ วันเข้า–วันออก ผู้เข้าพักรวม และสัตว์เลี้ยง |
| ทำเล | ระยะจากทะเล เลือกไม่จำกัดหรือไม่เกิน 500 ม., 1 กม., 3 กม. หรือ 5 กม. |
| งบประมาณและขนาดบ้าน | ราคาต่อคืนต่ำสุด–สูงสุด ห้องนอนต่ำสุด–สูงสุด และห้องน้ำขั้นต่ำ |
| หมวดบ้านพัก | ทุกหมวด หรือเลือกหนึ่งหมวดตามหน้าแรก |
| สระและพักผ่อน | สระว่ายน้ำส่วนตัว ระบบสระ สระเด็ก สไลเดอร์ ห่วงยางแฟนซี จากุซซี่ และอ่างอาบน้ำ |
| กิจกรรมและความบันเทิง | คาราโอเกะ สนุกเกอร์ โต๊ะพูล ไฟเธค โต๊ะปิงปอง และแอร์ฮอกกี้ |
| ความสะดวกในบ้าน | Wi-Fi เตาปิ้งย่าง และเตียงเสริม |

ระยะจากทะเลเป็นตัวกรองเชิงตัวเลขที่ใช้ร่วมกับหมวดจากหน้าแรกได้ แบบเสนอให้เทียบระยะที่อ่านเป็นเมตรหรือกิโลเมตรและผ่านเกณฑ์เท่านั้น หากยังไม่เลือกระยะจะใช้ผลตามเงื่อนไขอื่นตามปกติ ตัวเลือก 500 ม., 1 กม., 3 กม. และ 5 กม. อิงชุดอ้างอิงที่อ่านระยะได้ 1,016 จาก 1,128 หลัง ข้อมูลที่จอดรถและครัวที่มีอยู่เป็นข้อความรายละเอียด จึงต้องกำหนดข้อมูลที่เทียบเงื่อนไขได้ก่อนใช้กรอง [ข้อมูลระยะในแคตตาล็อก](../../uid-003/property-detail-r27-catalog/catalog-audit.jsonl) · [ที่มาของข้อมูลครัวและที่จอดรถ](../../uid-003/property-detail-r1/data-presentation.md)

การเลือกระยะจะแก้ค่าร่างในแผงเดียวกับเงื่อนไขอื่น ผลอัปเดตเมื่อกด **ใช้ตัวกรอง** เมื่อล้างค่าร่าง ระยะกลับเป็นไม่จำกัด ตัวอย่างผล 36 และ 9 หลังในภาพใช้เพื่อสื่อสถานะ [เลือกระยะ](TL2ke.png) · [ผลหลังใช้](P7IRe.png)
