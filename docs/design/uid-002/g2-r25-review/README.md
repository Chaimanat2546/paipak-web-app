## โหลดครั้งแรกไม่สำเร็จ

แสดงข้อความกับ **ลองโหลดอีกครั้ง** กึ่งกลางพื้นที่ผลค้นหา เก็บเงื่อนไขเดิมไว้และเปิดตัวกรองได้ ยังไม่แสดงจำนวนผลหรือการ์ดเพราะไม่มีข้อมูลที่โหลดสำเร็จ ไม่กล่าวว่ามี 0 หลังหรือยืนยันสาเหตุเป็นการเชื่อมต่อหากยังไม่ทราบ

กดลองโหลดอีกครั้งแล้วกลับ Skeleton โหลดครั้งแรกตาม L-01 ของ G2-r12 ด้วยเงื่อนไขที่ส่งเดิม เมื่อสำเร็จจึงแสดงจำนวนและรายการ ถ้าได้ 0 หลังจึงเข้าสู่สถานะไม่พบตามเงื่อนไขตามบริบทนั้น

## โหลดหน้า 2 ไม่สำเร็จ

คงหน้า 1 ที่โหลดสำเร็จล่าสุดและตัวกรองที่ยืนยันไว้ หน้า 1 ยังคงถูกเลือก ข้อความอยู่ใกล้ตัวเปลี่ยนหน้าว่า **โหลดหน้า 2 ไม่สำเร็จ** และ **รายการด้านบนยังเป็นหน้า 1** ปุ่ม **ลองโหลดหน้า 2 อีกครั้ง** ระบุคำขอชัดเจน

กดปุ่มแล้วกลับ Skeleton ของการเปลี่ยนหน้าด้วยหน้า 2 และเงื่อนไขเดิม ป้องกันคำขอซ้ำระหว่างรอ เมื่อสำเร็จจึงเปลี่ยนรายการ หน้าที่เลือกและ URL พร้อมกัน และเลื่อนไปต้นรายการตาม [G2-r23 ที่รับแล้ว](../g2-r23-review/README.md)

ข้อเสนอวางข้อความต่อจากตัวเปลี่ยนหน้าและก่อน Footer เพื่อเห็นบริบทของหน้าที่แสดงกับหน้าที่โหลดไม่ได้ ภาพใช้ตำแหน่งที่เห็นข้อความครบ โฟกัสและการเลื่อนเพื่อให้เห็นสถานะต้องตรวจใน implementation

## ขอบเขตและผลตรวจ

แทน L-05 และ L-07 ใน [G2-r12](../g2-r12-review/README.md) สถานะ [G2-r22](../g2-r22-review/README.md) ที่เจ้าของรับเป็นกรณีโหลดสำเร็จแต่ไม่พบตามเงื่อนไขใหม่ ยังคงเดิม ไม่ใช้ผล 0 หลังหรือข้อความไม่พบที่พักในชุดโหลดล้มเหลวนี้

ตรวจข้อความครบทั้ง 4 เฟรม ไม่มีคำว่าผล 0 หลังหรือไม่พบที่พักใน UI ของชุดนี้ ตรวจว่าปุ่มหน้า 1 ยังเลือกอยู่ทั้ง Desktop/Mobile และคำสั่งลองโหลดระบุหน้า 2 ถูกต้อง พบเฉพาะเนื้อหาตัวกรองที่ครอบเพื่อเลื่อน 1 จุดและหน้าเต็มที่ครอบตาม viewport 2 จุด

เปิดดูภาพ Mobile โหลดครั้งแรกกับโหลดหน้า 2 ไม่สำเร็จแล้ว ตัวกรองล่าสุด ข้อมูลหน้า 1 และราคายังคงอยู่ ภาพเป็นไวร์เฟรมนิ่ง ยังไม่ได้ทดสอบคำขอจริง การลองโหลดซ้ำ โฟกัส หรือเครื่องอ่านหน้าจอ
