เจ้าของให้ตรวจหน้าไม่พบที่พักต่อจากสถานะตัวกรองโหลดไม่สำเร็จ ชุดนี้ยก G2-r13 มาใช้กับแผงตัวกรองล่าสุด และใช้คำสั่ง **เปลี่ยนตัวกรอง** ให้สอดคล้องกับ [G2-r20 ที่รับแล้ว](../g2-r20-review/README.md)

## การแสดงผลและการแก้เงื่อนไข

E-01 หมายถึงโหลดสำเร็จและได้ 0 หลัง แสดงจำนวนผล เงื่อนไขเข้าพัก ราคา และห้องนอนที่ใช้ โดยไม่มีการ์ดบ้านเดิม ตัวอย่างคือพัทยา วันเข้า 12 ธ.ค. ผู้เข้าพัก 8 คน สัตว์เลี้ยง 1 ตัว ราคา 1,000–2,000 บาทต่อคืน และห้องนอน 5–6 ห้อง

กด **เปลี่ยนตัวกรอง** แล้ว Mobile เปิดแผงเดิม ส่วน Desktop เลื่อนแผงด้านข้างให้เห็นช่วงราคาและขนาดบ้าน เริ่มร่างด้วยค่าที่ใช้ล่าสุดตาม E-02 ไม่ส่งคำขอเมื่อเปิดแผง

E-03 แสดงการแก้ช่วงราคาเป็น 5,000–10,000 บาท ขณะที่ผลด้านหลังยังเป็น 0 หลังและสรุปราคาที่ยืนยันยังเป็น 1,000–2,000 บาท ห้องนอนยังเป็น 5–6 ห้อง เมื่อกด **ใช้ตัวกรอง** จึงส่งร่าง เริ่มหน้า 1 ปิดแผง Mobile และแสดง Skeleton ตาม [G2-r12](../g2-r12-review/README.md)

ถ้าโหลดใหม่สำเร็จจึงอัปเดตจำนวนผล สรุปเงื่อนไข และรายการพร้อมกัน ถ้ายังได้ 0 หลังให้แสดง E-01 ด้วยเงื่อนไขใหม่ หากโหลดไม่สำเร็จใช้ [G2-r20](../g2-r20-review/README.md) โดยระบุว่าเป็นผลก่อนปรับตัวกรอง ไม่แสดงคำแนะนำว่าให้ค้นหาซ้ำทันที

## ผลตรวจ

ตรวจค่า 0 หลังและคำสั่งเปลี่ยนตัวกรองครบทั้ง 6 หน้าจอ ตรวจราคากับห้องนอนในร่าง Desktop/Mobile ตรงกัน และตัวอย่าง E-03 ยังรักษาสรุปราคาเดิม พบเฉพาะพื้นที่เนื้อหาในแผงที่ครอบเพื่อเลื่อน 5 จุด เปิดดู Mobile E-01 และ E-02 แล้ว ค่าครบและปุ่มใช้ตัวกรองมองเห็นได้

ยังเป็นไวร์เฟรมนิ่ง การกด การเลื่อน โฟกัส การส่งคำขอ และการประกาศผลให้เครื่องอ่านหน้าจอต้องตรวจใน runtime การรับหน้าเต็ม G2-r18 ไอคอน G2-r17 และสถานะ G2-r20 คงเดิม
