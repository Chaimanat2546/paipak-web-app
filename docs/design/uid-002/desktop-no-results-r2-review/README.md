# UID-002 · ที่พักอื่นในพัทยา · r2

20 พฤศจิกายน 2026 · ภูอนุมัติแบบเดสก์ท็อปและมือถือ · Pencil บอร์ด `kHRZV` ในกลุ่ม **การโหลดและผลการค้นหา** ของชุดใช้จริง `MilCd` · [บันทึกคำอนุมัติ](owner-r2-acceptance.json)

- เมื่อผลค้นหาตรงเงื่อนไขได้ 0 หลังและไม่มีผลเดิม แสดงกล่องแจ้งสถานะ แล้ววาง **ที่พักอื่นในพัทยา** ใต้กล่อง โดยขยายเฉพาะเงื่อนไขราคาและจำนวนห้องนอน และยังใช้ทำเล วันเข้าพัก จำนวนคนและสัตว์เลี้ยงที่เลือก
- การ์ด 3 ใบในภาพใช้แสดงการจัดวางในแบบ ข้อมูลราคา วันว่าง และการรับสัตว์เลี้ยงจริงต้องตรวจจากข้อมูลของเว็บ
- กรณีมีผลเดิมใช้ป้าย **ผลก่อนเปลี่ยนตัวกรอง** ตาม [แบบ G4-r1](../g4-r1-review/implementation-reference.md)
- มือถือใช้ปุ่ม **เปลี่ยนตัวกรอง** เต็มความกว้างภายในกล่อง แล้วแสดงหัวข้อและการ์ดกว้างหนึ่งใบต่อแถว เลื่อนลงเพื่อดูใบถัดไป
