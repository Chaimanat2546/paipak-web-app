# UID-002 · เปิดปิดตัวกรองและคืนโฟกัส · G3-r10

| ภาพเทียบ | ตอนเปิด | ตอนปิด |
| --- | --- | --- |
| [Desktop](zPUmt.png) | โฟกัสที่วันที่เลือกในปฏิทิน | เมื่อปิดปฏิทิน โฟกัสกลับช่องวันเข้าพัก |
| [Mobile](DrVjz.png) | โฟกัสที่ปุ่มปิดแผง | เมื่อปิดแผง โฟกัสกลับปุ่มตัวกรอง |

Mobile เปิดแผงแล้วโฟกัสอยู่ในแผง ปุ่มปิดมีพื้นที่กด 44 × 44px ปิดก่อนกดใช้แล้วคงผลและเงื่อนไขล่าสุดตาม Q-08 Desktop ใช้ตัวอย่างปิดปฏิทินในแถบข้าง

ภาพใช้วงโฟกัสกรมท่า 2px เพื่ออธิบายลำดับคีย์บอร์ด กลุ่ม `q651jp` ใน Pen ตรวจพื้นที่กด ตำแหน่งวงโฟกัส และความต่อเนื่องของผลเดิมจากภาพแล้ว พฤติกรรม Tab, Escape, การคืนโฟกัส และการทิ้งร่างรอตรวจบนเว็บจริง
