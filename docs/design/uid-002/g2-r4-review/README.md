# ไวร์เฟรมหน้าผลค้นหาที่พัก · UID-002 G2-r4

18 พฤศจิกายน 2026 · ชุดภาพก่อนจัดกลุ่มตัวกรอง · [ชุดตรวจปัจจุบัน G2-r5](../g2-r5-review/README.md) · [ไฟล์ Pencil กลาง](../../dsd-001/papaipak-ui.pen) section `wIR59`

ภูตอบ “กรองต่อ” หลังเห็นผลตรวจข้อมูล จึงเพิ่มห้องน้ำขั้นต่ำและระบบสระทั้ง Desktop B และ Mobile A กลุ่มลักษณะบ้าน สิ่งอำนวยความสะดวก และกติกาค่าร่างอ้างชุดตรวจ [ตัวกรอง G2-r3](../g2-r3-review/README.md)

## ตัวกรองที่เพิ่ม

- **ห้องน้ำอย่างน้อย** อยู่ถัดจากจำนวนห้องนอน เริ่มจากไม่ระบุและใช้ปุ่มลด/เพิ่ม แคตตาล็อกอ้างอิงมีจำนวนห้องน้ำเป็นตัวเลขครบ 1,128 หลัง ค่าที่พบตั้งแต่ 1 ถึง 34 ห้อง ตัวอย่างในแบบใช้ขั้นต่ำ 4 ห้อง [บัญชีแคตตาล็อก](../../uid-003/property-detail-r27-catalog/catalog-audit.jsonl) · [ภาพค่าร่าง](vPrqW.png)
- **ระบบสระ** อยู่ใต้ตัวเลือกสระว่ายน้ำ เลือกได้หนึ่งค่า ได้แก่ **ทุกระบบ**, **คลอรีน** หรือ **น้ำเกลือ** การเจาะจงระบบจะเลือกสระว่ายน้ำร่วมด้วยและนับเป็นเงื่อนไขเดียว หากเอาสระว่ายน้ำออก ให้ล้างชนิดระบบที่เลือกด้วย จากบ้านอ้างอิงที่ยืนยันว่ามีสระ 1,047 หลัง พบคลอรีน 722 หลังและน้ำเกลือ 325 หลัง [เลือกน้ำเกลือ](UzBSH.png) · [ฟิลด์สระในรายละเอียดบ้าน](../../uid-003/property-detail-r31-checklist/README.md)
- แสดง **ราคาเริ่มต้นต่อคืน** เมื่อช่วงราคาของผลชุดนั้นใช้ราคาเริ่มต้น เช่น ค้นโดยเว้นวัน เมื่อใช้ราคาตามวัน ระบบต้องยืนยันราคาของวันนั้นและระบุฐานราคาที่แสดง กติกาค้นด้วยวันเข้าอย่างเดียวยังคงเว้นวันออกได้ [กติกาข้อมูลราคาและวัน](../../uid-003/property-detail-r27-catalog/handoff.md)
- กด **ใช้ตัวกรอง** แล้วแสดงห้องน้ำขั้นต่ำและระบบสระในส่วน **ตัวกรองที่ใช้** ตัวอย่าง F-22 คงพัทยา วันเข้า 12 ธ.ค. ผู้เข้าพัก 8 คน และสัตว์เลี้ยง 1 ตัว การล้างค่าร่างคืนห้องน้ำเป็นไม่ระบุและคืนระบบสระเป็นทุกระบบ [ผลหลังใช้](MqrVb.png) · [ล้างค่าร่าง](g2r6Ld.png)
