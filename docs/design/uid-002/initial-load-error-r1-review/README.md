# UID-002 · โหลดรายการที่พักครั้งแรกไม่สำเร็จ · r1

20 พฤศจิกายน 2026 · ภูอนุมัติทั้งเดสก์ท็อปและมือถือ · Pencil บอร์ด `tOPKe` ในกลุ่ม **การโหลดและผลการค้นหา** ของชุดใช้จริง `MilCd` · [บันทึกคำอนุมัติ](owner-r1-acceptance.json)

ภูให้จัดข้อความ **โหลดรายการที่พักไม่สำเร็จ** และปุ่มกลางพื้นหน้าตามเลย์เอาต์ F-05 ของหน้าบทความ ส่วนท้ายหน้าต่อจากพื้นที่แจ้งสถานะโดยตรงตามคำขอให้เว้นส่วนแนะนำ

- **ลองโหลดอีกครั้ง** ใช้เงื่อนไขค้นหาเดิม และ **กลับหน้าแรก** พาไปหน้าแรก
- เดสก์ท็อปวางปุ่มคู่กัน มือถือวางปุ่มเรียงลงมา
