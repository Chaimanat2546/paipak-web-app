## เงื่อนไขที่กำกับแบบ

- พื้นที่รอผลมี Skeleton ของรูป ชื่อบ้าน ข้อมูล ราคา และจำนวนผลค้นหา ขนาดการ์ดสอดคล้องกับรายการเมื่อมีข้อมูล
- ระหว่างเปลี่ยนหน้า ให้เก็บตัวกรองและตำแหน่งตัวเปลี่ยนหน้าไว้ ล็อกการส่งซ้ำช่วงรอ หน้าใหม่เป็นหน้าปัจจุบันเมื่อโหลดสำเร็จ หากล้มเหลวให้คืนผลของหน้าที่สำเร็จล่าสุด
- ระหว่างใช้ตัวกรอง ปุ่มที่ส่งคำขอป้องกันการกดซ้ำ แผง Mobile ปิดทันทีหลังส่ง และใช้ค่าที่ส่งล่าสุดเป็นจุดเริ่มต้นเมื่อเปิดแก้ต่อ
- บันทึกผลชุดที่โหลดสำเร็จล่าสุดไว้สำหรับแสดงเมื่อคำขอใหม่ล้มเหลว จำนวนผล สรุปเงื่อนไข เลขหน้า และรายการต้องเป็นชุดเดียวกัน คำสั่งลองใหม่ใช้เงื่อนไขและหน้าที่ต้องการจากคำขอที่ล้มเหลว
- Skeleton เป็นส่วนตกแต่งที่ซ่อนจากเครื่องอ่านหน้าจอ บริเวณผลมีสถานะกำลังทำงานและข้อความประกาศสำหรับเครื่องอ่านหน้าจอ เมื่อโหลดสำเร็จจึงประกาศจำนวนผล ส่วนการเปลี่ยนหน้าคืนโฟกัสไปหัวข้อผล
- ตัวเลือกการเคลื่อนไหวของผู้ใช้กำกับเอฟเฟกต์ Skeleton ภาพตรวจเป็นไวร์เฟรมนิ่ง
- กรณีโหลดครั้งแรกไม่สำเร็จ ไอคอน ข้อความ และลองใหม่จัดกึ่งกลางพื้นที่ผลค้นหา ส่วนภาพบ้านโหลดไม่ได้ใช้ [กติกาภาพ Q-07](../../uxd-002/review-decisions.md)

ชุดนี้ใช้ร่วมกับ [หน้าผลค้นหาและตัวกรอง G2-r9](../g2-r9-review/README.md) ตรวจขอบเขตเลเยอร์ 18 หน้าจอ การปิดแผง Mobile และการแทนพื้นที่รอข้อมูลด้วย Skeleton แล้ว การเคลื่อนไหว การส่งคำขอ การลองใหม่ โฟกัส และเครื่องอ่านหน้าจอต้องตรวจในงาน implementation
