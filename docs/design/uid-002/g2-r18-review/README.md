## ขอบเขตที่เจ้าของให้ทำต่อ

เจ้าของรับไอคอน G2-r17 ด้วยข้อความ “สวยละ” แล้วให้ทำต่อจากข้อเสนอรวมหน้าเต็มล่าสุด งานนี้รวมหน้าผลค้นหา Desktop/Mobile แผงตัวกรอง G2-r15 หมวดบ้านพัก และสิ่งอำนวยความสะดวก G2-r17 เพื่อให้ตรวจทั้งหน้าต่อเนื่อง โดยยังอยู่ในขั้นไวร์เฟรม UID-002

## แผนจัดภาพ

- คัดลอกหน้าผลค้นหาพัทยาและแผงล่าสุด แสดงรายการตัวอย่าง 12 หลังถึงตัวเปลี่ยนหน้าและ Footer
- Desktop คงแผงกรองด้านข้าง Mobile เปิดจากคำสั่งตัวกรองบนหน้าผลลัพธ์
- แสดงภาพเต็มแผงตัวกรอง หมวด และสิ่งอำนวยความสะดวกแยกจากภาพหน้าจอจริง เพื่ออ่านเนื้อหาทุกข้อ
- คงค่าร่างและ Apply Filters, Skeleton และกติกาย้อนกลับจากชุดเดิม
- ตรวจภาพทั้งสองขนาด การ์ด จำนวนตัวอย่าง ปุ่ม และขอบเขตเลเยอร์ ก่อนส่งภาพให้เจ้าของตรวจ

จำนวน 12 หลังต่อภาพใช้ทดสอบองค์ประกอบและการเลื่อน ยังเป็นข้อเสนอสำหรับจำนวนต่อหน้าจริง ชื่อ ราคา และข้อมูลบ้านเป็นข้อมูลจำลอง ภาพบ้านใช้ช่องภาพไวร์เฟรมตามเดิม

## กติกาที่คงไว้

ค่าผลค้นหาตัวอย่างคือพัทยา วันเข้า 12 ธ.ค. ยังไม่ระบุวันออก ผู้เข้าพักรวม 8 คนและสัตว์เลี้ยง 1 ตัว พบ 36 หลัง การ์ด Desktop เรียง 3 คอลัมน์ในพื้นที่ข้างแผง Mobile เรียงหนึ่งคอลัมน์ ใช้ข้อมูลชื่อ ราคา ความจุ และห้องนอนชุดเดียวกันตามลำดับ

แผงหลักเริ่มจากค่าที่ใช้ล่าสุด ตัวกรองเพิ่มเติมเป็นค่าเริ่มต้นทั้งหมด ภาพสิ่งอำนวยความสะดวกเป็นอีกสถานะของร่างที่เลือกสระกับคาราโอเกะ 2 ข้อและสระน้ำเกลือ การเลือกยังไม่เปลี่ยนผลจนกดใช้ตัวกรอง ไม่มีปุ่มค้นหาชุดอื่นแยกทำงานเหนือรายการ

เมื่อกดใช้ตัวกรองให้กลับหน้า 1 ปิดแผง Mobile และใช้ [Skeleton G2-r12](../g2-r12-review/README.md) ผลว่างใช้ [G2-r13](../g2-r13-review/README.md) การเปลี่ยนหน้าและย้อนจากรายละเอียดคงกติกาใน [ชุดฐาน G2-r9](../g2-r9-review/README.md) ชุดรวมนี้ยังไม่ขอรับสถานะโหลดและกติกาย้อนกลับทั้งหมดแทนการตรวจแยก

## ผลตรวจ

- ตรวจ Native ทั้งชุด พบเฉพาะจุดครอบเนื้อหาที่เลื่อนโดยตั้งใจ 4 จุด ไม่มีป้ายปุ่มหรือส่วนอื่นล้นกรอบ
- ตรวจการ์ด 12 หลังของ Desktop/Mobile ชื่อ ลำดับ ความจุ ห้องนอน และราคาตรงกัน มี Footer หนึ่งจุดและตัวเลือกหน้า 1 ถึง 3 ต่อหน้าผลลัพธ์
- เปิดดูภาพเต็ม Desktop และ Mobile แล้ว ตัวเปลี่ยนหน้าและ Footer อยู่หลังการ์ดสุดท้าย
- สิ่งอำนวยความสะดวกคงหัวกลุ่มตัวปกติสี `#65717D` ไม่มีไอคอนหัวกลุ่ม และใช้ path ดิสโก้ต้นฉบับตามรุ่นที่รับแล้ว
- ภาพนี้เป็นไวร์เฟรมนิ่ง การแตะ การเลื่อน โฟกัส การส่งคำขอ และการเข้าถึงใน runtime ยังไม่ได้ทดสอบ

## สถานะการรับแบบ

เจ้าของรับการจัดองค์ประกอบหน้าเต็มและความต่อเนื่องของแผงล่าสุดแล้ว ภาพที่รับแสดงการ์ดตัวอย่าง 12 หลัง ส่วนชุดสถานะโหลด ผลว่าง และพฤติกรรมเปลี่ยนหน้ากับย้อนกลับยังแยกตรวจต่อ การรับครั้งนี้ไม่ใช่การรับ G2 ทั้งชุด ไอคอน G2-r17 ที่รับแล้วคงเดิม [บันทึกการรับไอคอน](../g2-r17-review/owner-icon-acceptance.json)
