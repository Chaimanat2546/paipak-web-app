## เปลี่ยนหน้า

กดเลขหน้าหรือหน้าถัดไปแล้วคงเงื่อนไขที่ยืนยันล่าสุด ระหว่างรอใช้ Skeleton ตาม L-03 ของ [G2-r12](../g2-r12-review/README.md) และป้องกันส่งซ้ำ หน้าที่โหลดสำเร็จล่าสุดยังเป็นหน้าปัจจุบันจนกว่าคำขอใหม่จะสำเร็จ

เมื่อหน้า 2 สำเร็จจึงเปลี่ยนรายการ เลขหน้าที่เลือก และ URL ให้ตรงกัน เริ่มต้นรายการของหน้าใหม่ ย้ายโฟกัสไปหัวข้อผลตามวิธีนำทางที่เหมาะสม จำนวนผลตัวอย่างยังเป็น 36 หลัง ใช้ 12 หลังต่อภาพและตัวเลือกหน้า 1 ถึง 3 ตามตัวอย่างหน้าเต็มที่รับไว้ ชื่อและข้อมูลบ้านในหน้านี้เป็น mock

ถ้าโหลดหน้าใหม่ไม่สำเร็จให้คงหน้าที่สำเร็จล่าสุดและระบุหน้าที่ขอโหลดตาม L-07 เดิม การลองใหม่เป็นคำขอหน้าเดิมพร้อมเงื่อนไขเดิม ไม่เปลี่ยนเป็นผล 0 หลัง และไม่ใช้ข้อความไม่พบตามเงื่อนไขของ G2-r22 มาปะปนกับความล้มเหลวในการโหลด

เมื่อเปลี่ยนตัวกรองแล้วกดใช้ ให้เริ่มหน้า 1 ตามกติกาเดิม การเปลี่ยนหน้าไม่ล้างสถานที่ วัน ผู้เข้าพัก หมวด หรือสิ่งอำนวยความสะดวก

## ย้อนจากรายละเอียด

บันทึกสถานะหน้าผลค้นหาที่ผู้ใช้เปิดบ้านออกไป โดยคืนเงื่อนไขที่ยืนยัน เลขหน้า ตำแหน่งเลื่อนหน้า ตำแหน่งเลื่อนแผงกรอง และภาพใน carousel ของบ้านที่ดูไว้ เมื่อย้อนกลับในการนำทางที่ต่อเนื่องกัน ไม่เริ่มหน้า 1 หรือกระโดดขึ้นต้นรายการ

ตัวอย่าง Mobile เลื่อนให้บ้านพักชมสวนอยู่ที่ตำแหน่งเดิม 105 พิกเซลจากขอบบน และเลือกภาพลำดับ 3 ก่อนเปิดรายละเอียด ภาพเมื่อย้อนกลับแสดงสถานะเดียวกัน Desktop แสดงบ้านหลังเดียวกันในแถวและตำแหน่งเดิม ไม่มีข้อความแจ้งกลับสำเร็จหรือป้ายใหม่ใน UI

URL เก็บเงื่อนไขที่ยืนยันและเลขหน้าตามกติกาฐาน ไม่ส่งค่าร่างที่ยังไม่กดใช้ ข้อกำหนดการคืนตำแหน่งนี้ใช้กับการย้อนกลับจากรายละเอียด ยังไม่สัญญาว่าการเปิด URL ใหม่หรือ reload จะคืนทุกภาพและทุกตำแหน่งเลื่อน

## ผลตรวจ

ตรวจหน้าเต็ม Desktop/Mobile มีการ์ด 12 หลัง ลำดับเดียวกัน ระบุหน้า 2 และเลข 2 ถูกเลือก ตรวจภาพเทียบ Mobile ใช้ offset เดียวกันและภาพลำดับ 3 เดียวกัน ตรวจขอบเขตพบเฉพาะการครอบเนื้อหาเต็มหน้าตาม viewport 8 จุดกับเนื้อหาแผงกรอง 3 จุด ไม่มีข้อความหรือปุ่มล้นกรอบ

ภาพเป็นไวร์เฟรมนิ่งสำหรับตกลงพฤติกรรม ยังไม่ได้ทดสอบ browser history, URL, scroll restoration, carousel, focus หรือคำขอจริง ไม่เปลี่ยนหน้าเต็ม G2-r18 และสถานะไม่พบตามเงื่อนไข G2-r22 ที่รับแล้ว
