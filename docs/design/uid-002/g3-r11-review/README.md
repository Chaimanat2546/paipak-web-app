# UID-002 · ลองโหลดหน้า 2 อีกครั้ง · G3-r11

[ภาพ Desktop](avnMT.png) · [ภาพ Mobile](Ktc6s.png)

ตัวอย่างเริ่มจากหน้า 1 ขอหน้า 2 แล้วโหลดไม่สำเร็จ ปุ่ม **ลองโหลดหน้า 2 อีกครั้ง** ใช้คำขอเดิมทั้งเลขหน้าและตัวกรองที่ยืนยันไว้ ระหว่างรอแสดง Skeleton โดยหน้า 1 ยังเป็นหน้าที่โหลดสำเร็จล่าสุด เมื่อสำเร็จจึงเปลี่ยนรายการ เลขหน้าที่เลือก และ URL เป็นหน้า 2

ภาพตัวอย่างใช้พัทยา วันเข้า 12 ธ.ค. ไม่ระบุวันออก ผู้เข้าพัก 8 คน และสัตว์เลี้ยง 1 ตัว ซ่อมลูกศรหน้าถัดไปในภาพโหลดหน้า 2 ไม่สำเร็จบน Desktop ของ G3-r7 ด้วย

ภาพใน Pen กลุ่ม `zyryF` ตัดเฉพาะจุดที่ตรวจ ผลตรวจยืนยันข้อความและสถานะตัวเปลี่ยนหน้าในภาพ ทดสอบคำขอจริงและ URL เมื่อเว็บทำงาน
