ช่วงรอใช้ Skeleton เฉพาะพื้นที่รูป พอโหลดรูปไม่สำเร็จใช้ไอคอนกับข้อความ **โหลดรูปไม่ได้** กลางพื้นที่รูป ขนาดการ์ด ชื่อ ข้อมูลบ้าน และราคาคงเดิม รูปของบ้านอื่นที่โหลดแล้วแสดงตามปกติ

ทั้งสองสถานะยังเห็นปุ่มบันทึกบ้าน จุดบอกลำดับรูป และลูกศรไปภาพถัดไป เปิดรายละเอียดได้ตามกติกาที่รับใน G2-r24 กรณีรูปเดียวซ่อนจุดและลูกศรตามกติกาเดิม ปุ่มบันทึกบนพื้นสีอ่อนใช้ไอคอนกรมท่าบนพื้นขาวเพื่อให้มองเห็นชัด

แบบอยู่ใน Pen กลุ่ม `X2OSED` ตรวจขนาดการ์ด การจัดวาง และภาพส่งออกทั้งสี่เฟรมแล้ว ส่วนการโหลดและการกดจริงรอตรวจในระบบ
