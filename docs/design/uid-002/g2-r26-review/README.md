# ส่งตัวกรองแล้วโหลดผลใหม่ไม่ได้ · UID-002 G2-r26

หลังส่งตัวกรองให้ปิดแผง Mobile และใช้ Skeleton ของจำนวนผลกับรายการบ้านตามที่เจ้าของเลือก Desktop เก็บร่างที่ส่งไว้ในแผงเดียวกันและป้องกันส่งซ้ำ ไม่มีข้อความกำลังโหลดในแผงตัวกรอง

เมื่อดึงข้อมูลผลชุดใหม่ไม่ได้ ใช้ **โหลดผลล่าสุดไม่สำเร็จ** กับคำอธิบาย **ยังตรวจผลของตัวกรองใหม่ไม่ได้** ระบุเงื่อนไขที่ส่งและแยกผลก่อนเปลี่ยนตัวกรอง 36 หลังไว้ด้านล่าง ไม่แสดงว่าผลใหม่เป็น 0 หลัง เพราะยังไม่ได้ข้อมูลมายืนยัน

ปุ่ม **ลองโหลดผลล่าสุด** ส่งเงื่อนไขที่ล้มเหลวชุดเดิม ตัวอย่างราคา 5,000–10,000 บาทและห้องนอน 3–5 ห้อง กลับ Skeleton ระหว่างรอ เมื่อสำเร็จจึงอัปเดตผล สรุปเงื่อนไขและจำนวนพร้อมกันโดยเริ่มหน้า 1 เปิดตัวกรองได้ผ่านคำสั่งตัวกรองตามเดิม

ถ้าโหลดสำเร็จแต่ไม่มีผล ให้ใช้ [G2-r22 ที่รับแล้ว](../g2-r22-review/README.md) พร้อมปุ่มเปลี่ยนตัวกรอง โหลดครั้งแรกและโหลดหน้าใหม่ไม่สำเร็จใช้ [G2-r25 ที่รับแล้ว](../g2-r25-review/README.md) สถานะทั้งสามมีเหตุการณ์และคำสั่งต่อที่แยกกัน

ตรวจทั้ง 4 เฟรม ไม่พบข้อความผล 0 หลังหรือไม่พบที่พักใน UI ชุดนี้ เงื่อนไขร่างตรงกันทั้งสองขนาด พบเฉพาะเนื้อหาแผงที่ครอบเพื่อเลื่อน 2 จุด ภาพ Mobile เปิดดูแล้ว ยังเป็นไวร์เฟรมนิ่งและไม่ได้ตรวจ runtime
