## พฤติกรรมที่ใช้ตรวจ

- เปิด **สิ่งอำนวยความสะดวก** แล้วเลือกได้หลายข้อ เมื่อกด **กลับไปตัวกรอง** ค่าที่เลือกยังอยู่ในร่างและมีจำนวนกำกับ การกด **ใช้ตัวกรอง** ใช้เงื่อนไขทั้งชุด เช่น ผลต้องมีทั้งสไลเดอร์และคาราโอเกะเมื่อเลือกสองข้อนี้ [ค่าร่าง](AN7eg.png) · [ผลหลังใช้](ApCze.png)
- **ล้างค่า** ล้างค่าร่างในแผง ผลเดิมยังอยู่จนกด **ใช้ตัวกรอง** กดปิดแผงมือถือก่อนใช้ให้กลับผลเดิม เปิดซ้ำแล้วเห็นค่าที่ใช้ล่าสุด [หลังล้างค่าร่าง](J1XElK.png) · [ผลเดิมที่กลับไป](MDUw4.png) · [กติกาปิดแผง](../../uxd-002/review-decisions.md)
- เมื่อกรอกช่วงราคากลับด้าน ให้แสดงข้อความใต้ช่วงราคาและพักปุ่ม **ใช้ตัวกรอง** จนแก้ค่าได้ ช่วงห้องนอนใช้การตรวจลำดับต่ำสุดและสูงสุดแบบเดียวกัน โดยภาพรอบนี้แสดงกรณีราคา [ตัวอย่างช่วงราคากลับด้าน](lWWCy.png)
- คำค้นแนะนำใช้เงื่อนไขที่ยืนยันแล้ว ผลว่างเปิดแผงเดิมจากปุ่ม **ปรับช่วงราคา** [กติกาคำค้นแนะนำ G2-r2](../g2-r2-review/README.md)
