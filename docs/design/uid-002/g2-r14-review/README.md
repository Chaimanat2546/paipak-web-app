## เนื้อหาแผงเดียวกัน

1. สถานที่ วันเข้าพัก–วันออก และผู้เข้าพักรวมกับสัตว์เลี้ยง
2. คำค้นแนะนำที่เติมค่าร่างได้
3. ตัวกรองเพิ่มเติมที่มีระยะจากทะเลและราคาต่อคืน
4. ห้องนอนต่ำสุด–สูงสุดและห้องน้ำขั้นต่ำ
5. หมวดบ้านพักตามหน้าแรก และทางเปิดสิ่งอำนวยความสะดวกครบทุกกลุ่ม

ตัวอย่างเริ่มจากพัทยา วันเข้า 12 ธ.ค. ผู้เข้าพัก 8 คน สัตว์เลี้ยง 1 ตัว โดยตัวกรองเพิ่มเติมเป็นค่าเริ่มต้น หมวดเป็นทุกหมวด ช่วงราคากับขนาดบ้านเว้นว่างไว้

หัวข้อ **ตัวกรองเพิ่มเติม** อยู่ในเนื้อหาที่เลื่อน ส่วนหัวแผง **ล้างค่า** และ **ใช้ตัวกรอง** อยู่กับขอบแผง การเลื่อนเปลี่ยนเฉพาะส่วนที่มองเห็นและเก็บค่าร่างทุกกลุ่มไว้ กดใช้ครั้งเดียวเพื่อส่งทั้งชุด และแสดง Skeleton ตาม [G2-r12](../g2-r12-review/README.md)

บน Mobile ปุ่มตัวกรองในหน้าผลค้นหาเปิดที่ต้นแผง จากหน้าไม่พบที่พักสามารถเลื่อนถึงเงื่อนไขที่กำลังแก้ได้โดยใช้เนื้อหาแผงเดียวกัน [ทางกลับจากผลว่าง G2-r13](../g2-r13-review/README.md) การเปิดหมวดหรือสิ่งอำนวยความสะดวกและย้อนกลับเก็บค่าร่างต่อเนื่องตามกติกาเดิม [รายการหมวดและสิ่งอำนวยความสะดวก](../g2-r9-review/README.md#ภาพเต็มของเมนูย่อย)

ภาพคลี่เต็มใช้ตรวจลำดับและความครบของรายการ แบบขนาดจอใช้พื้นที่เลื่อนภายในแผง มีการครอบเนื้อหานอกพื้นที่เลื่อนโดยตั้งใจ 4 จุดจากสองคู่หน้าจอ ตรวจการครอบส่วนอื่นและขอบเขตเนื้อหาภาพคลี่เต็มแล้ว การเลื่อนจริง การส่งคำขอ และโฟกัสต้องตรวจในงาน implementation

ใช้ R-01/R-02 เป็นแหล่งอ้างอิงแผงตัวกรองรวมล่าสุดของ [หน้าค้นหา G2-r9](../g2-r9-review/README.md) โดยชุดโหลดกับผลว่างยังอ้างตามลิงก์ด้านบน
