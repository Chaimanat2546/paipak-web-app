# UID-002 · ตัวกรองเพิ่มเติม UI G3-r2

19 พฤศจิกายน 2026 · เจ้าของรับรูปลักษณ์ตัวกรองที่แสดงแล้ว · ต่อจาก [หน้าเต็ม G3-r1](../g3-r1-review/README.md)

เจ้าของถาม “ตัวกรองเพิ่มเติมอ่ะ” จึงเติม UI ละเอียดของหมวดบ้านพักและสิ่งอำนวยความสะดวก พร้อมภาพส่วนล่างของตัวกรองให้เห็นครบ ใช้โครงที่รับใน G2-r30 และสีเดียวกับ G3-r1

ภาพขยายช่วงล่างใช้ตรวจเนื้อหาส่วนเพิ่มเติมในแผงเดิม ไม่ใช่หน้าใหม่หรือปุ่มเปิดตัวกรองแยกอีกชุด ภาพเต็มยังรวมเงื่อนไขเข้าพัก คำแนะนำค้นหา และส่วนเพิ่มเติมไว้ด้วยกัน ตัวกรองจริงเลื่อนเนื้อหาแยกจากแถบคำสั่งตาม G2-r30

ส่วนเพิ่มเติมประกอบด้วยระยะจากทะเล งบประมาณ จำนวนห้องนอนขั้นต่ำ/สูงสุด ห้องน้ำขั้นต่ำ หมวดบ้านพัก และสิ่งอำนวยความสะดวก หมวดเลือกได้หนึ่งหมวดหรือทุกหมวด สิ่งอำนวยความสะดวกมี 15 รายการ พร้อมระบบสระทุกระบบ/คลอรีน/น้ำเกลือ

คงหัวข้อย่อยน้ำหนัก 400 สี `#65717D` ไม่มีไอคอนหน้าหัวข้อกลุ่ม ไอคอนรายการยังเป็นชุด Lucide/MDI/Phosphor ที่รับไว้ การเลือกทั้งหมดแก้ค่าร่าง และผลเปลี่ยนเมื่อกด **ใช้ตัวกรอง**

ตรวจ native 7 เฟรม ไม่พบการล้นหรือครอบเนื้อหา ตรวจสิ่งอำนวยความสะดวกครบ 15 แถวทั้ง Desktop/Mobile และตรวจภาพ Mobile ที่ส่งออกจริง ดู [หลักฐาน](native-verification.json) กับ [รายการแบบ](review-manifest.json) Native group `wt9xJ` ใน [Pencil](../../dsd-001/papaipak-ui.pen)

G3 ยังเหลือ popover และสถานะโหลด/ไม่พบ/ผิดพลาด การเปลี่ยนหน้า/ย้อนกลับ และ interaction states ตาม G2-r30 เจ้าของรับเฉพาะรูปลักษณ์ตัวกรองเพิ่มเติม หมวด และสิ่งอำนวยความสะดวกที่แสดง ด้วยคำตอบ “ได้” ดู [บันทึกการรับ](owner-filter-appearance-acceptance.json) ยังไม่ได้รับการอนุมัติทั้ง G3/G4 ไม่ใช่การทดสอบ runtime และไม่เริ่ม Frontend

รูปลักษณ์ส่วนเพิ่มเติม ลำดับหมวด และไอคอนสิ่งอำนวยความสะดวกที่แสดงได้รับการยืนยันแล้ว ไม่ขยายการรับนี้เป็นทั้ง G3
