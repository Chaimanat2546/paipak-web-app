# UID-002 · หน้าค้นหาที่พัก · ชุดใช้จริง

ใช้ Hi-Fi **G4-r1** เป็นแบบหลักสำหรับ Desktop 1440px และ Mobile 390px รวม 15 หลังต่อหน้า แบบสถานะแต่ละกรณีใช้หนึ่งคู่ Desktop/Mobile ส่วนกติกาและจุดที่มองไม่เห็นจากภาพอ้างอิงจาก [กติกาหน้าค้นหาที่อนุมัติ](../g2-r30-review/interaction-contract.md)

เปิด Section `tYF4Q` ใน [ไฟล์ Pen หลัก](../../dsd-001/papaipak-ui.pen) · [Wireframe G2-r30](../g2-r30-review/README.md) อยู่ซ้ายใน `Jpzxu` และ Hi-Fi ชุดใช้จริงอยู่ขวาใน `MilCd` รวมสถานะฉบับอนุมัติวันที่ 20 พฤศจิกายน 2026 ไว้ที่ตำแหน่งของแต่ละกรณีในตาราง

## กติกาที่ใช้กับแบบ

- ใช้การ์ด `V0hJN` และ Skeleton `cDP8I` ร่วมกัน [ชื่อยาวและข้อมูลราคาที่ 360px](../g3-r8-review/README.md) · [รูปเดียวและรูปสุดท้าย](../g3-r9-review/README.md)
- แสดงชุดข้อมูลห้องน้ำเมื่อจำนวนมากกว่า 0 เท่านั้น ถ้าข้อมูลขาดหรือเป็น 0 ให้ยุบชุดทั้งหมด ใช้ [กติกาและภาพเทียบ r1](../card-bathroom-visibility-r1/README.md) กับการ์ดบ้านพักทุกหน้า
- เปิดและปิดตัวกรองตามจุดโฟกัสที่กำหนด [ตำแหน่งโฟกัส](../g3-r10-review/README.md)
- ลองโหลดใหม่ด้วยตัวกรองและเลขหน้าที่ขอไว้ [ลำดับตอนลองโหลดใหม่](../g3-r11-review/README.md)
- ย้อนจากรายละเอียดแล้วคืนตัวกรอง เลขหน้า ตำแหน่งเลื่อน และรูปที่ดู [ลำดับตอนย้อนกลับ](../g3-r12-review/README.md)
