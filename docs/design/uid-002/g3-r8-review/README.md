การ์ดกว้าง 328px ที่ระยะขอบ 16px ใช้คอมโพเนนต์เดิม `V0hJN` ทั้งสัดส่วนภาพประมาณ 3:2 มุมมน ไอคอน ขนาดตัวอักษร และตำแหน่งราคา พื้นที่ข้อมูลเท่าเดิมที่ 152px

ชื่อเต็มตัวอย่างกว้าง 551px เมื่อวางบรรทัดเดียว เกินพื้นที่ชื่อ 300px และขึ้นบรรทัดสองทับทำเล แบบหลังปรับแสดงชื่อหนึ่งบรรทัดลงท้ายด้วย … ข้อความที่เห็นกว้าง 274px และเก็บชื่อเต็มในข้อมูลตัวอย่าง กำหนดให้ระบบตัดชื่อจากพื้นที่จริงและใช้ชื่อเต็มเป็นชื่อที่เข้าถึงได้

ภาพย้อนหลังแสดงขีดในช่องห้องน้ำตามแบบรอบนั้น กติกาปัจจุบัน [ยุบชุดข้อมูลห้องน้ำเมื่อจำนวนขาดหรือเป็น 0](../card-bathroom-visibility-r1/README.md) ราคาที่ยังไม่มีข้อมูลใช้ข้อความ **ยังไม่มีข้อมูลราคา** แถวข้อมูลเดิมใช้พื้นที่มากสุด 249px จาก 300px ในชุดทดสอบ หน้าจอ 360px ยังเห็นปุ่มตัวกรอง และภาพท้ายหน้ามีตัวเปลี่ยนหน้าก่อน Footer

บันทึกใน Pen กลุ่ม `OW6FH` ตรวจภาพและขอบเขตของแบบแล้ว การตัดชื่ออัตโนมัติและการอ่านชื่อเต็มรอตรวจตอนระบบทำงาน
