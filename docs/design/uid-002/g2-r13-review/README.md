## การกลับไปค้นหา

- บน Desktop คำสั่ง **ปรับตัวกรอง** พาโฟกัสไปหัวข้อแผงด้านข้างและเลื่อนแผงไปยังช่วงราคาที่เห็นในตัวอย่าง ส่วน Mobile เปิดแผงตัวกรองเดิมและให้โฟกัสหัวข้อแผง
- กดปิดแผง Mobile ก่อนใช้ ให้กลับผลชุดที่ยืนยันล่าสุดและคืนโฟกัสที่คำสั่งเปิดแผง ค่าที่แก้เป็นร่างใช้กติกาปิดแผงที่กำหนดไว้ [กติกา Q-08](../../uxd-002/review-decisions.md)
- กด **ใช้ตัวกรอง** แล้วปิดแผง Mobile และแสดง Skeleton ตาม L-02 เมื่อได้ผลใหม่จึงเปลี่ยนจำนวนผล สรุปเงื่อนไข และรายการพร้อมกัน ผลหน้าใหม่เริ่มหน้า 1 [สถานะ Skeleton G2-r12](../g2-r12-review/README.md)
- โหลดสำเร็จแล้วได้ 0 หลัง ให้กลับ E-01 พร้อมเงื่อนไขที่ยืนยันครั้งนั้น โหลดล้มเหลวให้ใช้ L-06 พร้อมข้อมูลชุดที่โหลดสำเร็จล่าสุด และลองใหม่ด้วยค่าที่ส่ง
- เมื่อผลสำเร็จเป็น 0 หลัง ประกาศจำนวนผลพร้อมข้อความไม่พบที่พักให้เครื่องอ่านหน้าจอทราบ แล้วให้ผู้ใช้ไปปรับเงื่อนไขต่อได้

ตัวอย่างเริ่มจากพัทยา วันเข้า 12 ธ.ค. ผู้เข้าพัก 8 คน สัตว์เลี้ยง 1 ตัว และราคา 1,000–2,000 บาทสำหรับ 5–6 ห้องนอน ตัวเลขใช้สื่อสถานะของไวร์เฟรม

ชุดนี้ต่อจาก [หน้าค้นหา G2-r9](../g2-r9-review/README.md) โดยแสดง E-01 แทนตัวอย่างผลว่าง F-09 และใช้สถานะโหลดจาก G2-r12 ตรวจจำนวนผล ค่าร่าง ค่าในสรุป และขอบเขตเลเยอร์ของทั้ง 6 หน้าจอแล้ว การกด โฟกัส การส่งคำขอ และการประกาศสถานะต้องตรวจในงาน implementation
