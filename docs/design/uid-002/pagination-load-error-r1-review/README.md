# UID-002 · โหลดหน้าที่เลือกไม่สำเร็จ · r1

20 พฤศจิกายน 2026 · ภูรับแบบเดสก์ท็อปและมือถือ · Pencil บอร์ด `XD8nL` ในกลุ่ม **เปลี่ยนหน้าและสถานะรูปบ้าน** ของชุดใช้จริง `MilCd` · [บันทึกคำอนุมัติ](owner-r1-acceptance.json)

ใช้เลย์เอาต์เต็มหน้าจาก [แบบโหลดครั้งแรกไม่สำเร็จที่อนุมัติ](../initial-load-error-r1-review/README.md) ข้อความระบุเลขหน้าที่โหลดไม่สำเร็จ โดยใช้หน้า 2 เป็นตัวอย่าง **ลองโหลดอีกครั้ง** ขอหน้าที่ระบุด้วยตัวกรองเดิม **กลับหน้าก่อนหน้า** คืนหน้าผลค้นหาที่โหลดสำเร็จล่าสุดพร้อมตัวกรองเดิม เช่น กลับหน้า 1 เมื่อโหลดหน้า 2 ไม่สำเร็จ

รายการที่โหลดสำเร็จล่าสุดยังเป็นสถานะของผลค้นหาจนกว่าจะโหลดหน้าใหม่สำเร็จ ในแบบ r1 พื้นที่ผลค้นหาถูกแทนที่ด้วยหน้าแจ้งข้อผิดพลาดระหว่างเกิดปัญหา
